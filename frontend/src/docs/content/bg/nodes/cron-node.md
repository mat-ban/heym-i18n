# Cron

**Cron** node стартира workflow по график, използвайки cron израз. Не се изисква потребителско въвеждане — workflow се изпълнява автоматично в зададените моменти.

## Преглед

| Свойство | Стойност |
|----------|-------|
| Входове | 0 |
| Изходи | 1 |
| Изход | Trigger event (без payload) |

## Параметри

| Параметър | Тип | Описание |
|-----------|------|-------------|
| `label` | string | Идентификатор на node (camelCase) |
| `cronExpression` | string | Cron израз (напр. `0 * * * *` за всеки час) |

## Формат на Cron израз

Стандартен 5-полетен cron: `minute hour day-of-month month day-of-week`

| Поле | Стойности | Пример |
|-------|--------|---------|
| Минута | 0–59 | `0` = в минута 0 |
| Час | 0–23 | `*` = всеки час |
| Ден от месеца | 1–31 | `*` = всеки ден |
| Месец | 1–12 | `*` = всеки месец |
| Ден от седмицата | 0–7 (0 и 7 = неделя) | `*` = всеки ден |

**Често използвани примери:**

- `0 * * * *` – всеки час
- `0 0 * * *` – ежедневно в полунощ
- `*/15 * * * *` – на всеки 15 минути
- `0 9 * * 1-5` – делнични дни в 9:00

## Пример

```json
{
  "type": "cron",
  "data": {
    "label": "hourlyCheck",
    "cronExpression": "0 * * * *"
  }
}
```
