# MCP Call Node

**MCP Call** node извиква конкретен инструмент на [Model Context Protocol (MCP)](https://modelcontextprotocol.io) директно, без LLM да решава кой инструмент да бъде извикан. Използвайте го, когато знаете точно кой инструмент да извикате и искате детерминистично изпълнение в една стъпка.

## Преглед

| Свойство | Стойност |
|----------|-------|
| Входове | 1 |
| Изходи | 1 |
| Изход | `$nodeLabel.result` |

## Кога да използвате

Използвайте MCP Call node, когато:
- Знаете точно кой MCP инструмент да извикате още при проектирането
- Не се нуждаете от LLM, който да избира между инструменти
- Искате лека, детерминистична алтернатива на agent node за извикване на един инструмент

Използвайте [Agent node](./agent-node.md) вместо това, когато LLM трябва да реши кои инструменти да извика или когато се нуждаете от многостъпково разсъждение.

> MCP Call node **не може** да бъде свързан към agent node като инструмент.

## Конфигурация на връзката

Node се свързва към един MCP сървър. Изберете транспорт и попълнете съответните полета.

### SSE / Streamable HTTP

| Поле | Описание |
|-------|-------------|
| `transport` | `sse` или `streamable_http` |
| `url` | Пълен URL на MCP сървъра (напр. `https://mcp.example.com/sse`). Поддържа DSL изрази. |
| `headers` | JSON обект с HTTP headers (напр. `{"Authorization": "Bearer ..."}`) |
| `timeoutSeconds` | Таймаут за връзка в секунди (по подразбиране: 30) |

### stdio

| Поле | Описание |
|-------|-------------|
| `transport` | `stdio` |
| `command` | Изпълним файл за стартиране (напр. `npx`) |
| `args` | JSON масив с аргументи (напр. `["-y", "@modelcontextprotocol/server-filesystem"]`) |
| `env` | JSON обект с променливи на средата (напр. `{"API_KEY": "..."}`) |
| `timeoutSeconds` | Таймаут за връзка в секунди (по подразбиране: 30) |

## Избор на инструмент

1. Попълнете полетата за връзка.
2. Натиснете **Fetch Tools** — node се свързва към MCP сървъра и изброява наличните инструменти.
3. Изберете инструмент от падащото меню.

**Изборът на инструмент е задължителен.** Node няма да се изпълни без избран инструмент.

## Аргументи

След като изберете инструмент, node показва по едно поле за всеки аргумент, дефиниран в схемата за вход на инструмента. Всяко поле приема:
- Статична стойност: `10`
- DSL израз: `$userInput.body.text`

Задължителните аргументи са отбелязани със `*`.

## Изход

| Поле | Описание |
|-------|-------------|
| `$nodeLabel.result` | Резултат от инструмента. Ако отговорът е валиден JSON, това е парснат обект. В противен случай е низ. |

## Пример

Извикване на инструмент `search` на SSE MCP сървър, подавайки заявката на потребителя:

```json
{
  "type": "mcpCall",
  "data": {
    "label": "searchCall",
    "connection": {
      "transport": "sse",
      "url": "https://mcp.example.com/sse",
      "timeoutSeconds": 30
    },
    "selectedTool": "search",
    "toolArguments": {
      "query": "$userInput.body.text",
      "limit": "10"
    },
    "timeoutSeconds": 30
  }
}
```

Достъп до резултата надолу по веригата:

```
$searchCall.result.items   ← ако резултатът е JSON обект
$searchCall.result         ← ако резултатът е обикновен низ
```

## Бележки

- Node разрешава DSL изрази в `url`, `headers`, `env` и всички стойности на `toolArguments` преди извикване на инструмента.
- `timeoutSeconds` на ниво node се отнася за цялостното изпълнение; `connection.timeoutSeconds` се отнася за самата MCP сесия.
- Ако MCP сървърът е недостъпен или върне грешка, node се проваля и съобщението за грешка е налично в workflow трасето.
