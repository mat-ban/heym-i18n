# Merge

**Merge** node изчаква множество паралелни входове и ги обединява в единен изход. Използвайте го, когато трябва да обедините резултати от паралелни разклонения, преди да продължите.

## Преглед

| Свойство | Стойност |
|----------|-------|
| Входове | n (конфигурируем) |
| Изходи | 1 |
| Изход | `$nodeLabel.merged` – обект с входове от всяко разклонение |

## Параметри

| Параметър | Тип | Описание |
|-----------|------|-------------|
| `label` | string | Идентификатор на node (camelCase) |
| `inputCount` | number | Брой входове, които да се изчакат (по подразбиране: 2) |

## Кога да се използва

- Използвайте, когато трябва да **комбинирате** или **обедините** резултати от паралелни разклонения
- **Не** използвайте за паралелни workflows, които завършват с отделни [Output](./output-node.md) nodes
- Всяко входно разклонение допринася за обединения изход

## Пример

```json
{
  "type": "merge",
  "data": {
    "label": "combineResults",
    "inputCount": 2
  }
}
```

Свържете множество разклонения към merge node. Node изчаква всички входове, преди да произведе изход.
