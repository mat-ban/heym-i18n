# Изчакване

**Възелът Изчакване** (Wait) поставя на пауза изпълнението на workflow за определен период от време. Използвайте го за ограничаване на честотата (rate limiting), отложени действия или интервали за периодично запитване (polling).

## Преглед

| Свойство | Стойност |
|----------|-------|
| Входове | 1 |
| Изходи | 1 |
| Изход | Препредава входа |

## Параметри

| Параметър | Тип | Описание |
|-----------|------|-------------|
| `label` | string | Идентификатор на възела (camelCase) |
| `duration` | number | Забавяне в милисекунди (напр. 1000 = 1 секунда). Редакторът приема от 1 до 900000 (15 минути) |

## Пример

```json
{
  "type": "wait",
  "data": {
    "label": "delayOneSecond",
    "duration": 1000
  }
}
```
