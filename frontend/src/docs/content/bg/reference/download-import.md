# Изтегляне и импортиране

Експортирайте workflows или цели папки като файлове или ги импортирайте чрез drag & drop. Използвайте това за архивиране, споделяне или мигриране на workflows между инстанции.

## Изтегляне на Workflow (JSON)

**Местоположение:** Лента с инструменти на редактора → бутон **Download** (видим на големи екрани)

**Какво се експортира:**
- `nodes` – Всички nodes върху canvas
- `edges` – Всички връзки между nodes

**Име на файла:** `{workflow-name}.json` (взето от името на workflow)

**Формат:** Вижте [Workflow Structure](./workflow-structure.md) за JSON схемата.

## Изтегляне на папка (ZIP)

**Местоположение:** Dashboard → раздел Workflows → меню с три точки на папката → **Download as ZIP**

**Какво се експортира:**
- Всички workflows в папката и всички подпапки, рекурсивно
- Йерархията на папките се запазва като директории в ZIP архива

**Структура на ZIP:**
```
FolderName/
  workflow1.json
  workflow2.json
  SubFolder/
    workflow3.json
    DeepSub/
      workflow4.json
```

Всеки `.json` файл съдържа `{ name, nodes, edges }`.

## Импортиране

### От Dashboard (раздел Workflows)

1. Отворете раздела [Workflows](../tabs/workflows-tab.md)
2. Плъзнете **JSON** или **ZIP** файл върху областта за workflows

**JSON файл:** Създава се нов workflow. Името на workflow идва от полето `name` в JSON файла или от името на файла, ако `name` липсва.

**ZIP файл:** Цялата структура от папки се пресъздава на най-горно ниво. Всеки `.json` файл в ZIP архива се превръща в workflow, поставен в съответстващата папка. Удостоверения и между-workflow референции, които не съществуват в текущата инстанция, се изчистват автоматично. Ако някои workflows не успеят да се импортират, се показва обобщение с броя на успешните.

### От Canvas (редактор)

1. Отворете workflow в редактора
2. Плъзнете JSON файл върху canvas
3. Ако canvas вече съдържа nodes или edges, се показва диалог за потвърждение дали да се замени текущият workflow
4. Импортираните nodes и edges заменят или се сливат с текущия workflow

## Файлови формати

### JSON (единичен workflow)

```json
{
  "nodes": [...],
  "edges": [...],
  "name": "Optional workflow name"
}
```

- `nodes` – Задължително; масив от node обекти
- `edges` – Незадължително; масив от edge обекти (по подразбиране `[]`)
- `name` – Незадължително; използва се при създаване на нов workflow от импортиране през Dashboard

### ZIP (папка)

ZIP архив, в който структурата на директориите отразява йерархията на папките. Всеки файл е workflow JSON (вижте по-горе). Имената на папките и workflows се вземат съответно от имената на директориите и файловете.

Вижте [Workflow Structure](./workflow-structure.md) за форматите на node и edge.

## Сценарии на употреба

- **Архивиране** – Изтеглете workflows или цели папки преди значителни промени
- **Споделяне** – Експортирайте и споделяйте JSON файлове с колеги
- **Мигриране** – Прехвърляйте workflows или структури от папки между инстанции на Heym
- **Контрол на версиите** – Съхранявайте workflow JSON в Git заедно с кода
