# Клавишни комбинации

Heym предоставя клавишни комбинации в редактора на Workflows и работната площ, които ускоряват често използвани действия.

## Глобални комбинации в редактора

Тези комбинации са активни навсякъде в редактора на Workflows.

| Комбинация | Действие |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Отваряне на Command Palette |
| `Ctrl + I` / `Cmd + I` | Превключване на панела [AI Assistant](./ai-assistant.md) (работи по време на писане) |
| `Ctrl + Enter` / `Cmd + Enter` | Стартиране на текущия Workflow |
| `Ctrl + S` / `Cmd + S` | Запазване на Workflow |
| `Ctrl + Z` / `Cmd + Z` | Отмяна |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Повтаряне |
| `Ctrl + Y` / `Cmd + Y` | Повтаряне (алтернативна комбинация) |
| `Escape` | Затваряне на отворени наслагвания, диалогови прозорци и панели |

## Комбинации в работната площ

Тези комбинации се прилагат, когато работната площ е на фокус (няма активен текстов вход).

### Селекция и навигация

| Комбинация | Действие |
|----------|--------|
| `Ctrl + A` / `Cmd + A` | Избиране на всички възли |
| `Shift` (задържане) | Плъзгане за избиране на няколко възела |
| `Ctrl` / `Cmd` (задържане) | Кликване за добавяне на отделни възли към селекцията |
| `Escape` | Премахване на селекцията на всички възли; затваряне на вграденото търсене на възли |

### Редактиране на възли

| Комбинация | Действие |
|----------|--------|
| `Ctrl + C` / `Cmd + C` | Копиране на избрания(те) възел(и) |
| `Ctrl + X` / `Cmd + X` | Изрязване на избрания(те) възел(и) |
| `Ctrl + V` / `Cmd + V` | Поставяне на възел(и) |
| `Delete` или `Backspace` | Изтриване на избрания(те) възел(и) и/или връзка(и) |
| `D` | Превключване на избрания(те) възел(и) между включен / изключен |
| `P` | Превключване на фиксираните данни на избрания възел |

### Вградено търсене на възли

Въвеждането на който и да е печатен символ върху работната площ (когато няма фокусиран текстов вход) отваря изскачащия прозорец за вградено търсене на възли. Въведеният символ става първи символ на заявката за търсене.

| Комбинация | Действие |
|----------|--------|
| Всеки печатен символ | Отваряне на вграденото търсене на възли и започване на писане |
| `Backspace` | Премахване на последния символ от заявката за търсене |
| `Escape` | Затваряне на вграденото търсене на възли |

## Command Palette (`Ctrl + K`)

Command Palette е достъпна от редактора, таблото, документацията и изгледите за оценяване. Тя Ви позволява бързо да навигирате до Workflows, раздели и страници с документация, без да напускате клавиатурата.

| Комбинация | Действие |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Отваряне на Command Palette |
| `↑` / `↓` | Навигация в списъка с резултати |
| `Tab` / `Shift + Tab` | Навигация в списъка с резултати |
| `Enter` | Отваряне на избрания елемент |
| `Escape` | Затваряне на палетата |

## Комбинации в таблото

Тези комбинации са активни в раздела Workflows, когато няма активен друг текстов вход.

| Комбинация | Действие |
|----------|--------|
| `Ctrl + F` / `Cmd + F` | Фокусиране върху търсенето на Workflows |
| `Escape` | Изчистване на търсенето на Workflows, когато съдържа текст |

## Комбинации в панела със свойства

Тези комбинации са активни, докато е избран възел и панелът със свойства е отворен.

| Комбинация | Действие |
|----------|--------|
| `Ctrl + Shift + O` / `Cmd + Shift + O` | Отваряне на свързания под-Workflow в нов раздел (само за Execute node) |

## Комбинации в диалога за оценяване

Тези комбинации са активни, докато диалогът за оценяване е отворен.

| Комбинация | Действие |
|----------|--------|
| `Ctrl + Enter` / `Cmd + Enter` | Прилагане на израза и затваряне на диалога |
| `Ctrl + Z` / `Cmd + Z` | Отмяна на промените в редактора на изрази |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Повтаряне на промените в редактора на изрази |
| `Ctrl + Y` / `Cmd + Y` | Повтаряне на промените в редактора на изрази (алтернативна комбинация) |

## Комбинации в историята и изпълненията

Тези комбинации са налични в диалога за история на изпълненията и панела с изпълнения.

| Комбинация | Действие |
|----------|--------|
| `S` | Превключване на полето за търсене за филтриране на записи |
