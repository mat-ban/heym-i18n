# Assignador de sortida HTML

El node **Assignador de sortida HTML** renderitza una única plantilla HTML en una pàgina. Utilitzeu-lo quan el sol·licitant sigui un **navegador** en lloc d'un client d'API — el workflow respon amb `text/html` en comptes de JSON.

## Visió general

| Propietat | Valor |
|----------|-------|
| Entrades | 1 |
| Sortides | 0 (terminal) |
| Sortida en temps d'execució | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Paràmetres

| Paràmetre | Tipus | Descripció |
|-----------|------|-------------|
| `label` | string | Identificador del node (camelCase) |
| `html` | string | La plantilla de la pàgina. Les expressions `$nodeLabel.field` s'interpolen in situ. |
| `statusCode` | number | Estat HTTP per a la resposta (per defecte `200`) |
| `contentType` | string | Tipus de contingut de la resposta (per defecte `text/html; charset=utf-8`) |

## Comportament del Webhook i de l'execució

Quan aquest node és l'**únic** node de sortida terminal del workflow, l'endpoint d'execució respon amb la pàgina renderitzada, el codi d'estat configurat i el tipus de contingut configurat — sense embolcall JSON ni embolcall d'etiqueta.

Dues circumstàncies ho desactiven:

- **Un segon node terminal.** Amb un altre node terminal actiu al graf, Heym recorre al mapa JSON habitual per etiqueta i la pàgina arriba com a camp de cadena.
- **`X-Simple-Response: false`.** Aquesta capçalera sol·licita l'embolcall complet amb `status`, `node_results` i temps d'execució, que és el que utilitza el canvas de l'editor. Envieu-la quan estigueu depurant un workflow de pàgina.

## Servir una pàgina a un navegador

Establiu el **mètode de sol·licitud** del workflow a `GET` al diàleg de cURL per tal que una navegació simple del navegador hi arribi. Una sol·licitud `GET` no porta cos, de manera que les entrades provenen de la cadena de consulta:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Llegiu aquests valors amb `$input.query.name`. Consulteu [Webhooks](../reference/webhooks.md) per al contracte complet de mètodes.

Un workflow sense node trigger l'únic terminal del qual és aquest node mostra una etiqueta **WEB** a la [pestanya Workflows](../tabs/workflows-tab.md).

## Ús com a eina d'Agent

No compatible. Aquest node és un terminal de sortida, de manera que no es pot adjuntar a una nansa d'eines d'un [Node Agent](./agent-node.md). El mateix s'aplica a l'[assignador de sortida JSON](./json-output-mapper-node.md).

## Restricció de bucles

Mateixa regla que a [Sortida](./output-node.md): no col·loqueu aquest node dins d'una branca d'iteració de bucle — només després de la branca `done` del bucle. Consulteu [Bucle](./loop-node.md).

## Exemple

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
