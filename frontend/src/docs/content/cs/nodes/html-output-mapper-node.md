# Mapování HTML výstupu

Uzel **Mapování HTML výstupu** vykresluje jednu HTML šablonu do stránky. Použijte jej, když je volajícím **prohlížeč** namísto API klienta — workflow odpovídá `text/html` místo JSON.

## Přehled

| Vlastnost | Hodnota |
|----------|-------|
| Vstupy | 1 |
| Výstupy | 0 (sink) |
| Výstup za běhu | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Parametry

| Parametr | Typ | Popis |
|-----------|------|-------------|
| `label` | string | Identifikátor uzlu (camelCase) |
| `html` | string | Šablona stránky. Výrazy `$nodeLabel.field` jsou interpolovány na místě. |
| `statusCode` | number | HTTP status odpovědi (výchozí `200`) |
| `contentType` | string | Typ obsahu odpovědi (výchozí `text/html; charset=utf-8`) |

## Chování Webhooku a spuštění

Když je tento uzel **jediným** koncovým výstupem workflow, endpoint pro spuštění odpovídá vykreslenou stránkou, nakonfigurovaným stavovým kódem a nakonfigurovaným typem obsahu — žádný JSON obal, žádný wrapper s labelem.

Dvě věci to vypnou:

- **Druhý koncový uzel.** S dalším aktivním koncovým uzlem v grafu se Heym vrací k běžné JSON mapě podle labelů a stránka dorazí jako pole typu string.
- **`X-Simple-Response: false`.** Tato hlavička vyžaduje plný obal s `status`, `node_results` a časováním, což je to, co používá canvas editoru. Posílejte ji, když ladíte workflow se stránkou.

## Poskytování stránky prohlížeči

Nastavte **metodu požadavku** workflow na `GET` v dialogu cURL, aby na něj dosáhla běžná navigace prohlížeče. Požadavek `GET` nenese tělo, takže vstupy pocházejí z query stringu:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Tyto hodnoty čtěte pomocí `$input.query.name`. Úplný kontrakt metod naleznete v [Webhooks](../reference/webhooks.md).

Workflow bez trigger uzlu, jehož jediným koncovým uzlem je tento uzel, zobrazuje v [záložce Workflows](../tabs/workflows-tab.md) štítek **WEB**.

## Použití jako nástroj agenta

Není podporováno. Tento uzel je koncový sink, takže nemůže být připojen k handle nástrojů [Agent Node](./agent-node.md). Totéž platí pro [Mapování JSON výstupu](./json-output-mapper-node.md).

## Omezení smyčky

Stejné pravidlo jako u [Output](./output-node.md): neumisťujte tento uzel do větve iterace smyčky — pouze za větev `done` smyčky. Viz [Loop](./loop-node.md).

## Příklad

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
