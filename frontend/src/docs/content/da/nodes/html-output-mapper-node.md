# HTML output mapper

**HTML output mapper**-noden renderer en enkelt HTML-skabelon til en side. Anvendes, når modtageren er en **browser** i stedet for en API-klient – workflowet svarer med `text/html` i stedet for JSON.

## Oversigt

| Egenskab | Værdi |
|----------|-------|
| Inputs | 1 |
| Outputs | 0 (sink) |
| Runtime output | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Parametre

| Parameter | Type | Beskrivelse |
|-----------|------|-------------|
| `label` | string | Node-identifikator (camelCase) |
| `html` | string | Sideskabelonen. `$nodeLabel.field`-udtryk interpoleres på plads. |
| `statusCode` | number | HTTP-status for svaret (standard `200`) |
| `contentType` | string | Svarsindholdstype (standard `text/html; charset=utf-8`) |

## Webhook og kørseladfærd

Når denne node er den **eneste** terminale output af workflowet, svarer execute-endepunktet med den renderede side, den konfigurerede statuskode og den konfigurerede indholdstype – ingen JSON-envelope, ingen label-wrapper.

To ting deaktiverer dette:

- **En anden terminal node.** Med en anden aktiv terminal i grafen falder Heym tilbage til den normale per-label JSON-map, og siden ankommer som et strengfelt.
- **`X-Simple-Response: false`.** Denne header anmoder om den fulde envelope med `status`, `node_results` og timing, som editorens canvas bruger. Sendes, når der foretages fejlfinding af et side-workflow.

## Servering af en side til en browser

Indstil workflowets **request method** til `GET` i cURL-dialogen, så en simpel browser-navigation kan nå det. En `GET`-anmodning har ingen body, så inputs kommer fra query-strengen:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Læs disse værdier med `$input.query.name`. Se [Webhooks](../reference/webhooks.md) for den fulde metodekontrakt.

Et workflow uden trigger-node, hvis eneste terminal er denne node, viser en **WEB**-chip i [Workflows-tab](../tabs/workflows-tab.md).

## Agent-værktøjsbrug

Ikke understøttet. Denne node er en terminal sink, så den kan ikke tilknyttes [Agent Node](./agent-node.md)-værktøjer. Det samme gælder for [JSON output mapper](./json-output-mapper-node.md).

## Loop-begrænsning

Samme regel som [Output](./output-node.md): denne node må ikke placeres inden for en loop-iterationsgren – kun efter loop `done`-grenen. Se [Loop](./loop-node.md).

## Eksempel

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
