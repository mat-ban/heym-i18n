# Crawler-Knoten

Der **Crawler-Knoten** durchsucht Websites rekursiv, extrahiert Texte und bereitet Daten für Vektorspeicher oder LLMs auf.

## Konfiguration

- Start-URL
- Maximale Tiefe und Seitenanzahl
- Filter für Pfade und Domänen
