# Drive-Knoten

Der **Drive-Knoten** ermöglicht das Lesen, Schreiben, Löschen und Konvertieren von Dateien im integrierten Dateispeicher Heym Drive.

## Operationen

- **Upload / Save**: Speichert Dateiinhalte aus vorherigen Schritten
- **Read**: Liest Dateien und extrahiert Text aus PDFs, CSVs und Dokumenten
- **List**: Listet Dateien in Ordnern auf
- **Delete**: Entfernt Dateien
