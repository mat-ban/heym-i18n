# Ausführen-Knoten

Der **Ausführen-Knoten** (Execute) ruft einen anderen Heym-Workflow als modularen Sub-Workflow auf und wartet auf dessen Rückgabe.

## Konfiguration

- Wählen Sie den Ziel-Workflow aus
- Übergeben Sie Parameter an den Sub-Workflow
- Erfassen Sie die Rückgabe über `$nodeLabel.output`
