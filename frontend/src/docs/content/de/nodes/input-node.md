# Eingabe-Knoten

Der **Eingabe-Knoten** (Input) bildet den Einstiegspunkt für Workflows, die manuell, über den Chat, über das Portal oder per API aufgerufen werden.

## Übersicht

| Eigenschaft | Wert |
|---|---|
| Eingänge | 0 |
| Ausgänge | 1 |
| Ausgabe | `$input.text`, `$input.files`, `$input.customField` |

## Schema-Definition

Definieren Sie Eingabefelder mit Typen und Beschreibungen, die in Formularen oder Portal-Chats als Eingabemaske gerendert werden.
