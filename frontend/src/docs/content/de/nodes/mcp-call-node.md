# MCP-Aufruf-Knoten

Der **MCP-Aufruf-Knoten** führt ein spezifisches Tool eines registrierten MCP-Servers deterministisch als Einzelschritt im Workflow aus – ohne unberechenbare LLM-Entscheidungen.

## Konfiguration

- Wählen Sie den MCP-Server aus dem Dropdown
- Wählen Sie das gewünschte Werkzeug
- Übergeben Sie Eingabeparameter mit DSL-Ausdrücken
