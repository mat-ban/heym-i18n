# Ausgabe-Knoten

Der **Ausgabe-Knoten** (Output) liefert das finale Ergebnis eines Workflows an den Aufrufer (API-Response, Chat-Nachricht oder Webhook-Antwort) zurück.

## Übersicht

| Eigenschaft | Wert |
|---|---|
| Eingänge | 1 |
| Ausgänge | 0 |
| Ausgabe | Finales Ergebnisobjekt |
