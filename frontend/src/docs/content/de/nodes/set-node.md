# Set-Knoten

Der **Set-Knoten** transformiert Eingabedaten und weist Feldern feste oder ausdrucksbasierte Werte für nachfolgende Knoten zu.

## Konfiguration

Erstellen Sie Schlüssel-Wert-Paare wie `fullName: {{ $input.firstName }} {{ $input.lastName }}`.
