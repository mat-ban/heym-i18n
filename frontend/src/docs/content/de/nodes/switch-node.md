# Switch-Knoten

Der **Switch-Knoten** leitet den Ausführungsfluss basierend auf Fallunterscheidungen oder Mustervergleichen auf mehrere alternative Pfade weiter.

## Übersicht

| Eigenschaft | Wert |
|---|---|
| Eingänge | 1 |
| Ausgänge | Variabel (1 Ausgang pro Fall plus optionaler `default`-Ausgang) |
| Ausgabe | Gibt die Eingabedaten an den passenden Zweig weiter |
