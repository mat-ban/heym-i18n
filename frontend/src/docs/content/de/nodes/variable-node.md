# Variablen-Knoten

Der **Variablen-Knoten** liest oder schreibt Workflow-Variablen oder aktualisiert Werte im globalen Variablenspeicher.

## Operationen

- `get`: Liest eine Variable
- `set`: Setzt einen neuen Wert
- `append`: Hängt Elemente an eine Liste an
