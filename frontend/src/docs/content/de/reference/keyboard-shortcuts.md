# Tastenkombinationen

Heym bietet Tastaturkürzel im gesamten Workflow-Editor und auf dem Canvas, um gängige Aktionen zu beschleunigen.

## Globale Editor-Kürzel

Diese Kürzel sind überall im Workflow-Editor aktiv.

| Kürzel | Aktion |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Die Befehlspalette öffnen |
| `Ctrl + I` / `Cmd + I` | Das Panel des [KI-Assistent](./ai-assistant.md) ein-/ausblenden (funktioniert auch während der Eingabe) |
| `Ctrl + Enter` / `Cmd + Enter` | Den aktuellen Workflow ausführen |
| `Ctrl + S` / `Cmd + S` | Den Workflow speichern |
| `Ctrl + Z` / `Cmd + Z` | Rückgängig |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Wiederholen |
| `Ctrl + Y` / `Cmd + Y` | Wiederholen (alternativ) |
| `Escape` | Geöffnete Overlays, Dialoge und Panels schließen |

## Canvas-Kürzel

Diese Kürzel gelten, wenn der Canvas fokussiert ist (keine Texteingabe aktiv).

### Auswahl & Navigation

| Kürzel | Aktion |
|----------|--------|
| `Ctrl + A` / `Cmd + A` | Alle Knoten auswählen |
| `Shift` (halten) | Ziehen, um mehrere Knoten auszuwählen |
| `Ctrl` / `Cmd` (halten) | Klicken, um einzelne Knoten zur Auswahl hinzuzufügen |
| `Escape` | Alle Knoten abwählen; die Inline-Knotensuche schließen |

### Knoten bearbeiten

| Kürzel | Aktion |
|----------|--------|
| `Ctrl + C` / `Cmd + C` | Ausgewählte(n) Knoten kopieren |
| `Ctrl + X` / `Cmd + X` | Ausgewählte(n) Knoten ausschneiden |
| `Ctrl + V` / `Cmd + V` | Knoten einfügen |
| `Delete` oder `Backspace` | Ausgewählte(n) Knoten und/oder Kante(n) löschen |
| `D` | Ausgewählte(n) Knoten aktivieren / deaktivieren |
| `P` | Angeheftete Daten am ausgewählten Knoten ein-/ausblenden |

### Inline-Knotensuche

Das Eingeben eines beliebigen druckbaren Zeichens auf dem Canvas (wenn keine Texteingabe fokussiert ist) öffnet das Popup der Inline-Knotensuche. Das eingegebene Zeichen wird zum ersten Zeichen der Suchanfrage.

| Kürzel | Aktion |
|----------|--------|
| Beliebiges druckbares Zeichen | Inline-Knotensuche öffnen und mit der Eingabe beginnen |
| `Backspace` | Das letzte Zeichen aus der Suchanfrage entfernen |
| `Escape` | Die Inline-Knotensuche schließen |

## Befehlspalette (`Ctrl + K`)

Die Befehlspalette ist im Editor, im Dashboard, in der Dokumentation und in den Evaluierungsansichten verfügbar. Sie ermöglicht es dir, schnell zu Workflows, Reitern und Dokumentationsseiten zu navigieren, ohne die Tastatur zu verlassen.

| Kürzel | Aktion |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Die Befehlspalette öffnen |
| `↑` / `↓` | In der Ergebnisliste navigieren |
| `Tab` / `Shift + Tab` | In der Ergebnisliste navigieren |
| `Enter` | Das ausgewählte Element öffnen |
| `Escape` | Die Palette schließen |

## Dashboard-Kürzel

Diese Kürzel sind im Reiter Workflows aktiv, wenn keine andere Texteingabe aktiv ist.

| Kürzel | Aktion |
|----------|--------|
| `Ctrl + F` / `Cmd + F` | Die Workflow-Suche fokussieren |
| `Escape` | Die Workflow-Suche leeren, wenn sie Text enthält |

## Kürzel im Eigenschaften-Panel

Diese Kürzel sind aktiv, während ein Knoten ausgewählt und das Eigenschaften-Panel geöffnet ist.

| Kürzel | Aktion |
|----------|--------|
| `Ctrl + Shift + O` / `Cmd + Shift + O` | Den verknüpften Sub-Workflow in einem neuen Tab öffnen (nur Execute-Knoten) |

## Kürzel im Evaluierungsdialog

Diese Kürzel sind aktiv, während der Evaluierungsdialog geöffnet ist.

| Kürzel | Aktion |
|----------|--------|
| `Ctrl + Enter` / `Cmd + Enter` | Den Ausdruck anwenden und den Dialog schließen |
| `Ctrl + Z` / `Cmd + Z` | Änderungen im Ausdruckseditor rückgängig machen |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Änderungen im Ausdruckseditor wiederholen |
| `Ctrl + Y` / `Cmd + Y` | Änderungen im Ausdruckseditor wiederholen (alternativ) |

## Kürzel für Verlauf & Traces

Diese Kürzel sind im Dialog für den Ausführungsverlauf und im Traces-Panel verfügbar.

| Kürzel | Aktion |
|----------|--------|
| `S` | Das Sucheingabefeld ein-/ausblenden, um Einträge zu filtern |
