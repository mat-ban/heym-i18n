# Κώδικας

Ο κόμβος **Κώδικας** εκτελεί Python που γράφετε εσείς, με το δικό του `requirements.txt`, και επιστρέφει JSON. Κάθε εκτέλεση λαμβάνει ένα ολοκαίνουργιο container που καταστρέφεται όταν ολοκληρωθεί η εκτέλεση, επομένως μια εκτέλεση δεν μπορεί ποτέ να δει ή να επηρεάσει μια άλλη.

## Επισκόπηση

| Ιδιότητα | Τιμή |
|----------|-------|
| Είσοδοι | 1 |
| Έξοδοι | 1 |
| Έξοδος | `$nodeLabel.result` (ό,τι επέστρεψε η `main`), συν `$nodeLabel.logs` και `$nodeLabel.install` |

## Παράμετροι

| Παράμετρος | Τύπος | Περιγραφή |
|-----------|------|-------------|
| `label` | string | Αναγνωριστικό κόμβου (camelCase) |
| `codeSource` | string | Πηγαίος κώδικας Python. Πρέπει να ορίζει `main(params)` και να επιστρέφει μια τιμή σειριοποιήσιμη σε JSON |
| `codeParameters` | expression | Ένα αντικείμενο JSON που συνδέει δεδομένα του workflow με τον κώδικα. Οι εκφράσεις επιλύονται πριν εκτελεστεί ο κώδικας |
| `codeRequirements` | string | Περιεχόμενα του `requirements.txt`, ένα πακέτο ανά γραμμή. Κενό παραλείπει την εγκατάσταση |
| `codeAllowNetwork` | boolean | Αν ο κώδικας μπορεί ο ίδιος να έχει πρόσβαση στο δίκτυο (προεπιλογή `false`) |

## Η συνάρτηση `main`

Ο κώδικάς σας πρέπει να ορίζει μια `main` σε επίπεδο module που δέχεται ένα όρισμα:

```python
def main(params):
    name = params.name
    return {"message": f"Hello, {name}!", "length": len(name)}
```

Οι εντολές σε επίπεδο module εκτελούνται, αλλά μόνο ό,τι επιστρέφει η `main` γίνεται η έξοδος του κόμβου.

Ο επεξεργαστής εμφανίζει αριθμούς γραμμών, και το κουμπί ανάπτυξης δίπλα στο **Format** ανοίγει έναν μεγαλύτερο που κλείνει με `Esc` — οι αλλαγές εφαρμόζονται καθώς πληκτρολογείτε, οπότε δεν υπάρχει τίποτα να αποθηκεύσετε. Το κουμπί **Format** αναμορφοποιεί τον κώδικά σας με το Ruff, διατηρώντας τα σχόλια. Επίσης διορθώνει τη ζημιά στην εσοχή που προκαλεί συνήθως η επικόλληση: ένα ομοιόμορφα εσοχιασμένο block, tab που έχουν αναμειχθεί με κενά, και μια γραμμή που βρίσκεται ένα ή δύο κενά έξω από το block της διορθώνονται όλα αντί να απορρίπτονται. Ένα πραγματικό συντακτικό σφάλμα αναφέρεται με τη γραμμή και τη στήλη του. Η μορφοποίηση εκτελείται στο ίδιο απομονωμένο container στο οποίο εκτελείται ο κόμβος — χωρίς δίκτυο, χωρίς περιβάλλον backend — επομένως χρειάζεται Docker όπως ακριβώς και η εκτέλεση.

## Ανάγνωση παραμέτρων

Το `params` υποστηρίζει σημειογραφία με τελείες, συμπεριλαμβανομένων ένθετων αντικειμένων και λιστών:

```python
def main(params):
    city = params.user.address.city
    first_order = params.orders[0].id
    return {"city": city, "first_order": first_order}
```

- `params["my key"]` διαβάζει κλειδιά που δεν είναι έγκυρα αναγνωριστικά Python
- `params.get("maybe")` επιστρέφει `None` αντί να προκαλέσει σφάλμα όταν ένα κλειδί απουσιάζει
- `params.to_dict()` επιστρέφει το απλό λεξικό
- Η ανάγνωση ενός κλειδιού που δεν δόθηκε ποτέ προκαλεί σφάλμα που ονομάζει το κλειδί και απαριθμεί ό,τι είναι διαθέσιμο

## Έξοδος

```json
{
  "result": { "message": "Hello, Heym!", "length": 4 },
  "logs": "",
  "install": { "ok": true, "tool": "none", "log": "" }
}
```

- `result` — η τιμή επιστροφής της `main`. Οι επόμενοι κόμβοι διαβάζουν `$nodeLabel.result.message`
- `logs` — ό,τι έστειλε ο κώδικας στο `print`, καταγεγραμμένο ξεχωριστά ώστε να μην αλλοιώνει ποτέ το αποτέλεσμα
- `install` — ποιο εργαλείο εγκατέστησε τις εξαρτήσεις (`uv`, `pip`, ή `none`) και η έξοδός του

## Εξαρτήσεις

Καταγράψτε τα πακέτα στο `requirements.txt` ακριβώς όπως θα το κάνατε τοπικά:

```
requests==2.32.3
feedparser
```

Τα πακέτα εγκαθίστανται με `uv` σε έναν προσωρινό κατάλογο πριν εκτελεστεί ο κώδικας· αν το `uv` δεν μπορεί να χειριστεί ένα πακέτο, το Heym επαναλαμβάνει με `pip`. Τίποτα δεν αποθηκεύεται στην προσωρινή μνήμη μεταξύ εκτελέσεων, οπότε οι βαριές εξαρτήσεις προσθέτουν αρκετά δευτερόλεπτα σε κάθε εκτέλεση. Το να αφήσετε το `requirements.txt` κενό παραλείπει εντελώς το βήμα εγκατάστασης και είναι αισθητά ταχύτερο.

Τα πακέτα που δεν παρέχουν wheel και χρειάζονται μεταγλωττιστή C θα αποτύχουν να εγκατασταθούν. Ο λόγος εμφανίζεται στο `install.log`.

## Δίκτυο

| Φάση | Δίκτυο |
|-------|---------|
| Εγκατάσταση εξαρτήσεων | Πάντα ενεργό — τα pip και uv πρέπει να φτάσουν στο PyPI |
| Εκτέλεση του κώδικά σας | Ανενεργό από προεπιλογή. Το `codeAllowNetwork` το ενεργοποιεί |

Με το `codeAllowNetwork` ανενεργό, μια εξερχόμενη κλήση όπως `requests.get(...)` αποτυγχάνει με σφάλμα σύνδεσης. Αυτή είναι η προβλεπόμενη προεπιλογή: οι περισσότεροι κόμβοι Κώδικα μετασχηματίζουν δεδομένα που έχει ήδη ανακτήσει ένας άλλος κόμβος. Προτιμήστε την ανάκτηση με έναν κόμβο **HTTP** και τη μεταβίβαση του σώματος μέσω `codeParameters`.

## Sandbox και όρια

Ο κώδικάς σας εκτελείται ως μη-root χρήστης σε ένα container με όλες τις δυνατότητες Linux να έχουν αφαιρεθεί, `no-new-privileges` ενεργοποιημένο, και ένα σύστημα αρχείων ρίζας μόνο για ανάγνωση. Δεν λαμβάνει socket Docker ούτε κανένα από τα μυστικά ή το περιβάλλον του backend.

| Όριο | Τιμή |
|-------|-------|
| Μνήμη | 512 MB |
| CPUs | 1 |
| Διεργασίες | 256 |
| Χρονικό όριο εγκατάστασης εξαρτήσεων | 120 δευτερόλεπτα |
| Χρονικό όριο εκτέλεσης | 60 δευτερόλεπτα |

Αυτές είναι σταθερές ιδιότητες του sandbox, όχι ρύθμιση.

> **Απαιτείται Docker.** Σε αντίθεση με τα Agent Python tools και skills, ο κόμβος Κώδικα δεν έχει λειτουργία τοπικής εφεδρείας ούτε μεταβλητή περιβάλλοντος για να την χαλαρώσει. Χωρίς προσβάσιμο daemon Docker ο κόμβος αποτυγχάνει με σαφές σφάλμα αντί να εκτελέσει τον κώδικά σας στη διεργασία του backend. Στην ανάπτυξη με εγγενές `./run.sh`, ξεκινήστε το Docker πριν χρησιμοποιήσετε αυτόν τον κόμβο. Δείτε [Ασφάλεια → Sandbox κόμβου Κώδικα](../reference/security.md#code-node-sandbox).

## Παράδειγμα

Σειρές βαθμολογίας που παράγονται από έναν ανάντη node:

```python
def main(params):
    rows = params.rows
    total = sum(r.amount * r.weight for r in rows)
    return {"total": round(total, 2), "count": len(rows)}
```

Με το `codeParameters` ορισμένο σε `{ "rows": "$fetchRows.result" }`, οι κατάντη nodes διαβάζουν το `$scoreRows.result.total`.
