# Καταγραφή Κονσόλας

Ο node **Καταγραφή Κονσόλας** καταγράφει μια τιμή στην κονσόλα του backend (διακομιστή). Χρησιμοποιήστε τον για αποσφαλμάτωση και επιθεώρηση κατά την ανάπτυξη.

## Επισκόπηση

| Ιδιότητα | Τιμή |
|----------|-------|
| Είσοδοι | 1 |
| Έξοδοι | 1 |
| Έξοδος | Διέρχεται μέσω της εισόδου |

## Παράμετροι

| Παράμετρος | Τύπος | Περιγραφή |
|-----------|------|-------------|
| `label` | string | Αναγνωριστικό node (camelCase) |
| `logMessage` | expression | Τιμή προς καταγραφή. Υποστηρίζει [εκφράσεις](../reference/expression-dsl.md). |

## Παράδειγμα

```json
{
  "type": "consoleLog",
  "data": {
    "label": "debugOutput",
    "logMessage": "$userInput.body"
  }
}
```

Η έξοδος εμφανίζεται στα logs του διακομιστή (π.χ. έξοδος τερματικού κατά την εκτέλεση του `uvicorn`).
