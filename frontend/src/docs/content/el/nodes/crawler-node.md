# Crawler

Ο κόμβος **Crawler** πραγματοποιεί scraping ιστοσελίδων χρησιμοποιώντας το FlareSolverr, με προαιρετική εξαγωγή HTML μέσω CSS selectors. Χρησιμοποιήστε τον για web scraping και εξαγωγή περιεχομένου.

## Επισκόπηση

| Ιδιότητα | Τιμή |
|----------|-------|
| Είσοδοι | 1 |
| Έξοδοι | 1 |
| Έξοδος | `$nodeLabel.body` (HTML ή εξαγόμενο περιεχόμενο) |

## Παράμετροι

| Παράμετρος | Τύπος | Περιγραφή |
|-----------|------|-------------|
| `credentialId` | UUID | Διαπιστευτήριο FlareSolverr από την καρτέλα [Διαπιστευτήρια](../tabs/credentials-tab.md) |
| `crawlerUrl` | expression | URL προς scraping (υποστηρίζει expressions) |
| `crawlerWaitSeconds` | number | Δευτερόλεπτα αναμονής πριν το scraping (προεπιλογή: 0) |
| `crawlerMaxTimeout` | number | Μέγιστο timeout σε ms (προεπιλογή: 60000) |
| `crawlerMode` | string | `"basic"` ή άλλες λειτουργίες |
| `crawlerSelectors` | array | CSS selectors για εξαγωγή. Κάθε ένα: `{ selector, attribute? }` |

## Παράδειγμα

```json
{
  "type": "crawler",
  "data": {
    "label": "scrapePage",
    "credentialId": "flaresolverr-credential-uuid",
    "crawlerUrl": "$userInput.body.url",
    "crawlerWaitSeconds": 2,
    "crawlerSelectors": [
      { "selector": "h1" },
      { "selector": ".content", "attribute": "innerHTML" }
    ]
  }
}
```

## Ασφάλεια εξερχόμενης κίνησης

- Το URL του FlareSolverr που είναι αποθηκευμένο στο διαπιστευτήριο πρέπει να χρησιμοποιεί `http://` ή `https://` και δεν επιτρέπεται να επιλύεται σε διεύθυνση link-local ή cloud-metadata. Το σύνολο των απορριπτόμενων διευθύνσεων είναι `169.254.0.0/16`, `fe80::/10`, οι διευθύνσεις metadata IPv6 της Alibaba Cloud και της AWS, καθώς και οι μορφές μετάβασης IPv6 που μπορούν να μεταφέρουν μία από αυτές. Πρόκειται για λίστα γνωστών endpoints, όχι για εγγύηση σχετικά με κάθε πάροχο.
- Οι διευθύνσεις loopback και οι ιδιωτικές διευθύνσεις επιτρέπονται σκόπιμα, ώστε η τεκμηριωμένη ρύθμιση `http://localhost:8191` και ονόματα υπηρεσιών compose όπως `http://flaresolverr:8191` να συνεχίσουν να λειτουργούν. Η συνέπεια είναι ότι αυτό το πεδίο μπορεί επίσης να κατευθυνθεί σε οποιαδήποτε άλλη υπηρεσία μπορεί να προσπελάσει το backend σε αυτές τις διευθύνσεις, και η απόκριση επιστρέφεται στην έξοδο του κόμβου. Ο διαμοιρασμός διαπιστευτηρίων δεν το περιορίζει: κάθε συνδεδεμένος χρήστης μπορεί να δημιουργήσει το δικό του διαπιστευτήριο FlareSolverr, οπότε η απόκρυψη ενός υπάρχοντος δεν αλλάζει τίποτα. Οι έλεγχοι που εφαρμόζονται είναι η εμπιστοσύνη στα άτομα που μπορούν να συντάσσουν workflows και οι κανόνες δικτύου που περιορίζουν το τι μπορεί να προσπελάσει το backend.
- Το Heym καθηλώνει τη διεύθυνση που έχει επιλυθεί πριν από τη σύνδεση, ώστε μια απάντηση DNS να μην μπορεί να μετακινήσει το αίτημα σε διεύθυνση metadata μετά τον έλεγχο. Οι proxies περιβάλλοντος απενεργοποιούνται όσο ο μηχανισμός προστασίας είναι ενεργός, και οι ανακατευθύνσεις δεν ακολουθούνται.
- Η σελίδα που ανακτά στη συνέχεια το FlareSolverr για εσάς αποτελεί ξεχωριστό βήμα που επιλύει το ίδιο το FlareSolverr. Το Heym δεν την επιθεωρεί, οπότε ο περιορισμός του πού επιτρέπεται να συνδεθεί το container του FlareSolverr ανήκει στην πολιτική δικτύου σας.
- Οι αξιόπιστες self-hosted εγκαταστάσεις μπορούν να άρουν τον κανόνα metadata με `HEYM_HTTP_ALLOW_PRIVATE_URLS=true`. Διατηρήστε την προεπιλεγμένη τιμή σε hosted ή multi-tenant εγκαταστάσεις.
