# Cron

Ο κόμβος **Cron** ενεργοποιεί ένα workflow βάσει χρονοδιαγράμματος, χρησιμοποιώντας μια έκφραση cron. Δεν απαιτείται είσοδος από τον χρήστη—το workflow εκτελείται αυτόματα στις καθορισμένες χρονικές στιγμές.

## Επισκόπηση

| Ιδιότητα | Τιμή |
|----------|-------|
| Είσοδοι | 0 |
| Έξοδοι | 1 |
| Έξοδος | Trigger event (χωρίς payload) |

## Παράμετροι

| Παράμετρος | Τύπος | Περιγραφή |
|-----------|------|-------------|
| `label` | string | Αναγνωριστικό κόμβου (camelCase) |
| `cronExpression` | string | Έκφραση cron (π.χ. `0 * * * *` για ωριαία εκτέλεση) |

## Μορφή Έκφρασης Cron

Τυπική cron 5 πεδίων: `minute hour day-of-month month day-of-week`

| Πεδίο | Τιμές | Παράδειγμα |
|-------|--------|---------|
| Λεπτό | 0–59 | `0` = στο λεπτό 0 |
| Ώρα | 0–23 | `*` = κάθε ώρα |
| Ημέρα του μήνα | 1–31 | `*` = κάθε ημέρα |
| Μήνας | 1–12 | `*` = κάθε μήνα |
| Ημέρα της εβδομάδας | 0–7 (0 και 7 = Κυριακή) | `*` = κάθε ημέρα |

**Συνήθη παραδείγματα:**

- `0 * * * *` – κάθε ώρα
- `0 0 * * *` – καθημερινά τα μεσάνυχτα
- `*/15 * * * *` – κάθε 15 λεπτά
- `0 9 * * 1-5` – καθημερινές στις 9:00

## Παράδειγμα

```json
{
  "type": "cron",
  "data": {
    "label": "hourlyCheck",
    "cronExpression": "0 * * * *"
  }
}
```
