# Google Meet

Βρείτε διαθέσιμα χρονικά διαστήματα στο Google Calendar και δημιουργήστε, ενημερώστε ή διαγράψτε προσκλήσεις σε συσκέψεις με συνδέσμους Google Meet, email συμμετεχόντων και επιλεγμένες ώρες. Ο συνδεδεμένος λογαριασμός Google είναι ο κάτοχος του συμβάντος· οι συμμετέχοντες λαμβάνουν προσκλήσεις μέσω email.

## Σύνδεση του λογαριασμού σας

1. Στο [Google Cloud Console](https://console.cloud.google.com), ενεργοποιήστε το **Google Calendar API**.
2. Διαμορφώστε την οθόνη συναίνεσης OAuth και δημιουργήστε έναν πελάτη OAuth για **Εφαρμογή Ιστού** (Web application). Προσθέστε τον λογαριασμό σας Google ως δοκιμαστικό χρήστη εάν η εφαρμογή είναι σε λειτουργία δοκιμής.
3. Καταχωρίστε το `https://your-heym-domain/api/credentials/google-meet/oauth/callback` ως εξουσιοδοτημένο URI ανακατεύθυνσης. Για τοπική ανάπτυξη, χρησιμοποιήστε το Heym origin του προγράμματος περιήγησής σας με την ίδια διαδρομή.
4. Ανοίξτε **Dashboard → Διαπιστευτήρια → Νέο → Google Meet (OAuth2)**, εισαγάγετε όνομα, Client ID και Client Secret, κάντε κλικ στο **Σύνδεση** και συνδεθείτε με την Google.
5. Παραχωρήστε και τα δύο δικαιώματα: Συμβάντα ημερολογίου (`calendar.events`) και διαθεσιμότητα ημερολογίου (`calendar.events.freebusy`). Επιλέξτε αυτό το credential στον κόμβο.

Τα tokens κρυπτογραφούνται στον χώρο αποθήκευσης και ανανεώνονται αυτόματα. Πρόκειται για ξεχωριστό credential από τα Google AI, Sheets ή Drive. Ένα ημερολόγιο πρέπει να υποστηρίζει τηλεδιασκέψεις Google Meet για να πετύχει η δημιουργία.

## Λειτουργίες

| Λειτουργία | Συμπεριφορά | Απαιτούμενα πεδία |
| --- | --- | --- |
| `read` | Επιστροφή διαθέσιμων και απασχολημένων διαστημάτων για ένα ημερολόγιο | Διαπιστευτήρια |
| `create` | Δημιουργία προγραμματισμένου συμβάντος με νέα τηλεδιάσκεψη Meet και προσκλήσεις μέσω email | Τίτλος, ώρα έναρξης, ώρα λήξης |
| `update` | Ενημέρωση των παρεχόμενων πεδίων συμβάντος και ειδοποίηση προσκεκλημένων | ID συμβάντος και τουλάχιστον ένα τροποποιημένο πεδίο |
| `delete` | Διαγραφή του συμβάντος και ειδοποίηση προσκεκλημένων για την ακύρωση | ID συμβάντος |

## Διαμόρφωση

Τα παρακάτω πεδία κειμένου δέχονται εκφράσεις. Όλα τα πεδία, συμπεριλαμβανομένης της επιλογής λεπτομερειών boolean, μπορούν να παρασχεθούν από έναν Agent όταν αυτός ο κόμβος προσαρτάται ως εργαλείο.

| Πεδίο | Προεπιλογή | Σκοπός |
| --- | --- | --- |
| `gmCalendarId` | `primary` | Κύριο ημερολόγιο του συνδεδεμένου λογαριασμού, ή προσβάσιμο ID/email ημερολογίου |
| `gmTimeZone` | `UTC` | Ζώνη IANA, όπως `Europe/Athens`, που χρησιμοποιείται για τοπικές ημερομηνίες και χρόνους απόκρισης |
| `gmStartDate` | Τρέχουσα ώρα | Έναρξη εύρους ανάγνωσης ως ημερομηνία ISO ή datetime |
| `gmEndDate` | Πρώτη ημέρα του επόμενου μήνα τα μεσάνυχτα | Αποκλειστικό τέλος εύρους ανάγνωσης· το μέγιστο εύρος είναι 60 ημερολογιακές ημέρες |
| `gmIncludeBusyDetails` | `false` | Μόνο ανάγνωση: συμπερίληψη τίτλων συμβάντων και συμμετεχόντων στο `busy_slots`· boolean |
| `gmEventId` | Κενό | ID συμβάντος ημερολογίου για update/delete· χρησιμοποιήστε το επιστρεφόμενο `event_id`, όχι URL Meet |
| `gmTitle` | Κενό | Τίτλος πρόσκλησης· απαιτείται κατά το `create` |
| `gmDescription` | Κενό | Περιγραφή πρόσκλησης |
| `gmStartTime` | Κενό | Έναρξη συνάντησης, π.χ. `2026-11-10T14:00:00+02:00` |
| `gmEndTime` | Κενό | Λήξη συνάντησης· πρέπει να ακολουθεί την έναρξη |
| `gmAttendees` | Κενό | Emails διαχωρισμένα με κόμμα/ερωτηματικό/αλλαγή γραμμής ή πίνακας JSON με συμβολοσειρές email |
| `gmLocation` | Κενό | Προαιρετική τοποθεσία συνάντησης παράλληλα με την τηλεδιάσκεψη Meet |

### Διαθέσιμα χρονικά διαστήματα

Η προεπιλεγμένη ανάγνωση καλύπτει το διάστημα από την τρέχουσα ώρα έως την **1η του επόμενου μήνα, 00:00** στην επιλεγμένη ζώνη ώρας. Περάστε το `gmEndDate` για να ορίσετε διαφορετικό παράθυρο. Ένα εύρος άνω των 60 ημερών ή μια μη έγκυρη ημερομηνία απορρίπτεται πριν από την κλήση της Google.

Το αποτέλεσμα βασίζεται στο **free/busy** API της Google. Τα απασχολημένα διαστήματα συγχωνεύονται και αφαιρούνται από το ζητούμενο παράθυρο. Το `available_slots` περιέχει συνεχή διαστήματα με χρονοσήμανση `start` και `end`.

```json
{
  "type": "googleMeet",
  "data": {
    "label": "Availability",
    "credentialId": "YOUR_GOOGLE_MEET_CREDENTIAL_ID",
    "gmOperation": "read",
    "gmCalendarId": "primary",
    "gmTimeZone": "Europe/Berlin",
    "gmStartDate": "2026-11-06",
    "gmEndDate": "2026-11-13"
  }
}
```

### Συμπερίληψη λεπτομερειών απασχολημένων συμβάντων

Στην ενότητα **Ανάγνωση διαθέσιμων χρονικών διαστημάτων**, ενεργοποιήστε την επιλογή **Συμπερίληψη λεπτομερειών απασχολημένων συμβάντων** (`gmIncludeBusyDetails: true`) για να προσθέσετε τον τίτλο και τους συμμετέχοντες σε κάθε κατειλημμένο slot. Αυτή η επιλογή είναι απενεργοποιημένη από προεπιλογή.

```json
{
  "start": "2026-11-06T21:15:00+01:00",
  "end": "2026-11-06T21:30:00+01:00",
  "title": "Daily check-in",
  "attendees": [
    "colleague@example.com"
  ]
}
```

### Κράτηση συνάντησης

1. Εκτελέστε έναν κόμβο `read` χρησιμοποιώντας τα credentials του κατόχου του workflow.
2. Εμφανίστε το `available_slots` στη διεπαφή κρατήσεων σας.
3. Περάστε τα `email`, `startTime` και `endTime` ως εισόδους του workflow.
4. Εκτελέστε το `create` με τα ίδια credentials. Ο επισκέπτης δεν χρειάζεται λογαριασμό Google· το email του καταγράφεται ως συμμετέχων.

```json
{
  "type": "googleMeet",
  "data": {
    "label": "Booking",
    "credentialId": "YOUR_GOOGLE_MEET_CREDENTIAL_ID",
    "gmOperation": "create",
    "gmCalendarId": "primary",
    "gmTimeZone": "Europe/Berlin",
    "gmTitle": "Meet with me",
    "gmDescription": "A meeting booked through Heym",
    "gmAttendees": "$input.email",
    "gmStartTime": "$input.startTime",
    "gmEndTime": "$input.endTime"
  }
}
```

## Έξοδος

| Λειτουργία | Πεδία εξόδου |
| --- | --- |
| `read` | `available_slots`, `busy_slots`, `count`, `calendar_id`, `time_zone`, `start`, `end` |
| `create`, `update` | `event_id`, `meet_url`, `conference_status`, `event`, `calendar_id` |
| `delete` | `event_id`, `calendar_id`, `deleted: true` |

Χρησιμοποιήστε τα `$Availability.available_slots` ή `$Booking.meet_url` στους επόμενους κόμβους. Κάθε λειτουργία επιστρέφει επίσης `status: "success"` και την αντίστοιχη `operation`.
