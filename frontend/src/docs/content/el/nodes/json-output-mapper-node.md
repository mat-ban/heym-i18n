# Αντιστοιχιστής εξόδου JSON

Ο κόμβος **Αντιστοιχιστής εξόδου JSON** δημιουργεί ένα αντικείμενο JSON από [αντιστοιχίσεις](./set-node.md) κλειδιού/τιμής (ίδιο μοντέλο με τον κόμβο [Set](./set-node.md)). Χρησιμοποιήστε τον όταν οι καλούντες θα πρέπει να λαμβάνουν ένα **απλό σώμα JSON** στη ρίζα της απόκρισης.

## Επισκόπηση

| Ιδιότητα | Τιμή |
|----------|-------|
| Είσοδοι | 1 |
| Έξοδοι | 0 (καταβόθρα) |
| Έξοδος χρόνου εκτέλεσης | Αντικείμενο που δημιουργείται από τις `mappings` |

## Παράμετροι

| Παράμετρος | Τύπος | Περιγραφή |
|-----------|------|-------------|
| `label` | string | Αναγνωριστικό κόμβου (camelCase) |
| `mappings` | array | Καταχωρίσεις `{ "key": "fieldName", "value": "expression" }` (ίδιες με τον κόμβο Set) |

## Χρήση ως εργαλείο Agent

Δεν υποστηρίζεται. Αυτός ο κόμβος είναι τερματική καταβόθρα, επομένως δεν μπορεί να συνδεθεί σε λαβή εργαλείων [Agent Node](./agent-node.md). Χρησιμοποιήστε έναν κόμβο [Set](./set-node.md) όταν ένας agent χρειάζεται να διαμορφώσει τιμές κατά τη διάρκεια μιας συνομιλίας.

## Συμπεριφορά Webhook και εκτέλεσης

Όταν αυτός ο κόμβος είναι η **μοναδική** τερματική έξοδος του workflow, οι **έξοδοι** εκτέλεσης είναι το ίδιο το αντιστοιχισμένο αντικείμενο: τα κλειδιά από τις `mappings` εμφανίζονται στο **ανώτατο επίπεδο** του JSON. **Δεν** υπάρχει εξωτερικό περιτύλιγμα με κλειδί το label του κόμβου και **δεν** υπάρχει αντικείμενο `{ "result": ... }` (σε αντίθεση με τον κόμβο [Output](./output-node.md)).

Εάν πολλοί τερματικοί κόμβοι παράγουν εξόδους (για παράδειγμα [Output](./output-node.md) μαζί με Αντιστοιχιστή εξόδου JSON, ή πολλοί κλάδοι), το Heym χρησιμοποιεί το κανονικό σχήμα: κάθε τερματικός κόμβος έχει ως κλειδί το `label` του.

## Περιορισμός βρόχου

Ίδιος κανόνας με τον κόμβο [Output](./output-node.md): μην τοποθετείτε αυτόν τον κόμβο μέσα σε κλάδο επανάληψης βρόχου—μόνο μετά τον κλάδο `done` του βρόχου. Ανατρέξτε στον κόμβο [Loop](./loop-node.md).

## Παράδειγμα

```json
{
  "type": "jsonOutputMapper",
  "data": {
    "label": "apiPayload",
    "mappings": [
      { "key": "message", "value": "$llm.text" },
      { "key": "ok", "value": "true" }
    ]
  }
}
```
