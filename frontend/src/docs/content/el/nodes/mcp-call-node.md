# MCP Call Node

Ο κόμβος **MCP Call** καλεί απευθείας ένα συγκεκριμένο εργαλείο [Model Context Protocol (MCP)](https://modelcontextprotocol.io), χωρίς ένα LLM να αποφασίζει ποιο εργαλείο θα επικαλεστεί. Χρησιμοποιήστε τον όταν γνωρίζετε ακριβώς ποιο εργαλείο θέλετε να καλέσετε και επιθυμείτε ντετερμινιστική εκτέλεση ενός βήματος.

## Επισκόπηση

| Ιδιότητα | Τιμή |
|----------|-------|
| Είσοδοι | 1 |
| Έξοδοι | 1 |
| Έξοδος | `$nodeLabel.result` |

## Πότε να Χρησιμοποιηθεί

Χρησιμοποιήστε τον κόμβο MCP Call όταν:
- Γνωρίζετε ακριβώς ποιο εργαλείο MCP θέλετε να καλέσετε κατά τον σχεδιασμό
- Δεν χρειάζεστε ένα LLM για να επιλέξει μεταξύ εργαλείων
- Επιθυμείτε μια ελαφριά, ντετερμινιστική εναλλακτική αντί ενός agent node για μία μόνο κλήση εργαλείου

Χρησιμοποιήστε τον [Agent node](./agent-node.md) αντ' αυτού όταν ένα LLM πρέπει να αποφασίσει ποια εργαλεία θα καλέσει ή όταν χρειάζεστε συλλογισμό πολλαπλών βημάτων.

> Ο κόμβος MCP Call **δεν** μπορεί να συνδεθεί σε έναν agent node ως εργαλείο.

## Διαμόρφωση Σύνδεσης

Ο κόμβος συνδέεται σε έναν μόνο MCP server. Επιλέξτε ένα transport και συμπληρώστε τα αντίστοιχα πεδία.

### SSE / Streamable HTTP

| Πεδίο | Περιγραφή |
|-------|-------------|
| `transport` | `sse` ή `streamable_http` |
| `url` | Πλήρες URL του MCP server (π.χ. `https://mcp.example.com/sse`). Υποστηρίζει εκφράσεις DSL. |
| `headers` | Αντικείμενο JSON με HTTP headers (π.χ. `{"Authorization": "Bearer ..."}`) |
| `timeoutSeconds` | Χρονικό όριο ανά σύνδεση σε δευτερόλεπτα (προεπιλογή: 30) |

### stdio

| Πεδίο | Περιγραφή |
|-------|-------------|
| `transport` | `stdio` |
| `command` | Εκτελέσιμο προς εκτέλεση (π.χ. `npx`) |
| `args` | Πίνακας JSON με ορίσματα (π.χ. `["-y", "@modelcontextprotocol/server-filesystem"]`) |
| `env` | Αντικείμενο JSON με μεταβλητές περιβάλλοντος (π.χ. `{"API_KEY": "..."}`) |
| `timeoutSeconds` | Χρονικό όριο ανά σύνδεση σε δευτερόλεπτα (προεπιλογή: 30) |

## Επιλογή Εργαλείου

1. Συμπληρώστε τα πεδία σύνδεσης.
2. Κάντε κλικ στο **Fetch Tools** — ο κόμβος συνδέεται στον MCP server και εμφανίζει τα διαθέσιμα εργαλεία.
3. Επιλέξτε ένα εργαλείο από το αναπτυσσόμενο μενού.

**Η επιλογή εργαλείου είναι υποχρεωτική.** Ο κόμβος δεν θα εκτελεστεί χωρίς επιλεγμένο εργαλείο.

## Ορίσματα

Αφού επιλέξετε ένα εργαλείο, ο κόμβος εμφανίζει ένα πεδίο εισόδου για κάθε όρισμα που ορίζεται στο input schema του εργαλείου. Κάθε πεδίο δέχεται:
- Μια στατική τιμή: `10`
- Μια έκφραση DSL: `$userInput.body.text`

Τα υποχρεωτικά ορίσματα επισημαίνονται με `*`.

## Έξοδος

| Πεδίο | Περιγραφή |
|-------|-------------|
| `$nodeLabel.result` | Αποτέλεσμα εργαλείου. Εάν η απόκριση είναι έγκυρο JSON, πρόκειται για αναλυμένο αντικείμενο. Διαφορετικά είναι συμβολοσειρά. |

## Παράδειγμα

Κλήση ενός εργαλείου `search` σε έναν SSE MCP server, περνώντας το query του χρήστη:

```json
{
  "type": "mcpCall",
  "data": {
    "label": "searchCall",
    "connection": {
      "transport": "sse",
      "url": "https://mcp.example.com/sse",
      "timeoutSeconds": 30
    },
    "selectedTool": "search",
    "toolArguments": {
      "query": "$userInput.body.text",
      "limit": "10"
    },
    "timeoutSeconds": 30
  }
}
```

Πρόσβαση στο αποτέλεσμα στη συνέχεια του workflow:

```
$searchCall.result.items   ← if result is a JSON object
$searchCall.result         ← if result is a plain string
```

## Σημειώσεις

- Ο κόμβος επιλύει τις εκφράσεις DSL στα `url`, `headers`, `env` και σε όλες τις τιμές των `toolArguments` πριν καλέσει το εργαλείο.
- Το `timeoutSeconds` στο επίπεδο του κόμβου εφαρμόζεται στη συνολική εκτέλεση· το `connection.timeoutSeconds` εφαρμόζεται στην ίδια τη συνεδρία MCP.
- Εάν ο MCP server δεν είναι διαθέσιμος ή επιστρέψει σφάλμα, ο κόμβος αποτυγχάνει και το μήνυμα σφάλματος είναι διαθέσιμο στο workflow trace.
