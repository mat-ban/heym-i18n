# Merge

Ο κόμβος **Merge** αναμένει πολλαπλές παράλληλες εισόδους και τις συνδυάζει σε μία μοναδική έξοδο. Χρησιμοποιήστε τον όταν χρειάζεται να ενώσετε αποτελέσματα από παράλληλους κλάδους πριν συνεχίσετε.

## Επισκόπηση

| Ιδιότητα | Τιμή |
|----------|-------|
| Είσοδοι | n (διαμορφώσιμες) |
| Έξοδοι | 1 |
| Έξοδος | `$nodeLabel.merged` – αντικείμενο με εισόδους από κάθε κλάδο |

## Παράμετροι

| Παράμετρος | Τύπος | Περιγραφή |
|-----------|------|-------------|
| `label` | string | Αναγνωριστικό κόμβου (camelCase) |
| `inputCount` | number | Αριθμός εισόδων που αναμένονται (προεπιλογή: 2) |

## Πότε να το Χρησιμοποιήσετε

- Χρησιμοποιήστε το όταν χρειάζεται να **συνδυάσετε** ή να **ενώσετε** αποτελέσματα από παράλληλους κλάδους
- Μην το χρησιμοποιείτε για παράλληλα workflows που καταλήγουν σε ξεχωριστούς κόμβους [Output](./output-node.md)
- Κάθε κλάδος εισόδου συνεισφέρει στη συγχωνευμένη έξοδο

## Παράδειγμα

```json
{
  "type": "merge",
  "data": {
    "label": "combineResults",
    "inputCount": 2
  }
}
```

Συνδέστε πολλαπλούς κλάδους στον κόμβο merge. Ο κόμβος αναμένει όλες τις εισόδους πριν παράγει έξοδο.
