# Έξοδος

Ο κόμβος **Έξοδος** είναι το τελικό σημείο του workflow που επιστρέφει την απόκριση στον καλούντα. Αναφέρετε πάντα τον προηγούμενο κόμβο μέσω της ετικέτας—μην χρησιμοποιείτε ποτέ το `$input`.

## Επισκόπηση

| Ιδιότητα | Τιμή |
|----------|-------|
| Είσοδοι | 1 |
| Έξοδοι | 1 (προαιρετικά, για ασύγχρονη μετα-επεξεργασία) |
| Έξοδος | Επιστρέφει το `message` στον καλούντα |

## Παράμετροι

| Παράμετρος | Τύπος | Περιγραφή |
|-----------|------|-------------|
| `label` | string | Αναγνωριστικό κόμβου (camelCase) |
| `message` | expression | Τιμή εξόδου. **Πρέπει** να αναφέρεται στον προηγούμενο κόμβο: `$previousNodeLabel.field` |
| `allowDownstream` | boolean | Εάν είναι true, οι κόμβοι μετά την έξοδο εκτελούνται ασύγχρονα αφού σταλεί η απόκριση |

## Χρήση ως εργαλείο agent

Όταν ένας κόμβος Έξοδος συνδέεται με έναν [Κόμβο Agent](./agent-node.md) ως εργαλείο canvas, το πεδίο `message` μπορεί να επισημανθεί ως **παρεχόμενο από τον agent** με το εικονίδιο bot. Ο agent τότε παρέχει το μήνυμα όταν καλεί το εργαλείο. Εάν ο κόμβος Έξοδος δεν είναι συνδεδεμένος ως εργαλείο agent, το εικονίδιο bot κρύβεται.

## Κρίσιμος Κανόνας

**Μην χρησιμοποιείτε ποτέ το `$input` στον κόμβο εξόδου.** Χρησιμοποιείτε πάντα την ετικέτα του προηγούμενου κόμβου:

- ❌ `"message": "$input.text"`
- ✅ `"message": "$processData.text"` (όπου `processData` είναι η ετικέτα του προηγούμενου κόμβου)

## Ασύγχρονη Μετα-Επεξεργασία

Όταν `allowDownstream: true`, η απόκριση επιστρέφεται αμέσως. Οι κόμβοι που συνδέονται μετά την έξοδο εκτελούνται στο παρασκήνιο (π.χ. ειδοποιήσεις Slack, καταγραφή). Επειδή το downstream τμήμα μπορεί να ολοκληρωθεί αργότερα, μια αποτυχία downstream μπορεί να αλλάξει την καταγεγραμμένη κατάσταση εκτέλεσης σε `error` αφού έχει ήδη επιστραφεί η πρώιμη απόκριση· το τελικό ιστορικό και τα analytics αντικατοπτρίζουν αυτό το μεταγενέστερο αποτέλεσμα.

## Παράδειγμα

```json
{
  "type": "output",
  "data": {
    "label": "apiResponse",
    "message": "$generateResponse.text"
  }
}
```

## Παράδειγμα – Με Ασύγχρονη Εκτέλεση

```json
{
  "type": "output",
  "data": {
    "label": "apiResponse",
    "message": "$generateResponse.text",
    "allowDownstream": true
  }
}
```

Στη συνέχεια, συνδέστε έναν κόμβο [Telegram](./telegram-node.md), [Slack](./slack-node.md) ή άλλο κόμβο μετά την έξοδο για ειδοποιήσεις fire-and-forget.
