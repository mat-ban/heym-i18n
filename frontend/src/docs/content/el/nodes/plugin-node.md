# Κόμβος Plugin

Ο κόμβος **Plugin** εκτελεί μια προσαρμοσμένη ενέργεια που παρέχεται από ένα εγκατεστημένο plugin. Τα plugins επεκτείνουν το Heym με νέους τύπους κόμβων — ενέργειες, ενσωματώσεις τρίτων ή οτιδήποτε μπορεί να εκφραστεί σε Python — χωρίς τροποποίηση του πυρήνα της εφαρμογής.

## Επισκόπηση

| Ιδιότητα | Τιμή |
|----------|-------|
| Είσοδοι | 1 |
| Έξοδοι | 1 |
| Έξοδος | `$nodeLabel.<keys returned by the plugin>` |

Ένα **πακέτο** plugin (ένα zip) μπορεί να περιέχει **πολλαπλούς κόμβους** — οποιονδήποτε συνδυασμό ενεργειών και triggers. Κάθε κόμβος εμφανίζεται στην παλέτα κάτω από την κατηγορία **Plugins** με το δικό του όνομα και περιγραφή. Η μεταφορά ενός κόμβου στον καμβά δημιουργεί έναν κόμβο Plugin συνδεδεμένο με αυτό το πακέτο (`pluginId`) και τον κόμβο (`pluginNodeKey`).

## Πότε να Χρησιμοποιηθεί

Χρησιμοποιήστε έναν κόμβο Plugin όταν ένας διαχειριστής έχει εγκαταστήσει ένα plugin που εκτελεί την ενέργεια που χρειάζεστε — για παράδειγμα κλήση ενός ιδιωτικού API, επικοινωνία με ένα εσωτερικό σύστημα ή εκτέλεση προσαρμοσμένης λογικής γραμμένης για την εγκατάστασή σας.

Για plugins τύπου trigger που ξεκινούν ένα workflow, ανατρέξτε στον
[κόμβο Plugin Trigger](./plugin-trigger-node.md).

## Διαμόρφωση

Η φόρμα διαμόρφωσης του κόμβου δημιουργείται από το manifest του plugin. Κάθε πεδίο που δηλώνεται από το plugin (`string`, `number`, `boolean` ή `select`) αποδίδεται αυτόματα. Τα μη-απόρρητα πεδία string χρησιμοποιούν το πεδίο εισαγωγής έκφρασης, και οι αποθηκευμένες τιμές διαμόρφωσης string που ξεκινούν με `$` επιλύονται πριν εκτελεστεί ο handler του plugin.

Τα απόρρητα πεδία (όπως τα API keys) αποκρύπτονται στη διεπαφή και δεν καταγράφονται ποτέ στα logs.

## Πώς Εκτελούνται τα Plugins

Τα plugins παρέχονται από το Heym και εγκαθίστανται από έναν διαχειριστή, επομένως ο κώδικας του plugin είναι **αξιόπιστος** και εκτελείται εντός της διεργασίας όπως ένας ενσωματωμένος κόμβος, με πλήρη πρόσβαση στο δίκτυο και τις βιβλιοθήκες. Ένα plugin μπορεί να δηλώσει `dependencies` pip που εγκαθίστανται στην εγκατάσταση κατά τη στιγμή της εγκατάστασης.

Η εγκατάσταση και αφαίρεση plugins περιορίζεται σε διαχειριστές των οποίων το email αναφέρεται στο `HEYM_PLUGIN_ADMIN_EMAILS`, και ολόκληρο το υποσύστημα ελέγχεται από το `HEYM_PLUGINS_ENABLED` (απενεργοποιημένο από προεπιλογή). Ανατρέξτε στο
[Εκτέλεση & Ανάπτυξη](../getting-started/running-and-deployment.md) για τις μεταβλητές περιβάλλοντος.

## Προσαρμοσμένα Εικονίδια

Ένα plugin μπορεί να παρέχει προσαρμοσμένα λογότυπα SVG. Τοποθετήστε ένα `icon.svg` στη ρίζα του πακέτου για να ορίσετε μια προεπιλογή για κάθε κόμβο, ή/και δώστε σε έναν κόμβο το δικό του `"icon": "<file>.svg"` στο manifest. Το εικονίδιο εμφανίζεται τόσο στην κάρτα της παλέτας όσο και στον κόμβο του καμβά· οι κόμβοι χωρίς εικονίδιο χρησιμοποιούν το προεπιλεγμένο σύμβολο puzzle.

## AI Builder

Τα εγκατεστημένα plugins είναι διαθέσιμα στον βοηθό AI και στον καμβά chat, ώστε να μπορείτε να ζητήσετε από το Heym να "χρησιμοποιήσει το plugin Acme CRM για να δημιουργήσει μια εγγραφή" και αυτό θα δημιουργήσει τον κόμβο Plugin με το σωστό `pluginId` και `config`.
