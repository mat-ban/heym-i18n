# Wait

Ο κόμβος **Wait** παύει την εκτέλεση του workflow για καθορισμένη διάρκεια. Χρησιμοποιήστε τον για περιορισμό ρυθμού, καθυστερημένες ενέργειες ή διαστήματα polling.

## Επισκόπηση

| Ιδιότητα | Τιμή |
|----------|-------|
| Είσοδοι | 1 |
| Έξοδοι | 1 |
| Έξοδος | Διέρχεται μέσω της εισόδου |

## Παράμετροι

| Παράμετρος | Τύπος | Περιγραφή |
|-----------|------|-------------|
| `label` | string | Αναγνωριστικό κόμβου (camelCase) |
| `duration` | number | Καθυστέρηση σε χιλιοστά του δευτερολέπτου (π.χ. 1000 = 1 δευτερόλεπτο). Ο επεξεργαστής δέχεται 1 έως 900000 (15 λεπτά) |

## Παράδειγμα

```json
{
  "type": "wait",
  "data": {
    "label": "delayOneSecond",
    "duration": 1000
  }
}
```
