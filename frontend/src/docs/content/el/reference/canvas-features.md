# Δυνατότητες Καμβά

Ο επεξεργαστής workflow παρέχει αρκετές δυνατότητες για αποσφαλμάτωση, δοκιμή και οργάνωση κόμβων: **Εκτέλεση έως τον Κόμβο**, **AI σε έναν κόμβο**, **Καρφίτσωμα Δεδομένων**, **Αρχεία Καταγραφής Εκτελέσεων**, **Ενεργοποίηση/Απενεργοποίηση** και **Εξαγωγή σε Υπο-Workflow**.

## Εκτέλεση έως τον Κόμβο

Τοποθετήστε τον δείκτη σε οποιονδήποτε κόμβο εκτός από ένα sticky note και κάντε κλικ στο **Run** που βρίσκεται από κάτω του. Το Heym εκτελεί αυτόν τον κόμβο και τις ανάντη εξαρτήσεις του, αφήνοντας ανέπαφους τους κατάντη κόμβους και τους άσχετους κλάδους. Αυτό χρησιμοποιεί τη λειτουργία δοκιμής του καμβά, συμπεριλαμβανομένων των καρφιτσωμένων εξόδων και των κανονικών συνθηκών διακλάδωσης του workflow.

Εάν η επιλεγμένη διαδρομή έχει πεδία εισόδου, ανοίγει το δεξιό πλαίσιο **Run** και εστιάζει στο πρώτο πεδίο. Εισαγάγετε τις τιμές και, στη συνέχεια, κάντε κλικ στο **Run to _node label_** ή πατήστε **Ctrl+Enter** (Cmd+Enter σε macOS). Η λειτουργία γενικού σώματος εστιάζει στον επεξεργαστή σώματος JSON. Οι διαδρομές χωρίς πεδία εισόδου εκτελούνται αμέσως χωρίς να ανοίξει το πλαίσιο. Οι καρφιτσωμένοι κόμβοι Input επαναχρησιμοποιούν την καρφιτσωμένη έξοδό τους χωρίς να ζητούν είσοδο.

Το πλαίσιο διατηρεί τον επιλεγμένο στόχο για τις επόμενες εκτελέσεις. Επιλέξτε **Run full workflow** για να διαγράψετε τον στόχο. Τα κουμπιά Run είναι απενεργοποιημένα όσο εκτελείται μια εκτέλεση. Ένας στόχος μέσα σε έναν βρόχο σταματά την εκτέλεση όταν ο κόμβος αυτός προσεγγιστεί για πρώτη φορά· επιλέγοντας έναν κόμβο μετά τον βρόχο εκτελείται ο πλήρης ανάντη βρόχος.

## AI σε έναν κόμβο

Τοποθετήστε τον δείκτη πάνω από οποιονδήποτε κόμβο εκτός από μια αυτοκόλλητη σημείωση και κάντε κλικ στο **AI** από πάνω του. Το [AI Assistant](./ai-assistant.md) ανοίγει σε αυτόν τον κόμβο και προσφέρει **Change this node as ...**, **Fix error in this node ...** και **Other**. Σε λειτουργία Agent ο βοηθός αλλάζει μόνο αυτόν τον κόμβο· άλλοι κόμβοι, συνδέσεις και η διάταξη παραμένουν ως έχουν. Δείτε [AI Assistant › Τροποποίηση μεμονωμένου κόμβου](./ai-assistant.md#changing-one-node).

Το κουμπί είναι κρυφό σε workflows στα οποία έχετε μόνο δικαίωμα προβολής.

## Καρφίτσωμα Δεδομένων

Το Καρφίτσωμα Δεδομένων σας επιτρέπει να καρφιτσώσετε την έξοδο ενός κόμβου από την τελευταία εκτέλεση, ώστε να μπορείτε να δοκιμάσετε κατάντη κόμβους χωρίς να επανεκτελέσετε τον καρφιτσωμένο κόμβο.

### Πού θα το Βρείτε

- **Πλαίσιο ιδιοτήτων** – Επιλέξτε έναν κόμβο και μεταβείτε στην ενότητα **Pinned Data**
- **Σήμα κόμβου** – Ένα εικονίδιο pin εμφανίζεται στον κόμβο όταν έχουν καρφιτσωθεί δεδομένα

### Ενέργειες

| Ενέργεια | Περιγραφή |
|--------|-------------|
| **Pin** | Καρφιτσώνει την έξοδο της τελευταίας εκτέλεσης του κόμβου (διαθέσιμο μετά από μια εκτέλεση) |
| **Clear** | Αφαιρεί τα καρφιτσωμένα δεδομένα |
| **Edit** | Επεξεργαστείτε απευθείας το καρφιτσωμένο JSON· κάντε κλικ στο Save για εφαρμογή |

### Συμπεριφορά Λειτουργίας Δοκιμής

Κατά την εκτέλεση ενός workflow σε λειτουργία δοκιμής, οι κόμβοι με `pinnedData` παραλείπουν την εκτέλεση και χρησιμοποιούν την καρφιτσωμένη έξοδο. Χρησιμοποιήστε το για να:

- Δοκιμάσετε κατάντη λογική χωρίς κλήση εξωτερικών API
- Αποσφαλματώσετε εκφράσεις που αναφέρονται στην έξοδο του κόμβου
- Επαναλάβετε prompts ή συνθήκες με σταθερά δείγματα δεδομένων

Η συμπλήρωση εκφράσεων στον επεξεργαστή χρησιμοποιεί καρφιτσωμένα δεδομένα όταν είναι διαθέσιμα για να προτείνει πεδία.

## Αρχεία Καταγραφής Εκτελέσεων

Το **πλαίσιο Debug** (κάτω συρτάρι) εμφανίζει αρχεία καταγραφής εκτέλεσης σε πραγματικό χρόνο κατά τη διάρκεια εκτελέσεων workflow. Μπορείτε επίσης να ανοίξετε μια εκτέλεση παραγωγής που βρίσκεται σε εξέλιξη είτε από το παράθυρο διαλόγου Ιστορικού είτε από μια κάρτα Board. Ο επεξεργαστής συνδέεται με τη ροή SSE αυτής της εκτέλεσης, επαναφέρει τα αποτελέσματα των ολοκληρωμένων κόμβων και συνεχίζει να εμφανίζει κινούμενα σχέδια κόμβων και αρχεία καταγραφής καθώς νέοι κόμβοι ξεκινούν και ολοκληρώνονται.

### Τι Εμφανίζει

- **Αποτελέσματα κόμβων** – Κατάσταση ανά κόμβο (`success`, `error`, `skipped`, `running`), χρόνος εκτέλεσης και έξοδος
- **Τελικές έξοδοι** – Συγκεντρωμένες έξοδοι από κόμβους [Output](../nodes/output-node.md)
- **Πρόοδος Agent** – Για κόμβους [Agent](../nodes/agent-node.md), κλήσεις εργαλείων βήμα προς βήμα και συλλογισμός

### Ενέργειες

- **Copy as JSON** – Αντιγραφή του πλήρους αρχείου καταγραφής εκτέλεσης στο πρόχειρο
- **Open in JSON editor** – Ανοίγει το αρχείο καταγραφής στο JSON Hero ή στο JSON Editor Online για επιθεώρηση
- **Download generated files** – Εάν μια δεξιότητα παρήγαγε αρχεία προς λήψη (`_generated_files`), εμφανίζεται ένα κουμπί Download. Ένα μεμονωμένο αρχείο λαμβάνεται απευθείας· πολλαπλά αρχεία ανοίγουν ένα αναδυόμενο παράθυρο επιλογής.

### Διάκριση από την Καρτέλα Logs

Το πλαίσιο Debug εμφανίζει αρχεία καταγραφής **εκτέλεσης workflow** (αποτελέσματα κόμβων, έξοδοι). Η [Καρτέλα Logs](../tabs/logs-tab.md) εμφανίζει αρχεία καταγραφής **περιέκτη Docker** (backend, frontend, βάση δεδομένων). <!-- pragma: allowlist secret -->

## Ενεργοποίηση / Απενεργοποίηση

Μπορείτε να απενεργοποιήσετε κόμβους ώστε να παραλείπονται κατά την εκτέλεση. Οι απενεργοποιημένοι κόμβοι εμφανίζουν ένα σήμα "off" και εμφανίζονται θαμπωμένοι.

### Πώς να Εναλλάσσετε

| Μέθοδος | Περιγραφή |
|--------|-------------|
| **Πλαίσιο ιδιοτήτων** | Επιλέξτε κόμβο → Εικονίδιο Power (πάνω δεξιά) |
| **Μενού περιβάλλοντος** | Κάντε δεξί κλικ σε κόμβο(ους) → Disable ή Enable |
| **Πληκτρολόγιο** | Επιλέξτε κόμβο(ους) → πατήστε **D** (δείτε [Συντομεύσεις Πληκτρολογίου](./keyboard-shortcuts.md)) |

### Πολλαπλή Επιλογή

Όταν είναι επιλεγμένοι πολλοί κόμβοι, η Ενεργοποίηση/Απενεργοποίηση εφαρμόζεται σε όλους. Το μενού περιβάλλοντος εμφανίζει "Enable" εάν οποιοσδήποτε επιλεγμένος κόμβος είναι απενεργοποιημένος, "Disable" εάν όλοι είναι ενεργοποιημένοι.

### Συμπεριφορά κατά την Εκτέλεση

Οι κόμβοι με `active: false` παραλείπονται. Οι κατάντη κόμβοι δεν λαμβάνουν δεδομένα από παραλειπόμενους κόμβους. Χρησιμοποιήστε το για να εξαιρέσετε προσωρινά κόμβους χωρίς να τους διαγράψετε.

Για να ενεργοποιήσετε ή να απενεργοποιήσετε έναν κόμβο από μέσα σε ένα workflow αντί χειροκίνητα, χρησιμοποιήστε τους κόμβους [Disable Node](../nodes/disable-node.md) και [Enable Node](../nodes/enable-node.md).
## Γράφημα μνήμης Agent

Οι κόμβοι [Agent](../nodes/agent-node.md) με ενεργοποιημένη την **[persistent memory](./agent-persistent-memory.md)** εμφανίζουν ένα ροζ χειριστήριο **brain** στον κόμβο. Κάντε κλικ σε αυτό για να ανοίξετε τον επεξεργαστή γραφήματος μνήμης: οι οντότητες αποδίδονται ως ένα κινούμενο, force-directed γράφημα ομαδοποιημένο κατά τύπο οντότητας, με αναζητήσιμους επιλογείς Source/Target για την προσθήκη σχέσεων και έναν πίνακα συνδέσεων για μετάβαση μεταξύ συνδεδεμένων οντοτήτων. Το ίδιο παράθυρο διαλόγου περιλαμβάνει την επιλογή **Share memory with other agents** (workflow → agent → read ή read/write) για [κοινή χρήση μνήμης μεταξύ agents](./agent-persistent-memory.md#sharing-with-other-agents). Όσο το παράθυρο διαλόγου είναι ανοιχτό, η αναίρεση/επανάληψη του κύριου καμβά αναβάλλεται, ώστε η επεξεργασία του γραφήματος να διατηρεί το δικό της ιστορικό.

**Φιλτράρισμα του γραφήματος.** Στο επάνω αριστερό μέρος του καμβά υπάρχει ένα χειριστήριο αναζήτησης, συμπτυγμένο σε κουμπί συντόμευσης μέχρι να κάνετε κλικ σε αυτό ή να πατήσετε **Ctrl/Cmd+F**. Αντιστοιχίζει το όνομα μιας οντότητας, τον τύπο της και κάθε κλειδί και τιμή χαρακτηριστικού, καθώς και τον τύπο μιας σχέσης (`parent_of`) και τις ιδιότητές της· μια σχέση που αντιστοιχίζεται φέρνει μαζί της και τις δύο οντότητές της. Όλοι οι όροι που χωρίζονται με κενά διαστήματα πρέπει να αντιστοιχίζονται. Μια οντότητα που αντιστοιχίζεται φέρνει μαζί της ολόκληρη τη γειτονιά της — κάθε σχέση στην οποία συμμετέχει και την οντότητα στην άλλη άκρη καθεμιάς — ώστε μια αντιστοίχιση να μην αφήνεται ποτέ ως ασύνδετη κουκκίδα. Μια σχέση που αντιστοιχίζεται φέρνει μόνο τις δύο οντότητες που ενώνει και σταματά εκεί, καθώς η αναζήτηση τύπου σχέσης είναι ερώτημα για αυτή τη σχέση και όχι για όλα όσα είναι συνδεδεμένα στα άκρα της. Όλα τα υπόλοιπα κρύβονται εντελώς — όχι θαμπά — στον καμβά και στη λίστα **All edges**, και ένα σήμα δείχνει πόσες από τις συνολικές οντότητες απομένουν. Το **✕** μέσα στο πλαίσιο καθαρίζει πρώτα το ερώτημα και μετά κλείνει το πλαίσιο με δεύτερο πάτημα. Το Escape ακολουθεί την ίδια αντίστροφη πορεία, από μέσα προς τα έξω: καθαρίζει το ερώτημα, μετά κλείνει το πλαίσιο αναζήτησης, μετά εξέρχεται από την εκτεταμένη προβολή του καμβά και κλείνει το παράθυρο διαλόγου μόνο όταν κανένα από αυτά δεν είναι ανοιχτό. Ο καθαρισμός επαναφέρει το πλήρες γράφημα με κάθε οντότητα στη θέση της.

**Τοποθέτηση οντοτήτων με το χέρι.** Το σύρσιμο μιας οντότητας την καρφιτσώνει εκεί που την αφήνετε, ώστε η αυτόματη διάταξη να τακτοποιεί την υπόλοιπη γραφή γύρω της αντί να την τραβά πίσω. Το σύρσιμο της επιλεγμένης οντότητας μετακινεί μαζί της τις άμεσα συνδεδεμένες οντότητες, διατηρώντας το σχήμα της ομάδας· το σύρσιμο οποιασδήποτε άλλης οντότητας μετακινεί μόνο αυτήν. Το **Tidy layout** (το κουμπί με το ραβδί) απελευθερώνει κάθε καρφιτσωμένη οντότητα και εκτελεί ξανά την αυτόματη διάταξη.

## Extract to Sub-Workflow

Μετατρέψτε τους επιλεγμένους κόμβους σε ένα επαναχρησιμοποιήσιμο sub-workflow και αντικαταστήστε τους με έναν κόμβο [Execute](../nodes/execute-node.md).

### Πώς να το Χρησιμοποιήσετε

1. Επιλέξτε έναν ή περισσότερους κόμβους στον καμβά
2. Κάντε δεξί κλικ → **Extract to Sub-Workflow**
3. Εισαγάγετε ένα όνομα (και προαιρετική περιγραφή) για το νέο workflow
4. Κάντε κλικ στο **Extract**

### Τι Συμβαίνει

- Δημιουργείται ένα νέο workflow με τους επιλεγμένους κόμβους
- Οι εξωτερικές είσοδοι (ακμές από έξω από την επιλογή) γίνονται πεδία [Input](../nodes/input-node.md) του sub-workflow
- Οι εξωτερικές έξοδοι (ακμές προς κόμβους έξω από την επιλογή) αντιστοιχίζονται στο [Output](../nodes/output-node.md) του sub-workflow
- Οι επιλεγμένοι κόμβοι αντικαθίστανται από έναν μόνο κόμβο [Execute](../nodes/execute-node.md) που καλεί το νέο workflow
- Οι αντιστοιχίσεις εισόδου/εξόδου διατηρούνται αυτόματα

### Περιπτώσεις Χρήσης

- Επαναχρησιμοποίηση μιας ακολουθίας κόμβων σε πολλαπλά workflows
- Απλοποίηση ενός σύνθετου workflow με ομαδοποίηση σχετικής λογικής
- Δημιουργία αρθρωτών, ελέγξιμων sub-workflows

## Run with cURL

Το κουμπί **cURL** στη γραμμή εργαλείων του επεξεργαστή (επάνω δεξιά) ανοίγει ένα παράθυρο διαλόγου για τη δημιουργία και αντιγραφή μιας εντολής cURL για την ενεργοποίηση του workflow μέσω API.

- Επιλέξτε τη λειτουργία σώματος αιτήματος του workflow (`Defined` ή `Generic`)
- Ορίστε τον τύπο ταυτοποίησης (Anonymous, JWT ή Header Auth)
- Διαμορφώστε την προσωρινή αποθήκευση αποκρίσεων και τον περιορισμό ρυθμού
- Ενεργοποιήστε/απενεργοποιήστε τη ροή SSE και προσαρμόστε τα μηνύματα έναρξης ανά κόμβο
- Επεξεργαστείτε το σώμα του αιτήματος
- Στη λειτουργία Generic, ο πίνακας εκτέλεσης του καμβά χρησιμοποιεί το ίδιο ακατέργαστο σώμα JSON με το παράθυρο διαλόγου cURL
- Κάντε κλικ στο **Copy cURL** για να αντιγράψετε την έτοιμη προς εκτέλεση εντολή

Ανατρέξτε στο [Webhooks](./webhooks.md#run-with-curl-dialog) για πλήρεις λεπτομέρειες του παραθύρου διαλόγου και στο [SSE Streaming](./sse-streaming.md) για το πρωτόκολλο συμβάντων.
