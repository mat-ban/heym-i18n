# Φωνή Chat (TTS & STT)

Η καρτέλα Chat μπορεί να διαβάζει μηνύματα δυνατά και να εκτελεί μια διαδραστική λειτουργία φωνής hands-free, με υποστήριξη από το [ElevenLabs](https://elevenlabs.io). Και οι δύο κατευθύνσεις χρησιμοποιούν ένα διαπιστευτήριο ElevenLabs: **text-to-speech** για αναπαραγωγή και **Scribe speech-to-text** για το μικρόφωνο.

## Ρύθμιση

1. Ανοίξτε τις **Ρυθμίσεις** (το avatar σας, επάνω δεξιά) → καρτέλα **Voice**.
2. Επιλέξτε ένα **διαπιστευτήριο ElevenLabs** ή κάντε κλικ στο **Add credential** για να δημιουργήσετε ένα. Το API key χρειάζεται τα δικαιώματα **Text to Speech**, **Speech to Text** και **Voices** ενεργοποιημένα στον λογαριασμό σας ElevenLabs.
3. Επιλέξτε μια **Voice** από τον λογαριασμό σας ElevenLabs.
4. Κάντε κλικ στο **Save Voice Settings**.

Εάν πατήσετε ένα κουμπί φωνής πριν το ρυθμίσετε, η καρτέλα Voice ανοίγει αυτόματα ώστε να ολοκληρώσετε τη διαμόρφωση.

Το API key του ElevenLabs αποθηκεύεται κρυπτογραφημένο και δεν φτάνει ποτέ στο πρόγραμμα περιήγησης — όλες οι κλήσεις δρομολογούνται μέσω του backend του Heym. Δείτε [Διαπιστευτήρια](./credentials.md) και [Ρυθμίσεις](./user-settings.md).

## Ανάγνωση μηνύματος δυνατά

Κάθε φυσαλίδα μηνύματος (δική σας και του assistant) έχει ένα κουμπί ηχείου δίπλα στο **Copy**. Κάντε κλικ για να αναπαραχθεί το μήνυμα· κάντε κλικ ξανά — ή αναπαράγετε άλλο μήνυμα — για να σταματήσει. Η αναπαραγωγή χρησιμοποιεί το πολυγλωσσικό μοντέλο του ElevenLabs, οπότε η γλώσσα του κειμένου ανιχνεύεται αυτόματα.

## Διαδραστική λειτουργία φωνής

Το κουμπί κυματομορφής στο πεδίο εισαγωγής του chat ανοίγει μια λειτουργία φωνής hands-free πλήρους οθόνης (φωτεινή/σκοτεινή και προσαρμοσμένη για κινητά):

1. Ακούει μέσω του μικροφώνου σας και ανιχνεύει πότε σταματάτε να μιλάτε.
2. Η ομιλία σας μεταγράφεται με το **Scribe** (αυτόματη ανίχνευση γλώσσας — χωρίς χειροκίνητο διακόπτη TR/EN).
3. Η μεταγραφή αποστέλλεται ως κανονικό μήνυμα chat στην **ίδια συνομιλία**.
4. Η απάντηση του assistant διαβάζεται δυνατά και στη συνέχεια συνεχίζει να ακούει.

Χρησιμοποιήστε το κουμπί **mute** για παύση της ακρόασης και το **✕** για έξοδο (το οποίο απελευθερώνει το μικρόφωνο). Η εγγραφή λειτουργεί σε όλα τα σύγχρονα προγράμματα περιήγησης, συμπεριλαμβανομένου του Firefox.

## Σημειώσεις

- Η επιλογή φωνής και διαπιστευτηρίου είναι προτιμήσεις ανά χρήστη· η ενεργή συνομιλία, το μοντέλο και το διαπιστευτήριο για το LLM παραμένουν αμετάβλητα.
- Η χρήση του ElevenLabs (τόσο TTS όσο και STT) χρεώνεται στον δικό σας λογαριασμό ElevenLabs.
