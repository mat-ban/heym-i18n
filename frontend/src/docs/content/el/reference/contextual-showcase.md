# Ενσωματωμένη Επίδειξη Περιβάλλοντος

Η **Ενσωματωμένη Επίδειξη Περιβάλλοντος** είναι μια ελαφριά ενσωματωμένη ράγα οδηγού που εξηγεί τη σελίδα στην οποία βρίσκεστε αυτή τη στιγμή, χωρίς να σας ωθεί αμέσως σε μια πλήρη ροή τεκμηρίωσης.

## Τι Κάνει

- Εμφανίζει μια σύντομη σύνοψη για την τρέχουσα σελίδα
- Διατηρεί το πρώτο επίπεδο συνοπτικό, ώστε να μην υπερφορτώνεστε
- Σας επιτρέπει να αναπτύξετε μια μικρή ποσότητα πρόσθετης λεπτομέρειας μόνο όταν είναι απαραίτητο
- Παρέχει συνδέσμους προς την πλήρη σελίδα τεκμηρίωσης για βαθύτερη ανάγνωση

## Πού Εμφανίζεται

Στην έκδοση v1, η επίδειξη είναι διαθέσιμη στις κύριες πιστοποιημένες επιφάνειες του Heym:

- Καρτέλες Πίνακα Ελέγχου
- [Αξιολογήσεις](../tabs/evals-tab.md)
- [Τεκμηρίωση](../getting-started/introduction.md)
- Τον καμβά του επεξεργαστή workflow

Δημόσιες σελίδες όπως η σύνδεση, η εγγραφή, η πύλη chat και η αξιολόγηση HITL δεν εμφανίζουν την επίδειξη.

## Πρόσβαση

### Desktop

- Ένα σταθερό trigger **Page Guide** εμφανίζεται στη δεξιά άκρη της οθόνης
- Η επίδειξη ανοίγει ως συρτάρι στη δεξιά πλευρά
- Παραμένει κλειστή από προεπιλογή
- Ένα teaser μίας χρήσης βοηθά να αποκαλυφθεί ότι ο οδηγός υπάρχει, χωρίς να εξαναγκάζεται το άνοιγμά του

### Mobile

- Το ίδιο περιεχόμενο είναι διαθέσιμο από ένα αιωρούμενο κουμπί **Page Guide**
- Ανοίγει σε bottom sheet αντί για δεξιά ράγα

## Μοντέλο Περιεχομένου

Κάθε καταχώρηση επίδειξης χρησιμοποιεί ένα δομημένο ορισμό αντί για ένα πλήρως προσαρμοσμένο component.

- **Title** – Τι είναι αυτή η σελίδα
- **Summary** – Μία σύντομη εξήγηση
- **Bullets** – Λίγα ευανάγνωστα σημεία
- **Highlights** – Μικρές κάρτες για βασική αξία ή μοτίβα χρήσης
- **More Detail** – Συμπτυγμένες ενότητες για πρόσθετο περιβάλλον
- **Actions** – Συνήθως ένας ή δύο σύνδεσμοι, τις περισσότερες φορές προς την πλήρη τεκμηρίωση

Αυτό διατηρεί το σύστημα ευέλικτο, αποφεύγοντας παράλληλα μακριά και θορυβώδη πάνελ βοήθειας.

## Επίγνωση Περιβάλλοντος

Η επίδειξη αλλάζει ανάλογα με την τρέχουσα επιφάνεια.

- Κάθε καρτέλα του Πίνακα Ελέγχου έχει τη δική της σύνοψη
- Ο επεξεργαστής παραπέμπει στα [Canvas Features](./canvas-features.md)
- Η σελίδα τεκμηρίωσης χρησιμοποιεί μια γενική επισκόπηση τεκμηρίωσης και, όταν είναι δυνατό, παραπέμπει στο τρέχον άρθρο που έχετε ήδη ανοιχτό

## Διατήρηση Κατάστασης

Η επίδειξη αποθηκεύει μια μικρή ποσότητα προσωπικής κατάστασης UI στον χώρο αποθήκευσης του browser:

- Αν το πάνελ ή το sheet ήταν τελευταία ανοιχτό
- Ποιες σελίδες έχουν ήδη εμφανίσει το teaser
- Την τελευταία αναπτυγμένη ενότητα λεπτομερειών ανά περιβάλλον

## Γιατί Υπάρχει

Ο στόχος είναι να γίνει το Heym ευκολότερο στην εκμάθηση, χωρίς να προστίθενται περισσότερα βαριά στοιχεία UI.

- Σύντομη καθοδήγηση, πάντα κοντά, για προσανατολισμό
- Σαφής διαδρομή προς βαθύτερη τεκμηρίωση
- Χαμηλή διακοπή για έμπειρους χρήστες
