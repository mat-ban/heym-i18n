# Λήψη & Εισαγωγή

Εξάγετε workflows ή ολόκληρους φακέλους ως αρχεία ή εισαγάγετέ τους μέσω drag & drop. Χρησιμοποιήστε το για δημιουργία αντιγράφων ασφαλείας, κοινή χρήση ή μετεγκατάσταση workflows μεταξύ instances.

## Λήψη Workflow (JSON)

**Τοποθεσία:** Γραμμή εργαλείων επεξεργαστή → κουμπί **Download** (ορατό σε μεγάλες οθόνες)

**Τι εξάγεται:**
- `nodes` – Όλοι οι κόμβοι στον καμβά
- `edges` – Όλες οι συνδέσεις μεταξύ κόμβων

**Όνομα αρχείου:** `{workflow-name}.json` (προέρχεται από το όνομα του workflow)

**Μορφή:** Ανατρέξτε στο [Workflow Structure](./workflow-structure.md) για το σχήμα JSON.

## Λήψη Φακέλου (ZIP)

**Τοποθεσία:** Dashboard → καρτέλα Workflows → μενού 3 τελειών φακέλου → **Download as ZIP**

**Τι εξάγεται:**
- Όλα τα workflows στον φάκελο και σε όλους τους υποφακέλους, αναδρομικά
- Η ιεραρχία φακέλων διατηρείται ως κατάλογοι εντός του ZIP

**Δομή ZIP:**
```
FolderName/
  workflow1.json
  workflow2.json
  SubFolder/
    workflow3.json
    DeepSub/
      workflow4.json
```

Κάθε αρχείο `.json` περιέχει `{ name, nodes, edges }`.

## Εισαγωγή

### Από το Dashboard (Καρτέλα Workflows)

1. Μεταβείτε στην καρτέλα [Workflows](../tabs/workflows-tab.md)
2. Σύρετε ένα αρχείο **JSON** ή **ZIP** στην περιοχή workflow

**Αρχείο JSON:** Δημιουργείται ένα νέο workflow. Το όνομα του workflow προέρχεται από το πεδίο `name` στο JSON ή από το όνομα αρχείου εάν λείπει το `name`.

**Αρχείο ZIP:** Η ολόκληρη δομή φακέλων αναδημιουργείται στο ριζικό επίπεδο. Κάθε αρχείο `.json` εντός του ZIP γίνεται ένα workflow που τοποθετείται στον αντίστοιχο φάκελο. Διαπιστευτήρια και αναφορές μεταξύ workflows που δεν υπάρχουν στο τρέχον instance καθαρίζονται αυτόματα. Εάν ορισμένα workflows αποτύχουν να εισαχθούν, εμφανίζεται σύνοψη που δείχνει πόσα εισήχθησαν επιτυχώς.

### Από τον Καμβά (Επεξεργαστής)

1. Ανοίξτε ένα workflow στον επεξεργαστή
2. Σύρετε ένα αρχείο JSON στον καμβά
3. Εάν ο καμβάς έχει ήδη κόμβους ή edges, εμφανίζεται παράθυρο επιβεβαίωσης που ρωτά εάν θα αντικατασταθεί το τρέχον workflow
4. Οι εισαγόμενοι κόμβοι και edges αντικαθιστούν ή συγχωνεύονται στο τρέχον workflow

## Μορφές Αρχείων

### JSON (μεμονωμένο workflow)

```json
{
  "nodes": [...],
  "edges": [...],
  "name": "Optional workflow name"
}
```

- `nodes` – Απαιτείται· πίνακας αντικειμένων κόμβων
- `edges` – Προαιρετικό· πίνακας αντικειμένων edge (προεπιλογή `[]`)
- `name` – Προαιρετικό· χρησιμοποιείται κατά τη δημιουργία νέου workflow από την εισαγωγή στο Dashboard

### ZIP (φάκελος)

ZIP αρχείο όπου η δομή καταλόγων αντικατοπτρίζει την ιεραρχία φακέλων. Κάθε αρχείο είναι ένα workflow JSON (βλ. παραπάνω). Τα ονόματα φακέλων και workflows προέρχονται από τα ονόματα καταλόγων και αρχείων αντίστοιχα.

Ανατρέξτε στο [Workflow Structure](./workflow-structure.md) για τις μορφές κόμβων και edges.

## Περιπτώσεις Χρήσης

- **Δημιουργία αντιγράφων ασφαλείας** – Λήψη workflows ή ολόκληρων φακέλων πριν από σημαντικές αλλαγές
- **Κοινή χρήση** – Εξαγωγή και κοινή χρήση αρχείων JSON με συνεργάτες
- **Μετεγκατάσταση** – Μετακίνηση workflows ή δομών φακέλων μεταξύ instances του Heym
- **Έλεγχος εκδόσεων** – Αποθήκευση workflow JSON σε Git μαζί με κώδικα
