# Drive

Η καρτέλα Drive παρέχει ένα κεντρικό σημείο για την προβολή, τη διαχείριση και τον διαμοιρασμό όλων των αρχείων που δημιουργούνται από skills.

## Πρόσβαση στο Drive

Μεταβείτε στην καρτέλα **Drive** στον πίνακα ελέγχου. Όλα τα αρχεία που δημιουργούνται από τα skills του workflow σας εμφανίζονται εδώ, ταξινομημένα κατά ημερομηνία δημιουργίας.

## Λίστα αρχείων

Η λίστα αρχείων εμφανίζει:

- **Name** - Το αρχικό όνομα αρχείου με εικονίδιο ανά τύπο
- **Type** - Ο MIME τύπος αρχείου (π.χ. pdf, csv, docx)
- **Size** - Το μέγεθος αρχείου σε αναγνώσιμη μορφή
- **Source** - Η ετικέτα του node που δημιούργησε το αρχείο
- **Date** - Πότε δημιουργήθηκε το αρχείο
- **Actions** - Κουμπιά λήψης, διαμοιρασμού και διαγραφής

## Μαζικές ενέργειες

Κάθε αρχείο που σας ανήκει έχει ένα πλαίσιο επιλογής στην αρχή της γραμμής του. Τα αρχεία που σας έχουν κοινοποιηθεί μέσω μιας ομάδας είναι μόνο για ανάγνωση και δεν μπορούν να επιλεγούν. Επιλέξτε πολλά αρχεία (με Shift-click επιλέγεται ένα συνεχόμενο εύρος· το πλαίσιο επιλογής της κεφαλίδας επιλέγει ολόκληρη τη σελίδα) για να εμφανιστεί η γραμμή μαζικών ενερειών πάνω από τη λίστα, και έπειτα κάντε κλικ στο **Bulk actions** για να ανοίξει ένα παράθυρο διαλόγου που εφαρμόζει την ίδια ρύθμιση σε κάθε επιλεγμένο αρχείο:

- **Share all with my teams** / **Remove team sharing** — ενεργοποιεί ή απενεργοποιεί τον διαμοιρασμό με ομάδες για όλα τα επιλεγμένα αρχεία ταυτόχρονα
- **Create share link for each file** — δημιουργεί έναν σύνδεσμο διαμοιρασμού σε κάθε επιλεγμένο αρχείο χρησιμοποιώντας τις ίδιες τιμές λήξης, κωδικού πρόσβασης και μέγιστου αριθμού λήψεων

Το παράθυρο διαλόγου αναφέρει σε πόσα αρχεία εφαρμόστηκε η ενέργεια· τα αρχεία που δεν σας ανήκουν παραλείπονται. Ο επιλογέας γραμμών ανά σελίδα (25 / 50 / 100 / **All**) στο κάτω μέρος της λίστας σας επιτρέπει να φορτώσετε περισσότερα αρχεία σε μία σελίδα, ώστε να μπορείτε να επιλέξετε σε ολόκληρο το Drive σας.

## Διαμοιρασμός αρχείων

Κάντε κλικ στο εικονίδιο **Share** για να ανοίξει το παράθυρο διαλόγου διαμοιρασμού. Μπορείτε να δημιουργήσετε πολλούς συνδέσμους διαμοιρασμού ανά αρχείο με διαφορετικές ρυθμίσεις και προαιρετικά να κοινοποιήσετε το αρχείο στις τρέχουσες ομάδες σας.

### Δημόσιος σύνδεσμος (βασισμένος σε Token)

Δημιουργήστε έναν σύνδεσμο διαμοιρασμού χωρίς κωδικό πρόσβασης. Οποιοσδήποτε έχει τον σύνδεσμο μπορεί να κατεβάσει το αρχείο.

### Σύνδεσμος με προστασία κωδικού πρόσβασης (Basic Auth)

Ορίστε έναν κωδικό πρόσβασης κατά τη δημιουργία του διαμοιρασμού. Το URL λήψης χρησιμοποιεί HTTP Basic Authentication - οι browsers θα ζητήσουν όνομα χρήστη (`file`) και κωδικό πρόσβασης όταν ανοίγει ο σύνδεσμος.

### Επιλογές συνδέσμου

- **Expires (hours)** - Προαιρετικά ορίστε χρόνο λήξης
- **Max downloads** - Προαιρετικά περιορίστε τον αριθμό των λήψεων
- Και τα δύο μπορούν να συνδυαστούν για μέγιστο έλεγχο

### Διαμοιρασμός με τις ομάδες μου

Ενεργοποιήστε το **Share with my teams** για να παραχωρήσετε πρόσβαση μόνο για ανάγνωση σε όλες τις ομάδες στις οποίες ανήκετε αυτή τη στιγμή. Τα μέλη της ομάδας μπορούν να δουν και να κατεβάσουν το αρχείο από το Drive και να χρησιμοποιήσουν λειτουργίες ανάγνωσης του Drive node, αλλά μόνο ο κάτοχος του αρχείου μπορεί να διαγράψει το αρχείο, να δημιουργήσει ή να ανακαλέσει δημόσιους συνδέσμους ή να αλλάξει τον κωδικό πρόσβασης/το TTL/τα όρια λήψεων.

Η ρύθμιση είναι συγκεκριμένη για κάθε αρχείο. Εάν αργότερα συμμετάσχετε ή δημιουργήσετε μια άλλη ομάδα, ενεργοποιήστε ξανά τον διαμοιρασμό ή εκτελέστε τη λειτουργία `shareWithMyTeams` του Drive node για να προσθέσετε αυτή την ομάδα. Χρησιμοποιήστε το `unshareWithMyTeams` για να αφαιρέσετε τους διαμοιρασμούς ομάδας από το αρχείο σε ένα workflow.

### Διαχείριση διαμοιρασμών

Το παράθυρο διαλόγου διαμοιρασμού εμφανίζει όλους τους υπάρχοντες συνδέσμους διαμοιρασμού με:
- Τρέχοντα αριθμό λήψεων
- Κατάσταση λήξης
- Εάν είναι ενεργοποιημένο το Basic Auth
- Κουμπιά αντιγραφής και ανάκλησης

## Σύνδεσμοι αρχείων στο Chat & Portal

Όταν ένα skill δημιουργεί αρχεία κατά τη διάρκεια μιας εκτέλεσης workflow μέσω του Portal chat ή του Quick Drawer, οι σύνδεσμοι λήψης εμφανίζονται αυτόματα στην απάντηση. Οι χρήστες μπορούν να κάνουν κλικ για λήψη απευθείας.

## Αποθήκευση

Τα παραγόμενα αρχεία αποθηκεύονται στο σύστημα αρχείων του διακομιστή στη διαδρομή `data/files/`. Σε αναπτύξεις Docker, αυτό είναι προσαρτημένο ως volume για μονιμότητα.

## Διαχείριση αρχείων από Workflows

Το [Drive node](../nodes/drive-node.md) σας επιτρέπει να διαχειρίζεστε αρχεία Drive προγραμματιστικά μέσα από ένα workflow. Χρησιμοποιήστε το για να:

- **List** τα αρχεία σας και να επιστρέψετε μεταδεδομένα όπως όνομα αρχείου, MIME τύπο, μέγεθος, πηγή και URL λήψης
- **Delete** ένα αρχείο αφού παραδοθεί στον χρήστη
- **Share or unshare with your teams** ώστε τα μέλη της ομάδας να μπορούν να το διαβάσουν και να το κατεβάσουν μόνο όσο υπάρχει ο διαμοιρασμός ομάδας
- **Set a password** στον σύνδεσμο λήψης
- **Set a TTL** ώστε ο σύνδεσμος να λήγει μετά από N ώρες
- **Set a max downloads** όριο

Η μετατροπή ενός αρχείου σε άλλη μορφή είναι αρμοδιότητα του [Converter node](../nodes/converter-node.md), με `conversion: "fileConvert"`. Διαβάζει ένα αρχείο Drive και αποθηκεύει το μετατρεπόμενο αποτέλεσμα ως νέο αρχείο.

Ανατρέξτε στο αρχείο με το ID του από την έξοδο του skill: `$agentLabel._generated_files[0].id`

Δείτε την [τεκμηρίωση του Drive node](../nodes/drive-node.md) για λεπτομέρειες διαμόρφωσης.

## Ανάγνωση αρχείων Drive από Skills

Τα Agent skills μπορούν να ενεργοποιήσουν την ανάγνωση από το Drive με τη ρύθμιση **Enable Drive files** της κάρτας skill. Όταν είναι ενεργοποιημένη, το runtime του skill περιλαμβάνει ένα παραγόμενο βοηθητικό αρχείο `heym_drive.py`. Ο κώδικας του skill μπορεί να εισάγει βοηθητικές συναρτήσεις όπως `read_drive_text`, `read_drive_file`, `read_drive_base64`, `get_drive_file`, `get_drive_file_path` και `list_drive_files`.

Οι αναγνώσεις από το Drive περιορίζονται σε αρχεία προσβάσιμα στον δρών του workflow: αρχεία που του ανήκουν και αρχεία που του έχουν κοινοποιηθεί μέσω ομάδων. Χρησιμοποιήστε ένα file id για ακριβή αναζήτηση ή ένα ακριβές όνομα αρχείου όταν ο χρήστης αναφέρεται σε ένα αρχείο με το όνομά του. Η αναζήτηση με όνομα αρχείου επιστρέφει το νεότερο προσβάσιμο αρχείο με αυτό το όνομα· το `list_drive_files(filename="...")` επιστρέφει όλες τις αντιστοιχίσεις.

## Καθαρισμός
Τα ληγμένα share tokens καθαρίζονται αυτόματα καθημερινά. Τα ίδια τα αρχεία παραμένουν μέχρι να διαγραφούν χειροκίνητα μέσω της καρτέλας Drive. Χρησιμοποιήστε το **Clear All** για να διαγράψετε κάθε αρχείο και τους συνδέσμους διαμοιρασμού του με μία ενέργεια.
