# Ιστορικό Επεξεργασίας

Το Ιστορικό Επεξεργασίας παρακολουθεί τις αποθηκευμένες εκδόσεις ενός workflow. Χρησιμοποιήστε το για να προβάλλετε αλλαγές διαχρονικά, να συγκρίνετε εκδόσεις ή να επαναφέρετε μια προηγούμενη κατάσταση.

**Σημείωση:** Το Ιστορικό Επεξεργασίας είναι διαφορετικό από το [Ιστορικό Εκτελέσεων](./execution-history.md). Το Ιστορικό Επεξεργασίας παρακολουθεί τις **αποθηκεύσεις** (αλλαγές στη δομή του workflow)· το Ιστορικό Εκτελέσεων παρακολουθεί τις **εκτελέσεις** (παρελθούσες εκτελέσεις).

## Πού θα το Βρείτε

**Γραμμή εργαλείων επεξεργαστή** → **Ιστορικό Επεξεργασίας** (εικονίδιο GitBranch)

## Εκδόσεις

Μια νέα έκδοση δημιουργείται κάθε φορά που **Αποθηκεύετε** το workflow. Η λίστα εμφανίζει:

- **Τρέχουσα** – Η τελευταία αποθηκευμένη κατάσταση (αυτή που βλέπετε στον καμβά)
- **Έκδοση N** – Παρελθούσες αποθηκεύσεις με χρονοσημάνσεις

Οι εκδόσεις χωρίς αλλαγές σε σύγκριση με την προηγούμενη κρύβονται.

## Προβολή Διαφορών

Επιλέξτε μια έκδοση για να δείτε τι άλλαξε σε σύγκριση με το τρέχον workflow:

| Τύπος Αλλαγής | Περιγραφή |
|-------------|--------------|
| **Nodes** | Προστέθηκαν, αφαιρέθηκαν ή τροποποιήθηκαν nodes |
| **Edges** | Προστέθηκαν, αφαιρέθηκαν ή τροποποιήθηκαν συνδέσεις |
| **Config** | Ρυθμίσεις επιπέδου workflow (auth, όρια ρυθμού, κ.λπ.) |

Αναπτύξτε κάθε αλλαγή για να δείτε διαφορές σε επίπεδο πεδίου (π.χ. ποιες ιδιότητες node άλλαξαν).

## Προεπισκόπηση

Για να δείτε πώς έμοιαζε το workflow σε μια παρελθούσα έκδοση, κάντε κλικ στο **Προεπισκόπηση** δίπλα στο Επαναφορά.

Ανοίγει ένας καμβάς μόνο για ανάγνωση που εμφανίζει τα nodes και τα edges αυτής της έκδοσης. Μπορείτε να μετακινηθείτε και να κάνετε zoom για να εξερευνήσετε τη διάταξη· δεν μπορούν να γίνουν αλλαγές από αυτή την προβολή.

## Επαναφορά

Για να επαναφέρετε μια παρελθούσα έκδοση:

1. Επιλέξτε την έκδοση που θέλετε
2. Κάντε κλικ στο **Επαναφορά**
3. Επιβεβαιώστε την ενέργεια
4. Το τρέχον workflow αντικαθίσταται με την επιλεγμένη έκδοση· η σελίδα επαναφορτώνεται

Η επαναφορά δημιουργεί μια νέα "τρέχουσα" κατάσταση—μπορείτε να επαναφέρετε ξανά εάν χρειαστεί.

## Εκκαθάριση Ιστορικού

Κάντε κλικ στο εικονίδιο κάδου απορριμμάτων στην κεφαλίδα του παραθύρου διαλόγου για να αφαιρέσετε όλο το ιστορικό εκδόσεων. Αυτή η ενέργεια δεν μπορεί να αναιρεθεί. Το τρέχον workflow παραμένει· διαγράφονται μόνο οι παρελθούσες εκδόσεις.

## Πότε Δημιουργούνται Εκδόσεις

Οι εκδόσεις δημιουργούνται μόνο όταν **Αποθηκεύετε** (Ctrl/Cmd+S ή το κουμπί Αποθήκευση). Οι μη αποθηκευμένες αλλαγές δεν αποθηκεύονται στο Ιστορικό Επεξεργασίας μέχρι να αποθηκεύσετε.

Οι επεξεργασίες δεξιοτήτων Agent περιλαμβάνονται σε αυτά τα snapshots. Για να περιηγηθείτε ή να επαναφέρετε μια μεμονωμένη δεξιότητα χωρίς να επαναφέρετε ολόκληρο το workflow, χρησιμοποιήστε το κουμπί **Ιστορικό** στην κάρτα αυτής της δεξιότητας στο πάνελ ιδιοτήτων του node Agent. Ανατρέξτε στο [Node Agent](../nodes/agent-node.md#skill-history).
