# Enterprise

Εμπορική αδειοδότηση, επαγγελματική υποστήριξη και υπηρεσίες ανάπτυξης για την πλατφόρμα Heym.

## Επισκόπηση

Το Heym είναι δωρεάν στη χρήση και στη φιλοξενία σε δικό σας περιβάλλον υπό την άδεια source-available. Για οργανισμούς που χρειάζονται εμπορική αδειοδότηση, υποστήριξη ανάπτυξης παραγωγικού επιπέδου ή αποκλειστική υποστήριξη, το πρόγραμμα Enterprise παρέχει υπηρεσίες άμεσης συνεργασίας από την ομάδα του Heym.

| Υπηρεσία | Περιγραφή |
|---------|-------------|
| **Υποστήριξη Παραγωγικών Agents** | Αξιολογήσεις αρχιτεκτονικής, καθοδήγηση σχεδιασμού agents και workflows, και πρακτική βοήθεια για τη μετάβαση agents σε παραγωγή |
| **Εκπαίδευση στα Εργαλεία** | Συνεδρίες onboarding και εκπαίδευση για την ομάδα σας που καλύπτουν τον επεξεργαστή workflows, τους AI nodes, τους agents και τις ενσωματώσεις |
| **Heym Q&A** | Άμεση πρόσβαση στην ομάδα μηχανικών του Heym για ερωτήσεις σχετικά με την πλατφόρμα, βέλτιστες πρακτικές και αντιμετώπιση προβλημάτων |
| **Ανάπτυξη σε Kubernetes** | Βοήθεια με ρυθμίσεις πολλαπλών worker nodes, sidecar containers, στρατηγικές κλιμάκωσης και διαμόρφωση cluster |
| **Συμβουλευτική Λύσεων** | Σχεδιασμός προσαρμοσμένων λύσεων για τη συγκεκριμένη περίπτωση χρήσης σας, συμπεριλαμβανομένου του σχεδιασμού ενσωματώσεων και συστάσεων αρχιτεκτονικής |
| **Υποστήριξη Προτεραιότητας & SLA** | Εγγυημένοι χρόνοι απόκρισης και επίλυση ζητημάτων κατά προτεραιότητα |
| **Προσαρμοσμένη Ανάπτυξη** | Ανάπτυξη λειτουργιών και τροποποιήσεις προσαρμοσμένες στις απαιτήσεις του οργανισμού σας |

## Heym Work

Το [Heym Work](./heym-work.md) είναι η διεπαφή για επιχειρηματικές ομάδες που εκτελείται πάνω από το Heym. Οι χρήστες περιγράφουν μια εργασία, απαντούν σε μερικές ερωτήσεις και αποκτούν ένα δοκιμασμένο workflow, εργάζονται από σελίδες σχεδιασμένες για αυτούς και απαντούν σε ελέγχους, με ενιαία σύνδεση (SSO), ρόλους Owner, Editor και Viewer, και ένα όνομα σε κάθε εκτέλεση. Εκτελείται δίπλα στο Heym σας με δική του άδεια χρήσης· συνδέστε το στις **Settings → Heym Work**. Μάθετε περισσότερα και ζητήστε δοκιμαστική έκδοση στο [heym.run/enterprise](https://heym.run/enterprise).

## Υποστήριξη Παραγωγικών Agents

Η ομάδα του Heym σάς βοηθά να σχεδιάσετε, να υλοποιήσετε και να θωρακίσετε agents και workflows για τις επιχειρηματικές σας διαδικασίες. Αυτό περιλαμβάνει την αξιολόγηση των απαιτήσεών σας, τη σύσταση διαμορφώσεων nodes και τη διασφάλιση ότι τα workflows σας ακολουθούν βέλτιστες πρακτικές για αξιοπιστία, παρατηρησιμότητα και διακυβέρνηση.

Η υποστήριξη καλύπτει όλους τους τύπους nodes, συμπεριλαμβανομένων των [LLM](../nodes/llm-node.md), [Agent](../nodes/agent-node.md), [HTTP](../nodes/http-node.md) και των triggers [Cron](../nodes/cron-node.md) — καθώς και προηγμένα μοτίβα όπως η [πολυ-πρακτορική ενορχήστρωση](./agent-architecture.md), τα σημεία ελέγχου [Human-in-the-Loop](./human-in-the-loop.md) και η [παράλληλη εκτέλεση](./parallel-execution.md) μεταξύ κλάδων.

## Ανάπτυξη σε Kubernetes

Ο τυπικός οδηγός [Εκτέλεσης & Ανάπτυξης](../getting-started/running-and-deployment.md) καλύπτει το Docker Compose για ρυθμίσεις παραγωγής σε έναν διακομιστή. Οι πελάτες Enterprise λαμβάνουν βοήθεια με αναπτύξεις Kubernetes παραγωγής για υψηλή διαθεσιμότητα και οριζόντια κλιμάκωση:

- **Πολλαπλοί worker nodes** — Κατανομή των backend workers του Heym σε πολλαπλούς κόμβους Kubernetes για πλεονασμό και εξισορρόπηση φόρτου
- **Sidecar containers** — Διαμόρφωση μοτίβων sidecar για συλλογή logs, agents παρακολούθησης, service meshes (Istio, Linkerd) και έγχυση μυστικών (Vault)
- **Σχεδιασμός πόρων** — Αιτήματα/όρια CPU και μνήμης, pod disruption budgets και πολιτικές οριζόντιας αυτόματης κλιμάκωσης pods
- **Δικτύωση** — Διαμόρφωση ingress controller, τερματισμός TLS και εσωτερική επικοινωνία υπηρεσιών μεταξύ pods backend, frontend και βάσης δεδομένων
- **Μόνιμη αποθήκευση** — Παροχή όγκων για βάση δεδομένων και διανυσματικό χώρο αποθήκευσης με κατάλληλο StorageClass και στρατηγικές δημιουργίας αντιγράφων ασφαλείας
- **Παρακολούθηση** — Ενσωμάτωση με Prometheus, Grafana ή την υπάρχουσα στοίβα παρατηρησιμότητας για μετρήσεις containers, logs και ειδοποιήσεις

## Συμβουλευτική Λύσεων

Κάθε οργανισμός εκτελεί agents σε διαφορετικά συστήματα και περιορισμούς. Η ομάδα του Heym παρέχει συμβουλευτική για να σας βοηθήσει να:

- Αξιολογήσετε κατά πόσο το Heym ταιριάζει στη συγκεκριμένη περίπτωση χρήσης σας
- Σχεδιάσετε αρχιτεκτονικές agents και workflows από άκρο σε άκρο
- Σχεδιάσετε ενσωματώσεις με την υπάρχουσα υποδομή και υπηρεσίες τρίτων
- Εντοπίσετε σφάλματα σε σύνθετα workflows και να επιλύσετε ζητήματα παραγωγής
- Μετεγκαταστήσετε υπάρχοντα workflows από εργαλεία όπως n8n, Zapier ή Make.com
