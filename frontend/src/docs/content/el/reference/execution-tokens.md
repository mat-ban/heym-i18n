# Execution Tokens

Τα execution tokens είναι scoped JWTs που παρέχουν πρόσβαση στα execute και stream endpoints ενός μόνο workflow. Επιτρέπουν την κλήση ενός workflow από εξωτερικά συστήματα χωρίς την έκθεση του μακροχρόνιου token της συνεδρίας σας.

## Γιατί να Χρησιμοποιήσετε Execution Tokens

Όταν ο έλεγχος ταυτότητας ενός workflow έχει οριστεί σε **JWT**, το endpoint απαιτεί κανονικά μια έγκυρη συνεδρία χρήστη. Τα execution tokens σας επιτρέπουν να:

- Μοιράζεστε ένα callable token με εξωτερικά scripts, CI pipelines ή integrations χωρίς να μοιράζεστε τα διαπιστευτήρια του λογαριασμού σας.
- Περιορίζετε την έκθεση — ένα token είναι έγκυρο μόνο για ένα συγκεκριμένο workflow.
- Ανακαλείτε την πρόσβαση άμεσα χωρίς αλλαγή κωδικού πρόσβασης ή περιστροφή των tokens συνεδρίας.
- Επιλέγετε μεταξύ βραχύβιων tokens (λεπτά ή ώρες) και μακρόβιων tokens (έως 10 χρόνια).

## Δημιουργία ενός Token

Ανοίξτε το παράθυρο διαλόγου **Run with cURL** στον editor (γραμμή εργαλείων επάνω δεξιά). Όταν ο έλεγχος ταυτότητας του workflow έχει οριστεί σε **JWT Token**, το παράθυρο διαλόγου εμφανίζει έναν διαχειριστή token:

1. Επιλέξτε **Short-lived** ή **Long-lived (10yr)**.
2. Για βραχύβια tokens, εισαγάγετε τη διάρκεια σε δευτερόλεπτα (ελάχιστο 60).
3. Κάντε κλικ στο **+ New Token**.

Το token δημιουργείται αμέσως, προστίθεται στη λίστα και επιλέγεται αυτόματα, ώστε η εντολή cURL να ενημερωθεί για να το συμπεριλάβει.

## Λίστα Tokens

Κάθε γραμμή token εμφανίζει:

| Στήλη | Περιγραφή |
|--------|-------------|
| Created | Χρονική σήμανση δημιουργίας |
| Status | **Expires:** ημερομηνία, **Expired** ή **Revoked** |
| Eye icon | Εναλλαγή ορατότητας της τιμής του token |
| Revoke button | Σήμανση του token ως ανακληθέντος (μη αναστρέψιμη) |

Κάντε κλικ σε οποιαδήποτε ενεργή (μη ληγμένη, μη ανακληθείσα) γραμμή για να την επιλέξετε. Το επιλεγμένο token ενσωματώνεται στην προεπισκόπηση της εντολής cURL.

Τα ληγμένα και ανακληθέντα tokens παραμένουν ορατά στη λίστα αλλά δεν μπορούν να επιλεγούν.

## Χρήση ενός Token

Αντιγράψτε την τιμή του token από τη λίστα (κάντε κλικ στο eye icon για να την αποκαλύψετε) και συμπεριλάβετέ την ως token `Bearer`:

```bash
curl -X POST \
  -H "Content-Type: application/json" \
  -H "X-Trigger-Source: my-service" \
  -H "Authorization: Bearer <execution-token>" \
  "https://app.heym.ai/api/workflows/{workflow_id}/execute" \
  -d '{"message": "Hello"}'
```

Όταν χρησιμοποιείτε το **Copy cURL** στο παράθυρο διαλόγου με ένα επιλεγμένο token, το token είναι ήδη ενσωματωμένο στην εντολή — δεν απαιτείται χειροκίνητη αντικατάσταση.

## Token Scoping

Κάθε token φέρει τα εξής JWT claims:

| Claim | Τιμή |
|-------|-------|
| `sub` | User ID του δημιουργού του token |
| `wid` | Workflow UUID — το token απορρίπτεται για οποιοδήποτε άλλο workflow |
| `scope` | `workflow:execute` — το διακρίνει από ένα token συνεδρίας χρήστη |
| `jti` | Μοναδικό ID token που χρησιμοποιείται για αναζητήσεις ανάκλησης |
| `exp` | Χρονική σήμανση λήξης |

Το backend ελέγχει όλα αυτά σε κάθε αίτημα: εγκυρότητα υπογραφής, λήξη, αντιστοίχιση `wid` και ότι το `jti` δεν έχει ανακληθεί.

## Ανάκληση

Κάντε κλικ στο κουμπί ανάκλησης (circle-slash) δίπλα σε ένα token για να το ανακαλέσετε. Η ανάκληση τίθεται σε ισχύ αμέσως — τα επόμενα αιτήματα που χρησιμοποιούν αυτό το token επιστρέφουν `401`. Η γραμμή του token παραμένει ορατή στη λίστα με ετικέτα **Revoked**.

Δεν υπάρχει ακύρωση ανάκλησης. Δημιουργήστε ένα νέο token εάν χρειάζεται να αποκαταστήσετε την πρόσβαση.

## API

Τα endpoints διαχείρισης token πιστοποιούνται με την κανονική συνεδρία σας.

| Method | Path | Περιγραφή |
|--------|------|-------------|
| `POST` | `/api/workflows/{id}/execution-tokens` | Δημιουργία ενός token |
| `GET` | `/api/workflows/{id}/execution-tokens` | Λίστα των tokens σας για αυτό το workflow |
| `DELETE` | `/api/workflows/{id}/execution-tokens/{token_id}` | Ανάκληση ενός token |

**Create request body:**

```json
{ "ttl_seconds": 900 }
```

**Create response:**

```json
{
  "id": "uuid",
  "token": "<full jwt>",
  "expires_at": "2026-04-30T15:22:00Z",
  "created_at": "2026-04-30T15:07:00Z",
  "revoked": false
}
```

Το πεδίο `token` επιστρέφεται μόνο μία φορά κατά τη δημιουργία. Αποθηκεύστε το αμέσως· τα επόμενα αιτήματα `GET` επιστρέφουν την ίδια γραμμή, αλλά μπορείτε επίσης να το αποκαλύψετε στο παράθυρο διαλόγου cURL ανά πάσα στιγμή.

## Εύρος Ορατότητας

Κάθε χρήστης βλέπει μόνο τα tokens που έχει δημιουργήσει. Τα μέλη της ομάδας με πρόσβαση σε ένα κοινόχρηστο workflow δεν μπορούν να δουν τα tokens των άλλων.
