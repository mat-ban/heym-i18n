# Παράθυρο Διαλόγου Αξιολόγησης Παραστάσεων

Το Παράθυρο Διαλόγου Αξιολόγησης Παραστάσεων είναι ο εκτεταμένος επεξεργαστής για πεδία που υποστηρίζουν παραστάσεις. Ανοίγει από το κουμπί επέκτασης δίπλα σε ένα πεδίο εισαγωγής παράστασης και παρέχει μεγαλύτερο χώρο εργασίας, αυτόματη συμπλήρωση, ζωντανή προεπισκόπηση από το backend και περιήγηση εξόδου σε ένα σημείο.

## Άνοιγμα του Παραθύρου Διαλόγου

- Κάντε κλικ στο κουμπί επέκτασης δίπλα σε ένα πεδίο παράστασης στον πίνακα Ιδιοτήτων.
- Τα πεδία πολλαπλών γραμμών εμφανίζουν το κουμπί μέσα στο πεδίο εισαγωγής.
- Τα πεδία μίας γραμμής εμφανίζουν το κουμπί στα δεξιά του πεδίου εισαγωγής.

## Διάταξη Παραθύρου Διαλόγου

- Το παράθυρο διαλόγου ανοίγει ως κεντραρισμένο modal σε μέγεθος περίπου **80vw × 80vh**.
- Η κεφαλίδα εμφανίζει **Evaluate — {field name}** όταν η ετικέτα του πεδίου είναι γνωστή.
- Ο επεξεργαστής διατηρεί την αυτόματη συμπλήρωση, την πλοήγηση από πεδίο σε πεδίο και τις συνήθεις ενέργειες **Apply** / **Cancel**.
- Η προεπισκόπηση ανανεώνεται αυτόματα περίπου **300 ms** αφού σταματήσετε να πληκτρολογείτε.
- Πατήστε `Ctrl` / `Cmd` + `Enter` για να εφαρμόσετε το τρέχον κείμενο πίσω στο πεδίο και να κλείσετε το παράθυρο διαλόγου (ίδιο με το **Apply**).

## Ενότητα Εξόδου

Η περιοχή Εξόδου ανανεώνεται αυτόματα αφού σταματήσετε να πληκτρολογείτε στον επεξεργαστή.

### Αξιολόγηση

| Τύπος παράστασης | Αποτέλεσμα |
|---|---|
| Μεμονωμένο `$expr` (ολόκληρο το πεδίο) | Η αρχική τιμή διατηρείται |
| Μεμονωμένη διαδρομή με τελείες χωρίς `$` (ολόκληρο το πεδίο, χωρίς `$`, χωρίς ενσωματωμένη αλλαγή γραμμής) | Ίδιο με `$` + αυτή τη διαδρομή (το backend κανονικοποιεί για αξιολόγηση) |
| Κείμενο με ενσωματωμένα `$refs` | Το τελικό αποτέλεσμα είναι πάντα συμβολοσειρά |
| Κυριολεκτικό κείμενο (χωρίς `$`, όχι μεμονωμένη διαδρομή με τελείες) | Επιστρέφεται ως έχει |

**Παραδείγματα**

| Είσοδος | Αποτέλεσμα |
|---|---|
| `$input.items` | `[1, 2, 3]` |
| `input.items` (ίδιο με `$input.items` όταν ολόκληρη η τιμή είναι αυτή η διαδρομή) | `[1, 2, 3]` |
| `Hello $input.name` | `Hello John` |
| `$input.count + 1` | `6` |
| `just text` | `just text` |

Το πλαίσιο αξιολόγησης δημιουργείται με αυτή τη σειρά:

- **Pinned data** σε ανάντη nodes
- **Αποτελέσματα τελευταίας εκτέλεσης** από τον καμβά
- `null` όταν δεν υπάρχουν διαθέσιμα ανάντη δεδομένα

Εάν το τρέχον node έχει ανάντη εξαρτήσεις αλλά καμία από αυτές δεν έχει pinned data ή πρόσφατο αποτέλεσμα εκτέλεσης, το παράθυρο διαλόγου εκτελεί πρώτα μια δοκιμαστική εκτέλεση για να δημιουργήσει πλαίσιο και στη συνέχεια αξιολογεί το τρέχον κείμενο.

### Επιλογέας Διαδρομής Εξόδου

Όταν το αποτέλεσμα του backend είναι αντικείμενο ή πίνακας, η περιοχή Εξόδου μπορεί να εμφανίσει έναν διαδραστικό επιλογέα διαδρομής αντί για ακατέργαστο JSON.

- Κάντε διπλό κλικ σε μια γραμμή για να προσθέσετε αυτή τη διαδρομή στην τρέχουσα αναφορά `$node.path`.
- Κάντε ένα κλικ σε επεκτάσιμες γραμμές για να ανοίξετε ή να κλείσετε κλάδους.
- Χρησιμοποιήστε το ενσωματωμένο πλαίσιο αναζήτησης για αναζήτηση κλειδιών, τιμών και συμβολοσειρών διαδρομής.

## Αυτόματη Συμπλήρωση

- Πληκτρολογήστε `$` για να ανοίξετε προτάσεις για ανάντη nodes, ενσωματωμένα στοιχεία και μεθόδους.
- Πατήστε `Tab` ή `Enter` για να εισαγάγετε την επιλεγμένη πρόταση.
- Χρησιμοποιήστε `↑` / `↓` για να μετακινηθείτε στη λίστα προτάσεων.

### Παραδείγματα Απαντήσεων

Όταν συνεχίζετε μια αναφορά `$…` με τελεία, κάθε γραμμή πρότασης εμφανίζει την απάντηση που θα παρήγαγε αυτή η πρόταση, με έντονη γραφή στα δεξιά της γραμμής.

- Πληκτρολογώντας `$set.listItems.first().toString().u` εμφανίζονται τα `upper`, `urlEncode`, `urlDecode` και `unescape`, καθένα με το αξιολογημένο αποτέλεσμά του — ώστε να μπορείτε να επιλέξετε με βάση το αποτέλεσμα αντί για το όνομα.
- Πληκτρολογώντας `$node.text.toJson()` μετατρέπεται μια συμβολοσειρά JSON σε αντικείμενο ή πίνακα. Μετά το `.toJson()`, η αυτόματη συμπλήρωση μπορεί να προσφέρει τα αναλυμένα κλειδιά (για παράδειγμα `repoUrl`) όταν υπάρχει διαθέσιμη έξοδος τελευταίας εκτέλεσης ή pinned output.
- Τα αποτελέσματα αξιολογούνται στο backend με βάση τα ίδια pinned data και αποτελέσματα τελευταίας εκτέλεσης που χρησιμοποιεί η προεπισκόπηση του παραθύρου διαλόγου, ώστε να αντιστοιχούν σε αυτό που θα παράγει το πεδίο.
- Αξιολογούνται μόνο οι προτάσεις που στέκονται αυτόνομα: μέθοδοι χωρίς ορίσματα (`upper()`, `first()`, `keys()`, `toJson()`) και απλές ιδιότητες (`length`, `year`). Προτάσεις που χρειάζονται πρώτα ορίσματα — `map`, `filter`, `sort`, `replace` — παραμένουν κενές.
- Μια γραμμή παραμένει κενή όταν το υποψήφιο στοιχείο δεν παράγει απάντηση: σφάλμα, `null` ή μέθοδος που δεν εφαρμόζεται σε αυτή την τιμή.
- Οι απαντήσεις συντομεύονται σε μία γραμμή. Τοποθετήστε τον δείκτη πάνω από μια συντομευμένη απάντηση για να δείτε περισσότερα.

## Build with AI

Το κουμπί **Build with AI** εμφανίζεται στην επάνω δεξιά γωνία του παραθύρου διαλόγου αξιολόγησης όταν έχει φορτωθεί ένα workflow. Ανοίγει ένα ένθετο modal όπου μπορείτε να περιγράψετε την παράσταση που θέλετε σε απλό κείμενο και να την δημιουργήσει ένα LLM για εσάς.

### Πώς λειτουργεί

1. Κάντε κλικ στο **Build with AI** στη γραμμή εργαλείων του παραθύρου διαλόγου αξιολόγησης.
2. Επιλέξτε ένα διαπιστευτήριο LLM και μοντέλο από τα αναπτυσσόμενα μενού.
3. Πληκτρολογήστε μια περιγραφή σε απλό κείμενο για αυτό που θέλετε — για παράδειγμα, *"Get the customer name from the API response"*.
4. Κάντε κλικ στο **Generate**. Το modal καλεί το backend, το οποίο χρησιμοποιεί το system prompt του [Expression DSL](./expression-dsl.md) μαζί με τα αποτελέσματα της τελευταίας εκτέλεσης του workflow ως πλαίσιο, και επιστρέφει μία συμβολοσειρά παράστασης.
5. Η παραγόμενη παράσταση αξιολογείται αμέσως με βάση τα ίδια δεδομένα του καμβά, ώστε να μπορείτε να δείτε το αποτέλεσμα πριν την εφαρμόσετε.
6. Κάντε κλικ στο **Apply** για να αντικαταστήσετε το περιεχόμενο του επεξεργαστή με την παραγόμενη παράσταση, ή στο **Regenerate** για να δοκιμάσετε ξανά.

### Πλαίσιο που χρησιμοποιείται

Ο generator λαμβάνει τις εξόδους των nodes από την τελευταία δοκιμαστική εκτέλεση στον καμβά. Εάν το workflow δεν έχει εκτελεστεί ακόμη, το LLM δημιουργεί μια παράσταση κατά το δυνατόν καλύτερη με βάση τις ετικέτες των nodes και τις συμβάσεις του DSL.

### Απαιτήσεις

- Ένα διαπιστευτήριο LLM (OpenAI, Google ή Custom) πρέπει να έχει ρυθμιστεί στην καρτέλα [Διαπιστευτήρια](./credentials.md).
- Το workflow πρέπει να είναι ανοιχτό στον επεξεργαστή.

## Συντομεύσεις Πληκτρολογίου

| Συντόμευση | Ενέργεια |
|---|---|
| Παύση πληκτρολόγησης (~300 ms) | Ανανέωση προεπισκόπησης backend |
| `Ctrl` / `Cmd` + `Enter` | Εφαρμογή και κλείσιμο του παραθύρου διαλόγου |
| `Escape` | Κλείσιμο αυτόματης συμπλήρωσης πρώτα, διαφορετικά κλείσιμο του παραθύρου διαλόγου |
## Ένθετο `$` σε ορίσματα μεθόδων

Για αξιολόγηση dialog / backend, μπορείτε να περάσετε μια άλλη αναφορά με ένθετο `$` μέσα σε κλήσεις όπως `.get($other.field)` όταν χρειάζεστε ένα δυναμικό κλειδί. Μπορείτε επίσης να χρησιμοποιήσετε μια γυμνή διαδρομή μέσα στο `.get(...)` (για παράδειγμα `other.field`)· το backend την επιλύει με τον ίδιο τρόπο. Τα αποθηκευμένα πεδία workflow θα πρέπει να ακολουθούν τους κανόνες του [Expression DSL](./expression-dsl.md)· το evaluate API δέχεται επίσης μια γυμνή διαδρομή με τελείες σε πλήρη γραμμή για ευκολία (βλ. πίνακα παραπάνω).

## Πλοήγηση

Οι επεξεργαστές αντιστοίχισης Set και Execute μπορούν να εμφανίζουν κουμπιά **Prev** / **Next**, ώστε να μπορείτε να μετακινείστε μεταξύ πεδίων χωρίς να κλείνετε το dialog.
