# Ανάλυση αρχείων

Η ανάλυση αρχείων επιτρέπει στο Chat, στον [κόμβο Agent](../nodes/agent-node.md) και στον [κόμβο Code](../nodes/code-node.md) να ανοίγουν και να αναλύουν μεγάλα αρχεία από το [Drive](./drive.md) σε ένα απομονωμένο περιβάλλον δοκιμών (sandbox) Python. Αρχεία PDF, υπολογιστικά φύλλα, CSV, DOCX και JSON ελέγχονται πρώτα και στη συνέχεια διαβάζονται επιλεκτικά, ώστε ένα συμβόλαιο 200 σελίδων ή ένα βιβλίο εργασίας με ένα εκατομμύριο γραμμές να μην χρειάζεται ποτέ να χωρέσει εξ ολοκλήρου στο context ενός μοντέλου.

## Πώς λειτουργεί

Κάθε κλήση εκτελείται σε ένα νέο container χωρίς πρόσβαση στο δίκτυο. Τα απαιτούμενα αρχεία αντιγράφονται σε λειτουργία μόνο για ανάγνωση, ο κώδικας εκτελείται και το container αφαιρείται. Ένας μικρός φάκελος εργασίας διατηρείται μεταξύ των κλήσεων της ίδιας συνεδρίας, επιτρέποντας σε ένα επόμενο βήμα να αξιοποιήσει τα αποτελέσματα που αποθήκευσε ένα προηγούμενο.

| Διαδρομή | Περιεχόμενο |
|------|--------|
| `/input` | Τα αρχεία Drive αυτής της συνεδρίας, μόνο για ανάγνωση |
| `/work` | Χώρος εργασίας που διατηρείται κατά τη συνεδρία, π.χ. `/work/sales.pkl` |
| `/work/out` | Τα αρχεία που γράφονται εδώ αποθηκεύονται στο Drive μετά την κλήση και επιστρέφονται ως σύνδεσμοι |

Στο sandbox είναι προεγκατεστημένα τα pandas, openpyxl, xlrd, pdfplumber, pypdf, python-docx και langdetect, καθώς και το OCR Tesseract που χρησιμοποιεί ο [κόμβος Μετατροπέα](../nodes/converter-node.md).

## Εργαλεία

Το μοντέλο λειτουργεί με τρία εργαλεία, συν ένα τέταρτο στο Chat:

| Εργαλείο | Λειτουργία |
|------|----------|
| `list_files` | Παραθέτει τα αρχεία Drive που μπορείτε να ανοίξετε: όνομα, τύπος, μέγεθος, ημερομηνία |
| `inspect_file` | Επιστρέφει τον τύπο, τα μεταδεδομένα και τη δομή ενός αρχείου με ένα σύντομο δείγμα |
| `run_python` | Εκτελεί Python στα καθορισμένα αρχεία και επιστρέφει την έξοδο της κονσόλας |
| `clear_workspace` | Μόνο Chat: διαγράφει τον φάκελο εργασίας της συνομιλίας |

Το `inspect_file` διαβάζει μόνο ό,τι είναι απαραίτητο για μια σύνοψη:

| Τύπος | Σύνοψη |
|-----|-----------------|
| PDF | Αριθμός σελίδων, τίτλος και συντάκτης, δυνατότητα εξαγωγής κειμένου, γλώσσα, μεγέθη σελίδων, κείμενο και πίνακες πρώτης σελίδας. Τα σαρωμένα PDF διαβάζονται μέσω OCR (έως 5 σελίδες) |
| XLSX / XLS | Φύλλα με αριθμό γραμμών και στηλών, γραμμές κεφαλίδας, τύποι, pandas `read_hint`, ονομασμένες περιοχές, πρώτες γραμμές |
| CSV / TSV | Κωδικοποίηση, διαχωριστικό, αριθμός γραμμών, στήλες με τύπους, πρώτες γραμμές |
| DOCX | Δομή επικεφαλίδων, πίνακες, καταμέτρηση λέξεων και χαρακτήρων, συντάκτης και ημερομηνία |
| JSON | Ριζικός τύπος, κλειδιά, μήκος πίνακα, βάθος εμφώλευσης, δείγματα εγγραφών |

Μέσα στο `run_python`, ανοίξτε ένα αρχείο χρησιμοποιώντας τη μονάδα `heym_files`:

```python
import heym_files
import pandas as pd

df = pd.read_excel(heym_files.path("q3.xlsx"), sheet_name="Summary", usecols=["Region", "Amount"])
print(df.groupby("Region").Amount.sum())
df.to_csv(f"{heym_files.out_dir()}/by-region.csv", index=False)
```

## Στο Chat

Επισυνάψτε αρχεία PDF, υπολογιστικά φύλλα, DOCX, CSV ή JSON, εικόνες (PNG, JPG, GIF, WebP) ή αρχεία απλού κειμένου στην [καρτέλα Chat](../tabs/chat-tab.md), στο Chat του Heym Work ή μέσω του εργαλείου MCP `heym_chat`. Ένα μήνυμα μπορεί να περιλαμβάνει έως και 10 αρχεία. Κάθε αρχείο αποθηκεύεται στο Drive σας· μόνο το όνομα και το αναγνωριστικό του περιλαμβάνονται στο μήνυμα. Το Chat επιθεωρεί το αρχείο, διαβάζει το τμήμα που απαιτείται για την ερώτησή σας και απαντά με πίνακες ή αποσπάσματα.

## Σε workflows

Μια εκτέλεση ανοίγει μόνο τα δικά της αρχεία: εκείνα που μεταφορτώθηκαν μέσω του [Trigger Μεταφόρτωσης Αρχείου](../nodes/file-upload-trigger-node.md), εκείνα που οι κόμβοι της έγραψαν στο Drive και εκείνα που ένας [κόμβος Drive](../nodes/drive-node.md) ανέκτησε με το βήμα **Get** στην ίδια εκτέλεση.

- **Κόμβος Agent**: όταν η είσοδος ή το μήνυμα του agent περιέχει ένα αρχείο, λαμβάνει αυτόματα τα παραπάνω εργαλεία για αυτά τα αρχεία.
- **Κόμβος Code**: ορίστε το **Files** σε μια έκφραση όπως `$Upload.file.id`. Τα αρχεία προσαρτώνται και παρατίθενται στο `params.files`.

## Όρια

| Όριο | Τιμή |
|-----------|------|
| Μνήμη ανά κλήση | 2 GB |
| Χρόνος ανά κλήση | 120 δευτερόλεπτα |
| Φάκελος εργασίας ανά συνεδρία | 2 GB |
| Αρχεία εξόδου ανά κλήση | 20, έως 100 MB το καθένα |
| Εκτυπωμένη έξοδος που επιστρέφεται στο μοντέλο | 20.000 χαρακτήρες |
| Αρχεία ανά κλήση | 20 |

## Ασφάλεια

- Το sandbox δεν διαθέτει δίκτυο, δεν έχει πρόσβαση στις ρυθμίσεις ή τα μυστικά του Heym και εκτελείται ως μη προνομιούχος χρήστης.
- Τα αρχεία υποβάλλονται σε επεξεργασία αποκλειστικά εντός του sandbox.
- Στο Chat, η πρόσβαση ακολουθεί το Drive: ανοίγετε τα δικά σας αρχεία και εκείνα που μοιράζεστε με τις ομάδες σας.
- Το άνοιγμα ενός αρχείου στο Chat καταγράφεται στο αρχείο καταγραφής ελέγχου (audit log).
- Τα περιεχόμενα των αρχείων αντιμετωπίζονται αυστηρά ως δεδομένα· οι οδηγίες που περιέχονται σε αυτά δεν εκτελούνται.

## Απαιτήσεις

Η ανάλυση αρχείων απαιτεί υποδομή sandbox στο instance του Heym (Docker ή [Kubernetes](../getting-started/running-and-deployment.md#kubernetes)).
