# Καθολικές Μεταβλητές

Το **Κατάστημα Καθολικών Μεταβλητών** (Global Variable Store) αποθηκεύει μόνιμα δεδομένα key-value με εύρος χρήστη που διατηρούνται μεταξύ των εκτελέσεων workflow. Χρησιμοποιήστε το για διαμόρφωση, feature flags, μετρητές ή κοινόχρηστη κατάσταση που χρειάζονται πολλαπλά workflows.

> **Μην αποθηκεύετε μυστικά εδώ.** Οι καθολικές μεταβλητές δεν αποτελούν θησαυροφυλάκιο μυστικών: οι τιμές αποθηκεύονται χωρίς κρυπτογράφηση, επιστρέφονται πλήρως σε οποιονδήποτε τις μοιράζεστε και οι συνεργάτες μπορούν να τις επεξεργαστούν. Τα API keys, οι κωδικοί πρόσβασης και τα token ανήκουν στα [Διαπιστευτήρια](./credentials.md), τα οποία τα κρυπτογραφούν κατά την αποθήκευση και δεν επιστρέφουν ποτέ το μυστικό στον client.

## Τοπικές vs Καθολικές

| Κατάστημα | Σύνταξη | Εύρος | Μονιμότητα |
|-------|--------|-------|-------------|
| **Τοπικό Workflow** | `$vars.variableName` | Μόνο τρέχουσα εκτέλεση | Στη μνήμη, χάνεται όταν τελειώσει η εκτέλεση |
| **Καθολικό** | `$global.variableName` | Όλα τα workflows για τον χρήστη | Αποθηκεύεται στη βάση δεδομένων |

## Δημιουργία Καθολικών Μεταβλητών

1. **Από την καρτέλα Μεταβλητές** – [Καρτέλα Μεταβλητών](../tabs/global-variables-tab.md): Δημιουργήστε, επεξεργαστείτε και διαγράψτε μεταβλητές απευθείας.
2. **Από έναν node Μεταβλητής** – Ενεργοποιήστε το **Store in Global Variable Store** (`isGlobal: true`) στις ιδιότητες του node. Η μεταβλητή εγγράφεται στο κατάστημα όταν εκτελείται το workflow.

## Χρήση σε Εκφράσεις

Πρόσβαση σε καθολικές μεταβλητές με `$global.variableName`:

```
$global.environment
$global.settings.baseUrl
$global.userId
```

Χρησιμοποιήστε τις ίδιες μεθόδους όπως με τις τοπικές μεταβλητές workflow (π.χ. `.upper()`, `.length`, `.add()` για πίνακες).

## Τύποι Τιμών

Υποστηριζόμενοι τύποι: `string`, `number`, `boolean`, `array`, `object`. Επιλέξτε τον τύπο κατά τη δημιουργία ή επεξεργασία μιας μεταβλητής.

## Κοινοποίηση Καθολικών Μεταβλητών

Μπορείτε να μοιραστείτε μια καθολική μεταβλητή με άλλους χρήστες ή [Ομάδες](./teams.md) ώστε να μπορούν να τη χρησιμοποιήσουν στα δικά τους workflows.

- **Κοινοποίηση σε χρήστη** – Κάντε κλικ στο εικονίδιο κοινοποίησης δίπλα σε μια μεταβλητή που σας ανήκει, εισαγάγετε το email του παραλήπτη και κάντε κλικ στο **Share**. Ο παραλήπτης θα δει τη μεταβλητή στη λίστα Καθολικών Μεταβλητών του με σήμανση **Shared** και ετικέτα "Shared by &lt;your email&gt;".
- **Κοινοποίηση σε ομάδα** – Στο παράθυρο διαλόγου κοινοποίησης, επιλέξτε μια ομάδα και κάντε κλικ στο **Add**. Όλα τα μέλη της ομάδας αποκτούν πρόσβαση.
- **Πρόσβαση επεξεργασίας** – Οι παραλήπτες μπορούν να προβάλλουν, να επεξεργαστούν και να αναφερθούν στην κοινόχρηστη μεταβλητή μέσω `$global.variableName` στα workflows τους. Μόνο ο ιδιοκτήτης μπορεί να κοινοποιήσει, να ακυρώσει την κοινοποίηση ή να διαγράψει τη μεταβλητή.
- **Συγκρούσεις ονομάτων** – Εάν ένας παραλήπτης έχει ήδη μια μεταβλητή με το ίδιο όνομα, η δική του μεταβλητή υπερισχύει της κοινόχρηστης.
- **Ακύρωση κοινοποίησης** – Ανοίξτε το παράθυρο διαλόγου κοινοποίησης για τη μεταβλητή και κάντε κλικ στο κουμπί **×** δίπλα στον χρήστη από τον οποίο θέλετε να αφαιρέσετε την πρόσβαση.

## Ενσωμάτωση με Chat

Οι καθολικές μεταβλητές είναι διαθέσιμες στον βοηθό [Chat](../tabs/chat-tab.md). Το LLM μπορεί να αναφερθεί σε αυτές κατά την απάντηση ερωτήσεων ή τη δημιουργία περιεχομένου.
