# Guardrails

Τα Guardrails σάς επιτρέπουν να αποκλείετε μη ασφαλή ή ανεπιθύμητα μηνύματα χρηστών προτού φτάσουν σε έναν node [LLM](../nodes/llm-node.md) ή [Agent](../nodes/agent-node.md). Όταν ένα μήνυμα αντιστοιχεί σε αποκλεισμένη κατηγορία, ο node προκαλεί σφάλμα αντί να εκτελεστεί, το οποίο μπορείτε να συλλάβετε με έναν node [Error Handler](../nodes/error-handler-node.md).

## Ενεργοποίηση Guardrails

Ανοίξτε τον πίνακα Properties για έναν node **LLM** ή **AI Agent** και μεταβείτε στον διακόπτη **Enable Guardrails** (εικονίδιο ασπίδας). Η επιλογή του πλαισίου αποκαλύπτει την ενότητα διαμόρφωσης.

## Διαπιστευτήριο και Μοντέλο Guardrail

Όταν τα guardrails είναι ενεργοποιημένα, **πρέπει** να επιλέξετε ένα **διαπιστευτήριο και μοντέλο** για την ασφάλεια περιεχομένου. Ο έλεγχος guardrail χρησιμοποιεί το επιλεγμένο διαπιστευτήριο και μοντέλο από τον node — χωρίς εναλλακτική, χωρίς μεταβλητές περιβάλλοντος. Χρησιμοποιήστε ένα διαπιστευτήριο OpenAI ή Google για αξιόπιστο φιλτράρισμα περιεχομένου, ειδικά όταν το κύριο μοντέλο σας χρησιμοποιεί προσαρμοσμένο πάροχο (π.χ. Zhipu, GLM) που ενδέχεται να μην υποστηρίζει guardrails ή να επιστρέφει σφάλματα API (π.χ. 404).

Το workflow δεν μπορεί να εκτελεστεί μέχρι να επιλεγούν και το Guardrail Credential και το Guardrail Model.

## Αποκλεισμένες Κατηγορίες

Επιλέξτε μία ή περισσότερες κατηγορίες προς αποκλεισμό. Ένα μήνυμα που αντιστοιχεί σε οποιαδήποτε επιλεγμένη κατηγορία απορρίπτεται.

| Κατηγορία | Τι αποκλείει |
|---|---|
| **Violence** | Βίαιο, απειλητικό ή σωματικά επιβλαβές περιεχόμενο |
| **Hate Speech** | Διάκριση, ρατσισμός ή μισαλλοδοξία |
| **Sexual Content** | Ρητό σεξουαλικό περιεχόμενο ή σενάρια |
| **NSFW / Profanity** | Χυδαία γλώσσα, βωμολοχίες, ρητές προσβολές και αργκό ενηλίκων σε οποιαδήποτε γλώσσα |
| **Self-Harm** | Αυτοκτονία, αυτοτραυματισμός ή σχετικό περιεχόμενο |
| **Harassment** | Προσωπικές επιθέσεις, προσβολές, εκφοβισμός ή απειλές |
| **Illegal Activity** | Οδηγίες για διάπραξη παράνομων πράξεων |
| **Political Extremism** | Εξτρεμιστικό πολιτικό περιεχόμενο ή βίαιη προπαγάνδα |
| **Spam / Phishing** | Spam, phishing ή κοινωνική μηχανική |
| **Personal Data Request** | Παράκληση για ιδιωτικές ή προσωπικά αναγνωρίσιμες πληροφορίες |
| **Prompt Injection** | Απόπειρες παράκαμψης των οδηγιών συστήματος, έγχυσης κακόβουλων prompt ή χειραγώγησης της συμπεριφοράς του μοντέλου |

## Ευαισθησία

Η ρύθμιση **Sensitivity** ελέγχει πόσο αυστηρά ανιχνεύονται οι παραβάσεις:

| Επίπεδο | Συμπεριφορά |
|---|---|
| **Low** | Επισημαίνει ακόμη και οριακές ή αμφίσημες περιπτώσεις |
| **Medium** *(προεπιλογή)* | Επισημαίνει σαφείς παραβάσεις· αγνοεί οριακές περιπτώσεις |
| **High** | Επισημαίνει μόνο ακραίες, σαφείς παραβάσεις |

## Πώς Λειτουργεί η Ανίχνευση

Η ανίχνευση χρησιμοποιεί το **επιλεγμένο διαπιστευτήριο και μοντέλο guardrail**:

- **Διαπιστευτήρια OpenAI** — χρησιμοποιεί το [OpenAI Moderation API](https://platform.openai.com/docs/guides/moderation) (δωρεάν, γρήγορο, χωρίς κατανάλωση token) για τις πέντε κατηγορίες που καλύπτει εγγενώς (Violence, Hate Speech, Sexual Content, Self-Harm, Harassment). Οι υπόλοιπες κατηγορίες ελέγχονται με κλήση ταξινόμησης LLM χρησιμοποιώντας το επιλεγμένο μοντέλο guardrail.
- **Διαπιστευτήρια Google / προσαρμοσμένα** — όλες οι κατηγορίες ελέγχονται με κλήση ταξινόμησης LLM χρησιμοποιώντας το επιλεγμένο διαπιστευτήριο και μοντέλο guardrail.

Όταν το κύριο μοντέλο σας χρησιμοποιεί προσαρμοσμένο πάροχο (π.χ. Zhipu, Cerebras) που ενδέχεται να επιστρέφει 404 ή άλλα σφάλματα API, επιλέξτε ένα **διαπιστευτήριο OpenAI ή Google** για τα guardrails.

## Μορφή Σφάλματος

Όταν ενεργοποιείται ένα guardrail, ο node προκαλεί σφάλμα με το μήνυμα:

```
Guardrail violation: message blocked due to prohibited content.
Violated categories: Violence, Hate Speech
```

Το `output` του αποτελέσματος του node περιλαμβάνει επίσης το `guardrail_violated_categories` (πίνακας με τις ετικέτες των παραβιασμένων κατηγοριών), ώστε το Debug Panel και το Execution History να μπορούν να εμφανίζουν με σαφήνεια το "Blocked by: X, Y".

Χρησιμοποιήστε την επιλογή **Continue on error** του node (ή έναν [Error Handler](../nodes/error-handler-node.md)) για να δρομολογήσετε το workflow σε εναλλακτικό κλάδο όταν ενεργοποιούνται τα guardrails.

## Παράδειγμα Workflow

```
Input → Agent (guardrails: Violence, Illegal Activity, severity: Medium)
          ├── output handle → LLM → Output
          └── error handle  → Error Handler → Set("Sorry, that request was blocked.") → Output
```

## Σημειώσεις

- **Χωρίς επαναλήψεις**: Οι παραβάσεις guardrail είναι σκόπιμοι αποκλεισμοί και δεν επαναλαμβάνονται ποτέ, ακόμη και αν ο node έχει ενεργοποιημένη την επιλογή "Retry on failure".
- Δεν απαιτείται μετανάστευση βάσης δεδομένων — οι ρυθμίσεις guardrail αποθηκεύονται στο JSON του node του workflow μαζί με άλλα δεδομένα του node.
- Τα guardrails ελέγχουν το τελικό **μήνυμα χρήστη** (αφού αξιολογηθούν οι εκφράσεις προτύπου), όχι το αρχικό πρότυπο.
- Η ρύθμιση **καμίας κατηγορίας** ενώ τα guardrails είναι ενεργοποιημένα ισοδυναμεί με απενεργοποίησή τους — δεν εκτελείται κανένας έλεγχος.
- Σε **Low** ευαισθησία, η ταξινόμηση LLM εκτελείται πάντα (βέλτιστη πολυγλωσσική κάλυψη). Τα διαπιστευτήρια OpenAI εκτελούν επιπλέον το Moderation API.
- Σε **Medium/High** ευαισθησία, τα διαπιστευτήρια OpenAI χρησιμοποιούν το Moderation API για τις εγγενώς υποστηριζόμενες κατηγορίες και ταξινόμηση LLM για τις υπόλοιπες. Τα διαπιστευτήρια Google/προσαρμοσμένα χρησιμοποιούν πάντα ταξινόμηση LLM.
- Η ταξινόμηση LLM είναι **ανεξάρτητη γλώσσας** — ανιχνεύει παραβάσεις στα τουρκικά, αραβικά, ρωσικά, ισπανικά και άλλες γλώσσες.
