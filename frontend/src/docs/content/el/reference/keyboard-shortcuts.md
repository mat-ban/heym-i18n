# Συντομεύσεις Πληκτρολογίου

Το Heym παρέχει συντομεύσεις πληκτρολογίου σε ολόκληρο τον επεξεργαστή workflow και τον καμβά για την επιτάχυνση κοινών ενεργειών.

## Καθολικές Συντομεύσεις Επεξεργαστή

Αυτές οι συντομεύσεις είναι ενεργές οπουδήποτε στον επεξεργαστή workflow.

| Συντόμευση | Ενέργεια |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Άνοιγμα της Παλέτας Εντολών |
| `Ctrl + I` / `Cmd + I` | Εναλλαγή του πίνακα [AI Assistant](./ai-assistant.md) (λειτουργεί κατά την πληκτρολόγηση) |
| `Ctrl + Enter` / `Cmd + Enter` | Εκτέλεση του τρέχοντος workflow |
| `Ctrl + S` / `Cmd + S` | Αποθήκευση του workflow |
| `Ctrl + Z` / `Cmd + Z` | Αναίρεση |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Επανάληψη |
| `Ctrl + Y` / `Cmd + Y` | Επανάληψη (εναλλακτική) |
| `Escape` | Κλείσιμο ανοιχτών επικαλύψεων, παραθύρων διαλόγου και πινάκων |

## Συντομεύσεις Καμβά

Αυτές οι συντομεύσεις ισχύουν όταν ο καμβάς έχει την εστίαση (δεν είναι ενεργό κάποιο πεδίο κειμένου).

### Επιλογή & Πλοήγηση

| Συντόμευση | Ενέργεια |
|----------|--------|
| `Ctrl + A` / `Cmd + A` | Επιλογή όλων των nodes |
| `Shift` (πατημένο) | Σύρετε για επιλογή πολλαπλών nodes |
| `Ctrl` / `Cmd` (πατημένο) | Κλικ για προσθήκη μεμονωμένων nodes στην επιλογή |
| `Escape` | Αποεπιλογή όλων των nodes· κλείσιμο της ενσωματωμένης αναζήτησης nodes |

### Επεξεργασία Nodes

| Συντόμευση | Ενέργεια |
|----------|--------|
| `Ctrl + C` / `Cmd + C` | Αντιγραφή επιλεγμένου/ων node(s) |
| `Ctrl + X` / `Cmd + X` | Αποκοπή επιλεγμένου/ων node(s) |
| `Ctrl + V` / `Cmd + V` | Επικόλληση node(s) |
| `Delete` ή `Backspace` | Διαγραφή επιλεγμένου/ων node(s) ή/και edge(s) |
| `D` | Εναλλαγή ενεργοποίησης / απενεργοποίησης επιλεγμένου/ων node(s) |
| `P` | Εναλλαγή καρφιτσωμένων δεδομένων στο επιλεγμένο node |

### Ενσωματωμένη Αναζήτηση Nodes

Η πληκτρολόγηση οποιουδήποτε εκτυπώσιμου χαρακτήρα στον καμβά (όταν δεν έχει την εστίαση κάποιο πεδίο κειμένου) ανοίγει το αναδυόμενο παράθυρο ενσωματωμένης αναζήτησης nodes. Ο χαρακτήρας που πληκτρολογείται γίνεται ο πρώτος χαρακτήρας του ερωτήματος αναζήτησης.

| Συντόμευση | Ενέργεια |
|----------|--------|
| Οποιοσδήποτε εκτυπώσιμος χαρακτήρας | Άνοιγμα της ενσωματωμένης αναζήτησης nodes και έναρξη πληκτρολόγησης |
| `Backspace` | Αφαίρεση του τελευταίου χαρακτήρα από το ερώτημα αναζήτησης |
| `Escape` | Κλείσιμο της ενσωματωμένης αναζήτησης nodes |

## Παλέτα Εντολών (`Ctrl + K`)

Η Παλέτα Εντολών είναι διαθέσιμη από τον επεξεργαστή, τον πίνακα ελέγχου, την τεκμηρίωση και τις προβολές αξιολογήσεων. Σας επιτρέπει να πλοηγηθείτε γρήγορα σε workflows, καρτέλες και σελίδες τεκμηρίωσης χωρίς να αφήσετε το πληκτρολόγιο.

| Συντόμευση | Ενέργεια |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Άνοιγμα της Παλέτας Εντολών |
| `↑` / `↓` | Πλοήγηση στη λίστα αποτελεσμάτων |
| `Tab` / `Shift + Tab` | Πλοήγηση στη λίστα αποτελεσμάτων |
| `Enter` | Άνοιγμα του επιλεγμένου στοιχείου |
| `Escape` | Κλείσιμο της παλέτας |

## Συντομεύσεις Πίνακα Ελέγχου

Αυτές οι συντομεύσεις είναι ενεργές στην καρτέλα Workflows όταν δεν είναι ενεργό κάποιο άλλο πεδίο κειμένου.

| Συντόμευση | Ενέργεια |
|----------|--------|
| `Ctrl + F` / `Cmd + F` | Εστίαση στην αναζήτηση workflow |
| `Escape` | Καθαρισμός της αναζήτησης workflow όταν περιέχει κείμενο |

## Συντομεύσεις Πίνακα Ιδιοτήτων

Αυτές οι συντομεύσεις είναι ενεργές όταν είναι επιλεγμένο ένα node και ο πίνακας ιδιοτήτων είναι ανοιχτός.

| Συντόμευση | Ενέργεια |
|----------|--------|
| `Ctrl + Shift + O` / `Cmd + Shift + O` | Άνοιγμα του συνδεδεμένου sub-workflow σε νέα καρτέλα (μόνο για node Execute) |

## Συντομεύσεις Παραθύρου Αξιολόγησης

Αυτές οι συντομεύσεις είναι ενεργές όταν είναι ανοιχτό το παράθυρο διαλόγου Αξιολόγησης.

| Συντόμευση | Ενέργεια |
|----------|--------|
| `Ctrl + Enter` / `Cmd + Enter` | Εφαρμογή έκφρασης και κλείσιμο του παραθύρου διαλόγου |
| `Ctrl + Z` / `Cmd + Z` | Αναίρεση αλλαγών στον επεξεργαστή εκφράσεων |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Επανάληψη αλλαγών στον επεξεργαστή εκφράσεων |
| `Ctrl + Y` / `Cmd + Y` | Επανάληψη αλλαγών στον επεξεργαστή εκφράσεων (εναλλακτική) |

## Συντομεύσεις Ιστορικού & Εκτελέσεων

Αυτές οι συντομεύσεις είναι διαθέσιμες στο παράθυρο διαλόγου Ιστορικού Εκτελέσεων και στον πίνακα Εκτελέσεων.

| Συντόμευση | Ενέργεια |
|----------|--------|
| `S` | Εναλλαγή του πεδίου αναζήτησης για φιλτράρισμα καταχωρήσεων |
