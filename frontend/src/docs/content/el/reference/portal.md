# Portal

Το **Portal** εκθέτει τα workflows του Heym ως δημόσια περιβάλλοντα χρήσης τύπου chat. Οι τελικοί χρήστες μπορούν να εκτελούν workflows μέσω ενός URL χωρίς να συνδεθούν στο Heym.

## Τι Κάνει

- **Δημόσιο URL**: `/chat/{slug}` (π.χ. `/chat/my-workflow`)
- **Περιβάλλον chat**: Οι χρήστες αλληλεπιδρούν μέσω ενός UI chat (μηνύματα, εισροές, απαντήσεις)
- **Προαιρετικός έλεγχος ταυτότητας**: Εάν έχουν ρυθμιστεί χρήστες portal, απαιτείται σύνδεση· διαφορετικά το portal είναι δημόσιο
- **Streaming**: Πρόοδος node σε πραγματικό χρόνο κατά την εκτέλεση (όταν είναι ενεργοποιημένο)
- **Διακοπή εκτελέσεων που βρίσκονται σε εξέλιξη**: Οι χρήστες μπορούν να διακόψουν μια ενεργή εκτέλεση portal από το υποσέλιδο του chat· η ενεργή εκτέλεση του workflow ακυρώνεται και από την πλευρά του διακομιστή
- **Μεταφόρτωση αρχείων**: Προαιρετικές μεταφορτώσεις αρχείων (κείμενο, εικόνες κ.λπ.) ανά πεδίο εισόδου
- **Παράδοση σε ανθρώπινη αξιολόγηση**: Οι εκτελέσεις portal μπορούν να εμφανίζουν [συνδέσμους αξιολόγησης HITL](./human-in-the-loop.md) όταν ένας agent διακόπτεται για έγκριση
- **Εμφάνιση εικόνων**: Τα αποτελέσματα workflow που περιέχουν εικόνες (π.χ. από παραγωγή εικόνων LLM ή στιγμιότυπα Playwright) εμφανίζονται ως μικρογραφίες στο chat. Κάντε κλικ σε οποιαδήποτε εικόνα για να ανοίξετε ένα πρόγραμμα προβολής πλήρους οθόνης· πατήστε **Esc** ή χρησιμοποιήστε το κουμπί επιστροφής της συσκευής για κλείσιμο

## Διαμόρφωση Workflow

| Ρύθμιση | Περιγραφή |
|---------|-------------|
| `portal_enabled` | Ενεργοποίηση portal για αυτό το workflow |
| `portal_slug` | Slug URL (π.χ. `my-workflow` → `/chat/my-workflow`) |
| `portal_stream_enabled` | Χρήση εκτέλεσης με streaming |
| `portal_file_upload_enabled` | Να επιτρέπονται μεταφορτώσεις αρχείων |
| `portal_file_config` | Διαμόρφωση αρχείων ανά πεδίο (τύποι, όρια) |

Διαμορφώστε στον editor: Το κουμπί **Portal** στην κεφαλίδα του workflow ανοίγει το παράθυρο διαλόγου ρυθμίσεων του portal.

## Ροή

1. **Πληροφορίες**: `GET /api/portal/{slug}/info` – Επιστρέφει μεταδεδομένα workflow και πεδία εισόδου (χωρίς έλεγχο ταυτότητας)
2. **Σύνδεση** (εάν απαιτείται): `POST /api/portal/{slug}/login` – Επιστρέφει token συνεδρίας
3. **Εκτέλεση**: `POST /api/portal/{slug}/execute` – Το UI chat του portal καλεί αυτό το endpoint (ή την παραλλαγή streaming εσωτερικά όταν είναι ενεργοποιημένη)· οι τελικοί χρήστες αλληλεπιδρούν μέσω του περιβάλλοντος chat, όχι καλώντας απευθείας το API.
4. **Διακοπή**: `POST /api/portal/{slug}/executions/{execution_id}/cancel` – Ζητείται όταν ο χρήστης πατήσει **Stop** κατά τη διάρκεια μιας ενεργής εκτέλεσης portal

## HITL σε Εκτελέσεις Portal

Εάν ένα workflow portal φτάσει σε ένα [Agent Node](../nodes/agent-node.md) με ενεργοποιημένο το [Human-in-the-Loop](./human-in-the-loop.md), η απάντηση του portal εμφανίζει έναν σύνδεσμο αξιολόγησης αντί να φαίνεται κενή.

- Η κατάσταση εκτέλεσης του workflow γίνεται `pending`
- Το chat του portal εμφανίζει το URL αξιολόγησης
- Οποιοιδήποτε nodes είναι συνδεδεμένοι στη λαβή εξόδου `review` του agent μπορούν να ειδοποιήσουν άμεσα το Slack, το email ή άλλα κανάλια
- Ένας αξιολογητής ολοκληρώνει την απόφαση στο `/review/{token}` χωρίς να συνδεθεί
- Μετά την αξιολόγηση, το workflow συνεχίζεται από το αποθηκευμένο snapshot

Αυτό καθιστά δυνατό τον συνδυασμό δημόσιων ροών chat με ιδιωτικά βήματα ανθρώπινης έγκρισης.

## Πεδία Εισόδου

Τα πεδία εισόδου προέρχονται από nodes [Input](../nodes/input-node.md). Το API εξάγει nodes έναρξης τύπου `textInput` και τα `inputFields` τους. Η εκτέλεση χρησιμοποιεί την ίδια μηχανή με τις κανονικές εκτελέσεις· οι εισροές περνούν ως `body.inputs` και `conversation_history` για ροές πολλαπλών γύρων.

## Έλεγχος Ταυτότητας και Συνεδρίες

- **WorkflowPortalUser**: Όνομα χρήστη/κωδικός πρόσβασης ανά workflow (όταν είναι ενεργοποιημένος ο έλεγχος ταυτότητας)
- **PortalSession**: Tokens συνεδρίας με TTL 168 ωρών
- **Περιορισμός ρυθμού**: 3 αποτυχημένες προσπάθειες σύνδεσης → αποκλεισμός 24 ωρών ανά workflow+IP
- Οι ληγμένες συνεδρίες καθαρίζονται από μια εργασία cron

## Περιβάλλον Διαμόρφωσης

Καρτέλες **WebPortalSettingsDialog**:

1. **General**: Ενεργοποίηση portal, ορισμός slug, αντιγραφή URL portal
2. **Users**: Προσθήκη/αφαίρεση χρηστών portal (όνομα χρήστη/κωδικός πρόσβασης)
3. **Options**: Λειτουργία stream, μεταφόρτωση αρχείων, προβολή πεδίων εισόδου
