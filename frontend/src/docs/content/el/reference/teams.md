# Ομάδες

Οι Ομάδες σας επιτρέπουν να μοιράζεστε workflows, διαπιστευτήρια, καθολικές μεταβλητές, διανυσματικούς χώρους αποθήκευσης και αρχεία Drive με μια ομάδα χρηστών ταυτόχρονα.

## Επισκόπηση

- **Ομάδα** – Μια ονομασμένη ομάδα με δημιουργό και μέλη
- **Δημιουργός** – Είναι πάντα μέλος· μπορεί να επεξεργαστεί την ομάδα, να διαγράψει την ομάδα, να προσθέσει μέλη
- **Μέλος** – Μπορεί να προσθέσει και να αφαιρέσει άλλα μέλη (εκτός από τον δημιουργό)· έχει πρόσβαση σε πόρους που κοινοποιούνται με την ομάδα

## Δημιουργία και Διαχείριση Ομάδων

Δημιουργήστε ομάδες από την [καρτέλα Ομάδες](../tabs/teams-tab.md). Προσθέστε μέλη μέσω email· πρέπει να διαθέτουν λογαριασμό. Ο δημιουργός δεν μπορεί να αφαιρεθεί. Η διαγραφή μιας ομάδας αφαιρεί όλες τις κοινοποιήσεις της ομάδας.

## Μοντέλο Κοινοποίησης

Οι πόροι μπορούν να κοινοποιηθούν με:

1. **Μεμονωμένους χρήστες** – Μέσω email (κοινοποίηση χρήστη προς χρήστη)
2. **Ομάδες** – Επιλέγοντας μια ομάδα (κοινοποίηση ομάδας)

Και τα δύο μοντέλα είναι αθροιστικά. Ένας χρήστης αποκτά πρόσβαση εάν είτε:

- Του έχει κοινοποιηθεί άμεσα (κοινοποίηση χρήστη), ή
- Είναι μέλος μιας ομάδας που έχει κοινοποίηση ομάδας

## Τι Μπορεί να Κοινοποιηθεί με Ομάδες

| Πόρος | Τοποθεσία Κοινοποίησης |
|----------|----------------|
| Workflows | Παράθυρο διαλόγου κοινοποίησης στον επεξεργαστή workflow |
| Πρότυπα Workflow | Παράθυρο διαλόγου κοινοποίησης κατά τη δημιουργία/επεξεργασία προτύπου workflow |
| Πρότυπα Node | Παράθυρο διαλόγου κοινοποίησης κατά τη δημιουργία/επεξεργασία προτύπου node |
| Διαπιστευτήρια | Παράθυρο διαλόγου κοινοποίησης στην καρτέλα Διαπιστευτήρια |
| Καθολικές Μεταβλητές | Παράθυρο διαλόγου κοινοποίησης στην καρτέλα Μεταβλητές |
| Διανυσματικοί χώροι αποθήκευσης | Παράθυρο διαλόγου κοινοποίησης στην καρτέλα Vectors |
| Αρχεία Drive | Παράθυρο διαλόγου κοινοποίησης στην καρτέλα Drive ή λειτουργίες `shareWithMyTeams` / `unshareWithMyTeams` του node Drive |

Για πρότυπα, όταν η ορατότητα είναι **Συγκεκριμένοι χρήστες**, μπορείτε επίσης να επιλέξετε ομάδες. Όλα τα μέλη των επιλεγμένων ομάδων αποκτούν πρόσβαση στο πρότυπο.
Οι κοινοποιήσεις αρχείων Drive σε ομάδες είναι μόνο για ανάγνωση για τα μέλη της ομάδας· ο κάτοχος του αρχείου διατηρεί τα δικαιώματα διαχείρισης.

## Endpoints API

- `GET /api/teams` – Λίστα ομάδων στις οποίες ανήκει ο χρήστης
- `GET /api/teams/{id}` – Λήψη λεπτομερειών ομάδας με τα μέλη
- `GET /api/teams/{id}/shared-entities` – Επιστρέφει οντότητες που κοινοποιούνται με την ομάδα (workflows, διαπιστευτήρια, καθολικές μεταβλητές, διανυσματικούς χώρους αποθήκευσης, αρχεία, πρότυπα workflow, πρότυπα node)
- `POST /api/teams` – Δημιουργία ομάδας
- `PATCH /api/teams/{id}` – Ενημέρωση ομάδας
- `DELETE /api/teams/{id}` – Διαγραφή ομάδας (μόνο δημιουργός)
- `POST /api/teams/{id}/members` – Προσθήκη μέλους (body: `{ "email": "..." }`)
- `DELETE /api/teams/{id}/members/{user_id}` – Αφαίρεση μέλους

Κοινοποιήσεις ομάδας ανά πόρο:

- `GET/POST/DELETE /api/workflows/{id}/team-shares` – το body του POST δέχεται `permission` (`read` ή `write`, προεπιλογή `write`)· η εκ νέου υποβολή υπάρχουσας ομάδας ενημερώνει το δικαίωμά της
- `GET/POST/DELETE /api/credentials/{id}/team-shares`
- `GET/POST/DELETE /api/global-variables/{id}/team-shares`
- `GET/POST/DELETE /api/vector-stores/{id}/team-shares`
- `PATCH /api/files/{id}/team-sharing`
