# Ανάλυση Workflow

Η **Ανάλυση Workflow** είναι ένα αριστερό πλαϊνό πάνελ που περιέχει ένα κοινόχρηστο, επεξεργάσιμο έγγραφο Markdown ανά workflow. Χρησιμοποιήστε το για να εξηγήσετε τι κάνει ένα workflow και να καταγράψετε ιδέες βελτίωσης — και αφήστε το AI να δημιουργήσει ένα πρώτο προσχέδιο για εσάς.

Το έγγραφο είναι κοινόχρηστο: όποιος έχει πρόσβαση στο workflow μπορεί να το διαβάσει και να το επεξεργαστεί. Αποθηκεύεται μαζί με το workflow και διαγράφεται αυτόματα όταν διαγραφεί το workflow.

## Άνοιγμα του Πάνελ

1. Ανοίξτε ένα workflow στον editor.
2. Κάντε κλικ στο **Analyze** (εικονίδιο Sparkles) στη γραμμή εργαλείων του editor.
3. Το πάνελ ανοίγει στα αριστερά. Η παλέτα κόμβων (αριστερό πάνελ) συμπτύσσεται όσο αυτό είναι ανοιχτό· το άνοιγμα ξανά της παλέτας κόμβων κλείνει το πάνελ ανάλυσης.

Το πάνελ είναι διαθέσιμο μόνο για αποθηκευμένα workflows. Σε ένα ολοκαίνουργιο μη αποθηκευμένο workflow, αποθηκεύστε το πρώτα.

## Το Έγγραφο

Το πάνελ εμφανίζει ένα μόνο έγγραφο Markdown με δύο προβολές, οι οποίες εναλλάσσονται με τα κουμπιά **Edit** (μολύβι) και **Preview** (μάτι):

| Προβολή | Σκοπός |
|------|---------|
| **Edit** | Απλός editor Markdown (textarea). |
| **Preview** | Αποδοσμένο Markdown. |

Η κεφαλίδα εμφανίζει **ποιος επεξεργάστηκε τελευταία** το έγγραφο και πότε.

### Αποθήκευση

Κάντε κλικ στο **Save** για να αποθηκεύσετε τις αλλαγές σας. Το Save είναι ενεργό μόνο όταν υπάρχουν μη αποθηκευμένες αλλαγές.

Επειδή το έγγραφο είναι κοινόχρηστο, οι αποθηκεύσεις χρησιμοποιούν αισιόδοξη ταυτοχρονικότητα:

- Αν κάποιος άλλος έχει αποθηκεύσει μια νεότερη έκδοση από τότε που ανοίξατε το πάνελ, η αποθήκευσή σας απορρίπτεται και εμφανίζεται μια προειδοποίηση που αναφέρει τον άλλον συντάκτη.
- Στη συνέχεια μπορείτε να επιλέξετε **Reload (discard mine)** για να πάρετε την έκδοση του server, ή **Overwrite** για να επιβάλετε την αποθήκευση της δικής σας έκδοσης πάνω από τη δική τους.

## Ανάλυση AI

Επιλέξτε ένα **Credential** και **Model** LLM στο επάνω μέρος του πάνελ (η λίστα μοντέλων φορτώνεται από το επιλεγμένο credential — βλ. [Credentials](../tabs/credentials-tab.md)). Στη συνέχεια εκτελέστε την ανάλυση:

- **Analyze my workflow** — εμφανίζεται όταν το έγγραφο είναι κενό. Μεταδίδει (streams) μια αναφορά Markdown που δημιουργείται από AI απευθείας στον editor ως μη αποθηκευμένο προσχέδιο. Ελέγξτε και επεξεργαστείτε την, και στη συνέχεια κάντε **Save**.
- **Reanalyze** — εμφανίζεται όταν το έγγραφο έχει ήδη περιεχόμενο. Μεταδίδει μια νέα αναφορά σε ξεχωριστό **preview**, αφήνοντας το τρέχον έγγραφό σας ανέπαφο. Επιλέξτε **Accept** για να αντικαταστήσετε το περιεχόμενο του editor με τη νέα ανάλυση, ή **Discard** για να κρατήσετε αυτό που είχατε.

Και οι δύο ενέργειες πρώτα **εκτελούν το workflow** (όταν είναι έγκυρο και εκτελέσιμο) και συμπεριλαμβάνουν τα αποτελέσματα εκτέλεσης στο prompt ανάλυσης, ώστε η αναφορά να αντικατοπτρίζει το πώς συμπεριφέρεται πραγματικά το workflow. Αν το workflow δεν μπορεί να εκτελεστεί, η ανάλυση προχωρά με βάση τη στατική δομή του.

Η παραγόμενη αναφορά καλύπτει τρεις ενότητες, με τη σειρά: **Improvement areas** (συγκεκριμένες προτάσεις, συμπεριλαμβανομένης μιας οπτικής **security** κάθε φορά που το workflow αγγίζει credentials, είσοδο χρήστη, εξωτερικά αιτήματα ή έκθεση δεδομένων), τον **Purpose** του workflow, και το **What it does** (μια βήμα-προς-βήμα περιήγηση στους κόμβους).

Η ενότητα **Improvement areas** εκτελεί πάντα πέντε ρητούς ελέγχους:

1. **Error coverage** — αν ο καμβάς δεν έχει κόμβο [Error Handler](../nodes/error-handler-node.md) και δεν έχει ρυθμιστεί error workflow, η αναφορά το επισημαίνει και συνιστά την προσθήκη χειρισμού σφαλμάτων.
2. **Time saved** — αν δεν έχει οριστεί εκτιμώμενος χρόνος που εξοικονομείται ανά εκτέλεση, η αναφορά συνιστά να ρυθμιστεί ένας, ώστε να μπορεί να συμπληρωθεί η μετρική **Time Saved** των [Analytics](../tabs/analytics-tab.md).
3. **Network nodes** — για κόμβους που πραγματοποιούν δικτυακές κλήσεις (όπως [HTTP](../nodes/http-node.md) και κόμβοι ενσωμάτωσης), η αναφορά συνιστά χειρισμό σφαλμάτων ειδικά για τον κόμβο (retry ή/και continue-on-error) σε αυτούς τους κόμβους.
4. **Alerts** — όταν δεν έχουν ρυθμιστεί [alerts](../tabs/alerts-tab.md) για το workflow, η αναφορά συνιστά τη ρύθμιση ειδοποιήσεων πριν από τη μετάβαση σε prod.

5. **Evals**: όταν το workflow περιέχει έναν κόμβο [Agent](../nodes/agent-node.md) χωρίς σουίτα agent, η αναφορά συνιστά μια **Agent Suite** (ή μια **Prompt Suite**) στο [Evals](../tabs/evals-tab.md#agent-suites)· όταν περιέχει έναν κόμβο [LLM](../nodes/llm-node.md), συνιστά μια **Prompt Suite** για τη δοκιμή του prompt σε διαφορετικά μοντέλα.

### Εκτέλεση του Analyzer από τις Properties

Όταν ένα workflow έχει κόμβους στον καμβά αλλά δεν έχει ακόμη έγγραφο ανάλυσης, εμφανίζεται ένα κουμπί **Run Analyzer** στο πάνελ [Properties](./canvas-features.md) επιπέδου workflow (εμφανίζεται όταν δεν έχει επιλεγεί κόμβος). Ανοίγει αυτό το πάνελ Ανάλυσης Workflow, ώστε να μπορείτε να επιλέξετε credential και model και να δημιουργήσετε την αναφορά.

Κάθε εκτέλεση ανάλυσης καταγράφεται στα [Traces](../tabs/traces-tab.md) κάτω από την πηγή **Workflow Analysis**.

Αν δεν έχει ρυθμιστεί credential LLM, το κουμπί Analyze είναι απενεργοποιημένο — προσθέστε ένα στην [Credentials Tab](../tabs/credentials-tab.md).
