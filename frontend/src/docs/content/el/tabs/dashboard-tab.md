# Πίνακας ελέγχου

Η καρτέλα **Πίνακας ελέγχου** είναι ένας χώρος τύπου Grafana όπου δημιουργείτε πλέγματα από widgets γραφημάτων. Κάθε widget αποδίδεται από την έξοδο του δικού του κρυφού workflow του Heym, οπότε οποιαδήποτε δεδομένα μπορείτε να παράγετε σε ένα workflow — ερωτήματα βάσης δεδομένων, κλήσεις API, αναζητήσεις RAG, έξοδο LLM — μπορούν να γίνουν γράφημα. Μπορείτε να διατηρείτε πολλούς πίνακες ελέγχου και να μοιράζεστε τον καθένα με άτομα ή ομάδες.

## Πίνακες ελέγχου

Όλοι ξεκινούν με έναν πίνακα ελέγχου, που δημιουργείται την πρώτη φορά που ανοίγουν την καρτέλα. Χρησιμοποιήστε τον επιλογέα πίνακα ελέγχου στο επάνω μέρος της καρτέλας για να εναλλάσσεστε μεταξύ πινάκων ελέγχου, και το **+** δίπλα του για να δημιουργήσετε έναν νέο. Ο επιλογέας παραθέτει πρώτα τους δικούς σας πίνακες ελέγχου και μετά αυτούς που έχουν μοιραστεί μαζί σας, με ετικέτα το όνομα του ατόμου που τους μοιράστηκε.

Η καρτέλα ανοίγει ξανά τον πίνακα ελέγχου που χρησιμοποιήσατε τελευταία, και η γραμμή διεύθυνσης μεταφέρει τον ανοιχτό πίνακα ελέγχου (`?tab=dashboard&dashboard=<id>`), οπότε ένας σύνδεσμος ανοίγει αυτόν τον συγκεκριμένο πίνακα ελέγχου για οποιονδήποτε έχει πρόσβαση σε αυτόν.

Το κουμπί ρυθμίσεων (μόνο για κατόχους) μετονομάζει τον πίνακα ελέγχου, διαχειρίζεται τον διαμοιρασμό και τον διαγράφει. Η διαγραφή ενός πίνακα ελέγχου αφαιρεί τα widgets του και τα workflows τους. Διατηρείτε πάντα τουλάχιστον έναν δικό σας πίνακα ελέγχου, οπότε ο τελευταίος δεν μπορεί να διαγραφεί.

## Widgets

Ένα widget είναι ένα μεμονωμένο γράφημα στο πλέγμα. Υποστηριζόμενοι τύποι γραφημάτων:

- **Bar** (κατακόρυφο ή οριζόντιο)
- **Line**
- **Area** (συμπληρωμένη τάση, υποστηρίζει πολλαπλές σειρές)
- **Pie**
- **Table** (με δυνατότητα κύλισης)
- **Numeric** (μία μόνο τιμή KPI με προαιρετική μονάδα)
- **Gauge** (μία μόνο τιμή έναντι εύρους min–max, π.χ. ένα ποσοστό)
- **Scatter** (σημεία X/Y για γραφήματα συσχέτισης)
- **Proportion** (μία μπάρα χωρισμένη σε μερίδια με υπόμνημα ποσοστών, π.χ. ανάλυση γλωσσών)
- **Bar gauge** (ένα οριζόντιο gauge ανά γραμμή με διαβάθμιση κόκκινο→πράσινο και μια τιμή, π.χ. ελεύθερος χώρος δίσκου)
- **Text** (ένα μήνυμα markdown, π.χ. μια σημείωση κατάστασης όπως "Last execution at 19:47"; υποστηρίζει [διαδραστικά πλαίσια ελέγχου](../nodes/chart-output-node.md#interactive-task-lists) όταν το markdown είναι στατικό, και [ρητές αριθμημένες λίστες](../nodes/chart-output-node.md#numbered-lists) για προσαρμοσμένη ή φθίνουσα αρίθμηση)
- **HITL** (οι εκκρεμείς ανθρώπινες αξιολογήσεις σας. Η κεφαλίδα εμφανίζει `1/n pending`. Το όνομα του workflow ανοίγει αυτή την εκτέλεση στον καμβά. Τα **Approve**, **Request changes** και **Reject** την επιλύουν. Το εικονίδιο ιστορικού δίπλα στον τίτλο του widget ανοίγει αυτή την εκτέλεση στο παράθυρο διαλόγου ιστορικού σε αυτή τη σελίδα. Το widget δεν χρησιμοποιεί ανάντη γραμμές, και κάθε άτομο βλέπει τη δική του ουρά)

Κάθε widget φορτώνει τα δεδομένα του ασύγχρονα όταν ανοίγετε την καρτέλα, οπότε η σελίδα παραμένει αποκρίσιμη όσο συμπληρώνονται τα γραφήματα.

## Προσθήκη widget

1. Κάντε κλικ στο **Add widget**, δώστε του έναν τίτλο και επιλέξτε έναν τύπο γραφήματος. Κάτω από τον επιλογέα, το παράθυρο διαλόγου σχεδιάζει ένα παράδειγμα αυτού του τύπου γραφήματος με δείγμα δεδομένων και ονομάζει τις γραμμές που αναμένει, ώστε να μπορείτε να συγκρίνετε τύπους πριν δημιουργήσετε οτιδήποτε.
2. Το widget ανοίγει στον επεξεργαστή workflow με ένα αρχικό γράφημα: έναν node [Set](../nodes/set-node.md) που παράγει τις γραμμές, συνδεδεμένο με έναν node [Chart Output](../nodes/chart-output-node.md). Αντικαταστήστε τον node Set με οποιαδήποτε πηγή δεδομένων. Ένα widget **HITL** είναι μόνο ο node Chart Output· διαβάζει τις εκκρεμείς αξιολογήσεις σας και δεν χρειάζεται πηγή δεδομένων.
3. Δημιουργήστε το workflow ώστε ο node που τροφοδοτεί το **Chart Output** να παράγει έναν πίνακα γραμμών, και μετά διαμορφώστε την αντιστοίχιση πεδίων του node Chart Output (πεδίο ετικέτας, πεδίο τιμής κ.λπ.).
4. Αποθηκεύστε, επιστρέψτε στην καρτέλα Πίνακας ελέγχου και το widget αποδίδεται.

Κάντε διπλό κλικ σε ένα widget (ή χρησιμοποιήστε το κουμπί επεξεργασίας του) για να ανοίξετε ξανά το workflow του οποιαδήποτε στιγμή. Χρησιμοποιήστε το **Clone
widget** στην κεφαλίδα του widget για να αντιγράψετε τόσο το widget όσο και το πλήρες workflow του. Το αντίγραφο
τοποθετείται κάτω από το πρωτότυπο και επισημαίνεται με **(Copy)** ώστε να μπορείτε να το επεξεργαστείτε ανεξάρτητα.

## Δημιουργία widget με AI

Κάντε κλικ στο **AI**, περιγράψτε τη μετρική που θέλετε (για παράδειγμα, "workflow success rate over the last 30 days as a bar chart") και επιλέξτε ένα διαπιστευτήριο LLM και μοντέλο. Το Heym δημιουργεί ένα πλήρες workflow widget που καταλήγει σε έναν node Chart Output και το προσθέτει στο πλέγμα. Δείτε το [Chart Output](../nodes/chart-output-node.md#example-ai-prompts) για παραδείγματα prompts ανά τύπο γραφήματος.

Χρησιμοποιήστε το κουμπί **Fine-tune with AI** ενός widget για να αναθεωρήσετε ένα υπάρχον widget με μια νέα οδηγία. Κάθε fine-tune με AI αποθηκεύει ένα στιγμιότυπο του προηγούμενου workflow στο **Ιστορικό** του widget, ώστε να μπορείτε να αναθεωρήσετε ή να επαναφέρετε αλλαγές από τον επεξεργαστή workflow.

## Επεξεργασία της διάταξης

Ενεργοποιήστε το **Edit** για να εισέλθετε σε λειτουργία επεξεργασίας, όπου μπορείτε να σύρετε widgets και να αλλάξετε το μέγεθός τους σε ένα πλέγμα 12 στηλών. Οι αλλαγές διάταξης αποθηκεύονται αυτόματα. Οι τίτλοι των widgets είναι επεξεργάσιμοι εν σειρά από την κεφαλίδα του widget.

## Προσωρινή αποθήκευση και ανανέωση

Κάθε widget αποθηκεύει προσωρινά τα τελευταία υπολογισμένα δεδομένα του στον διακομιστή για έναν διαμορφώσιμο χρόνο ζωής (TTL). Όσο η προσωρινή αποθήκευση είναι φρέσκια, το άνοιγμα ξανά του πίνακα ελέγχου σερβίρει το αποθηκευμένο αποτέλεσμα αντί να εκτελέσει ξανά το workflow. Η προσωρινή αποθήκευση αντικαθίσταται επί τόπου κάθε φορά που τα δεδομένα επανυπολογίζονται (μία προσωρινή αποθήκευση ανά widget), και ακυρώνεται αυτόματα όταν επεξεργάζεστε το workflow του widget.

Χρησιμοποιήστε το κουμπί **Refresh** ενός widget (ή το **Refresh** στη γραμμή εργαλείων) για να παρακάμψετε την προσωρινή αποθήκευση και να επανυπολογίσετε αμέσως.
## Κοινοποίηση

Οι κάτοχοι κοινοποιούν έναν πίνακα ελέγχου από τις ρυθμίσεις του, σε μεμονωμένους χρήστες (μέσω email) ή σε οποιαδήποτε [ομάδα](teams-tab.md) στην οποία ανήκουν. Κάθε κοινοποίηση είναι **Read** ή **Write**· όταν κάποιος έχει ταυτόχρονα προσωπική και κοινοποίηση ομάδας, ισχύει η ισχυρότερη.

| Ενέργεια | Κάτοχος | Write | Read |
|--------|:-----:|:-----:|:----:|
| Προβολή widgets, ανανέωσή τους, χρήση αυτόματης ανανέωσης | ✓ | ✓ | ✓ |
| Προσθήκη, κλωνοποίηση, διαγραφή, μετονομασία και αλλαγή μεγέθους widgets· δημιουργία και βελτιστοποίηση με AI· σήμανση στοιχείων λίστας ελέγχου | ✓ | ✓ | |
| Άνοιγμα του workflow ενός widget στον editor | ✓ | ✓ | |
| Μετονομασία ή διαγραφή του πίνακα ελέγχου, διαχείριση κοινοποίησης | ✓ | | |

**Τα widgets εκτελούνται πάντα ως ο κάτοχος του πίνακα ελέγχου.** Ανεξάρτητα από το ποιος προβάλλει, ένα widget χρησιμοποιεί τα διαπιστευτήρια και τις καθολικές μεταβλητές του κατόχου, και οι εκτελέσεις του εμφανίζονται στο ιστορικό εκτελέσεων και στα traces του κατόχου. Έτσι, τα μέλη της ομάδας βλέπουν τα ίδια δεδομένα χωρίς πρόσβαση στους λογαριασμούς πίσω από αυτά, και κάθε θεατής μοιράζεται το ένα αποθηκευμένο αποτέλεσμα ανά widget. Τα widgets που προσθέτει ή κλωνοποιεί ένας συνεργάτης με δικαίωμα εγγραφής ανήκουν επίσης στον κάτοχο.

Εξαιτίας αυτού, το **Write** φέρει την ίδια εμπιστοσύνη με την κοινοποίηση ενός workflow για επεξεργασία: ένας συνεργάτης με δικαίωμα εγγραφής μπορεί να αλλάξει τι εκτελείται με τα διαπιστευτήριά σας. Παρέχετέ το μόνο σε άτομα στα οποία θα επιτρέπατε να επεξεργάζονται τα workflows σας. Μια δοκιμαστική εκτέλεση που ξεκινά ένας συνεργάτης από τον editor του workflow χρησιμοποιεί τα δικά του διαπιστευτήρια, όπως συμβαίνει με οποιοδήποτε κοινόχρηστο workflow· μόνο ο ίδιος ο πίνακας ελέγχου εκτελείται ως ο κάτοχος. Το **Read** δεν παρέχει πρόσβαση στα workflows των widgets, και οι θεατές με δικαίωμα μόνο ανάγνωσης λαμβάνουν το ίδιο το γράφημα αλλά όχι τις λεπτομέρειες εκτέλεσης ανά node πίσω από αυτό.

Η αφαίρεση μιας κοινοποίησης, ή ο υποβιβασμός της από write σε read, τίθεται σε ισχύ αμέσως.
