# Πίνακας δεδομένων

Η καρτέλα **Πίνακας δεδομένων** σας επιτρέπει να δημιουργείτε και να διαχειρίζεστε δομημένους πίνακες δεδομένων απευθείας στο Heym. Οι πίνακες μπορούν να χρησιμοποιηθούν σε workflows μέσω του [node Πίνακα δεδομένων](../nodes/datatable-node.md) για προγραμματιστικές λειτουργίες CRUD.

## Δημιουργία πίνακα

1. Μεταβείτε στην καρτέλα Πίνακας δεδομένων από τον πίνακα ελέγχου
2. Κάντε κλικ στο **Δημιουργία Πίνακα δεδομένων**
3. Εισαγάγετε ένα όνομα και προαιρετική περιγραφή
4. Προσθέστε στήλες με τον επεξεργαστή στηλών

## Στήλες

Κάθε στήλη έχει:

| Ιδιότητα | Περιγραφή |
|----------|-------------|
| Όνομα | Εμφανιζόμενο όνομα στήλης |
| Τύπος | `string`, `number`, `boolean`, `date` ή `json` |
| Απαιτείται | Εάν οι νέες γραμμές πρέπει να περιλαμβάνουν αυτή τη στήλη |
| Μοναδικό | Εάν οι τιμές πρέπει να είναι μοναδικές μεταξύ των γραμμών |
| Προεπιλεγμένη τιμή | Συμπληρώνεται αυτόματα όταν μια γραμμή παραλείπει αυτή τη στήλη |

Προσθέστε, επεξεργαστείτε ή αφαιρέστε στήλες από την κεφαλίδα της προβολής λεπτομερειών του πίνακα.

## Δημιουργία στηλών με AI

Αντί να προσθέτετε στήλες χειροκίνητα, μπορείτε να περιγράψετε τον πίνακα σε φυσική γλώσσα (ή να επικολλήσετε δείγμα JSON) και να αφήσετε ένα LLM να προτείνει το σχήμα. Και τα δύο σημεία εισόδου ανοίγουν τον ίδιο διάλογο:

- **Δημιουργία με AI** (κεφαλίδα λίστας Πίνακα δεδομένων) — δημιουργεί έναν ολοκαίνουργιο πίνακα από την περιγραφή σας.
- **Στήλες AI** (προβολή λεπτομερειών πίνακα, δίπλα στα στοιχεία ελέγχου στηλών) — προτείνει *νέες* στήλες για προσάρτηση στον πίνακα που έχετε ανοιχτό.

### Πώς λειτουργεί

1. Επιλέξτε ένα **διαπιστευτήριο LLM** και **μοντέλο** (προεπιλέγεται το πρώτο διαπιστευτήριο LLM και το τελευταίο μοντέλο του).
2. Πληκτρολογήστε μια περιγραφή — για παράδειγμα *"Ένας πίνακας βιβλίων με τίτλο, συγγραφέα, αριθμό σελίδων και αν το έχω διαβάσει"* — ή επικολλήστε ένα δείγμα/σχήμα JSON.
3. Κάντε κλικ στο **Δημιουργία**. Το μοντέλο επιστρέφει ένα προτεινόμενο σχήμα.
4. Ελέγξτε τις παραγόμενες στήλες σε επεξεργάσιμη φόρμα: αλλάξτε το **όνομα**, τον **τύπο**, την **προεπιλεγμένη τιμή**, το **μοναδικό** και το **notEmpty** (απαιτείται) για κάθε μία, διαγράψτε ανεπιθύμητες στήλες ή **Προσθέστε στήλη** χειροκίνητα. Για έναν νέο πίνακα μπορείτε επίσης να επεξεργαστείτε το **όνομα** και την **περιγραφή** που προτείνει το AI.
5. Κάντε κλικ στο **Δημιουργία πίνακα** (νέος πίνακας) ή **Προσθήκη στηλών** (υπάρχων πίνακας) για αποθήκευση. Πατήστε **Esc** για να κλείσετε τον διάλογο ανά πάσα στιγμή.

### Μόνο προσάρτηση για υπάρχοντες πίνακες

Κατά τη δημιουργία στηλών για έναν υπάρχοντα πίνακα, το μοντέλο βλέπει τις τρέχουσες στήλες σας ως πλαίσιο και προτείνει **μόνο νέες** στήλες. Οι υπάρχουσες στήλες και τα δεδομένα τους δεν τροποποιούνται ποτέ ούτε αφαιρούνται — οι παραγόμενες στήλες προσαρτώνται. Τα διπλότυπα ονόματα (χωρίς διάκριση πεζών-κεφαλαίων) απορρίπτονται αυτόματα.

> Απαιτείται ένα διαπιστευτήριο LLM (OpenAI, Google ή Custom). Εάν δεν έχετε κανένα, προσθέστε ένα στις Ρυθμίσεις πρώτα.

## Διαχείριση γραμμών

- **Προσθήκη γραμμής**: Κάντε κλικ στο κουμπί προσθήκης για να δημιουργήσετε μια νέα γραμμή
- **Ενσωματωμένη επεξεργασία**: Κάντε διπλό κλικ σε οποιοδήποτε κελί για να επεξεργαστείτε την τιμή του. Πατήστε Enter ή κάντε κλικ αλλού για αποθήκευση, Escape για ακύρωση
- **Διαγραφή γραμμής**: Χρησιμοποιήστε το μενού ενεργειών γραμμής για να αφαιρέσετε μια γραμμή
- **Σελιδοποίηση**: Οι γραμμές εμφανίζονται 25 ανά σελίδα με πλοήγηση σελίδων

## Εισαγωγή/Εξαγωγή CSV

### Εισαγωγή
1. Κάντε κλικ στο **Εισαγωγή CSV** στην προβολή λεπτομερειών του πίνακα
2. Επιλέξτε ένα αρχείο CSV για μεταφόρτωση
3. Προεπισκόπηση των πρώτων 5 γραμμών και της αντιστοίχισης στηλών
4. Οι πράσινες στήλες αντιστοιχίζονται σε υπάρχουσες στήλες του πίνακα· οι κίτρινες δεν αντιστοιχίζονται
5. Κάντε κλικ στο Εισαγωγή για μαζική εισαγωγή γραμμών

### Εξαγωγή
Κάντε κλικ στο **Εξαγωγή CSV** για να κατεβάσετε όλες τις γραμμές ως αρχείο CSV.

## Κοινοποίηση

Κοινοποιήστε πίνακες σε άλλους χρήστες ή ομάδες:

1. Ανοίξτε τον διάλογο κοινοποίησης από την προβολή λεπτομερειών του πίνακα
2. Προσθέστε χρήστες μέσω email με δικαίωμα **ανάγνωσης** ή **εγγραφής**
3. Προσθέστε ομάδες με δικαίωμα **ανάγνωσης** ή **εγγραφής**
4. Οι χρήστες με δικαίωμα μόνο ανάγνωσης μπορούν να προβάλλουν δεδομένα· οι χρήστες με δικαίωμα εγγραφής μπορούν να τροποποιούν γραμμές

## Δημιουργία πινάκων από τον Βοηθό AI

Ο [Βοηθός AI](../reference/ai-assistant.md#data-tables) του καμβά, το [Chat](./chat-tab.md) και το εργαλείο `heym_chat` στην [καρτέλα MCP](./mcp-tab.md) μπορούν να επιλέξουν έναν από τους πίνακές σας για ένα workflow που δημιουργούν ή να δημιουργήσουν έναν νέο. Προτείνουν ένα όνομα και στήλες και δημιουργούν τον πίνακα όταν υποβάλετε την κάρτα ερώτησης. Δεν αλλάζουν ποτέ τις στήλες ενός υπάρχοντος πίνακα ούτε αγγίζουν τις γραμμές του: προσθέστε ή επεξεργαστείτε στήλες εδώ.

## Χρήση σε Workflows

Ο [node Πίνακα δεδομένων](../nodes/datatable-node.md) συνδέει πίνακες με workflows. Οι λειτουργίες περιλαμβάνουν find, getAll, getById, insert, update, remove και upsert. Δεν απαιτούνται διαπιστευτήρια.

## Πίνακας κόστους LLM (πίνακας συστήματος)

Μια καρφιτσωμένη ενότητα **Πίνακες συστήματος** εμφανίζεται πάνω από τους πίνακες που έχετε δημιουργήσει, με μία μόνο καταχώριση: **Πίνακας κόστους LLM**. Πρόκειται για μια προβολή σταθερού σχήματος, επεξεργάσιμη ανά χρήστη, της τιμολόγησης ανά μοντέλο που χρησιμοποιείται από τα γραφήματα κόστους των [Εκτελέσεων](./traces-tab.md).

### Από πού προέρχονται τα δεδομένα

Το Heym διατηρεί έναν καθολικό πίνακα τιμολόγησης ανά μοντέλο, αρχικοποιημένο από το δημόσιο endpoint τιμολόγησης της Helicone (`https://www.helicone.ai/api/llm-costs`). Ο συγχρονισμός εκτελείται στο παρασκήνιο την πρώτη φορά που ανοίγετε τον πίνακα ή τις Εκτελέσεις και περιορίζεται σε μία λήψη ανά 24 ώρες. Πατήστε **Ανανέωση** για να επιβάλετε άμεσο επανασυγχρονισμό. Οι καταχωρίσεις που αφαιρούνται από την upstream λίστα της Helicone δεν διαγράφονται τοπικά, ώστε οι ιστορικές αναζητήσεις κόστους να παραμένουν σταθερές.

### Σχήμα (στήλες μόνο για ανάγνωση)

| Στήλη | Σημασία |
|---|---|
| Provider | `ANTHROPIC`, `OPENAI`, `GOOGLE`, … (ενημερωτικό, χρησιμοποιείται από τη Helicone) |
| Model | Αναγνωριστικό μοντέλου που αντιστοιχίζεται με το `trace.model` |
| Op | Τελεστής αντιστοίχισης: `equals`, `startsWith` ή `includes` |
| Input $/1M | USD ανά 1 εκατομμύριο tokens prompt |
| Output $/1M | USD ανά 1 εκατομμύριο tokens completion |
| Source | `helicone`, `seed` ή `user` |
### Προσαρμογή τιμολόγησης

- **Επεξεργασία γραμμής** για παράκαμψη των τιμών της. Η παράκαμψη είναι ανά χρήστη και επισημαίνεται με το badge `Customized`· οι μελλοντικοί συγχρονισμοί της Helicone τη διατηρούν ανέπαφη.
- **Επαναφορά προεπιλογής** αφαιρεί την παράκαμψη και επαναφέρει την καθολική τιμή για τη συγκεκριμένη γραμμή.
- **Προσθήκη προσαρμοσμένου μοντέλου** ανοίγει ένα παράθυρο διαλόγου για τη δημιουργία γραμμής αποκλειστικά για τον χρήστη (για παράδειγμα, ένα ιδιωτικό fine-tuned μοντέλο που δεν περιλαμβάνεται στη λίστα της Helicone). Οι προσαρμοσμένες γραμμές επισημαίνονται με `User added` και η διαγραφή τους τις αφαιρεί εντελώς.

### Αντιστοίχιση με traces

Όταν ο πίνακας ελέγχου Traces υπολογίζει το κόστος, αντιστοιχίζει κάθε `trace.model` με:

1. Τις παρακάμψεις σας (ακριβής αντιστοίχιση στο όνομα μοντέλου) πρώτα
2. Διαφορετικά τον καθολικό πίνακα — η ακριβής αντιστοίχιση `equals` έχει προτεραιότητα έναντι των `startsWith`/`includes`· οι ισοπαλίες εντός του ίδιου τελεστή επιλύονται με το μεγαλύτερο σε μήκος ταιριαστό πρόθεμα/υποσυμβολοσειρά μοντέλου

Εάν καμία γραμμή δεν αντιστοιχεί, το μοντέλο εμφανίζεται στην ειδοποίηση **Unpriced models** στη σελίδα Traces· η συνεισφορά του στο κόστος είναι μηδενική μέχρι να προσθέσετε μια προσαρμοσμένη γραμμή ή να παρακάμψετε κάποια.
