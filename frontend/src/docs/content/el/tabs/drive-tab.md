# Καρτέλα Drive

Η καρτέλα Drive εμφανίζει όλα τα αρχεία που δημιουργούνται από skills σε όλα τα workflows σας.

## Επισκόπηση

Τα αρχεία που δημιουργούνται από skills (PDF, DOCX, CSV, εικόνες κ.λπ.) αποθηκεύονται και καταγράφονται αυτόματα στην καρτέλα Drive. Κάθε αρχείο εμφανίζει το όνομα, τον τύπο, το μέγεθος, τον node προέλευσης, την ημερομηνία δημιουργίας και την κατάσταση κοινοποίησης στην ομάδα.

## Δυνατότητες

- **Αναζήτηση** - Φιλτράρετε αρχεία κατά όνομα, τύπο ή node προέλευσης
- **Αντιγραφή ID αρχείου** - Αντιγράψτε το UUID του αρχείου στο πρόχειρο, έτοιμο για επικόλληση σε έναν node [Drive](../nodes/drive-node.md) ή [Converter](../nodes/converter-node.md)
- **Λήψη** - Πιστοποιημένη λήψη για τα αρχεία σας και τα αρχεία που κοινοποιούνται σε εσάς μέσω ομάδων
- **Κοινοποίηση** - Δημιουργήστε συνδέσμους λήψης προς κοινοποίηση με προαιρετική προστασία κωδικού πρόσβασης και λήξη, ή κοινοποιήστε ένα αρχείο με δικαιώματα μόνο ανάγνωσης στις τρέχουσες ομάδες σας
- **Διαγραφή** - Αφαιρέστε αρχεία και τους συνδέσμους κοινοποίησής τους
- **Εκκαθάριση όλων** - Διαγράψτε κάθε αρχείο και τους συνδέσμους κοινοποίησής του μετά από επιβεβαίωση
- **Μαζικές ενέργειες** - Επιλέξτε πολλά αρχεία με πλαίσια επιλογής (Shift-click για εύρος) και εφαρμόστε την ίδια ενέργεια σε όλα ταυτόχρονα
- **Σελιδοποίηση** - Περιηγηθείτε σε μεγάλες συλλογές αρχείων, με επιλογέα γραμμών ανά σελίδα (25 / 50 / 100 / Όλα)

## Μαζικές Ενέργειες

Τα αρχεία που σας ανήκουν εμφανίζουν ένα πλαίσιο επιλογής στην αρχή της γραμμής τους (τα αρχεία που κοινοποιούνται σε εσάς μέσω ομάδας είναι μόνο ανάγνωσης και δεν είναι επιλέξιμα). Επιλέξτε πολλές γραμμές — ή χρησιμοποιήστε το πλαίσιο επιλογής της κεφαλίδας για να επιλέξετε ολόκληρη τη σελίδα, και **Shift-click** για να επιλέξετε εύρος — και στη συνέχεια χρησιμοποιήστε τη γραμμή μαζικών ενεργειών που εμφανίζεται πάνω από τη λίστα:

- **Λήψη ZIP** συσκευάζει κάθε επιλεγμένο αρχείο σε ένα ενιαίο αρχείο ZIP και το λαμβάνει
- **Μαζικές ενέργειες** ανοίγει ένα παράθυρο διαλόγου για να εφαρμόσετε μία ρύθμιση σε κάθε επιλεγμένο αρχείο:
  - **Κοινοποίηση όλων στις ομάδες μου** / **Αφαίρεση κοινοποίησης ομάδας** με ένα κλικ
  - **Δημιουργία συνδέσμου κοινοποίησης για κάθε αρχείο** χρησιμοποιώντας τις ίδιες ρυθμίσεις κωδικού πρόσβασης, λήξης και μέγιστου αριθμού λήψεων
- **Διαγραφή** αφαιρεί κάθε επιλεγμένο αρχείο και τους συνδέσμους κοινοποίησής του μετά από επιβεβαίωση
- **Εκκαθάριση επιλογής** αποεπιλέγει τα πάντα

Το παράθυρο διαλόγου αναφέρει σε πόσα αρχεία εφαρμόστηκε (τα αρχεία που δεν σας ανήκουν παραλείπονται). Χρησιμοποιήστε την επιλογή **Όλα** του επιλογέα γραμμών ανά σελίδα για να φορτώσετε κάθε αρχείο σε μία σελίδα και να επιλέξετε σε ολόκληρο το Drive σας. Η πληκτρολόγηση στο πεδίο αναζήτησης αλλάζει αυτόματα τον επιλογέα γραμμών ανά σελίδα σε **Όλα**, ώστε η αναζήτηση να καλύπτει κάθε αρχείο, όχι μόνο την τρέχουσα σελίδα· η εκκαθάριση της αναζήτησης επαναφέρει την προηγούμενη επιλογή σας.

## Κοινοποίηση

Δημιουργήστε συνδέσμους κοινοποίησης με:
- **Χωρίς πιστοποίηση** - Δημόσιο URL λήψης βασισμένο σε token
- **Basic Auth** - Σύνδεσμος με προστασία κωδικού πρόσβασης (όνομα χρήστη: `file`)
- **Λήξη** - Προαιρετική λήξη βάσει χρόνου
- **Όρια λήψεων** - Προαιρετικός μέγιστος αριθμός λήψεων

Ενεργοποιήστε την επιλογή **Κοινοποίηση στις ομάδες μου** σε ένα αρχείο για να το κάνετε ορατό σε όλες τις ομάδες στις οποίες ανήκετε αυτή τη στιγμή. Τα μέλη της κοινόχρηστης ομάδας αποκτούν δικαιώματα μόνο ανάγνωσης· οι ενέργειες διαχείρισης παραμένουν αποκλειστικά στον κάτοχο.

## Πρόσβαση Agent Skill

Τα skills στον node Agent μπορούν να ενεργοποιήσουν την ανάγνωση αρχείων Drive. Όταν η επιλογή **Ενεργοποίηση αρχείων Drive** είναι ενεργοποιημένη για ένα skill, ο κώδικας Python του μπορεί να διαβάζει προσβάσιμα αρχεία Drive κατά ID αρχείου ή ακριβές όνομα αρχείου μέσω του παραγόμενου βοηθητικού αρχείου `heym_drive.py`. Η ρύθμιση είναι απενεργοποιημένη από προεπιλογή.

Ανατρέξτε στην [αναφορά Drive](../reference/drive.md) για πλήρεις λεπτομέρειες.
