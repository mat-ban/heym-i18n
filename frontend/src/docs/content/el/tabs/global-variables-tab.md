# Καρτέλα Μεταβλητών

Η καρτέλα **Μεταβλητές** διαχειρίζεται τον **Καθολικό Χώρο Αποθήκευσης Μεταβλητών** – επίμονα δεδομένα κλειδιού-τιμής που κοινοποιούνται σε όλα τα workflows σας.

## Επισκόπηση

- Δημιουργία, επεξεργασία και διαγραφή καθολικών μεταβλητών
- Οι μεταβλητές είναι περιορισμένες στον χρήστη και παραμένουν σε όλες τις εκτελέσεις workflow
- Αναφορά σε εκφράσεις μέσω `$global.variableName`

## Δημιουργία Μεταβλητής

1. Κάντε κλικ στο **Νέα Μεταβλητή**
2. Εισαγάγετε ένα **όνομα** (χρησιμοποιείται σε εκφράσεις)
3. Ορίστε την **τιμή** (string, number, boolean, array ή object)
4. Επιλέξτε **τύπο τιμής** (Auto, String, Number, Boolean, Array, Object)

## Επεξεργασία και Διαγραφή

- **Επεξεργασία** – Κάντε κλικ στο εικονίδιο επεξεργασίας σε μια γραμμή μεταβλητής
- **Διαγραφή** – Κάντε κλικ στο εικονίδιο κάδου απορριμμάτων· τα workflows που τη χρησιμοποιούν θα χρειαστούν αντικατάσταση
- **Μαζική διαγραφή** – Επιλέξτε πολλαπλές μεταβλητές και χρησιμοποιήστε **Διαγραφή επιλεγμένων**

## Χρήση σε Workflows

Αναφέρετε μεταβλητές σε οποιαδήποτε έκφραση:

```
$global.environment
$global.settings.baseUrl
```

Μπορείτε επίσης να ορίσετε καθολικές μεταβλητές από έναν [node Μεταβλητής](../nodes/variable-node.md) ενεργοποιώντας την επιλογή **Αποθήκευση στον Καθολικό Χώρο Αποθήκευσης Μεταβλητών**.
