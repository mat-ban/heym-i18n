# Καρτέλα Χρονοδιαγραμμάτων

Η καρτέλα **Χρονοδιαγράμματα** εμφανίζει όλα τα ενεργά cron workflows σε ένα οπτικό ημερολόγιο. Εναλλάξτε μεταξύ προβολών ημέρας, εβδομάδας και μήνα για να δείτε πότε είναι προγραμματισμένες να εκτελεστούν οι αυτοματοποιήσεις σας.

## Προβολές

- **Ημέρα** – Χρονολόγιο ανά ώρα για την επιλεγμένη ημέρα· κάθε εκτέλεση εμφανίζεται ως block στην προγραμματισμένη ώρα της
- **Εβδομάδα** – Πλέγμα επτά στηλών που καλύπτει την τρέχουσα εβδομάδα· τα blocks στοιβάζονται όταν πολλαπλά workflows ενεργοποιούνται την ίδια ώρα
- **Μήνας** – Πλέγμα ολόκληρου του μήνα· κάθε κελί παραθέτει τα workflows που είναι προγραμματισμένα να εκτελεστούν εκείνη την ημέρα

## Blocks Workflow

Κάθε block εμφανίζει:

- **Όνομα workflow** – Κάντε κλικ για να ανοίξετε απευθείας τον καμβά του workflow
- **Έκφραση Cron** – Ορατή κατά την αιώρηση, εμφανίζοντας το ακατέργαστο χρονοδιάγραμμα (π.χ. `0 9 * * 1-5`)

## Πλοήγηση

Οι διαχειριστές instance που αναφέρονται στο `HEYM_ADMIN_EMAILS` βλέπουν τα χρονοδιαγράμματα κάθε κατόχου όταν είναι επιλεγμένη η επιλογή **Show all workflows**. Αποεπιλέξτε την για να βλέπετε μόνο τα δικά σας workflows. Οι υπόλοιποι χρήστες διατηρούν την επιλογή **Show shared with me**. Για να αποσύρετε την αυτοματοποίηση ενός υπαλλήλου, χρησιμοποιήστε τα [instance administration controls](./workflows-tab.md#instance-administration) στην προεπισκόπηση Workflows για παύση ή συνέχιση των triggers.

- Χρησιμοποιήστε τα βέλη **previous / next** για να μετακινηθείτε μεταξύ ημερών, εβδομάδων ή μηνών
- Το κουμπί **Today** επιστρέφει στην τρέχουσα ημερομηνία άμεσα
