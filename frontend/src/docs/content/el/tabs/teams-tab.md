# Καρτέλα Teams

Η καρτέλα **Teams** σας επιτρέπει να δημιουργείτε και να διαχειρίζεστε ομάδες για την κοινή χρήση workflows, διαπιστευτηρίων, μεταβλητών, διανυσματικών χώρων αποθήκευσης και αρχείων Drive με ομάδες χρηστών.

## Δημιουργία Ομάδας

1. Κάντε κλικ στο **New Team**
2. Εισαγάγετε ένα όνομα και προαιρετικά μια περιγραφή
3. Κάντε κλικ στο **Create**

Γίνεστε αυτόματα ο δημιουργός της ομάδας και το πρώτο μέλος.

## Διαχείριση Μελών

- **Add member** – Εισαγάγετε το email ενός χρήστη στο παράθυρο λεπτομερειών της ομάδας και κάντε κλικ στο **Add**
- **Remove member** – Κάντε κλικ στο X δίπλα σε ένα μέλος (ο δημιουργός δεν μπορεί να αφαιρεθεί)
- **Edit team** – Οι δημιουργοί μπορούν να επεξεργαστούν το όνομα και την περιγραφή
- **Delete team** – Οι δημιουργοί μπορούν να διαγράψουν την ομάδα· όλες οι κοινοποιήσεις της ομάδας αφαιρούνται
- **Shared resources** – Το παράθυρο λεπτομερειών της ομάδας εμφανίζει workflows, διαπιστευτήρια, μεταβλητές, διανυσματικούς χώρους αποθήκευσης, αρχεία Drive, πρότυπα workflow και πρότυπα node που έχουν κοινοποιηθεί στην ομάδα. Κάντε κλικ σε ένα workflow για να το ανοίξετε στον editor· μεταβείτε στην αντίστοιχη καρτέλα για άλλους πόρους.

## Κοινοποίηση με Ομάδες

Κοινοποιήστε πόρους με ομάδες από:

- **Workflows** – Παράθυρο κοινοποίησης στον editor workflow
- **Workflow Templates** – Παράθυρο κοινοποίησης κατά τη δημιουργία/επεξεργασία ενός προτύπου workflow (ορατότητα: Specific users)
- **Node Templates** – Παράθυρο κοινοποίησης κατά τη δημιουργία/επεξεργασία ενός προτύπου node (ορατότητα: Specific users)
- **Credentials** – Παράθυρο κοινοποίησης στην καρτέλα Credentials
- **Variables** – Παράθυρο κοινοποίησης στην καρτέλα Variables
- **Vector Stores** – Παράθυρο κοινοποίησης στην καρτέλα Vectors
- **Dashboards** – Ρυθμίσεις Dashboard στην καρτέλα Dashboard (read ή write)
- **Drive Files** – Παράθυρο κοινοποίησης στην καρτέλα Drive ή λειτουργίες `shareWithMyTeams` / `unshareWithMyTeams` του node Drive

Όταν κοινοποιείτε σε μια ομάδα, όλα τα μέλη της ομάδας αποκτούν πρόσβαση. Ανατρέξτε στο [Teams](../reference/teams.md) για λεπτομέρειες.

Όταν κοινοποιείτε ένα workflow σε μια ομάδα, κοινοποιήστε επίσης τα διαπιστευτήρια και τα sub-workflows από τα οποία εξαρτάται το workflow στην ίδια ομάδα. Η πρόσβαση στο workflow από μόνη της δεν παρέχει πρόσβαση σε διαπιστευτήρια ή child workflow.

## Ενσωμάτωση Chat

Ο AI assistant της [καρτέλας Chat](./chat-tab.md) μπορεί να εμφανίσει τις ομάδες σας. Ρωτήστε "my teams" για να δείτε σε ποιες ομάδες ανήκετε.
