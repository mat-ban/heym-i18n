# Καρτέλα Traces

Η καρτέλα **Traces** εμφανίζει traces εκτέλεσης LLM. Επιθεωρήστε τα payloads αιτημάτων/αποκρίσεων, τον χρονισμό, τις κλήσεις εργαλείων και αποσφαλματώστε τη συμπεριφορά των κόμβων [Agent](../nodes/agent-node.md) και [LLM](../reference/node-types.md), καθώς και συγκεντρωτικές μετρήσεις (κλήσεις, tokens, κόστος, καθυστέρηση, ποσοστό σφαλμάτων) σε οποιοδήποτε χρονικό παράθυρο.

## Επικεφαλίδα Στατιστικών

Η σελίδα ανοίγει με μια σύνοψη στατιστικών πάνω από τη λίστα traces, υπολογισμένη στο επιλεγμένο χρονικό εύρος και με τα υπόλοιπα ενεργά φίλτρα:

- **Κάρτες KPI** – Total Calls, Total Tokens, Total Cost (USD), Avg Latency, Error %
- **Tokens by Model** – Γράφημα ντόνατ του όγκου tokens ανά μοντέλο
- **Cost by Model** – Γράφημα ντόνατ της δαπάνης σε USD ανά μοντέλο. Τα μοντέλα χωρίς τιμολόγηση εμφανίζουν σύνδεσμο "Configure pricing" προς τον [LLM Cost Table](./datatable-tab.md#llm-cost-table-system-table)
- **Calls Over Time** – Γράφημα στοιβαγμένης περιοχής επιτυχημένων vs αποτυχημένων κλήσεων ανά κάδο (5 min / 1 h / 6 h / 1 day, επιλεγμένο αυτόματα ανά εύρος)
- **Unpriced models notice** – Εμφανίζεται κάτω από τα γραφήματα όταν ορισμένα traced μοντέλα δεν έχουν γραμμή τιμολόγησης, με σύνδεσμο προς τον LLM Cost Table

## Χρονικό Εύρος

Ένας μόνο επιλογέας **Time range** στην κορυφή της γραμμής φίλτρων καθοδηγεί τόσο την επικεφαλίδα στατιστικών όσο και τη λίστα traces. Επιλογές: Last 1 hour, Last 24 hours, Last 7 days (προεπιλογή), Last 30 days, All time. Η αλλαγή του εύρους επαναφέρει τη σελιδοποίηση και επαναφορτώνει μαζί τα γραφήματα και τη λίστα.

## Λίστα Traces

- Σελιδοποιημένη λίστα πρόσφατων traces εντός του επιλεγμένου χρονικού εύρους
- Κάθε trace εμφανίζει: workflow, node, credential, χρονική σήμανση, διάρκεια
- Κάντε κλικ σε ένα trace για να ανοίξετε την προβολή λεπτομερειών
- Χρησιμοποιήστε **Prev / Next** μέσα στο παράθυρο λεπτομερειών για να μετακινηθείτε μεταξύ traces χωρίς να το κλείσετε

## Φιλτράρισμα

- **Time range** – 1h / 24h / 7d / 30d / All; φιλτράρει μαζί γραφήματα και λίστα
- **Credential** – Φιλτράρισμα κατά credential (API key) που χρησιμοποιήθηκε
- **Source** – Φιλτράρισμα κατά πηγή workflow ή εκτέλεσης
- **Search** – Αναζήτηση κατά μοντέλο, workflow, credential ή ετικέτα node
- **Refresh** – Επαναφόρτωση της τρέχουσας σελίδας traces

## Λεπτομέρειες Trace

Όταν ανοίγετε ένα trace:

- **Steps** – Ένα χρονολόγιο από πάνω προς τα κάτω που διαβάζει το trace ως διατεταγμένη αλυσίδα: System → User → Assistant → Tool → Answer. Κάθε βήμα είναι συμπτυσσόμενο· η ανάπτυξη ενός εμφανίζει μια ευανάγνωστη λεπτομέρεια (κείμενο μηνύματος ή τα ορίσματα και το αποτέλεσμα ενός εργαλείου) ακολουθούμενη από το JSON αυτού του βήματος. Το περιεχόμενο JSON σε κάθε τύπο συμβάντος—συμπεριλαμβανομένων των κλήσεων MCP και των payloads JSON-RPC—ανοίγει από προεπιλογή σε αναπτυσσόμενο δέντρο, με το πρώτο επίπεδο ανεπτυγμένο. Χρησιμοποιήστε **Tree / Raw** για εναλλαγή μεταξύ της μορφοποιημένης δομής και του αρχικού κειμένου. Το κακοσχηματισμένο JSON παραμένει ορατό ως απλό κείμενο. Τα βήματα εργαλείων εμφανίζουν τη διάρκειά τους και ένα σήμα MCP/Skill όπου ισχύει, καθώς και σήματα pending / timeout / cancelled όταν έχει οριστεί η κατάσταση της κλήσης εργαλείου. Το βήμα Answer μπορεί να εμφανίσει συγκεντρωτικά σήματα `tool_metrics` (πλήθη κλήσεων ανά κατάσταση και συνολική διάρκεια εργαλείων). Όταν ένα trace καταγράφει κάθε κλήση μοντέλου, όπως κάνει ένα μήνυμα Dashboard Chat και ένας δρομολογημένος agent, ένα βήμα **LLM** βρίσκεται πριν από τα εργαλεία που ζήτησε η κλήση, και το **Duration Breakdown** παραθέτει κάθε κλήση μοντέλου, εργαλείο και απόφαση δρομολόγησης σε ένα χρονολόγιο. Ένα μήνυμα Dashboard Chat είναι ένα μόνο trace, ανεξάρτητα από τον αριθμό των γύρων εργαλείων που χρειάστηκαν. Τα traces χωρίς αλυσίδα μηνυμάτων (για παράδειγμα η παραγωγή εικόνας) εμφανίζουν ένα ελάχιστο χρονολόγιο Request → Response.
- **Request** – Πλήρες payload αιτήματος που στάλθηκε στο LLM, με προβολές JSON **Tree / Raw**
- **Response** – Απόκριση μοντέλου, συμπεριλαμβανομένων τυχόν κλήσεων εργαλείων, με προβολές JSON **Tree / Raw**
- **Tool metrics** – Όταν υπάρχουν στην απόκριση, μια συμπαγής σύνοψη των πλήθων κλήσεων εργαλείων (`success` / `error` / `pending` / `timeout` / `cancelled`) και της συνολικής διάρκειας εργαλείων
- **Timing breakdown** – `llm_ms`, `tools_ms`, `mcp_list_ms` για ανάλυση απόδοσης
- **Tool calls** – Όνομα εργαλείου, ορίσματα, αποτέλεσμα, κατάσταση και χρόνος που πέρασε
- **Skills included** – Skills που πέρασαν στο μοντέλο στο αίτημα
- **Go to Workflow** – Μετάβαση απευθείας στο σχετικό workflow από το παράθυρο λεπτομερειών trace

## Αντιγραφή και Εξαγωγή

- Αντιγραφή του JSON αιτήματος ή απόκρισης στο πρόχειρο· η αντιγραφή χρησιμοποιεί πάντα το πλήρες raw payload ανεξάρτητα από την ενεργή προβολή
- Χρήσιμο για αποσφαλμάτωση ή κοινοποίηση με την υποστήριξη

## Συντήρηση

- **Clear All** – Διαγραφή όλων των αποθηκευμένων traces μετά από επιβεβαίωση
- Τα στοιχεία ελέγχου σελιδοποίησης εμφανίζουν το τρέχον ορατό εύρος (για παράδειγμα `1-25 of 240`)
