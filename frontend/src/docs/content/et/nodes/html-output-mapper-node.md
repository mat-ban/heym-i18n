# HTML output mapper

**HTML output mapper** node renderdab ühe HTML-malli leheks. Kasutage seda siis, kui kutsuja on **brauser**, mitte API-klient — workflow vastab `text/html`-iga JSON-i asemel.

## Ülevaade

| Property | Value |
|----------|-------|
| Inputs | 1 |
| Outputs | 0 (sink) |
| Runtime output | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Parameetrid

| Parameter | Type | Description |
|-----------|------|-------------|
| `label` | string | Node'i identifikaator (camelCase) |
| `html` | string | Lehe mall. `$nodeLabel.field` avaldised interpoleeritakse kohapeal. |
| `statusCode` | number | Vastuse HTTP staatus (vaikimisi `200`) |
| `contentType` | string | Vastuse sisutüüp (vaikimisi `text/html; charset=utf-8`) |

## Webhooki ja käivituse käitumine

Kui see node on workflow **ainus** terminalne väljund, vastab execute endpoint renderdatud lehega, konfigureeritud staatuskoodiga ja konfigureeritud sisutüübiga — ilma JSON-ümbriseta, ilma label-wrapperita.

Kaks asja lülitavad selle välja:

- **Teine terminalne node.** Kui graafis on veel üks aktiivne terminal, naaseb Heym tavalise per-label JSON-kaardi juurde ja leht saabub string-väljana.
- **`X-Simple-Response: false`.** See päis küsib täielikku ümbrist koos `status`, `node_results` ja ajastustega, mida kasutab redaktori lõuend. Saatke see, kui silute lehe workflow'd.

## Lehe serveerimine brauserile

Määrake workflow **request method**-iks `GET` cURL-dialoogis, et tavaline brauseri navigatsioon selleni jõuaks. `GET`-päring ei kanna body't, seega inputid tulevad query stringist:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Lugege neid väärtusi `$input.query.name`-iga. Vaadake [Webhooks](../reference/webhooks.md) täieliku meetodilepingu jaoks.

Workflow, millel pole trigger-nodet ja mille ainus terminal on see node, kuvab **WEB**-märgise [Workflows tab](../tabs/workflows-tab.md)-is.

## Agendi tööriista kasutamine

Ei ole toetatud. See node on terminalne sink, seega ei saa seda kinnitada [Agent Node](./agent-node.md) tools handle'i külge. Sama kehtib [JSON output mapper](./json-output-mapper-node.md) kohta.

## Loop'i piirang

Sama reegel nagu [Output](./output-node.md) puhul: ärge paigutage seda node'i loop'i iteratsiooniharru — ainult pärast loop'i `done` haru. Vaadake [Loop](./loop-node.md).

## Näide

```json
  "type": "htmlOutputMapper",
  "data": {

    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
