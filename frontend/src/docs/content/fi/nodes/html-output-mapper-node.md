# HTML-outputin mapper

**HTML-outputin mapper** -solmu renderöi yhden HTML-mallin sivustoksi. Käytä sitä, kun kutsujana on **selain** API-asiakkaan sijaan – workflow vastaa `text/html`-muodossa JSONin sijaan.

## Yleiskatsaus

| Ominaisuus | Arvo |
|----------|-------|
| Syötteet | 1 |
| Tulosteet | 0 (nielu) |
| Suorituksen output | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Parametrit

| Parametri | Tyyppi | Kuvaus |
|-----------|------|-------------|
| `label` | merkkijono | Solmun tunniste (camelCase) |
| `html` | merkkijono | Sivumalli. `$nodeLabel.field`-lausekkeet interpoloituvat paikoilleen. |
| `statusCode` | numero | HTTP-vastauksen statuskoodi (oletus `200`) |
| `contentType` | merkkijono | Vastauksen sisältötyyppi (oletus `text/html; charset=utf-8`) |

## Webhook- ja suorituskäyttäytyminen

Kun tämä solmu on workflown **ainoa** terminaalituloste, suoritusendpoint vastaa renderöidyllä sivulla, määritetyllä statuskoodilla ja sisältötyypillä – ilman JSON-käärettä tai tunnisteen käärettä.

Kaksi asiaa poistaa tämän toiminnan:

- **Toinen terminaalisolmu.** Kun graafissa on toinen aktiivinen terminaali, Heym palaa normaaliin tunnistekohtaiseen JSON-karttaan ja sivu saapuu merkkijonokenttänä.
- **`X-Simple-Response: false`.** Tämä otsake pyytää täydellistä käärettä, joka sisältää `status`, `node_results` ja ajankäytön – kuten editorin canvas käyttää. Lähetä se, kun debuggaat sivustoworkflowa.

## Sivun tarjoaminen selaimelle

Aseta workflown **pyynnön metodi** arvoon `GET` cURL-dialogissa, jotta tavallinen selainnavigointi pääsee käsiksi siihen. `GET`-pyyntö ei sisällä runkoa, joten syötteet tulevat kyselymerkkijonosta:

```bash
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Lue nämä arvot `$input.query.name` -lausekkeella. Katso [Webhookit](../reference/webhooks.md) täydellistä metodisopimusta varten.

Workflow, jossa ei ole trigger-solmua ja jonka ainoa terminaali on tämä solmu, näyttää **WEB**-merkin [Workflowt-välilehdessä](../tabs/workflows-tab.md).

## Agenttityökalun käyttö

Ei tuettu. Tämä solmu on terminaalinielu, joten sitä ei voi liittää [Agenttisolmun](./agent-node.md) työkalujen kahvaan. Sama koskee [JSON-outputin mapperia](./json-output-mapper-node.md).

## Silmukkarajoitus

Sama sääntö kuin [Output](./output-node.md) -solmussa: älä sijoita tätä solmua silmukan iterointihaaraan – vain silmukan `done`-haaran jälkeen. Katso [Silmukka](./loop-node.md).

## Esimerkki

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
