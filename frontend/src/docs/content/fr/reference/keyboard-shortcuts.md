# Raccourcis clavier

Heym met à disposition des raccourcis clavier dans l'éditeur de workflow et sur le canvas afin d'accélérer les actions courantes.

## Raccourcis globaux de l'éditeur

Ces raccourcis sont actifs partout dans l'éditeur de workflow.

| Raccourci | Action |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Ouvrir la palette de commandes |
| `Ctrl + I` / `Cmd + I` | Afficher/masquer le panneau [Assistant IA](./ai-assistant.md) (fonctionne pendant la saisie) |
| `Ctrl + Enter` / `Cmd + Enter` | Exécuter le workflow en cours |
| `Ctrl + S` / `Cmd + S` | Enregistrer le workflow |
| `Ctrl + Z` / `Cmd + Z` | Annuler |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Rétablir |
| `Ctrl + Y` / `Cmd + Y` | Rétablir (variante) |
| `Escape` | Fermer les superpositions, boîtes de dialogue et panneaux ouverts |

## Raccourcis du canvas

Ces raccourcis s'appliquent lorsque le canvas a le focus (aucune saisie de texte n'est active).

### Sélection et navigation

| Raccourci | Action |
|----------|--------|
| `Ctrl + A` / `Cmd + A` | Sélectionner tous les nœuds |
| `Shift` (maintenu) | Glisser pour sélectionner plusieurs nœuds |
| `Ctrl` / `Cmd` (maintenu) | Cliquer pour ajouter des nœuds individuellement à la sélection |
| `Escape` | Désélectionner tous les nœuds ; fermer la recherche de nœuds en ligne |

### Édition des nœuds

| Raccourci | Action |
|----------|--------|
| `Ctrl + C` / `Cmd + C` | Copier le(s) nœud(s) sélectionné(s) |
| `Ctrl + X` / `Cmd + X` | Couper le(s) nœud(s) sélectionné(s) |
| `Ctrl + V` / `Cmd + V` | Coller le(s) nœud(s) |
| `Delete` ou `Backspace` | Supprimer le(s) nœud(s) et/ou lien(s) sélectionné(s) |
| `D` | Activer / désactiver le(s) nœud(s) sélectionné(s) |
| `P` | Activer/désactiver les données épinglées sur le nœud sélectionné |

### Recherche de nœuds en ligne

La saisie de tout caractère imprimable sur le canvas (lorsqu'aucune saisie de texte n'a le focus) ouvre la fenêtre contextuelle de recherche de nœuds en ligne. Le caractère saisi devient le premier caractère de la requête de recherche.

| Raccourci | Action |
|----------|--------|
| Tout caractère imprimable | Ouvrir la recherche de nœuds en ligne et commencer la saisie |
| `Backspace` | Supprimer le dernier caractère de la requête de recherche |
| `Escape` | Fermer la recherche de nœuds en ligne |

## Palette de commandes (`Ctrl + K`)

La palette de commandes est accessible depuis l'éditeur, le tableau de bord, la documentation et les vues d'évaluations. Elle permet de naviguer rapidement vers les workflows, les onglets et les pages de documentation sans quitter le clavier.

| Raccourci | Action |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Ouvrir la palette de commandes |
| `↑` / `↓` | Parcourir la liste des résultats |
| `Tab` / `Shift + Tab` | Parcourir la liste des résultats |
| `Enter` | Ouvrir l'élément sélectionné |
| `Escape` | Fermer la palette |

## Raccourcis du tableau de bord

Ces raccourcis sont actifs dans l'onglet Workflows lorsqu'aucune autre saisie de texte n'est active.

| Raccourci | Action |
|----------|--------|
| `Ctrl + F` / `Cmd + F` | Placer le focus sur la recherche de workflows |
| `Escape` | Effacer la recherche de workflows lorsqu'elle contient du texte |

## Raccourcis du panneau de propriétés

Ces raccourcis sont actifs lorsqu'un nœud est sélectionné et que le panneau de propriétés est ouvert.

| Raccourci | Action |
|----------|--------|
| `Ctrl + Shift + O` / `Cmd + Shift + O` | Ouvrir le sous-workflow lié dans un nouvel onglet (nœud Execute uniquement) |

## Raccourcis de la boîte de dialogue Évaluer

Ces raccourcis sont actifs lorsque la boîte de dialogue Évaluer est ouverte.

| Raccourci | Action |
|----------|--------|
| `Ctrl + Enter` / `Cmd + Enter` | Appliquer l'expression et fermer la boîte de dialogue |
| `Ctrl + Z` / `Cmd + Z` | Annuler les modifications dans l'éditeur d'expression |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Rétablir les modifications dans l'éditeur d'expression |
| `Ctrl + Y` / `Cmd + Y` | Rétablir les modifications dans l'éditeur d'expression (variante) |

## Raccourcis Historique et Traces

Ces raccourcis sont disponibles dans la boîte de dialogue Historique d'exécution et dans le panneau Traces.

| Raccourci | Action |
|----------|--------|
| `S` | Afficher/masquer le champ de recherche pour filtrer les entrées |
