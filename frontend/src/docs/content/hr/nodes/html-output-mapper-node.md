# HTML output mapper

Čvor **HTML output mapper** renderira jedan HTML predložak u stranicu. Koristite ga kada je pozivatelj **preglednik**, a ne API klijent — workflow tada odgovara s `text/html` umjesto JSON-a.

## Pregled

| Svojstvo | Vrijednost |
|----------|-------|
| Ulazi | 1 |
| Izlazi | 0 (sink) |
| Izlaz u izvođenju | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Parametri

| Parametar | Tip | Opis |
|-----------|------|-------------|
| `label` | string | Identifikator čvora (camelCase) |
| `html` | string | Predložak stranice. Izrazi `$nodeLabel.field` interpoliraju se na mjestu. |
| `statusCode` | number | HTTP status odgovora (zadano `200`) |
| `contentType` | string | Vrsta sadržaja odgovora (zadano `text/html; charset=utf-8`) |

## Ponašanje Webhooka i izvođenja

Kada je ovaj čvor **jedini** završni izlaz workflowa, execute endpoint odgovara renderiranom stranicom, konfiguriranim statusnim kodom i konfiguriranom vrstom sadržaja — bez JSON omotnice, bez omotača s oznakom.

Dvije stvari to isključuju:

- **Drugi završni čvor.** Uz još jedan aktivni završni čvor u grafu, Heym se vraća na uobičajenu JSON mapu po oznakama i stranica dolazi kao string polje.
- **`X-Simple-Response: false`.** Taj zaglavlje zahtijeva punu omotnicu s `status`, `node_results` i vremenima, što je ono što koristi platno u editoru. Pošaljite ga kada otklanjate pogreške u workflowu stranice.

## Posluživanje stranice pregledniku

Postavite **request method** workflowa na `GET` u cURL dijalogu kako bi obična navigacija preglednikom došla do njega. `GET` zahtjev ne nosi tijelo, pa ulazi dolaze iz query stringa:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Te vrijednosti čitajte s `$input.query.name`. Pogledajte [Webhooks](../reference/webhooks.md) za puni ugovor o metodama.

Workflow bez trigger čvora čiji je jedini završni čvor ovaj čvor prikazuje **WEB** oznaku u [Workflows tab](../tabs/workflows-tab.md).

## Korištenje kao Agent tool

Nije podržano. Ovaj čvor je završni sink, pa se ne može priključiti na tools ručku [Agent Node](./agent-node.md). Isto vrijedi i za [JSON output mapper](./json-output-mapper-node.md).

## Ograničenje petlje

Isto pravilo kao kod [Output](./output-node.md): ne postavljajte ovaj čvor unutar grane iteracije petlje — samo nakon grane `done` petlje. Pogledajte [Loop](./loop-node.md).

## Primjer

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
