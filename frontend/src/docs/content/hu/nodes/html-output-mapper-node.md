# HTML output mapper

A **HTML output mapper** csomópont egyetlen HTML sablont renderel egy oldalba. Akkor használja, amikor a hívó egy **böngésző**, nem pedig egy API-kliens — a workflow `text/html` választ ad JSON helyett.

## Áttekintés

| Tulajdonság | Érték |
|----------|-------|
| Bemenetek | 1 |
| Kimenetek | 0 (sink) |
| Futásidejű kimenet | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Paraméterek

| Paraméter | Típus | Leírás |
|-----------|------|-------------|
| `label` | string | Csomópont-azonosító (camelCase) |
| `html` | string | Az oldalsablon. A `$nodeLabel.field` kifejezések a helyükön kerülnek behelyettesítésre. |
| `statusCode` | number | A válasz HTTP státuszkódja (alapértelmezett: `200`) |
| `contentType` | string | A válasz tartalomtípusa (alapértelmezett: `text/html; charset=utf-8`) |

## Webhook és futtatási viselkedés

Amikor ez a csomópont a workflow **egyetlen** terminális kimenete, az execute endpoint a renderelt oldallal, a beállított státuszkóddal és a beállított tartalomtípussal válaszol — JSON-burkoló és címke-wrapper nélkül.

Két dolog kapcsolja ezt ki:

- **Egy második terminális csomópont.** Ha a gráfban egy másik aktív terminális is található, a Heym visszaáll a szokásos, címkénkénti JSON-térképre, és az oldal string mezőként érkezik.
- **`X-Simple-Response: false`.** Ez a fejléc a teljes burkolót kéri `status`, `node_results` és időzítések mezőkkel, amit a szerkesztő vászna használ. Akkor küldje, amikor egy oldal-workflow-t hibakeres.

## Oldal kiszolgálása böngészőnek

Állítsa a workflow **request method** értékét `GET`-re a cURL párbeszédablakban, hogy egy egyszerű böngészőnavigáció elérje. A `GET` kérés nem tartalmaz body-t, így a bemenetek a query stringből származnak:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Ezeket az értékeket a `$input.query.name` kifejezéssel olvashatja ki. A teljes metódusszerződést lásd a [Webhooks](../reference/webhooks.md) oldalon.

Egy olyan workflow, amelynek nincs trigger csomópontja, és amelynek egyetlen terminálisa ez a csomópont, egy **WEB** jelvényt jelenít meg a [Workflows tab](../tabs/workflows-tab.md) oldalon.

## Agent tool használat

Nem támogatott. Ez a csomópont egy terminális sink, így nem csatolható egy [Agent Node](./agent-node.md) tools fogantyújához. Ugyanez vonatkozik a [JSON output mapper](./json-output-mapper-node.md) csomópontra is.

## Loop megkötés

Ugyanaz a szabály, mint az [Output](./output-node.md) esetében: ne helyezze ezt a csomópontot egy loop iterációs ágába — csak a loop `done` ága után. Lásd: [Loop](./loop-node.md).

## Példa

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
