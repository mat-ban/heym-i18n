# Pemeta Output HTML

Node **Pemeta keluaran HTML** merender satu templat HTML menjadi sebuah halaman. Gunakan node ini ketika pemanggil adalah **browser** alih-alih klien API — workflow akan merespons dengan `text/html` alih-alih JSON.

## Ikhtisar

| Properti | Nilai |
|----------|-------|
| Input | 1 |
| Output | 0 (sink) |
| Keluaran runtime | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Parameter

| Parameter | Tipe | Deskripsi |
|-----------|------|-------------|
| `label` | string | Pengidentifikasi node (camelCase) |
| `html` | string | Templat halaman. Ekspresi `$nodeLabel.field` diinterpolasi di tempat. |
| `statusCode` | number | Status HTTP untuk respons (default `200`) |
| `contentType` | string | Tipe konten respons (default `text/html; charset=utf-8`) |

## Perilaku Webhook dan eksekusi

Ketika node ini merupakan **satu-satunya** keluaran terminal dari workflow, endpoint eksekusi akan merespons dengan halaman yang dirender, kode status yang dikonfigurasi, dan tipe konten yang dikonfigurasi — tanpa envelope JSON, tanpa pembungkus label.

Dua hal menonaktifkan perilaku tersebut:

- **Node terminal kedua.** Dengan terminal aktif lain di dalam graph, Heym akan kembali ke peta JSON per-label yang normal dan halaman akan tiba sebagai field string.
- **`X-Simple-Response: false`.** Header tersebut meminta envelope lengkap dengan `status`, `node_results`, dan timing, yang digunakan oleh kanvas editor. Kirimkan header ini ketika Anda sedang men-debug workflow halaman.

## Menyajikan halaman ke browser

Atur **request method** workflow ke `GET` di dialog cURL agar navigasi browser biasa dapat menjangkaunya. Permintaan `GET` tidak membawa body, sehingga input berasal dari query string:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Baca nilai-nilai tersebut dengan `$input.query.name`. Lihat [Webhooks](../reference/webhooks.md) untuk kontrak method selengkapnya.

Workflow tanpa node trigger yang satu-satunya terminal adalah node ini akan menampilkan chip **WEB** di [tab Workflows](../tabs/workflows-tab.md).

## Penggunaan sebagai alat Agent

Tidak didukung. Node ini merupakan sink terminal, sehingga tidak dapat dilampirkan ke handle tools [Agent Node](./agent-node.md). Hal yang sama berlaku untuk [Pemeta keluaran JSON](./json-output-mapper-node.md).

## Batasan Loop

Aturan yang sama seperti [Output](./output-node.md): jangan tempatkan node ini di dalam cabang iterasi loop—hanya setelah cabang `done` loop. Lihat [Loop](./loop-node.md).

## Contoh

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
