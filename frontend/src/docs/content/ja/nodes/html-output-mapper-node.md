# HTML 出力マッパー

**HTML output mapper** ノードは、単一の HTML テンプレートをページとしてレンダリングします。呼び出し元が API クライアントではなく **ブラウザ** である場合に使用します。この場合、Workflow は JSON ではなく `text/html` で応答します。

## 概要

| プロパティ | 値 |
|----------|-------|
| 入力 | 1 |
| 出力 | 0（sink） |
| ランタイム出力 | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## パラメータ

| パラメータ | 型 | 説明 |
|-----------|------|-------------|
| `label` | string | ノード識別子（camelCase） |
| `html` | string | ページテンプレート。`$nodeLabel.field` 式はその場で展開されます。 |
| `statusCode` | number | レスポンスの HTTP ステータス（デフォルト `200`） |
| `contentType` | string | レスポンスのコンテンツタイプ（デフォルト `text/html; charset=utf-8`） |

## Webhook と実行時の動作

このノードが Workflow の **唯一の** 終端出力である場合、execute エンドポイントはレンダリングされたページ、設定されたステータスコード、および設定されたコンテンツタイプで応答します。JSON エンベロープも label ラッパーも付きません。

次の 2 つの条件でこの動作は無効になります。

- **2 つ目の終端ノード。** グラフ内に別のアクティブな終端が存在する場合、Heym は通常の label ごとの JSON マップにフォールバックし、ページは文字列フィールドとして返されます。
- **`X-Simple-Response: false`。** このヘッダーは `status`、`node_results`、タイミング情報を含む完全なエンベロープを要求します。これはエディタのキャンバスが使用する形式です。ページ Workflow をデバッグする際に送信してください。

## ブラウザへのページ配信

プレーンなブラウザナビゲーションで到達できるように、cURL ダイアログで Workflow の **request method** を `GET` に設定してください。`GET` リクエストはボディを持たないため、入力はクエリ文字列から取得します。

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

これらの値は `$input.query.name` で読み取ります。メソッドの完全な契約については [Webhooks](../reference/webhooks.md) を参照してください。

Trigger ノードを持たず、唯一の終端がこのノードである Workflow は、[Workflows タブ](../tabs/workflows-tab.md) に **WEB** チップを表示します。

## Agent ツールとしての使用

サポートされていません。このノードは終端 sink であるため、[Agent Node](./agent-node.md) の tools ハンドルに接続することはできません。[JSON output mapper](./json-output-mapper-node.md) にも同じことが当てはまります。

## ループの制約

[Output](./output-node.md) と同じルールです。このノードをループイテレーションの分岐内に配置しないでください。配置できるのはループの `done` 分岐の後のみです。[Loop](./loop-node.md) を参照してください。

## 例

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
