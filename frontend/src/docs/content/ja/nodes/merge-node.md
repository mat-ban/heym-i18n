# マージ

**Merge** ノードは、複数の並列入力を待機し、それらを単一の出力に統合します。並列ブランチの結果を結合してから処理を続行する必要がある場合に使用します。

## 概要

| プロパティ | 値 |
|----------|-------|
| 入力 | n（設定可能） |
| 出力 | 1 |
| 出力 | `$nodeLabel.merged` – 各ブランチからの入力を含むオブジェクト |

## パラメータ

| パラメータ | 型 | 説明 |
|-----------|------|-------------|
| `label` | string | ノード識別子（camelCase） |
| `inputCount` | number | 待機する入力の数（デフォルト: 2） |

## 使用する場面

- 並列ブランチの結果を**結合**または**統合**する必要がある場合に使用します
- 個別の [Output](./output-node.md) ノードで終了する並列 Workflow には使用し**ないでください**
- 各入力ブランチが統合された出力に寄与します

## 例

```json
{
  "type": "merge",
  "data": {
    "label": "combineResults",
    "inputCount": 2
  }
}
```

複数のブランチを Merge ノードに接続します。このノードは、出力を生成する前にすべての入力を待機します。
