# 待機

**Wait** ノードは、指定された時間だけ Workflow の実行を一時停止します。レート制限、遅延アクション、ポーリング間隔などにご利用ください。

## 概要

| プロパティ | 値 |
|----------|-------|
| 入力 | 1 |
| 出力 | 1 |
| 出力内容 | 入力をそのまま通過 |

## パラメータ

| パラメータ | 型 | 説明 |
|-----------|------|-------------|
| `label` | string | ノード識別子（camelCase） |
| `duration` | number | 遅延時間（ミリ秒単位、例：1000 = 1秒）。エディタでは 1 から 900000（15分）まで指定可能です |

## 例

```json
{
  "type": "wait",
  "data": {
    "label": "delayOneSecond",
    "duration": 1000
  }
}
```
