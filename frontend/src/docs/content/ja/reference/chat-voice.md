# チャット音声 (TTS & STT)

チャットタブでは、[ElevenLabs](https://elevenlabs.io) を活用して、メッセージの読み上げとハンズフリーのインタラクティブ音声モードを利用できます。どちらの方向も1つの ElevenLabs クレデンシャルを使用します。再生には**テキスト読み上げ（text-to-speech）**、マイクには **Scribe 音声認識（speech-to-text）** を使用します。

## セットアップ

1. **Settings**（右上のアバター）→ **Voice** タブを開きます。
2. **ElevenLabs クレデンシャル**を選択するか、**Add credential** をクリックして新規作成します。API キーには、ElevenLabs アカウントで **Text to Speech**、**Speech to Text**、**Voices** の権限を有効にする必要があります。
3. ElevenLabs アカウントから**ボイス**を選択します。
4. **Save Voice Settings** をクリックします。

セットアップ前に音声ボタンを押すと、Voice タブが自動的に開き、設定を完了できるようになります。

ElevenLabs の API キーは暗号化して保存され、ブラウザには一切送信されません。すべての呼び出しは Heym バックエンド経由でプロキシされます。詳細は[クレデンシャル](./credentials.md)および[設定](./user-settings.md)をご参照ください。

## メッセージの読み上げ

すべてのメッセージバブル（ご自身とアシスタントの両方）には、**Copy** の隣にスピーカーボタンがあります。クリックするとメッセージが再生され、もう一度クリックするか、別のメッセージを再生すると停止します。再生には ElevenLabs の多言語モデルが使用されるため、テキストの言語は自動的に検出されます。

## インタラクティブ音声モード

チャット入力欄の波形ボタンをクリックすると、全画面のハンズフリー音声モードが開きます（ライト／ダークおよびモバイルに対応）：

1. マイクを通じて聞き取り、発話が止まったタイミングを検出します。
2. 音声は **Scribe** で文字起こしされます（言語は自動検出 — 手動での TR/EN 切り替えは不要です）。
3. 文字起こしは、**同じ会話**内の通常のチャットメッセージとして送信されます。
4. アシスタントの返信が読み上げられた後、再び聞き取りを再開します。

**ミュート**ボタンで聞き取りを一時停止し、**✕** で終了します（マイクが解放されます）。録音は Firefox を含むすべてのモダンブラウザで動作します。

## 備考

- ボイスとクレデンシャルの選択はユーザーごとの設定です。LLM のアクティブな会話、モデル、クレデンシャルは変更されません。
- ElevenLabs の使用量（TTS と STT の両方）は、お客様自身の ElevenLabs アカウントに課金されます。
