# Heym とチャット

Chat with Heym は、ドキュメントのヘッダーから利用できるページ認識型のアシスタントです。中央に表示されるダイアログで開き、LLM の credential とモデルを選択すると、現在のドキュメントページを最初のコンテキストとして質問に回答します。

## ダイアログを開く

1. `/docs` 配下の任意のページを開きます
2. ヘッダーの **Chat with Heym** をクリックします
3. [credential](../tabs/credentials-tab.md) とモデルを選択します
4. ページまたはプラットフォームについて質問します

小さい画面ではトリガーはアイコンのみで表示され、大きい画面ではラベル全体が表示されます。

## 使用されるコンテキスト

- 現在開いているドキュメントのパスが、コンテキスト上のガイダンスとしてリクエストに注入されます
- バックエンドは引き続き既存の dashboard チャット endpoint とドキュメント検索ツールを使用します
- 同じチャットバックエンドが再利用されるため、アカウントレベルの [User Rules](./user-settings.md) が引き続き適用されます
- dashboard チャットと同様に、最終回答の前にライブの準備ステップがアシスタントのバブルにストリーミング表示されます
- 確認質問は [Chat tab](../tabs/chat-tab.md) と同様にカードとして表示されます。Workflow リクエストで credential が必要な場合は、カードから選択または作成できます。データテーブルが必要な場合は、同様の方法で既存のテーブルを選択するか、新しいテーブルを作成できます。

特定の記事でダイアログを開くと、小さなバッジにアクティブなドキュメントパスが表示されるため、どのページが優先されているかを確認できます。

## セッションの動作

- credential とモデルの選択は、ダイアログがマウントされている間は保持されます
- メッセージ履歴はセッション限りで、ダイアログを閉じるとクリアされます
- 背景のクリック、`Escape`、閉じるボタンのいずれでもセッションがリセットされます
- **Stop** は現在のストリーミング応答を中断します
- ダイアログは意図的に幅広で固定サイズとなっており、フルスクリーン切り替えは提供されていません

## 使用する場面

- ノードやリファレンスページを読みながら追加の質問をする
- ドキュメントから離れることなく機能の違いを明確にする
- エディターを開く前に適切な記事を見つける

Workflow を直接構築または変更したい場合は、エディター側の [AI Assistant](./ai-assistant.md) を使用してください。
