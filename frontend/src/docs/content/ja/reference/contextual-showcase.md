# コンテキスト Showcase

**コンテキスト・ショーケース**は、軽量なアプリ内ガイドレールであり、ユーザーをすぐに完全なドキュメントフローへ誘導することなく、現在表示しているページについて説明します。

## 機能概要

- 現在のページの短い概要を表示します
- 最初のレイヤーを簡潔に保ち、情報過多にならないようにします
- 必要なときにだけ、少量の追加詳細を展開できます
- より深く読むための完全なドキュメントページへのリンクを提供します

## 表示場所

v1 では、ショーケースは Heym の認証済みメイン画面で利用できます：

- Dashboard のタブ
- [Evals](../tabs/evals-tab.md)
- [Documentation](../getting-started/introduction.md)
- Workflow エディターのキャンバス

ログイン、登録、チャットポータル、HITL レビューなどの公開ページでは、ショーケースは表示されません。

## アクセス方法

### デスクトップ

- 画面の右端に固定の **Page Guide** トリガーが表示されます
- ショーケースは右側のドロワーとして開きます
- デフォルトでは閉じた状態です
- 一度だけ表示されるティーザーにより、強制的に開くことなくガイドの存在を知らせます

### モバイル

- 同じコンテンツをフローティングの **Page Guide** ボタンから利用できます
- 右側のレールではなく、ボトムシートで開きます

## コンテンツモデル

各ショーケースのエントリは、完全にカスタムなコンポーネントではなく、構造化された定義を使用します。

- **Title** – このページが何であるか
- **Summary** – 短い説明を 1 つ
- **Bullets** – ざっと確認できるいくつかの手がかり
- **Highlights** – 主要な価値や利用パターンを示す小さなカード
- **More Detail** – 追加のコンテキストのための折りたたみセクション
- **Actions** – 通常 1 つまたは 2 つのリンク、多くの場合完全なドキュメントへのリンク

これにより、長く煩雑なヘルプパネルを避けつつ、システムの柔軟性を保っています。

## コンテキスト認識

ショーケースは現在の画面に応じて変化します。

- Dashboard の各タブには、それぞれ独自の概要があります
- エディターは [Canvas Features](./canvas-features.md) を参照します
- ドキュメントページは汎用的なドキュメント概要を使用し、可能な場合は既に開いている現在の記事を参照します

## 永続化

ショーケースは、少量の個人的な UI 状態をブラウザストレージに保存します：

- パネルまたはシートが最後に開かれていたかどうか
- どのページコンテキストでティーザーが既に表示されたか
- コンテキストごとに最後に展開された詳細セクション

## 存在する理由

目的は、より重い UI クロームを追加することなく、Heym をより学びやすくすることです。

- オリエンテーションのための、短く常に手元にあるガイダンス
- より深いドキュメントへの明確な道筋
- 経験豊富なユーザーにとっての低い中断性
