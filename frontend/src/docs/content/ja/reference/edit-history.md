# 編集履歴

編集履歴は、Workflow の保存済みバージョンを追跡します。これを使用して、経時的な変更の確認、バージョンの比較、または以前の状態への復元が行えます。

**注記:** 編集履歴は[実行履歴](./execution-history.md)とは異なります。編集履歴は**保存**（Workflow 構造の変更）を追跡し、実行履歴は**実行**（過去の実行）を追跡します。

## 場所

**エディターツールバー** → **編集履歴**（GitBranch アイコン）

## バージョン

Workflow を**保存**するたびに、新しいバージョンが作成されます。リストには以下が表示されます：

- **Current** – 最新の保存状態（キャンバスに表示されている内容）
- **Version N** – タイムスタンプ付きの過去の保存

前のバージョンと比較して変更がないバージョンは非表示になります。

## Diff ビュー

バージョンを選択すると、現在の Workflow と比較して何が変更されたかを確認できます：

| 変更タイプ | 説明 |
|-------------|--------------|
| **Nodes** | 追加、削除、または変更されたノード |
| **Edges** | 追加、削除、または変更された接続 |
| **Config** | Workflow レベルの設定（認証、レート制限など） |

各変更を展開すると、フィールドレベルの差分（例：どのノードプロパティが変更されたか）を確認できます。

## プレビュー

過去のバージョンで Workflow がどのように表示されていたかを確認するには、Revert の横にある **Preview** をクリックします。

そのバージョンのノードとエッジを表示する読み取り専用のキャンバスが開きます。パンとズームでレイアウトを確認できますが、このビューから変更を加えることはできません。

## 復元

過去のバージョンを復元するには：

1. 復元したいバージョンを選択します
2. **Revert** をクリックします
3. 操作を確認します
4. 現在の Workflow が選択したバージョンに置き換えられ、ページが再読み込みされます

復元すると新しい「current」状態が作成されます。必要に応じて再度復元できます。

## 履歴のクリア

ダイアログヘッダーのゴミ箱アイコンをクリックすると、すべてのバージョン履歴が削除されます。この操作は元に戻せません。現在の Workflow は保持され、過去のバージョンのみが削除されます。

## バージョンが作成されるタイミング

バージョンは**保存**したとき（Ctrl/Cmd+S または保存ボタン）にのみ作成されます。保存されていない変更は、保存するまで編集履歴に記録されません。

Agent スキルの編集もこれらのスナップショットに含まれます。Workflow 全体を復元せずに単一のスキルを閲覧または復元するには、Agent ノードのプロパティパネルにあるそのスキルカードの **History** ボタンを使用します。[Agent ノード](../nodes/agent-node.md#skill-history)を参照してください。
