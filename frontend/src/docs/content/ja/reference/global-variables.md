# グローバル変数

**グローバル変数ストア**は、Workflow の実行をまたいで保持される、ユーザースコープの永続的なキーと値のデータを保持します。設定、フィーチャーフラグ、カウンター、または複数の Workflow で共有する必要がある状態などにご利用ください。

> **ここにシークレットを保存しないでください。** グローバル変数はシークレット保管庫ではありません。値は暗号化されずに保存され、共有相手には完全な値が返され、共同作業者は編集できます。API キー、パスワード、Token は [Credentials](./credentials.md) に保存してください。Credentials は保存時に暗号化され、クライアントにシークレットを返すことはありません。

## ローカル変数とグローバル変数

| ストア | 構文 | スコープ | 永続性 |
|-------|--------|-------|-------------|
| **Workflow ローカル** | `$vars.variableName` | 現在の実行のみ | メモリ内、実行終了時に失われる |
| **グローバル** | `$global.variableName` | ユーザーのすべての Workflow | データベースに永続化 |

## グローバル変数の作成

1. **Variables タブから** – [Variables タブ](../tabs/global-variables-tab.md)：変数を直接作成、編集、削除できます。
2. **Variable ノードから** – ノードのプロパティで **Store in Global Variable Store**（`isGlobal: true`）を有効にします。Workflow の実行時に変数がストアに書き込まれます。

## 式での使用

グローバル変数には `$global.variableName` でアクセスします：

```
$global.environment
$global.settings.baseUrl
$global.userId
```

Workflow ローカル変数と同じメソッド（例：`.upper()`、`.length`、配列の `.add()`）が使用できます。

## 値の型

サポートされている型：`string`、`number`、`boolean`、`array`、`object`。変数の作成または編集時に型を選択してください。

## グローバル変数の共有

グローバル変数は他のユーザーや [Teams](./teams.md) と共有でき、共有相手は自身の Workflow で利用できます。

- **ユーザーと共有** – 所有する変数の横にある共有アイコンをクリックし、受信者のメールアドレスを入力して **Share** をクリックします。受信者のグローバル変数リストに、**Shared** バッジと「Shared by &lt;あなたのメールアドレス&gt;」というラベル付きで変数が表示されます。
- **チームと共有** – 共有ダイアログでチームを選択し、**Add** をクリックします。すべてのチームメンバーがアクセス権を取得します。
- **編集可能なアクセス** – 受信者は共有変数を表示、編集し、自身の Workflow で `$global.variableName` を介して参照できます。変数の共有、共有解除、削除ができるのは所有者のみです。
- **名前の競合** – 受信者が同じ名前の変数をすでに持っている場合、自身の変数が共有変数よりも優先されます。
- **共有解除** – 変数の共有ダイアログを開き、アクセス権を削除したいユーザーの横にある **×** ボタンをクリックします。

## Chat 連携

グローバル変数は [Chat](../tabs/chat-tab.md) アシスタントから利用できます。LLM は質問への回答やコンテンツ生成の際にそれらを参照できます。
