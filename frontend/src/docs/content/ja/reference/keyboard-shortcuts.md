# キーボードショートカット

Heym は、Workflow エディターとキャンバス全体でキーボードショートカットを提供し、一般的な操作を迅速に行えるようにします。

## グローバルエディターショートカット

これらのショートカットは、Workflow エディター内のどこでも有効です。

| ショートカット | アクション |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | コマンドパレットを開く |
| `Ctrl + I` / `Cmd + I` | [AI Assistant](./ai-assistant.md) パネルを切り替える（入力中でも動作します） |
| `Ctrl + Enter` / `Cmd + Enter` | 現在の Workflow を実行する |
| `Ctrl + S` / `Cmd + S` | Workflow を保存する |
| `Ctrl + Z` / `Cmd + Z` | 元に戻す |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | やり直す |
| `Ctrl + Y` / `Cmd + Y` | やり直す（代替） |
| `Escape` | 開いているオーバーレイ、ダイアログ、パネルを閉じる |

## キャンバスショートカット

これらのショートカットは、キャンバスがフォーカスされているとき（テキスト入力がアクティブでないとき）に適用されます。

### 選択とナビゲーション

| ショートカット | アクション |
|----------|--------|
| `Ctrl + A` / `Cmd + A` | すべてのノードを選択する |
| `Shift`（長押し） | ドラッグして複数のノードを選択する |
| `Ctrl` / `Cmd`（長押し） | クリックして個々のノードを選択範囲に追加する |
| `Escape` | すべてのノードの選択を解除する。インラインノード検索を閉じる |

### ノードの編集

| ショートカット | アクション |
|----------|--------|
| `Ctrl + C` / `Cmd + C` | 選択したノードをコピーする |
| `Ctrl + X` / `Cmd + X` | 選択したノードを切り取る |
| `Ctrl + V` / `Cmd + V` | ノードを貼り付ける |
| `Delete` または `Backspace` | 選択したノードやエッジを削除する |
| `D` | 選択したノードの有効／無効を切り替える |
| `P` | 選択したノードの固定データを切り替える |

### インラインノード検索

キャンバス上で任意の印刷可能文字を入力すると（テキスト入力がフォーカスされていないとき）、インラインノード検索ポップアップが開きます。入力した文字は検索クエリの最初の文字になります。

| ショートカット | アクション |
|----------|--------|
| 任意の印刷可能文字 | インラインノード検索を開き、入力を開始する |
| `Backspace` | 検索クエリから最後の文字を削除する |
| `Escape` | インラインノード検索を閉じる |

## コマンドパレット（`Ctrl + K`）

コマンドパレットは、エディター、ダッシュボード、ドキュメント、evals ビューから利用できます。キーボードから離れることなく、Workflow、タブ、ドキュメントページへ素早く移動できます。

| ショートカット | アクション |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | コマンドパレットを開く |
| `↑` / `↓` | 結果リストを移動する |
| `Tab` / `Shift + Tab` | 結果リストを移動する |
| `Enter` | 選択した項目を開く |
| `Escape` | パレットを閉じる |

## ダッシュボードショートカット

これらのショートカットは、他のテキスト入力がアクティブでないとき、Workflows タブで有効です。

| ショートカット | アクション |
|----------|--------|
| `Ctrl + F` / `Cmd + F` | Workflow 検索にフォーカスする |
| `Escape` | テキストがある場合に Workflow 検索をクリアする |

## プロパティパネルショートカット

これらのショートカットは、ノードが選択され、プロパティパネルが開いているときに有効です。

| ショートカット | アクション |
|----------|--------|
| `Ctrl + Shift + O` / `Cmd + Shift + O` | リンクされたサブ Workflow を新しいタブで開く（Execute ノードのみ） |

## Evaluate ダイアログショートカット

これらのショートカットは、Evaluate ダイアログが開いているときに有効です。

| ショートカット | アクション |
|----------|--------|
| `Ctrl + Enter` / `Cmd + Enter` | 式を適用してダイアログを閉じる |
| `Ctrl + Z` / `Cmd + Z` | 式エディターでの変更を元に戻す |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | 式エディターでの変更をやり直す |
| `Ctrl + Y` / `Cmd + Y` | 式エディターでの変更をやり直す（代替） |

## 履歴とトレースのショートカット

これらのショートカットは、Execution History ダイアログと Traces パネルで利用できます。

| ショートカット | アクション |
|----------|--------|
| `S` | 検索入力を切り替えてエントリをフィルタリングする |
