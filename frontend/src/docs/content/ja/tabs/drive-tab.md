# Driveタブ

Driveタブには、Workflow全体でスキルによって生成されたすべてのファイルが表示されます。

## 概要

スキルによって生成されたファイル（PDF、DOCX、CSV、画像など）は自動的に保存され、Driveタブに一覧表示されます。各ファイルには、名前、種類、サイズ、ソースノード、作成日、チーム共有状態が表示されます。

## 機能

- **検索** - 名前、種類、ソースノードでファイルを絞り込み
- **ファイルIDをコピー** - ファイルのUUIDをクリップボードにコピーし、[Drive](../nodes/drive-node.md)ノードや[Converter](../nodes/converter-node.md)ノードに貼り付け可能
- **ダウンロード** - 自分のファイルおよびチーム経由で共有されたファイルの認証済みダウンロード
- **共有** - パスワード保護と有効期限を任意で設定できる共有ダウンロードリンクの作成、または現在所属しているチームへの読み取り専用共有
- **削除** - ファイルとその共有リンクを削除
- **すべてクリア** - 確認後、すべてのファイルとその共有リンクを削除
- **一括操作** - チェックボックスで複数ファイルを選択し（Shiftクリックで範囲選択）、同じ操作をまとめて適用
- **ページネーション** - 大量のファイルコレクションを閲覧可能。1ページあたりの行数セレクター付き（25 / 50 / 100 / すべて）

## 一括操作

自分が所有するファイルには、行の先頭にチェックボックスが表示されます（チーム経由で共有されたファイルは読み取り専用のため選択できません）。複数の行を選択するか、ヘッダーのチェックボックスでページ全体を選択し、**Shiftクリック**で範囲選択した後、リストの上に表示される一括操作バーを使用します：

- **ZIPをダウンロード** - 選択したすべてのファイルを1つのZIPアーカイブにまとめてダウンロード
- **一括操作** - 1つのダイアログで、選択したすべてのファイルに同じ設定を適用：
  - **すべてを自分のチームと共有** / **チーム共有を解除** をワンクリックで実行
  - **各ファイルの共有リンクを作成** - 同じパスワード、有効期限、最大ダウンロード数の設定を使用
- **削除** - 確認後、選択したすべてのファイルとその共有リンクを削除
- **選択をクリア** - すべての選択を解除

ダイアログには、適用されたファイル数が表示されます（自分が所有していないファイルはスキップされます）。1ページあたりの行数セレクターの**すべて**オプションを使用すると、すべてのファイルを1ページに読み込み、Drive全体にわたって選択できます。検索ボックスに入力すると、1ページあたりの行数セレクターが自動的に**すべて**に切り替わり、検索が現在のページだけでなくすべてのファイルを対象にします。検索をクリアすると、以前の選択が復元されます。

## 共有

共有リンクは以下の設定で作成できます：
- **認証なし** - 公開TokenベースのダウンロードURL
- **Basic認証** - パスワード保護リンク（ユーザー名：`file`）
- **有効期限** - 任意の時間ベースの有効期限
- **ダウンロード制限** - 任意の最大ダウンロード数

ファイルで**自分のチームと共有**を有効にすると、現在所属しているすべてのチームにファイルが表示されます。共有されたチームメンバーは読み取り専用アクセスとなり、管理操作はオーナーのみが実行できます。

## Agentスキルアクセス

Agentノード上のスキルは、Driveファイルの読み取りをオプトインできます。スキルで**Driveファイルを有効化**がオンになっている場合、そのPythonコードは生成された`heym_drive.py`ヘルパーを通じて、ファイルIDまたは正確なファイル名でアクセス可能なDriveファイルを読み取ることができます。この設定はデフォルトでオフになっています。

詳細は[Driveリファレンス](../reference/drive.md)をご参照ください。
