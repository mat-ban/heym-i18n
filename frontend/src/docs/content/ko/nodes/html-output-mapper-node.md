# HTML 출력 매퍼

**HTML output mapper** 노드는 단일 HTML 템플릿을 페이지로 렌더링합니다. 호출자가 API 클라이언트가 아닌 **브라우저**일 때 사용하십시오. 이 경우 Workflow는 JSON 대신 `text/html`로 응답합니다.

## 개요

| 속성 | 값 |
|----------|-------|
| 입력 | 1 |
| 출력 | 0 (sink) |
| 런타임 출력 | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## 파라미터

| 파라미터 | 타입 | 설명 |
|-----------|------|-------------|
| `label` | string | 노드 식별자 (camelCase) |
| `html` | string | 페이지 템플릿입니다. `$nodeLabel.field` 표현식은 해당 위치에 보간됩니다. |
| `statusCode` | number | 응답의 HTTP 상태 코드 (기본값 `200`) |
| `contentType` | string | 응답 콘텐츠 타입 (기본값 `text/html; charset=utf-8`) |

## Webhook 및 실행 동작

이 노드가 Workflow의 **유일한** 터미널 출력인 경우, execute Endpoint는 렌더링된 페이지, 설정된 상태 코드, 설정된 콘텐츠 타입으로 응답합니다. JSON envelope도, label 래퍼도 없습니다.

다음 두 가지 경우에는 이 동작이 해제됩니다.

- **두 번째 터미널 노드.** 그래프에 다른 활성 터미널이 있으면 Heym은 일반적인 label별 JSON 맵으로 폴백하며, 페이지는 문자열 필드로 전달됩니다.
- **`X-Simple-Response: false`.** 이 헤더는 `status`, `node_results`, 타이밍 정보를 포함한 전체 envelope를 요청하며, 이는 에디터의 캔버스가 사용하는 방식입니다. 페이지 Workflow를 디버깅할 때 이 헤더를 전송하십시오.

## 브라우저에 페이지 제공하기

일반 브라우저 탐색으로 이 Workflow에 도달할 수 있도록 cURL 대화 상자에서 Workflow의 **request method**를 `GET`으로 설정하십시오. `GET` 요청은 body를 포함하지 않으므로 입력은 쿼리 문자열에서 가져옵니다.

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

이 값들은 `$input.query.name`으로 읽습니다. 전체 메서드 계약은 [Webhooks](../reference/webhooks.md)를 참조하십시오.

Trigger 노드가 없고 이 노드만 유일한 터미널인 Workflow는 [Workflows tab](../tabs/workflows-tab.md)에서 **WEB** 칩을 표시합니다.

## Agent tool 사용

지원되지 않습니다. 이 노드는 터미널 sink이므로 [Agent Node](./agent-node.md)의 tools 핸들에 연결할 수 없습니다. [JSON output mapper](./json-output-mapper-node.md)에도 동일하게 적용됩니다.

## Loop 제한

[Output](./output-node.md)과 동일한 규칙입니다. 이 노드를 loop iteration 분기 안에 배치하지 마십시오. loop의 `done` 분기 뒤에만 배치하십시오. [Loop](./loop-node.md)를 참조하십시오.

## 예시

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
