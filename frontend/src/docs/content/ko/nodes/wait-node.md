# 대기

**Wait** 노드는 지정된 시간 동안 Workflow 실행을 일시 중지합니다. 속도 제한, 지연된 작업 또는 폴링 간격에 사용하십시오.

## 개요

| 속성 | 값 |
|----------|-------|
| 입력 | 1 |
| 출력 | 1 |
| 출력 결과 | 입력을 그대로 전달 |

## 파라미터

| 파라미터 | 타입 | 설명 |
|-----------|------|-------------|
| `label` | string | 노드 식별자 (camelCase) |
| `duration` | number | 지연 시간(밀리초) (예: 1000 = 1초). 에디터에서는 1부터 900000(15분)까지 허용됩니다 |

## 예시

```json
{
  "type": "wait",
  "data": {
    "label": "delayOneSecond",
    "duration": 1000
  }
}
```
