# 컨텍스트 Showcase

**Contextual Showcase**는 현재 보고 있는 페이지를 설명해 주는 가벼운 인앱 가이드 레일로, 사용자를 즉시 전체 문서 흐름으로 밀어 넣지 않으면서 안내를 제공합니다.

## 기능

- 현재 페이지에 대한 짧은 요약을 표시합니다
- 첫 번째 레이어를 간결하게 유지하여 과부하를 방지합니다
- 필요할 때만 소량의 추가 세부 정보를 펼쳐 볼 수 있습니다
- 더 깊이 있는 학습을 위해 전체 문서 페이지로 연결되는 링크를 제공합니다

## 표시 위치

v1에서는 Heym의 인증된 주요 화면에서 쇼케이스를 사용할 수 있습니다:

- Dashboard 탭
- [Evals](../tabs/evals-tab.md)
- [Documentation](../getting-started/introduction.md)
- Workflow 편집기 캔버스

로그인, 회원가입, 채팅 포털, HITL 리뷰와 같은 공개 페이지에서는 쇼케이스가 표시되지 않습니다.

## 접근 방법

### 데스크톱

- 화면 오른쪽 가장자리에 고정된 **Page Guide** 트리거가 나타납니다
- 쇼케이스는 오른쪽 사이드 drawer로 열립니다
- 기본적으로 닫힌 상태로 유지됩니다
- 일회성 티저가 가이드의 존재를 알려 주지만 강제로 열리지는 않습니다

### 모바일

- 동일한 콘텐츠를 플로팅 **Page Guide** 버튼에서 사용할 수 있습니다
- 오른쪽 레일 대신 하단 시트(bottom sheet)로 열립니다

## 콘텐츠 모델

각 쇼케이스 항목은 완전히 사용자 정의된 컴포넌트 대신 구조화된 정의를 사용합니다.

- **Title** – 이 페이지가 무엇인지
- **Summary** – 짧은 설명 하나
- **Bullets** – 빠르게 훑어볼 수 있는 몇 가지 단서
- **Highlights** – 핵심 가치나 사용 패턴을 담은 작은 카드
- **More Detail** – 추가 맥락을 위한 접힌 섹션
- **Actions** – 보통 하나 또는 두 개의 링크이며, 대부분 전체 문서로 연결됩니다

이를 통해 시스템은 유연하게 유지되면서 길고 복잡한 도움말 패널을 피할 수 있습니다.

## 컨텍스트 인식

쇼케이스는 현재 화면에 따라 변경됩니다.

- Dashboard 탭은 각각 자체 요약을 가집니다
- 편집기는 [Canvas Features](./canvas-features.md)를 가리킵니다
- 문서 페이지는 일반적인 문서 개요를 사용하며, 가능한 경우 이미 열려 있는 현재 문서를 가리킵니다

## 지속성

쇼케이스는 브라우저 저장소에 소량의 개인 UI 상태를 저장합니다:

- 패널 또는 시트가 마지막으로 열려 있었는지 여부
- 어떤 페이지 컨텍스트에서 이미 티저를 표시했는지
- 컨텍스트별 마지막으로 펼친 세부 섹션

## 존재 이유

목표는 더 무거운 UI 요소를 추가하지 않고도 Heym을 더 쉽게 학습할 수 있도록 하는 것입니다.

- 방향 파악을 위한 짧고 항상 가까이에 있는 안내
- 더 깊은 문서로 이어지는 명확한 경로
- 숙련된 사용자를 위한 낮은 방해 수준
