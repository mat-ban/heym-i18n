# Drive

Drive 탭은 스킬에서 생성된 모든 파일을 확인, 관리, 공유할 수 있는 중앙 공간을 제공합니다.

## Drive 접근

대시보드에서 **Drive** 탭으로 이동하십시오. Workflow 스킬에서 생성된 모든 파일이 생성 날짜순으로 정렬되어 여기에 표시됩니다.

## 파일 목록

파일 목록에는 다음이 표시됩니다:

- **Name** - 유형별 아이콘이 함께 표시되는 원본 파일명
- **Type** - 파일 MIME 유형 (예: pdf, csv, docx)
- **Size** - 사람이 읽기 쉬운 파일 크기
- **Source** - 파일을 생성한 노드 레이블
- **Date** - 파일이 생성된 시점
- **Actions** - 다운로드, 공유, 삭제 버튼

## 일괄 작업

본인이 소유한 각 파일의 행 시작 부분에 체크박스가 있습니다. 팀을 통해 공유받은 파일은 읽기 전용이며 선택할 수 없습니다. 여러 파일을 선택하면(Shift-클릭으로 연속 범위 선택, 헤더 체크박스로 전체 페이지 선택) 목록 위에 일괄 작업 바가 나타납니다. 그런 다음 **Bulk actions**를 클릭하면 선택한 모든 파일에 동일한 설정을 적용하는 단일 대화상자가 열립니다:

- **Share all with my teams** / **Remove team sharing** — 선택한 모든 파일의 팀 공유를 한 번에 전환합니다
- **Create share link for each file** — 동일한 만료, 비밀번호, 최대 다운로드 값을 사용하여 선택한 모든 파일에 공유 링크를 생성합니다

대화상자는 적용된 파일 수를 보고하며, 소유하지 않은 파일은 건너뜁니다. 목록 하단의 페이지당 행 수 선택기(25 / 50 / 100 / **All**)를 사용하면 한 페이지에 더 많은 파일을 로드하여 전체 Drive에서 선택할 수 있습니다.

## 파일 공유

**Share** 아이콘을 클릭하면 공유 대화상자가 열립니다. 파일당 서로 다른 구성으로 여러 공유 링크를 생성할 수 있으며, 선택적으로 현재 팀과 파일을 공유할 수 있습니다.

### 공개 링크 (Token 기반)

비밀번호 없이 공유 링크를 생성합니다. 링크를 가진 사람은 누구나 파일을 다운로드할 수 있습니다.

### 비밀번호 보호 링크 (Basic Auth)

공유 생성 시 비밀번호를 설정합니다. 다운로드 URL은 HTTP Basic Authentication을 사용하며, 링크를 열면 브라우저에서 사용자 이름(`file`)과 비밀번호를 묻는 메시지가 표시됩니다.

### 링크 옵션

- **Expires (hours)** - 선택적으로 만료 시간 설정
- **Max downloads** - 선택적으로 다운로드 횟수 제한
- 최대한의 제어를 위해 두 옵션을 함께 사용할 수 있습니다

### 내 팀과 공유

**Share with my teams**를 활성화하면 현재 소속된 모든 팀에 읽기 전용 접근 권한을 부여합니다. 팀 멤버는 Drive에서 파일을 보고 다운로드할 수 있으며 읽기 지향적인 Drive 노드 작업을 사용할 수 있지만, 파일 삭제, 공개 링크 생성 또는 취소, 비밀번호/TTL/다운로드 제한 변경은 파일 소유자만 가능합니다.

이 설정은 파일별로 적용됩니다. 나중에 다른 팀에 가입하거나 팀을 생성한 경우, 공유를 다시 전환하거나 Drive 노드의 `shareWithMyTeams` 작업을 실행하여 해당 팀을 추가하십시오. Workflow에서 파일의 팀 공유를 제거하려면 `unshareWithMyTeams`를 사용하십시오.

### 공유 관리

공유 대화상자에는 기존의 모든 공유 링크가 다음 정보와 함께 표시됩니다:
- 현재 다운로드 횟수
- 만료 상태
- Basic Auth 활성화 여부
- 복사 및 취소 버튼

## Chat 및 Portal의 파일 링크

Portal chat 또는 Quick Drawer를 통한 Workflow 실행 중에 스킬이 파일을 생성하면, 다운로드 링크가 응답에 자동으로 표시됩니다. 사용자는 클릭하여 바로 다운로드할 수 있습니다.

## 저장소

생성된 파일은 서버 파일 시스템의 `data/files/` 아래에 저장됩니다. Docker 배포에서는 영속성을 위해 볼륨으로 마운트됩니다.

## Workflow에서 파일 관리

[Drive 노드](../nodes/drive-node.md)를 사용하면 Workflow 내에서 프로그래밍 방식으로 Drive 파일을 관리할 수 있습니다. 다음과 같은 용도로 사용하십시오:

- 파일을 **List**하고 파일명, MIME 유형, 크기, 소스, 다운로드 URL과 같은 메타데이터를 반환
- 사용자에게 전달된 후 파일을 **Delete**
- **팀과 공유 또는 공유 해제**하여 팀 공유가 존재하는 동안에만 팀 멤버가 읽고 다운로드할 수 있도록 함
- 다운로드 링크에 **비밀번호 설정**
- N시간 후 링크가 만료되도록 **TTL 설정**
- **최대 다운로드** 제한 설정

파일을 다른 형식으로 변환하는 것은 [Converter 노드](../nodes/converter-node.md)의 역할이며, `conversion: "fileConvert"`를 사용합니다. 이 노드는 Drive 파일을 읽고 변환된 결과를 새 파일로 저장합니다.

스킬 출력에서 파일 ID로 참조하십시오: `$agentLabel._generated_files[0].id`

구성 세부 사항은 [Drive 노드 문서](../nodes/drive-node.md)를 참조하십시오.

## 스킬에서 Drive 파일 읽기

Agent 스킬은 스킬 카드의 **Enable Drive files** 설정으로 Drive 읽기를 선택적으로 활성화할 수 있습니다. 활성화되면 스킬 런타임에 생성된 `heym_drive.py` 헬퍼가 포함됩니다. 스킬 코드는 `read_drive_text`, `read_drive_file`, `read_drive_base64`, `get_drive_file`, `get_drive_file_path`, `list_drive_files`와 같은 헬퍼를 import할 수 있습니다.

Drive 읽기는 Workflow 실행자(actor)가 접근할 수 있는 파일로 제한됩니다: 소유한 파일 및 팀을 통해 실행자와 공유된 파일입니다. 정확한 조회에는 파일 ID를 사용하고, 사용자가 파일명으로 참조하는 경우에는 정확한 파일명을 사용하십시오. 파일명 조회는 해당 이름을 가진 가장 최근의 접근 가능한 파일을 반환하며, `list_drive_files(filename="...")`는 일치하는 모든 파일을 반환합니다.

## 정리
만료된 공유 Token은 매일 자동으로 정리됩니다. 파일 자체는 Drive 탭을 통해 수동으로 삭제할 때까지 유지됩니다. **Clear All**을 사용하면 모든 파일과 해당 공유 링크를 한 번에 삭제할 수 있습니다.
