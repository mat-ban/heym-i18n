# 편집 기록

편집 기록은 Workflow의 저장된 버전을 추적합니다. 이를 사용하여 시간 경과에 따른 변경 사항을 확인하거나, 버전을 비교하거나, 이전 상태로 되돌릴 수 있습니다.

**참고:** 편집 기록은 [실행 기록](./execution-history.md)과 다릅니다. 편집 기록은 **저장**(Workflow 구조 변경)을 추적하고, 실행 기록은 **실행**(과거 실행 내역)을 추적합니다.

## 찾는 위치

**에디터 툴바** → **편집 기록** (GitBranch 아이콘)

## 버전

Workflow를 **저장**할 때마다 새 버전이 생성됩니다. 목록에는 다음이 표시됩니다:

- **현재** – 가장 최근에 저장된 상태 (캔버스에 표시되는 내용)
- **버전 N** – 타임스탬프와 함께 표시되는 과거 저장 내역

이전 버전과 비교하여 변경 사항이 없는 버전은 숨겨집니다.

## Diff 보기

버전을 선택하면 현재 Workflow와 비교하여 무엇이 변경되었는지 확인할 수 있습니다:

| 변경 유형 | 설명 |
|-------------|--------------|
| **노드** | 추가, 제거 또는 수정된 노드 |
| **엣지** | 추가, 제거 또는 수정된 연결 |
| **Config** | Workflow 수준 설정 (인증, 속도 제한 등) |

각 변경 사항을 펼치면 필드 수준의 diff(예: 어떤 노드 속성이 변경되었는지)를 확인할 수 있습니다.

## 미리보기

과거 버전의 Workflow가 어떻게 보였는지 확인하려면 되돌리기 옆의 **미리보기**를 클릭하십시오.

해당 버전의 노드와 엣지를 보여주는 읽기 전용 캔버스가 열립니다. 레이아웃을 살펴보기 위해 이동하고 확대/축소할 수 있으며, 이 보기에서는 변경할 수 없습니다.

## 되돌리기

과거 버전을 복원하려면:

1. 원하는 버전을 선택합니다
2. **되돌리기**를 클릭합니다
3. 작업을 확인합니다
4. 현재 Workflow가 선택한 버전으로 대체되고 페이지가 새로고침됩니다

되돌리기는 새로운 "현재" 상태를 생성하므로, 필요하면 다시 되돌릴 수 있습니다.

## 기록 지우기

대화 상자 헤더의 휴지통 아이콘을 클릭하면 모든 버전 기록이 제거됩니다. 이 작업은 취소할 수 없습니다. 현재 Workflow는 유지되며, 과거 버전만 삭제됩니다.

## 버전이 생성되는 시점

버전은 **저장**할 때만 생성됩니다 (Ctrl/Cmd+S 또는 저장 버튼). 저장하지 않은 변경 사항은 저장하기 전까지 편집 기록에 저장되지 않습니다.

Agent skill 편집도 이러한 스냅샷에 포함됩니다. 전체 Workflow를 되돌리지 않고 단일 skill을 탐색하거나 복원하려면, Agent 노드 속성 패널의 해당 skill 카드에서 **기록** 버튼을 사용하십시오. [Agent 노드](../nodes/agent-node.md#skill-history)를 참조하십시오.
