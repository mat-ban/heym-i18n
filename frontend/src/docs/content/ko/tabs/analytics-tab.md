# Analytics 탭

**Analytics** 탭은 Workflow의 실행 지표와 추세를 보여줍니다. 사용량과 성능을 모니터링하고 병목 지점을 식별하십시오.

## 요약 통계

- **총 실행 수** – 선택한 기간 동안의 Workflow 실행 횟수
- **성공률** – 성공한 실행의 비율
- **평균 소요 시간** – 평균 실행 시간
- **절약된 시간** – 추정된 총 절약 시간: 각 Workflow에 설정된 실행당 절약 분 × 성공한 실행 수를 선택한 기간 전체에 대해 합산한 값
- **추세** – 이전 기간 대비 상승/하락 지표

## 시간 범위

- **1h**, **3h**, **6h** – 지난 1시간, 3시간 또는 6시간. 분석 데이터는 시간 단위로 유지되므로 윈도우가 시작하는 전체 시간을 온전히 계산합니다: 15:20 기준 '지난 1시간'은 14:00부터 현재까지를 포함합니다
- **24h** – 최근 24시간
- **7d** – 최근 7일
- **30d** – 최근 30일
- **All** – 사용 가능한 전체 이력

## Workflow 필터

- 특정 Workflow별로 지표를 필터링합니다
- **All workflows** – 모든 Workflow에 걸쳐 집계합니다

## 테이블

두 개의 테이블이 Workflow 사용량을 보여줍니다: **Most Used**(더 넓음)와 **Most Failed**.

- **Time Saved** – Most Used는 각 Workflow의 합산된 절약 시간(실행당 절약 분 × 성공한 실행 수)을 표시합니다. **Not Set**은 추정치가 누락되었음을 의미하며, 이를 클릭하면 해당 Workflow의 해당 필드가 열립니다.
- **정렬 가능한 열** – 열 헤더를 클릭하면 해당 열을 기준으로 정렬합니다. 다시 클릭하면 오름차순/내림차순이 전환됩니다. 화살표 지표가 정렬 방향을 표시합니다.
- **모바일 레이블** – 작은 화면에서는 열 레이블이 축약되어(예: "Executions" → "Runs", "Success" → "OK", "Error" → "Err") 테이블이 가로 스크롤 없이 맞춰집니다.

## 차트

- **Execution Volume Over Time** – 시간 구간별 실행 수를 나타내는 선 차트
- **Success vs Error Rate** – 정상 실행과 실패한 실행을 비교하는 영역 차트
- **Average Latency Over Time** – 응답 시간 변화를 보여주는 선 차트
- **드래그하여 선택** – 차트에서 클릭하고 드래그하여 사용자 정의 날짜 범위에 초점을 맞춥니다. 선택 영역은 차트에서 최소 두 개의 지점을 포함해야 합니다. 단순 클릭으로는 아무것도 선택되지 않습니다
- **선택 모드** – 선택한 범위는 기본 프리셋을 변경하지 않고 요약 카드, 차트, Workflow 테이블을 새로 고칩니다
- **Clear Selection** – 세부 분석을 마친 후 프리셋 시간 범위로 돌아갑니다

## 노드 유형

지연 시간 백분위수 아래 세 개의 차트는 표시된 워크플로 전체에서 노드 유형(Agent, HTTP Request, Code 등)별로 노드 시간과 오류가 어디에 집중되는지 보여줍니다:

- **가장 많은 시간을 소모한 노드** – 총 실행 시간이 가장 긴 상위 10개 노드 유형으로, 호출당 평균 지속 시간으로 표시됩니다. 특정 유형의 호출이 없었던 시간대에는 툴팁에 **호출 없음**으로 표시됩니다.
- **오류가 가장 많은 노드 유형** – 오류(오류 또는 timeout)가 가장 많은 상위 10개 노드 유형으로, 시간 구간별 자체 오류 수가 표시됩니다.
- **가장 많이 호출된 노드 유형** – 가장 많이 실행된 상위 10개 노드 유형으로, 시간 구간별 자체 호출 수가 표시됩니다. 건너뛴 노드는 계산되지 않습니다.

차트 위에 마우스를 올리면 포인터 바로 옆에 해당 노드 유형이 표시됩니다. 차트에서 가장 큰 노드 유형 옆에 표시하기에 너무 작은 노드 유형(1% 미만)은 해당 차트 및 범례에서 제외됩니다. 차트는 워크플로 필터, 시간 범위 및 차트에서 드래그하여 선택한 영역을 따릅니다. 노드 분석은 해당 기능을 도입한 릴리스 이후의 실행부터 기록되며 완료된 실행은 약 1분 이내에 표시됩니다. 이전 실행은 계산되지 않습니다.

## 자동 새로 고침
