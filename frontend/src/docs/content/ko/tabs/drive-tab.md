# Drive 탭

Drive 탭은 Workflow 전반에서 스킬에 의해 생성된 모든 파일을 표시합니다.

## 개요

스킬에 의해 생성된 파일(PDF, DOCX, CSV, 이미지 등)은 자동으로 저장되며 Drive 탭에 나열됩니다. 각 파일은 이름, 유형, 크기, 소스 노드, 생성 날짜, 팀 공유 상태를 표시합니다.

## 기능

- **검색** - 이름, 유형 또는 소스 노드로 파일을 필터링합니다
- **파일 ID 복사** - 파일 UUID를 클립보드에 복사하여 [Drive](../nodes/drive-node.md) 또는 [Converter](../nodes/converter-node.md) 노드에 붙여넣을 수 있습니다
- **다운로드** - 본인의 파일 및 팀을 통해 공유받은 파일에 대한 인증된 다운로드를 제공합니다
- **공유** - 선택적 비밀번호 보호 및 만료를 설정한 공유 가능한 다운로드 링크를 생성하거나, 현재 팀에 파일을 읽기 전용으로 공유합니다
- **삭제** - 파일 및 해당 공유 링크를 제거합니다
- **모두 지우기** - 확인 후 모든 파일 및 해당 공유 링크를 삭제합니다
- **일괄 작업** - 체크박스로 여러 파일을 선택하고(Shift-클릭으로 범위 선택) 동일한 작업을 한 번에 적용합니다
- **페이지네이션** - 대규모 파일 컬렉션을 탐색하며, 페이지당 행 수 선택기(25 / 50 / 100 / 전체)를 제공합니다

## 일괄 작업

본인이 소유한 파일은 행 시작 부분에 체크박스가 표시됩니다(팀을 통해 공유받은 파일은 읽기 전용이며 선택할 수 없습니다). 여러 행을 선택하거나 — 헤더 체크박스로 전체 페이지를 선택하고 **Shift-클릭**으로 범위를 선택할 수 있습니다 — 그런 다음 목록 위에 나타나는 일괄 작업 표시줄을 사용하십시오:

- **ZIP 다운로드**는 선택한 모든 파일을 단일 ZIP 아카이브로 묶어 다운로드합니다
- **일괄 작업**은 선택한 모든 파일에 하나의 설정을 적용할 수 있는 단일 대화 상자를 엽니다:
  - **내 팀에 모두 공유** / **팀 공유 제거**를 한 번의 클릭으로 수행합니다
  - **각 파일에 대한 공유 링크 생성**은 동일한 비밀번호, 만료, 최대 다운로드 설정을 사용합니다
- **삭제**는 확인 후 선택한 모든 파일 및 해당 공유 링크를 제거합니다
- **선택 해제**는 모든 선택을 해제합니다

대화 상자는 적용된 파일 수를 보고합니다(소유하지 않은 파일은 건너뜁니다). 페이지당 행 수 선택기의 **전체** 옵션을 사용하면 한 페이지에 모든 파일을 로드하여 전체 Drive에서 선택할 수 있습니다. 검색 상자에 입력하면 페이지당 행 수 선택기가 자동으로 **전체**로 전환되어 검색이 현재 페이지뿐만 아니라 모든 파일을 대상으로 수행됩니다. 검색을 지우면 이전 선택이 복원됩니다.

## 공유

다음과 같은 공유 링크를 생성할 수 있습니다:
- **인증 없음** - 공개 Token 기반 다운로드 URL
- **Basic Auth** - 비밀번호로 보호된 링크(사용자 이름: `file`)
- **만료** - 선택적 시간 기반 만료
- **다운로드 제한** - 선택적 최대 다운로드 횟수

파일에서 **내 팀에 공유**를 활성화하면 현재 소속된 모든 팀에 파일이 표시됩니다. 공유받은 팀 구성원은 읽기 전용 액세스 권한을 가지며, 관리 작업은 소유자만 수행할 수 있습니다.

## Agent Skill 액세스

Agent 노드의 스킬은 Drive 파일 읽기를 선택적으로 활성화할 수 있습니다. 스킬에 대해 **Enable Drive files**가 켜져 있으면, 해당 Python 코드는 생성된 `heym_drive.py` 헬퍼를 통해 파일 ID 또는 정확한 파일 이름으로 액세스 가능한 Drive 파일을 읽을 수 있습니다. 이 설정은 기본적으로 꺼져 있습니다.

전체 세부 사항은 [Drive reference](../reference/drive.md)를 참조하십시오.
