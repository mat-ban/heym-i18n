# HTML išvesties žemėlapis

**HTML išvesties žemėlapio** mazgas atvaizduoja vieną HTML šabloną į puslapį. Naudokite jį, kai kvietėjas yra **naršyklė**, o ne API klientas — darbo eiga atsako su `text/html`, o ne JSON.

## Apžvalga

| Ypatybė | Vertė |
|---------|-------|
| Įvestys | 1 |
| Išvestys | 0 (sugrįžimas) |
| Vykdymo išvestis | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Parametrai

| Parametras | Tipas | Aprašymas |
|------------|-------|-----------|
| `label` | string | Mazgo identifikatorius (camelCase) |
| `html` | string | Puslapio šablonas. `$nodeLabel.field` išraiškos yra interpoliuojamos vietoje. |
| `statusCode` | number | HTTP statusas atsakymui (numatytasis `200`) |
| `contentType` | string | Atsakymo turinio tipas (numatytasis `text/html; charset=utf-8`) |

## Webhook ir vykdymo elgsena

Kai šis mazgas yra **vienintelis** terminalinis išvestis darbo eigoje, vykdymo galas atsako su atvaizduotu puslapiu, sukonfigūruotu statuso kodu ir sukonfigūruotu turinio tipu — be JSON apvalkalo, be etiketės apvyniojimo.

Du dalykai tai išjungia:

- **Antras terminalinis mazgas.** Su kitu aktyviu terminalu grafike, Heym grįžta prie įprasto per etiketę JSON žemėlapio, o puslapis atkeliauja kaip eilutės laukas.
- **`X-Simple-Response: false`.** Šis antraštė prašo pilno apvalkalo su `status`, `node_results` ir laikais, kas yra tai, ką redaktoriaus drobė naudoja. Siųskite jį, kai derinate puslapio darbo eigą.

## Puslapio pateikimas naršyklei

Nustatykite darbo eigos **užklausos metodą** į `GET` cURL dialoge, kad paprasta naršyklės navigacija pasiektų jį. `GET` užklausa neturi kūno, todėl įvestys gaunamos iš užklausos eilutės:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Skaitykite tuos vertes su `$input.query.name`. Žiūrėkite [Webhooks](../reference/webhooks.md) pilnam metodo kontraktui.

Darbo eiga be trigero mazgo, kurios vienintelis terminalas yra šis mazgas, rodo **WEB** žymeklį [Darbo eigos skirtuke](../tabs/workflows-tab.md).

## Agentų įrankių naudojimas

Nepalaikoma. Šis mazgas yra terminalinis sugrižimas, todėl jo negalima prijungti prie [Agent Node](./agent-node.md) įrankių rankenos. Tas pats taikoma [JSON išvesties žemėlapiui](./json-output-mapper-node.md).

## Ciklo apribojimas

Ta pati taisyklė kaip [Išvestis](./output-node.md): neįdėkite šio mazgo į ciklo iteracijos šaką — tik po ciklo `done` šakos. Žiūrėkite [Ciklas](./loop-node.md).

## Pavyzdys

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
