# Klaviatūros Sparčiuosiuose Klavišuose

Heym siūlo klaviatūros sparčiuosius klavišus visame darbo eigos redaktoriuje ir drobėje, kad pagreitintų dažnai atliekamas veiklas.

## Globalūs Redaktoriaus Sparčiuosiuose Klavišuose

Šie sparčiuosieji klavišai veikia bet kurioje darbo eigos redaktoriaus vietoje.

| Sparčiasis Klavišas | Veiksmas |
|---------------------|----------|
| `Ctrl + K` / `Cmd + K` | Atidaryti Komandų Paletę |
| `Ctrl + I` / `Cmd + I` | Įjungti [AI Asistentą](./ai-assistant.md) (veikia rašant) |
| `Ctrl + Enter` / `Cmd + Enter` | Vykdyti dabartinę darbo eigą |
| `Ctrl + S` / `Cmd + S` | Išsaugoti darbo eigą |
| `Ctrl + Z` / `Cmd + Z` | Atšaukti |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Pakartoti |
| `Ctrl + Y` / `Cmd + Y` | Pakartoti (alternatyva) |
| `Escape` | Uždaryti atidarytas uždangas, dialogus ir paneles |

## Drobės Sparčiuosiuose Klavišuose

Šie sparčiuosieji klavišai taikomi, kai drobė yra fokusuota (aktyvus tekstinis įvedimas).

### Pasirinkimas ir Navigacija

| Sparčiasis Klavišas | Veiksmas |
|---------------------|----------|
| `Ctrl + A` / `Cmd + A` | Pasirinkti visus mazgus |
| `Shift` (laikyti) | Vilkti, kad pasirinktumėte kelis mazgus |
| `Ctrl` / `Cmd` (laikyti) | Spustelėti, kad pridėtumėte atskirus mazgus prie pasirinkimo |
| `Escape` | Atšaukti visus pasirinkimus; uždaryti įterptinį mazgo paiešką |

### Mazgų Redagavimas

| Sparčiasis Klavišas | Veiksmas |
|---------------------|----------|
| `Ctrl + C` / `Cmd + C` | Kopijuoti pasirinktą mazgą(-us) |
| `Ctrl + X` / `Cmd + X` | Iškirpti pasirinktą mazgą(-us) |
| `Ctrl + V` / `Cmd + V` | Įklijuoti mazgą(-us) |
| `Delete` arba `Backspace` | Ištrinti pasirinktą mazgą(-us) ir/arba briaunas |
| `D` | Įjungti/išjungti pasirinktą mazgą(-us) |
| `P` | Įjungti/išjungti prisegtus duomenis pasirinktame mazge |

### Įterptinė Mazgo Paieška

Įvedus bet kurį spausdinamą simbolį drobėje (kai nėra aktyvaus tekstinio įvedimo), atsidaro įterptinė mazgo paieškos iššokantis langas. Įvestas simbolis tampa pirmuoju paieškos užklausos simboliu.

| Sparčiasis Klavišas | Veiksmas |
|---------------------|----------|
| Bet kuris spausdinamas simbolis | Atidaryti įterptinę mazgo paiešką ir pradėti rašyti |
| `Backspace` | Pašalinti paskutinį simbolį iš paieškos užklausos |
| `Escape` | Uždaryti įterptinę mazgo paiešką |

## Komandų Paletė (`Ctrl + K`)

Komandų Paletė yra prieinama iš redaktoriaus, prietaisų skydelio, dokumentacijos ir vertinimų peržiūrų. Ji leidžia greitai naršyti darbo eigos, skirtukų ir dokumentacijos puslapiuose, nepaliekant klaviatūros.

| Sparčiasis Klavišas | Veiksmas |
|---------------------|----------|
| `Ctrl + K` / `Cmd + K` | Atidaryti Komandų Paletę |
| `↑` / `↓` | Naršyti rezultatų sąraše |
| `Tab` / `Shift + Tab` | Naršyti rezultatų sąraše |
| `Enter` | Atidaryti pasirinktą elementą |
| `Escape` | Uždaryti paletę |

## Prietaisų Skydelio Sparčiuosiuose Klavišuose

Šie sparčiuosieji klavišai veikia Darbo Eigos skirtuke, kai nėra aktyvaus kito tekstinio įvedimo.

| Sparčiasis Klavišas | Veiksmas |
|---------------------|----------|
| `Ctrl + F` / `Cmd + F` | Fokusuoti darbo eigos paiešką |
| `Escape` | Išvalyti darbo eigos paiešką, kai joje yra tekstas |

## Ypatybių Panelės Sparčiuosiuose Klavišuose

Šie sparčiuosieji klavišai veikia, kai mazgas yra pasirinktas ir ypatybių panelė yra atidaryta.

| Sparčiasis Klavišas | Veiksmas |
|---------------------|----------|
| `Ctrl + Shift + O` / `Cmd + Shift + O` | Atidaryti susietą sub-darbo eigą naujame skirtuke (tik Vykdyti mazgas) |

## Vertinimo Dialogo Sparčiuosiuose Klavišuose

Šie sparčiuosieji klavišai veikia, kai atidarytas Vertinimo dialogas.

| Sparčiasis Klavišas | Veiksmas |
|---------------------|----------|
| `Ctrl + Enter` / `Cmd + Enter` | Taikyti išraišką ir uždaryti dialogą |
| `Ctrl + Z` / `Cmd + Z` | Atšaukti pakeitimus išraiškos redaktoriuje |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Pakartoti pakeitimus išraiškos redaktoriuje |
| `Ctrl + Y` / `Cmd + Y` | Pakartoti pakeitimus išraiškos redaktoriuje (alternatyva) |

## Istorijos ir Vykdymų Sparčiuosiuose Klavišuose

Šie sparčiuosieji klavišai yra prieinami Vykdymo Istorijos dialoge ir Vykdymų panelėje.

| Sparčiasis Klavišas | Veiksmas |
|---------------------|----------|
| `S` | Įjungti paieškos įvedimą, kad filtruotumėte įrašus |
