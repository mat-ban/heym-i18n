# HTML izvades kartētājs

**HTML izvades kartētāja** mezgls renderē vienu HTML veidni lapā. Izmantojiet to, ja izsaucējs ir **pārlūkprogramma**, nevis API klients — workflow atbild ar `text/html`, nevis JSON.

## Pārskats

| Īpašība | Vērtība |
|----------|-------|
| Ievades | 1 |
| Izvades | 0 (sink) |
| Izpildlaika izvade | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Parametri

| Parametrs | Tips | Apraksts |
|-----------|------|-------------|
| `label` | string | Mezgla identifikators (camelCase) |
| `html` | string | Lapas veidne. `$nodeLabel.field` izteiksmes tiek interpolētas vietā. |
| `statusCode` | number | HTTP statuss atbildei (pēc noklusējuma `200`) |
| `contentType` | string | Atbildes satura tips (pēc noklusējuma `text/html; charset=utf-8`) |

## Webhook un izpildes darbība

Ja šis mezgls ir **vienīgā** terminālā izvade workflow, izpildes endpoint atbild ar renderēto lapu, konfigurēto statusa kodu un konfigurēto satura tipu — bez JSON aploksnes, bez label iesaiņojuma.

Divi apstākļi to izslēdz:

- **Otrs terminālais mezgls.** Ja grafā ir vēl viens aktīvs terminālis, Heym atgriežas pie parastā katra label JSON kartējuma, un lapa pienāk kā string lauks.
- **`X-Simple-Response: false`.** Šis header pieprasa pilnu aploksni ar `status`, `node_results` un laika mērījumiem, ko izmanto redaktora kanva. Sūtiet to, kad atkļūdojat lapas workflow.

## Lapas apkalpošana pārlūkprogrammai

Iestatiet workflow **pieprasījuma metodi** uz `GET` cURL dialogā, lai vienkārša pārlūkprogrammas navigācija to sasniegtu. `GET` pieprasījumam nav body, tāpēc ievades nāk no query string:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Lasiet šīs vērtības ar `$input.query.name`. Skatiet [Webhooks](../reference/webhooks.md) pilnīgam metodes līgumam.

Workflow bez trigger mezgla, kura vienīgais terminālis ir šis mezgls, [Workflows cilnē](../tabs/workflows-tab.md) parāda **WEB** birku.

## Aģenta rīka izmantošana

Netiek atbalstīta. Šis mezgls ir terminālais sink, tāpēc to nevar pievienot [Agent Node](./agent-node.md) rīku rokturim. Tas pats attiecas uz [JSON izvades kartētāju](./json-output-mapper-node.md).

## Cilpas ierobežojums

Tas pats noteikums kā [Output](./output-node.md): nenovietojiet šo mezglu cilpas iterācijas zarā — tikai pēc cilpas `done` zara. Skatiet [Loop](./loop-node.md).

## Piemērs

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
