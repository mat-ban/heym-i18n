# Tastatūras saīsnes

Heym nodrošina tastatūras saīsnes workflow redaktorā un kanvā, lai paātrinātu biežāk veicamās darbības.

## Globālās redaktora saīsnes

Šīs saīsnes ir aktīvas jebkurā workflow redaktora vietā.

| Saīsne | Darbība |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Atvērt komandu paleti |
| `Ctrl + I` / `Cmd + I` | Pārslēgt [AI Assistant](./ai-assistant.md) paneli (darbojas arī rakstīšanas laikā) |
| `Ctrl + Enter` / `Cmd + Enter` | Palaist pašreizējo workflow |
| `Ctrl + S` / `Cmd + S` | Saglabāt workflow |
| `Ctrl + Z` / `Cmd + Z` | Atsaukt |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Atkārtot |
| `Ctrl + Y` / `Cmd + Y` | Atkārtot (alternatīva) |
| `Escape` | Aizvērt atvērtos pārklājumus, dialogus un panelus |

## Kanvas saīsnes

Šīs saīsnes darbojas, kad kanva ir fokusā (nav aktīva teksta ievade).

### Atlase un navigācija

| Saīsne | Darbība |
|----------|--------|
| `Ctrl + A` / `Cmd + A` | Atlasīt visus mezglus |
| `Shift` (turēt) | Vilkšana, lai atlasītu vairākus mezglus |
| `Ctrl` / `Cmd` (turēt) | Klikšķis, lai pievienotu atsevišķus mezglus atlasei |
| `Escape` | Noņemt atlasi visiem mezgliem; aizvērt iekļauto mezglu meklēšanu |

### Mezglu rediģēšana

| Saīsne | Darbība |
|----------|--------|
| `Ctrl + C` / `Cmd + C` | Kopēt atlasīto(-os) mezglu(-us) |
| `Ctrl + X` / `Cmd + X` | Izgriezt atlasīto(-os) mezglu(-us) |
| `Ctrl + V` / `Cmd + V` | Ielīmēt mezglu(-us) |
| `Delete` vai `Backspace` | Dzēst atlasīto(-os) mezglu(-us) un/vai savienojumu(-us) |
| `D` | Pārslēgt atlasītā(-o) mezgla(-u) iespējošanu / atspējošanu |
| `P` | Pārslēgt piespraustos datus atlasītajā mezglā |

### Iekļautā mezglu meklēšana

Rakstot jebkuru iespieddrukājamu rakstzīmi kanvā (kad nav fokusā teksta ievade), tiek atvērts iekļautās mezglu meklēšanas uznirstošais logs. Ievadītā rakstzīme kļūst par meklēšanas vaicājuma pirmo rakstzīmi.

| Saīsne | Darbība |
|----------|--------|
| Jebkura iespieddrukājama rakstzīme | Atvērt iekļauto mezglu meklēšanu un sākt rakstīt |
| `Backspace` | Noņemt pēdējo rakstzīmi no meklēšanas vaicājuma |
| `Escape` | Aizvērt iekļauto mezglu meklēšanu |

## Komandu palete (`Ctrl + K`)

Komandu palete ir pieejama no redaktora, dashboard, dokumentācijas un novērtējumu skatiem. Tā ļauj ātri pārvietoties uz workflow, cilnēm un dokumentācijas lapām, neatstājot tastatūru.

| Saīsne | Darbība |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Atvērt komandu paleti |
| `↑` / `↓` | Pārvietoties rezultātu sarakstā |
| `Tab` / `Shift + Tab` | Pārvietoties rezultātu sarakstā |
| `Enter` | Atvērt atlasīto vienumu |
| `Escape` | Aizvērt paleti |

## Dashboard saīsnes

Šīs saīsnes ir aktīvas cilnē Workflows, kad nav aktīva cita teksta ievade.

| Saīsne | Darbība |
|----------|--------|
| `Ctrl + F` / `Cmd + F` | Fokusēt workflow meklēšanu |
| `Escape` | Notīrīt workflow meklēšanu, ja tajā ir teksts |

## Rekvizītu paneļa saīsnes

Šīs saīsnes ir aktīvas, kad ir atlasīts mezgls un rekvizītu panelis ir atvērts.

| Saīsne | Darbība |
|----------|--------|
| `Ctrl + Shift + O` / `Cmd + Shift + O` | Atvērt saistīto apakš-workflow jaunā cilnē (tikai Execute mezglam) |

## Novērtēšanas dialoga saīsnes

Šīs saīsnes ir aktīvas, kamēr ir atvērts novērtēšanas dialogs.

| Saīsne | Darbība |
|----------|--------|
| `Ctrl + Enter` / `Cmd + Enter` | Piemērot izteiksmi un aizvērt dialogu |
| `Ctrl + Z` / `Cmd + Z` | Atsaukt izmaiņas izteiksmes redaktorā |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Atkārtot izmaiņas izteiksmes redaktorā |
| `Ctrl + Y` / `Cmd + Y` | Atkārtot izmaiņas izteiksmes redaktorā (alternatīva) |

## Vēstures un izpildes saīsnes

Šīs saīsnes ir pieejamas izpildes vēstures dialogā un izpildes panelī.

| Saīsne | Darbība |
|----------|--------|
| `S` | Pārslēgt meklēšanas ievadi, lai filtrētu ierakstus |
