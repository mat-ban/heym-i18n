# HTML output mapper

De **HTML output mapper**-node rendert één HTML-sjabloon naar een pagina. Gebruik deze wanneer de aanroeper een **browser** is in plaats van een API-client — de workflow antwoordt dan met `text/html` in plaats van JSON.

## Overzicht

| Eigenschap | Waarde |
|----------|-------|
| Invoer | 1 |
| Uitvoer | 0 (sink) |
| Runtime-uitvoer | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Parameters

| Parameter | Type | Beschrijving |
|-----------|------|-------------|
| `label` | string | Node-identificatie (camelCase) |
| `html` | string | De paginasjabloon. `$nodeLabel.field`-expressies worden ter plaatse geïnterpoleerd. |
| `statusCode` | number | HTTP-status voor het antwoord (standaard `200`) |
| `contentType` | string | Contenttype van het antwoord (standaard `text/html; charset=utf-8`) |

## Webhook- en uitvoeringsgedrag

Wanneer deze node de **enige** terminale uitvoer van de workflow is, antwoordt het execute-endpoint met de gerenderde pagina, de geconfigureerde statuscode en het geconfigureerde contenttype — geen JSON-envelope, geen label-wrapper.

Twee zaken schakelen dit uit:

- **Een tweede terminale node.** Met een andere actieve terminal in de graph valt Heym terug op de normale JSON-map per label en arriveert de pagina als een stringveld.
- **`X-Simple-Response: false`.** Die header vraagt om de volledige envelope met `status`, `node_results` en timings, wat de canvas van de editor gebruikt. Verstuur deze bij het debuggen van een pagina-workflow.

## Een pagina aan een browser leveren

Stel de **request method** van de workflow in op `GET` in het cURL-dialoogvenster, zodat een gewone browsernavigatie de workflow bereikt. Een `GET`-verzoek bevat geen body, dus invoer komt uit de query string:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Lees deze waarden met `$input.query.name`. Zie [Webhooks](../reference/webhooks.md) voor het volledige method-contract.

Een workflow zonder trigger-node waarvan de enige terminal deze node is, toont een **WEB**-chip in het tabblad [Workflows](../tabs/workflows-tab.md).

## Gebruik als Agent-tool

Niet ondersteund. Deze node is een terminale sink en kan daarom niet worden gekoppeld aan een tools-handle van een [Agent Node](./agent-node.md). Hetzelfde geldt voor de [JSON output mapper](./json-output-mapper-node.md).

## Loop-beperking

Dezelfde regel als bij [Output](./output-node.md): plaats deze node niet in een iteratiebranch van een loop—alleen na de `done`-branch van de loop. Zie [Loop](./loop-node.md).

## Voorbeeld

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
