# Sneltoetsen

Heym biedt sneltoetsen in de workflow-editor en op het canvas om veelvoorkomende acties te versnellen.

## Algemene editor-sneltoetsen

Deze sneltoetsen zijn overal in de workflow-editor actief.

| Sneltoets | Actie |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Open het Command Palette |
| `Ctrl + I` / `Cmd + I` | Het paneel [AI Assistant](./ai-assistant.md) in- of uitschakelen (werkt tijdens het typen) |
| `Ctrl + Enter` / `Cmd + Enter` | De huidige workflow uitvoeren |
| `Ctrl + S` / `Cmd + S` | De workflow opslaan |
| `Ctrl + Z` / `Cmd + Z` | Ongedaan maken |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Opnieuw uitvoeren |
| `Ctrl + Y` / `Cmd + Y` | Opnieuw uitvoeren (alternatief) |
| `Escape` | Open overlays, dialogen en panelen sluiten |

## Canvas-sneltoetsen

Deze sneltoetsen zijn van toepassing wanneer het canvas is gefocust (geen tekstinvoer actief).

### Selectie en navigatie

| Sneltoets | Actie |
|----------|--------|
| `Ctrl + A` / `Cmd + A` | Alle nodes selecteren |
| `Shift` (ingedrukt houden) | Slepen om meerdere nodes te selecteren |
| `Ctrl` / `Cmd` (ingedrukt houden) | Klikken om afzonderlijke nodes aan de selectie toe te voegen |
| `Escape` | Alle nodes deselecteren; inline node-zoekopdracht sluiten |

### Nodes bewerken

| Sneltoets | Actie |
|----------|--------|
| `Ctrl + C` / `Cmd + C` | Geselecteerde node(s) kopiëren |
| `Ctrl + X` / `Cmd + X` | Geselecteerde node(s) knippen |
| `Ctrl + V` / `Cmd + V` | Node(s) plakken |
| `Delete` of `Backspace` | Geselecteerde node(s) en/of edge(s) verwijderen |
| `D` | Geselecteerde node(s) in- / uitschakelen |
| `P` | Vastgezette data op de geselecteerde node in- of uitschakelen |

### Inline node-zoekopdracht

Door een willekeurig afdrukbaar teken op het canvas te typen (wanneer geen tekstinvoer is gefocust) wordt de inline node-zoekpopup geopend. Het getypte teken wordt het eerste teken van de zoekopdracht.

| Sneltoets | Actie |
|----------|--------|
| Elk afdrukbaar teken | Inline node-zoekopdracht openen en beginnen met typen |
| `Backspace` | Het laatste teken uit de zoekopdracht verwijderen |
| `Escape` | De inline node-zoekopdracht sluiten |

## Command Palette (`Ctrl + K`)

Het Command Palette is beschikbaar vanuit de editor, het dashboard, de docs en de evaluatie-weergaven. Hiermee kunt u snel naar workflows, tabbladen en documentatiepagina's navigeren zonder het toetsenbord te verlaten.

| Sneltoets | Actie |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Het Command Palette openen |
| `↑` / `↓` | Door de resultatenlijst navigeren |
| `Tab` / `Shift + Tab` | Door de resultatenlijst navigeren |
| `Enter` | Het geselecteerde item openen |
| `Escape` | Het palette sluiten |

## Dashboard-sneltoetsen

Deze sneltoetsen zijn actief op het tabblad Workflows wanneer geen andere tekstinvoer actief is.

| Sneltoets | Actie |
|----------|--------|
| `Ctrl + F` / `Cmd + F` | Workflow-zoekopdracht focussen |
| `Escape` | Workflow-zoekopdracht wissen wanneer deze tekst bevat |

## Sneltoetsen voor het eigenschappenpaneel

Deze sneltoetsen zijn actief wanneer een node is geselecteerd en het eigenschappenpaneel is geopend.

| Sneltoets | Actie |
|----------|--------|
| `Ctrl + Shift + O` / `Cmd + Shift + O` | De gekoppelde sub-workflow in een nieuw tabblad openen (alleen Execute-node) |

## Sneltoetsen voor het Evaluate-dialoogvenster

Deze sneltoetsen zijn actief wanneer het Evaluate-dialoogvenster is geopend.

| Sneltoets | Actie |
|----------|--------|
| `Ctrl + Enter` / `Cmd + Enter` | Expressie toepassen en het dialoogvenster sluiten |
| `Ctrl + Z` / `Cmd + Z` | Wijzigingen in de expressie-editor ongedaan maken |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Wijzigingen in de expressie-editor opnieuw uitvoeren |
| `Ctrl + Y` / `Cmd + Y` | Wijzigingen in de expressie-editor opnieuw uitvoeren (alternatief) |

## Sneltoetsen voor Geschiedenis en Traces

Deze sneltoetsen zijn beschikbaar in het dialoogvenster Uitvoeringsgeschiedenis en het Traces-paneel.

| Sneltoets | Actie |
|----------|--------|
| `S` | Het zoekinvoerveld in- of uitschakelen om items te filteren |
