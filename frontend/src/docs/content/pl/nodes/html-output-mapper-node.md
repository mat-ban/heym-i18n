# Mapper wyjścia HTML

Węzeł **Mapper wyjścia HTML** renderuje pojedynczy szablon HTML do postaci strony. Należy go użyć, gdy wywołującym jest **przeglądarka**, a nie klient API — workflow odpowiada wówczas typem `text/html` zamiast JSON.

## Przegląd

| Właściwość | Wartość |
|----------|-------|
| Wejścia | 1 |
| Wyjścia | 0 (sink) |
| Wyjście wykonania | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Parametry

| Parametr | Typ | Opis |
|-----------|------|-------------|
| `label` | string | Identyfikator węzła (camelCase) |
| `html` | string | Szablon strony. Wyrażenia `$nodeLabel.field` są interpolowane w miejscu. |
| `statusCode` | number | Status HTTP odpowiedzi (domyślnie `200`) |
| `contentType` | string | Typ zawartości odpowiedzi (domyślnie `text/html; charset=utf-8`) |

## Zachowanie Webhook i wykonania

Gdy ten węzeł jest **jedynym** terminalnym wyjściem workflow, endpoint execute odpowiada wyrenderowaną stroną, skonfigurowanym kodem statusu oraz skonfigurowanym typem zawartości — bez koperty JSON i bez otoczki etykiety.

Dwie rzeczy to wyłączają:

- **Drugi węzeł terminalny.** Gdy w grafie istnieje inny aktywny węzeł terminalny, Heym powraca do standardowej mapy JSON według etykiet, a strona dociera jako pole typu string.
- **`X-Simple-Response: false`.** Ten nagłówek żąda pełnej koperty z `status`, `node_results` oraz pomiarami czasu, czego używa canvas edytora. Należy go wysłać podczas debugowania workflow strony.

## Serwowanie strony do przeglądarki

Aby zwykła nawigacja przeglądarki mogła dotrzeć do workflow, należy ustawić **metodę żądania** workflow na `GET` w oknie dialogowym cURL. Żądanie `GET` nie przenosi ciała, więc dane wejściowe pochodzą z query string:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Wartości te odczytuje się za pomocą `$input.query.name`. Pełny kontrakt metod opisano w sekcji [Webhooks](../reference/webhooks.md).

Workflow bez węzła trigger, którego jedynym węzłem terminalnym jest ten węzeł, wyświetla znacznik **WEB** w zakładce [Workflows](../tabs/workflows-tab.md).

## Użycie jako narzędzie agenta

Nieobsługiwane. Ten węzeł jest terminalnym sinkiem, więc nie można go podłączyć do uchwytu narzędzi [Agent Node](./agent-node.md). To samo dotyczy [Mappera wyjścia JSON](./json-output-mapper-node.md).

## Ograniczenie pętli

Ta sama zasada co w przypadku [Output](./output-node.md): nie należy umieszczać tego węzła wewnątrz gałęzi iteracji pętli — wyłącznie po gałęzi `done` pętli. Zobacz [Loop](./loop-node.md).

## Przykład

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
