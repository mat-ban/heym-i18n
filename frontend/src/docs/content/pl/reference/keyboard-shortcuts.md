# Skróty klawiaturowe

Heym udostępnia skróty klawiaturowe w edytorze workflow oraz na canvasie, aby przyspieszyć typowe działania.

## Globalne skróty edytora

Te skróty są aktywne w dowolnym miejscu edytora workflow.

| Skrót | Działanie |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Otwórz Paletę poleceń |
| `Ctrl + I` / `Cmd + I` | Przełącz panel [Asystenta AI](./ai-assistant.md) (działa podczas pisania) |
| `Ctrl + Enter` / `Cmd + Enter` | Uruchom bieżący workflow |
| `Ctrl + S` / `Cmd + S` | Zapisz workflow |
| `Ctrl + Z` / `Cmd + Z` | Cofnij |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Ponów |
| `Ctrl + Y` / `Cmd + Y` | Ponów (alternatywnie) |
| `Escape` | Zamknij otwarte nakładki, okna dialogowe i panele |

## Skróty na canvasie

Te skróty działają, gdy canvas jest aktywny (żadne pole tekstowe nie jest aktywne).

### Zaznaczanie i nawigacja

| Skrót | Działanie |
|----------|--------|
| `Ctrl + A` / `Cmd + A` | Zaznacz wszystkie węzły |
| `Shift` (przytrzymaj) | Przeciągnij, aby zaznaczyć wiele węzłów |
| `Ctrl` / `Cmd` (przytrzymaj) | Kliknij, aby dodać pojedyncze węzły do zaznaczenia |
| `Escape` | Odznacz wszystkie węzły; zamknij wbudowaną wyszukiwarkę węzłów |

### Edycja węzłów

| Skrót | Działanie |
|----------|--------|
| `Ctrl + C` / `Cmd + C` | Kopiuj zaznaczony(-e) węzeł(-y) |
| `Ctrl + X` / `Cmd + X` | Wytnij zaznaczony(-e) węzeł(-y) |
| `Ctrl + V` / `Cmd + V` | Wklej węzeł(-y) |
| `Delete` lub `Backspace` | Usuń zaznaczony(-e) węzeł(-y) i/lub krawędź(-e) |
| `D` | Przełącz zaznaczony(-e) węzeł(-y) między włączonym a wyłączonym |
| `P` | Przełącz przypięte dane na zaznaczonym węźle |

### Wbudowana wyszukiwarka węzłów

Wpisanie dowolnego znaku drukowalnego na canvasie (gdy żadne pole tekstowe nie jest aktywne) otwiera wyskakujące okno wbudowanej wyszukiwarki węzłów. Wpisany znak staje się pierwszym znakiem zapytania wyszukiwania.

| Skrót | Działanie |
|----------|--------|
| Dowolny znak drukowalny | Otwórz wbudowaną wyszukiwarkę węzłów i rozpocznij pisanie |
| `Backspace` | Usuń ostatni znak z zapytania wyszukiwania |
| `Escape` | Zamknij wbudowaną wyszukiwarkę węzłów |

## Paleta poleceń (`Ctrl + K`)

Paleta poleceń jest dostępna z poziomu edytora, dashboardu, dokumentacji oraz widoków ewaluacji. Umożliwia szybkie przechodzenie do workflow, kart i stron dokumentacji bez odrywania rąk od klawiatury.

| Skrót | Działanie |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Otwórz Paletę poleceń |
| `↑` / `↓` | Nawiguj po liście wyników |
| `Tab` / `Shift + Tab` | Nawiguj po liście wyników |
| `Enter` | Otwórz zaznaczony element |
| `Escape` | Zamknij paletę |

## Skróty dashboardu

Te skróty są aktywne na karcie Workflows, gdy żadne inne pole tekstowe nie jest aktywne.

| Skrót | Działanie |
|----------|--------|
| `Ctrl + F` / `Cmd + F` | Ustaw fokus na wyszukiwaniu workflow |
| `Escape` | Wyczyść wyszukiwanie workflow, gdy zawiera tekst |

## Skróty panelu właściwości

Te skróty są aktywne, gdy węzeł jest zaznaczony, a panel właściwości jest otwarty.

| Skrót | Działanie |
|----------|--------|
| `Ctrl + Shift + O` / `Cmd + Shift + O` | Otwórz powiązany pod-workflow w nowej karcie (tylko węzeł Execute) |

## Skróty okna dialogowego Evaluate

Te skróty są aktywne, gdy okno dialogowe Evaluate jest otwarte.

| Skrót | Działanie |
|----------|--------|
| `Ctrl + Enter` / `Cmd + Enter` | Zastosuj wyrażenie i zamknij okno dialogowe |
| `Ctrl + Z` / `Cmd + Z` | Cofnij zmiany w edytorze wyrażeń |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Ponów zmiany w edytorze wyrażeń |
| `Ctrl + Y` / `Cmd + Y` | Ponów zmiany w edytorze wyrażeń (alternatywnie) |

## Skróty historii i wykonań

Te skróty są dostępne w oknie dialogowym Historii wykonań oraz w panelu Wykonania.

| Skrót | Działanie |
|----------|--------|
| `S` | Przełącz pole wyszukiwania, aby filtrować wpisy |
