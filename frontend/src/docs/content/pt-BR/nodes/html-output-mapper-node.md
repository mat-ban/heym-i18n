# Mapeador de Saída HTML

O nó **Mapeador de saída HTML** renderiza um único template HTML em uma página. Utilize-o quando o chamador for um **navegador** em vez de um cliente de API — o workflow responde com `text/html` em vez de JSON.

## Visão geral

| Propriedade | Valor |
|----------|-------|
| Entradas | 1 |
| Saídas | 0 (sink) |
| Saída em tempo de execução | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Parâmetros

| Parâmetro | Tipo | Descrição |
|-----------|------|-------------|
| `label` | string | Identificador do nó (camelCase) |
| `html` | string | O template da página. Expressões `$nodeLabel.field` são interpoladas no local. |
| `statusCode` | number | Status HTTP para a resposta (padrão `200`) |
| `contentType` | string | Tipo de conteúdo da resposta (padrão `text/html; charset=utf-8`) |

## Comportamento de Webhook e execução

Quando este nó é a **única** saída terminal do workflow, o endpoint de execução responde com a página renderizada, o status code configurado e o content type configurado — sem envelope JSON, sem wrapper de label.

Duas situações desativam esse comportamento:

- **Um segundo nó terminal.** Com outro terminal ativo no grafo, o Heym recorre ao mapa JSON normal por label e a página chega como um campo string.
- **`X-Simple-Response: false`.** Esse header solicita o envelope completo com `status`, `node_results` e timings, que é o que o canvas do editor utiliza. Envie-o quando estiver depurando um workflow de página.

## Servindo uma página para um navegador

Defina o **request method** do workflow como `GET` no diálogo cURL para que uma navegação simples de navegador consiga alcançá-lo. Uma requisição `GET` não carrega body, então as entradas vêm da query string:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Leia esses valores com `$input.query.name`. Consulte [Webhooks](../reference/webhooks.md) para o contrato completo de métodos.

Um workflow sem nó de trigger cujo único terminal é este nó exibe um chip **WEB** na [aba Workflows](../tabs/workflows-tab.md).

## Uso como ferramenta de agente

Não suportado. Este nó é um sink terminal, portanto não pode ser anexado a um handle de ferramentas do [Nó de Agente](./agent-node.md). O mesmo se aplica ao [Mapeador de saída JSON](./json-output-mapper-node.md).

## Restrição de loop

Mesma regra do [Output](./output-node.md): não coloque este nó dentro de um branch de iteração de loop — apenas após o branch `done` do loop. Consulte [Loop](./loop-node.md).

## Exemplo

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
