# Mapeador de saída HTML

O nó **Mapeador de saída HTML** renderiza um único modelo HTML em uma página. Utilize-o quando o chamador for um **navegador** em vez de um cliente de API — o Workflow responde com `text/html` em vez de JSON.

## Visão geral

| Propriedade | Valor |
|----------|-------|
| Entradas | 1 |
| Saídas | 0 (sink) |
| Saída em tempo de execução | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Parâmetros

| Parâmetro | Tipo | Descrição |
|-----------|------|-----------|
| `label` | string | Identificador do nó (camelCase) |
| `html` | string | O modelo da página. As expressões `$nodeLabel.field` são interpoladas no local. |
| `statusCode` | number | Status HTTP para a resposta (padrão `200`) |
| `contentType` | string | Tipo de conteúdo da resposta (padrão `text/html; charset=utf-8`) |

## Comportamento de Webhook e execução

Quando este nó é a **única** saída terminal do Workflow, o endpoint de execução responde com a página renderizada, o código de status configurado e o tipo de conteúdo configurado — sem envelope JSON, sem wrapper de label.

Dois fatores desativam esse comportamento:

- **Um segundo nó terminal.** Com outro terminal ativo no grafo, o Heym recorre ao mapa JSON normal por label e a página chega como um campo string.
- **`X-Simple-Response: false`.** Esse header solicita o envelope completo com `status`, `node_results` e timings, que é o que o canvas do editor utiliza. Envie-o ao depurar um Workflow de página.

## Servindo uma página a um navegador

Defina o **método de requisição** do Workflow como `GET` no diálogo cURL para que uma navegação simples de navegador o alcance. Uma requisição `GET` não carrega corpo, portanto as entradas vêm da query string:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Leia esses valores com `$input.query.name`. Consulte [Webhooks](../reference/webhooks.md) para o contrato completo de métodos.

Um Workflow sem nó Trigger cujo único terminal é este nó exibe um chip **WEB** na [aba Workflows](../tabs/workflows-tab.md).

## Uso como ferramenta de Agent

Não suportado. Este nó é um sink terminal, portanto não pode ser anexado a um handle de ferramentas do [Nó Agent](./agent-node.md). O mesmo se aplica ao [Mapeador de saída JSON](./json-output-mapper-node.md).

## Restrição de Loop

Mesma regra do [Output](./output-node.md): não posicione este nó dentro de um ramo de iteração de loop — apenas após o ramo `done` do loop. Consulte [Loop](./loop-node.md).

## Exemplo

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
