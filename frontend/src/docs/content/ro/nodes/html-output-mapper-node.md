# Mapare ieșire HTML

Nodul **Mapare ieșire HTML** randează un singur șablon HTML într-o pagină. Utilizați-l atunci când apelantul este un **browser** și nu un client API — workflow-ul răspunde cu `text/html` în loc de JSON.

## Prezentare generală

| Proprietate | Valoare |
|----------|-------|
| Intrări | 1 |
| Ieșiri | 0 (sink) |
| Ieșire la runtime | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Parametri

| Parametru | Tip | Descriere |
|-----------|------|-------------|
| `label` | string | Identificatorul nodului (camelCase) |
| `html` | string | Șablonul paginii. Expresiile `$nodeLabel.field` sunt interpolate pe loc. |
| `statusCode` | number | Codul de stare HTTP pentru răspuns (implicit `200`) |
| `contentType` | string | Tipul de conținut al răspunsului (implicit `text/html; charset=utf-8`) |

## Comportamentul Webhook și la execuție

Atunci când acest nod este **singura** ieșire terminală a workflow-ului, endpoint-ul de execuție răspunde cu pagina randată, codul de stare configurat și tipul de conținut configurat — fără plic JSON, fără wrapper de etichetă.

Două situații dezactivează acest comportament:

- **Un al doilea nod terminal.** Cu un alt terminal activ în graf, Heym revine la harta JSON normală pe etichete, iar pagina ajunge ca un câmp string.
- **`X-Simple-Response: false`.** Acel header solicită plicul complet cu `status`, `node_results` și durate, ceea ce folosește canvas-ul editorului. Trimiteți-l atunci când depanați un workflow de tip pagină.

## Servirea unei pagini către un browser

Setați **metoda de cerere** a workflow-ului la `GET` în dialogul cURL, astfel încât o navigare simplă din browser să ajungă la el. O cerere `GET` nu transportă corp, deci intrările provin din query string:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Citiți acele valori cu `$input.query.name`. Consultați [Webhooks](../reference/webhooks.md) pentru contractul complet al metodelor.

Un workflow fără nod trigger a cărui singură ieșire terminală este acest nod afișează un chip **WEB** în [fila Workflows](../tabs/workflows-tab.md).

## Utilizarea ca unealtă pentru agent

Nu este acceptată. Acest nod este un sink terminal, deci nu poate fi atașat la un handle de unelte al unui [Nod Agent](./agent-node.md). Același lucru se aplică și pentru [Mapare ieșire JSON](./json-output-mapper-node.md).

## Restricție pentru bucle

Aceeași regulă ca la [Ieșire](./output-node.md): nu plasați acest nod în interiorul unei ramuri de iterație a buclei — doar după ramura `done` a buclei. Consultați [Buclă](./loop-node.md).

## Exemplu

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
