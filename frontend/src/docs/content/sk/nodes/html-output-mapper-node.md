# HTML output mapper

Uzol **HTML output mapper** vykresľuje jednu HTML šablónu do stránky. Použite ho, keď je volajúcim **prehliadač** a nie API klient — workflow odpovedá `text/html` namiesto JSON.

## Prehľad

| Vlastnosť | Hodnota |
|----------|-------|
| Vstupy | 1 |
| Výstupy | 0 (sink) |
| Výstup za behu | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Parametre

| Parameter | Typ | Popis |
|-----------|------|-------------|
| `label` | string | Identifikátor uzla (camelCase) |
| `html` | string | Šablóna stránky. Výrazy `$nodeLabel.field` sa interpolujú na mieste. |
| `statusCode` | number | HTTP status odpovede (predvolené `200`) |
| `contentType` | string | Typ obsahu odpovede (predvolené `text/html; charset=utf-8`) |

## Správanie Webhooku a behu

Keď je tento uzol **jediným** koncovým výstupom workflow, execute endpoint odpovedá vykreslenou stránkou, nakonfigurovaným status kódom a nakonfigurovaným typom obsahu — žiadny JSON obal, žiadny wrapper s labelom.

Dve veci to vypnú:

- **Druhý koncový uzol.** Pri inom aktívnom koncovom uzle v grafe Heym prepne späť na bežnú JSON mapu podľa labelov a stránka príde ako string pole.
- **`X-Simple-Response: false`.** Táto hlavička žiada plný obal so `status`, `node_results` a časovaním, čo je to, čo používa plátno editora. Pošlite ju, keď ladíte workflow stránky.

## Poskytovanie stránky prehliadaču

Nastavte **request method** workflow na `GET` v cURL dialógu, aby naň dosiahla obyčajná navigácia prehliadača. Požiadavka `GET` nenesie žiadne telo, takže vstupy pochádzajú z query stringu:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Tieto hodnoty čítajte pomocou `$input.query.name`. Plný kontrakt metód nájdete v [Webhooks](../reference/webhooks.md).

Workflow bez trigger uzla, ktorého jediným koncovým uzlom je tento uzol, zobrazuje v [Workflows tab](../tabs/workflows-tab.md) štítok **WEB**.

## Použitie ako nástroj agenta

Nepodporované. Tento uzol je koncový sink, takže ho nie je možné pripojiť k handle nástrojov [Agent Node](./agent-node.md). To isté platí pre [JSON output mapper](./json-output-mapper-node.md).

## Obmedzenie slučky

Rovnaké pravidlo ako pri [Output](./output-node.md): neumiestňujte tento uzol do vetvy iterácie slučky — iba za vetvu `done` slučky. Pozrite [Loop](./loop-node.md).

## Príklad

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
