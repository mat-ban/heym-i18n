# Klávesové skratky

Heym poskytuje klávesové skratky v rámci editora workflowov a plátna na zrýchlenie bežných akcií.

## Globálne skratky editora

Tieto skratky sú aktívne kdekoľvek v editore workflowov.

| Skratka | Akcia |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Otvorí Paletu príkazov |
| `Ctrl + I` / `Cmd + I` | Prepne panel [AI asistenta](./ai-assistant.md) (funguje aj počas písania) |
| `Ctrl + Enter` / `Cmd + Enter` | Spustí aktuálny workflow |
| `Ctrl + S` / `Cmd + S` | Uloží workflow |
| `Ctrl + Z` / `Cmd + Z` | Vráti späť |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Znovu vykoná |
| `Ctrl + Y` / `Cmd + Y` | Znovu vykoná (alternatíva) |
| `Escape` | Zatvorí otvorené prekrytia, dialógy a panely |

## Skratky plátna

Tieto skratky platia, keď je plátno aktívne (nie je aktívne žiadne textové pole).

### Výber a navigácia

| Skratka | Akcia |
|----------|--------|
| `Ctrl + A` / `Cmd + A` | Vyberie všetky uzly |
| `Shift` (podržať) | Potiahnutím vyberie viacero uzlov |
| `Ctrl` / `Cmd` (podržať) | Kliknutím pridá jednotlivé uzly do výberu |
| `Escape` | Zruší výber všetkých uzlov; zatvorí inline vyhľadávanie uzlov |

### Úprava uzlov

| Skratka | Akcia |
|----------|--------|
| `Ctrl + C` / `Cmd + C` | Skopíruje vybraný uzol (uzly) |
| `Ctrl + X` / `Cmd + X` | Vystrihne vybraný uzol (uzly) |
| `Ctrl + V` / `Cmd + V` | Vloží uzol (uzly) |
| `Delete` alebo `Backspace` | Odstráni vybraný uzol (uzly) a/alebo hranu (hrany) |
| `D` | Prepne povolenie/zakázanie vybraného uzla (uzlov) |
| `P` | Prepne pripnuté dáta na vybranom uzle |

### Inline vyhľadávanie uzlov

Napísanie ľubovoľného tlačiteľného znaku na plátne (keď nie je aktívne žiadne textové pole) otvorí vyskakovacie okno inline vyhľadávania uzlov. Napísaný znak sa stane prvým znakom vyhľadávacieho výrazu.

| Skratka | Akcia |
|----------|--------|
| Ľubovoľný tlačiteľný znak | Otvorí inline vyhľadávanie uzlov a začne písať |
| `Backspace` | Odstráni posledný znak z vyhľadávacieho výrazu |
| `Escape` | Zatvorí inline vyhľadávanie uzlov |

## Paleta príkazov (`Ctrl + K`)

Paleta príkazov je dostupná z editora, dashboardu, dokumentácie a zobrazení hodnotení. Umožňuje rýchlo navigovať k workflowom, kartám a stránkam dokumentácie bez opustenia klávesnice.

| Skratka | Akcia |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Otvorí Paletu príkazov |
| `↑` / `↓` | Naviguje v zozname výsledkov |
| `Tab` / `Shift + Tab` | Naviguje v zozname výsledkov |
| `Enter` | Otvorí vybranú položku |
| `Escape` | Zatvorí paletu |

## Skratky dashboardu

Tieto skratky sú aktívne na karte Workflowy, keď nie je aktívne žiadne iné textové pole.

| Skratka | Akcia |
|----------|--------|
| `Ctrl + F` / `Cmd + F` | Zameria vyhľadávanie workflowov |
| `Escape` | Vymaže vyhľadávanie workflowov, ak obsahuje text |

## Skratky panela vlastností

Tieto skratky sú aktívne, keď je vybraný uzol a panel vlastností je otvorený.

| Skratka | Akcia |
|----------|--------|
| `Ctrl + Shift + O` / `Cmd + Shift + O` | Otvorí prepojený pod-workflow na novej karte (iba uzol Execute) |

## Skratky dialógu Evaluate

Tieto skratky sú aktívne, keď je otvorený dialóg Evaluate.

| Skratka | Akcia |
|----------|--------|
| `Ctrl + Enter` / `Cmd + Enter` | Aplikuje výraz a zatvorí dialóg |
| `Ctrl + Z` / `Cmd + Z` | Vráti späť zmeny v editore výrazov |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Znovu vykoná zmeny v editore výrazov |
| `Ctrl + Y` / `Cmd + Y` | Znovu vykoná zmeny v editore výrazov (alternatíva) |

## Skratky histórie a spustení

Tieto skratky sú dostupné v dialógu histórie spustení a v paneli spustení.

| Skratka | Akcia |
|----------|--------|
| `S` | Prepne vstupné pole vyhľadávania na filtrovanie záznamov |
