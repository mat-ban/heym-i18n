# Maper za HTML izhod

**Mapper za HTML izhod** je vozlišče, ki upodobi eno samo HTML predlogo v stran. Uporabite ga, ko je klicatelj **brskalnik** in ne API odjemalec — workflow odgovori z `text/html` namesto JSON.

## Pregled

| Lastnost | Vrednost |
|----------|-------|
| Vhodi | 1 |
| Izhodi | 0 (sinko) |
| Izhod v času izvajanja | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Parametri

| Parameter | Tip | Opis |
|-----------|------|-------------|
| `label` | niz | Identifikator vozlišča (camelCase) |
| `html` | niz | Predloga strani. Izrazi `$nodeLabel.field` se interpolirajo na mestu. |
| `statusCode` | število | HTTP status za odgovor (privzeto `200`) |
| `contentType` | niz | Tip vsebine odgovora (privzeto `text/html; charset=utf-8`) |

## Obnašanje Webhook in izvajanja

Ko je to vozlišče **edini** terminalni izhod workflowa, se končni endpoint odzove z upodobljeno stranjo, konfiguriranim statusnim kodom in konfiguriranim tipom vsebine — brez JSON ovoja, brez ovitka z oznako.

Dve stvari to onemogočita:

- **Drugo terminalno vozlišče.** Z drugim aktivnim terminalom v grafu Heym preklopi na običajno JSON mapo po oznakah in stran prispe kot niz polja.
- **`X-Simple-Response: false`.** Ta glava zahteva celoten ovojnico z `status`, `node_results` in časovnimi podatki, kar uporablja platno urejevalnika. Pošljite jo, ko odpravljate napake v workflowu strani.

## Postrežba strani brskalniku

Nastavite **metodo zahteve** workflowa na `GET` v cURL dialogu, da dosežete preprosto navigacijo brskalnika. Zahteva `GET` ne prenaša telesa, zato vhodi prihajajo iz poizvedbenega niza:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Te vrednosti preberite z `$input.query.name`. Oglejte si [Webhook](../reference/webhooks.md) za celoten pogodbeni dogovor.

Workflow brez vozlišča sprožilca, katerega edini terminal je to vozlišče, prikazuje **WEB** oznako na [zavihku Workflows](../tabs/workflows-tab.md).

## Uporaba orodja agenta

Ni podprto. To vozlišče je terminalni sinko, zato ga ni mogoče povezati z ročajem [Agent Node](./agent-node.md). Enako velja za [mapper za JSON izhod](./json-output-mapper-node.md).

## Omejitev zank

Enaka pravila kot pri [Output](./output-node.md): tega vozlišča ne postavljajte znotraj veje iteracije zanke — le po veji `done` zanke. Oglejte si [Loop](./loop-node.md).

## Primer

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
