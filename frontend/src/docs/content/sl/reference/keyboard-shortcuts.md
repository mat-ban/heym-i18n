# Bližnjice na tipkovnici

Heym ponuja bližnjice na tipkovnici v urejevalniku workflow in platnu, da pospeši pogoste akcije.

## Globalne bližnjice urejevalnika

Te bližnjice so aktivne kjerkoli v urejevalniku workflow.

| Bližnjica | Akcija |
|-----------|--------|
| `Ctrl + K` / `Cmd + K` | Odprite paleto ukazov |
| `Ctrl + I` / `Cmd + I` | Preklopite ploščo [AI Assistant](./ai-assistant.md) (deluje med tipkanjem) |
| `Ctrl + Enter` / `Cmd + Enter` | Zaženite trenutni workflow |
| `Ctrl + S` / `Cmd + S` | Shranite workflow |
| `Ctrl + Z` / `Cmd + Z` | Razveljavi |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Ponovi |
| `Ctrl + Y` / `Cmd + Y` | Ponovi (alternativa) |
| `Escape` | Zaprite odprte prekrivne elemente, pogovorna okna in panele |

## Bližnjice na platnu

Te bližnjice veljajo, ko je platno osredotočeno (ni aktivnega vnosa besedila).

### Izbira in navigacija

| Bližnjica | Akcija |
|-----------|--------|
| `Ctrl + A` / `Cmd + A` | Izberite vse vozlišča |
| `Shift` (držite) | Povlecite za izbiro več vozlišč |
| `Ctrl` / `Cmd` (držite) | Kliknite za dodajanje posameznih vozlišč k izbiri |
| `Escape` | Prekličite izbiro vseh vozlišč; zaprite iskanje vozlišč v vrstici |

### Urejanje vozlišč

| Bližnjica | Akcija |
|-----------|--------|
| `Ctrl + C` / `Cmd + C` | Kopirajte izbrano vozlišče/vozlišča |
| `Ctrl + X` / `Cmd + X` | Izrežite izbrano vozlišče/vozlišča |
| `Ctrl + V` / `Cmd + V` | Prilepite vozlišče/vozlišča |
| `Delete` ali `Backspace` | Izbrišite izbrano vozlišče/vozlišča in/ali robove |
| `D` | Preklopite izbrano vozlišče/vozlišča med omogočeno/izključeno |
| `P` | Preklopite pritrjene podatke na izbranem vozlišču |

### Iskanje vozlišč v vrstici

Vnos katerega koli tiskljivega znaka na platnu (ko ni osredotočenega vnosa besedila) odpre pojavna okna za iskanje vozlišč v vrstici. Vneseni znak postane prvi znak iskalnega poizvedovanja.

| Bližnjica | Akcija |
|-----------|--------|
| Katerikoli tiskljiv znak | Odprite iskanje vozlišč v vrstici in začnite tipkati |
| `Backspace` | Odstranite zadnji znak iz iskalnega poizvedovanja |
| `Escape` | Zaprite iskanje vozlišč v vrstici |

## Paleta ukazov (`Ctrl + K`)

Paleta ukazov je na voljo iz urejevalnika, nadzorne plošče, dokumentacije in pogledov vrednotenja. Omogoča hitro navigacijo do workflow, zavihkov in strani dokumentacije, ne da bi zapustili tipkovnico.

| Bližnjica | Akcija |
|-----------|--------|
| `Ctrl + K` / `Cmd + K` | Odprite paleto ukazov |
| `↑` / `↓` | Navigirajte po seznamu rezultatov |
| `Tab` / `Shift + Tab` | Navigirajte po seznamu rezultatov |
| `Enter` | Odprite izbrani element |
| `Escape` | Zaprite paleto |

## Bližnjice na nadzorni plošči

Te bližnjice so aktivne na zavihku Workflows, ko ni aktivnega vnosa besedila.

| Bližnjica | Akcija |
|-----------|--------|
| `Ctrl + F` / `Cmd + F` | Osredotočite se na iskanje workflow |
| `Escape` | Počistite iskanje workflow, ko vsebuje besedilo |

## Bližnjice v panelu lastnosti

Te bližnjice so aktivne, ko je izbrano vozlišče in je odprt panel lastnosti.

| Bližnjica | Akcija |
|-----------|--------|
| `Ctrl + Shift + O` / `Cmd + Shift + O` | Odprite povezani pod-workflow v novem zavihku (samo vozlišče Execute) |

## Bližnjice v pogovornem oknu za vrednotenje

Te bližnjice so aktivne, ko je odprto pogovorno okno za vrednotenje.

| Bližnjica | Akcija |
|-----------|--------|
| `Ctrl + Enter` / `Cmd + Enter` | Uporabite izraz in zaprite pogovorno okno |
| `Ctrl + Z` / `Cmd + Z` | Razveljavite spremembe v urejevalniku izrazov |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Ponovite spremembe v urejevalniku izrazov |
| `Ctrl + Y` / `Cmd + Y` | Ponovite spremembe v urejevalniku izrazov (alternativa) |

## Bližnjice za zgodovino in sledi

Te bližnjice so na voljo v pogovornem oknu Zgodovina izvajanja in v panelu Sledi.

| Bližnjica | Akcija |
|-----------|--------|
| `S` | Preklopite iskalni vnos za filtriranje vnosov |
