# HTML-utdatamappare

Noden **HTML-utdatamappare** renderar en enskild HTML-mall till en sida. Den används när anroparen är en **webbläsare** snarare än en API-klient — workflowet svarar då med `text/html` i stället för JSON.

## Översikt

| Egenskap | Värde |
|----------|-------|
| Indata | 1 |
| Utdata | 0 (sink) |
| Körtidsutdata | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Parametrar

| Parameter | Typ | Beskrivning |
|-----------|-----|-------------|
| `label` | string | Nodidentifierare (camelCase) |
| `html` | string | Sidmallen. `$nodeLabel.field`-uttryck interpoleras på plats. |
| `statusCode` | number | HTTP-status för svaret (standard `200`) |
| `contentType` | string | Svarets innehållstyp (standard `text/html; charset=utf-8`) |

## Webhook- och körningsbeteende

När denna nod är workflowets **enda** terminala utdata svarar execute-endpointen med den renderade sidan, den konfigurerade statuskoden och den konfigurerade innehållstypen — ingen JSON-omslutning, ingen label-wrapper.

Två saker stänger av detta:

- **En andra terminal nod.** Med ytterligare en aktiv terminal i grafen faller Heym tillbaka till den normala JSON-mappningen per label och sidan levereras som ett strängfält.
- **`X-Simple-Response: false`.** Den headern begär det fullständiga höljet med `status`, `node_results` och tidsangivelser, vilket är vad redigerarens canvas använder. Skicka den vid felsökning av ett sid-workflow.

## Leverera en sida till en webbläsare

Ange workflowets **request method** till `GET` i cURL-dialogen så att en vanlig webbläsarnavigering når det. En `GET`-begäran innehåller ingen body, så indata kommer från query-strängen:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Läs dessa värden med `$input.query.name`. Se [Webhooks](../reference/webhooks.md) för det fullständiga metodkontraktet.

Ett workflow utan trigger-nod vars enda terminal är denna nod visar en **WEB**-chip i [Workflows-fliken](../tabs/workflows-tab.md).

## Användning som agentverktyg

Stöds inte. Denna nod är en terminal sink och kan därför inte kopplas till ett [Agent Node](./agent-node.md) tools-handtag. Samma sak gäller [JSON-utdatamappare](./json-output-mapper-node.md).

## Loop-begränsning

Samma regel som för [Output](./output-node.md): placera inte denna nod inuti en loop-iterationsgren — endast efter loopens `done`-gren. Se [Loop](./loop-node.md).

## Exempel

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
