# HTML Çıkış Eşleyici

**HTML output mapper** düğümü, tek bir HTML şablonunu bir sayfaya dönüştürür. Çağıran taraf bir API istemcisi yerine bir **tarayıcı** olduğunda bunu kullanın — workflow, JSON yerine `text/html` ile yanıt verir.

## Genel Bakış

| Özellik | Değer |
|----------|-------|
| Girişler | 1 |
| Çıkışlar | 0 (sink) |
| Çalışma zamanı çıktısı | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Parametreler

| Parametre | Tür | Açıklama |
|-----------|------|-------------|
| `label` | string | Düğüm tanımlayıcısı (camelCase) |
| `html` | string | Sayfa şablonu. `$nodeLabel.field` ifadeleri yerinde enterpolasyon edilir. |
| `statusCode` | number | Yanıt için HTTP durum kodu (varsayılan `200`) |
| `contentType` | string | Yanıt içerik türü (varsayılan `text/html; charset=utf-8`) |

## Webhook ve çalıştırma davranışı

Bu düğüm workflow'un **tek** terminal çıktısı olduğunda, execute endpoint'i oluşturulan sayfa, yapılandırılan durum kodu ve yapılandırılan içerik türü ile yanıt verir — JSON zarfı yok, label sarmalayıcısı yok.

Bunu devre dışı bırakan iki durum vardır:

- **İkinci bir terminal düğüm.** Grafikte başka bir etkin terminal olduğunda, Heym normal per-label JSON haritasına geri döner ve sayfa bir string alanı olarak gelir.
- **`X-Simple-Response: false`.** Bu header, `status`, `node_results` ve zamanlamaları içeren tam zarfı talep eder; editörün canvas'ının kullandığı da budur. Bir sayfa workflow'unu hata ayıklarken bunu gönderin.

## Bir sayfayı tarayıcıya sunma

Düz bir tarayıcı gezinmesinin ona ulaşabilmesi için cURL diyaloğunda workflow'un **request method** değerini `GET` olarak ayarlayın. Bir `GET` isteği gövde taşımaz, bu nedenle girişler query string'den gelir:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Bu değerleri `$input.query.name` ile okuyun. Tam method sözleşmesi için [Webhooks](../reference/webhooks.md) bölümüne bakın.

Tetikleyici düğümü olmayan ve tek terminali bu düğüm olan bir workflow, [Workflows sekmesinde](../tabs/workflows-tab.md) bir **WEB** rozeti gösterir.

## Agent tool kullanımı

Desteklenmez. Bu düğüm bir terminal sink olduğundan, bir [Agent Node](./agent-node.md) tools handle'ına bağlanamaz. Aynı durum [JSON output mapper](./json-output-mapper-node.md) için de geçerlidir.

## Loop kısıtlaması

[Output](./output-node.md) ile aynı kural: bu düğümü bir loop iterasyon dalının içine yerleştirmeyin — yalnızca loop `done` dalından sonra. Bkz. [Loop](./loop-node.md).

## Örnek

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
