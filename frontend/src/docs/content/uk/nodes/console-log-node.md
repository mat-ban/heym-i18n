# Console Log

Вузол **Console Log** записує значення до консолі бекенду (сервера). Використовуйте його для налагодження та перевірки під час розробки.

## Огляд

| Властивість | Значення |
|----------|-------|
| Входи | 1 |
| Виходи | 1 |
| Вихід | Передає вхід далі |

## Параметри

| Параметр | Тип | Опис |
|-----------|------|-------------|
| `label` | string | Ідентифікатор вузла (camelCase) |
| `logMessage` | expression | Значення для запису в журнал. Підтримує [вирази](../reference/expression-dsl.md). |

## Приклад

```json
{
  "type": "consoleLog",
  "data": {
    "label": "debugOutput",
    "logMessage": "$userInput.body"
  }
}
```

Вивід з'являється в журналах сервера (наприклад, у виводі термінала під час запуску `uvicorn`).
