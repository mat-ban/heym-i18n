# Cron

Вузол **Cron** запускає workflow за розкладом, використовуючи cron-вираз. Введення даних користувачем не потрібне — workflow виконується автоматично у визначений час.

## Огляд

| Властивість | Значення |
|----------|-------|
| Входи | 0 |
| Виходи | 1 |
| Вихід | Trigger event (без payload) |

## Параметри

| Параметр | Тип | Опис |
|-----------|------|-------------|
| `label` | string | Ідентифікатор вузла (camelCase) |
| `cronExpression` | string | Cron-вираз (наприклад, `0 * * * *` для щогодинного запуску) |

## Формат cron-виразу

Стандартний 5-полевий cron: `minute hour day-of-month month day-of-week`

| Поле | Значення | Приклад |
|-------|--------|---------|
| Хвилина | 0–59 | `0` = на 0-й хвилині |
| Година | 0–23 | `*` = щогодини |
| День місяця | 1–31 | `*` = щодня |
| Місяць | 1–12 | `*` = щомісяця |
| День тижня | 0–7 (0 і 7 = неділя) | `*` = щодня |

**Поширені приклади:**

- `0 * * * *` – щогодини
- `0 0 * * *` – щодня опівночі
- `*/15 * * * *` – кожні 15 хвилин
- `0 9 * * 1-5` – у будні о 9:00

## Приклад

```json
{
  "type": "cron",
  "data": {
    "label": "hourlyCheck",
    "cronExpression": "0 * * * *"
  }
}
```
