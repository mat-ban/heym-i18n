# Вимкнення вузла

Вузол **Disable Node** (Вимкнення вузла) остаточно вимикає інший вузол у workflow. Під час виконання він встановлює для цільового вузла значення `active` у `false` та зберігає цю зміну. Використовуйте його для одноразових операцій, як-от зупинка Cron-тригера після виконання певної умови.

## Огляд

| Властивість | Значення |
|----------|-------|
| Входи | 1 |
| Виходи | 1 |
| Вихід | `$nodeLabel.targetNode`, `$nodeLabel.disabled` |

## Параметри

| Параметр | Тип | Опис |
|-----------|------|-------------|
| `label` | string | Ідентифікатор вузла (camelCase) |
| `targetNodeLabel` | string | Мітка вузла, який потрібно вимкнути (наприклад, `hourlyCheck`) |

## Сценарій використання

Вимкніть [Cron](./cron-node.md)-тригер після виконання певної умови, щоб він більше не запускався під час наступних виконань workflow. Увімкніть його знову пізніше за допомогою вузла [Enable Node](./enable-node.md).

## Приклад

```json
{
  "type": "disableNode",
  "data": {
    "label": "stopCron",
    "targetNodeLabel": "hourlyCheck"
  }
}
```

Потік: Cron → HTTP-перевірка → Condition (статус завершено?) → якщо true: Disable Node (ціль: cron) → Output.
