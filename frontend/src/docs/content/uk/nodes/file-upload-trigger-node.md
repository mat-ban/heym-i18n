# Trigger завантаження файлів

Вузол **Trigger завантаження файлів** — це точка входу без вхідних даних для workflow, яким потрібен **великий файл** (аудіо, відео, архіви), що не може бути вбудований як base64 у JSON-запит. Виклик workflow повертає попередньо сформоване одноразове посилання для завантаження через `curl`; завантаження файлу за цим посиланням запускає виконання з прикріпленим файлом.

Використовуйте цей вузол, коли викликач — зокрема AI-агент, такий як Claude або ChatGPT, що працює в sandbox — має передати 20-мегабайтний голосовий запис або 75-мегабайтне відео до workflow Heym.

## Огляд

| Властивість | Значення |
|----------|-------|
| Входи | 0 |
| Виходи | 1 |
| Вихід | `$nodeLabel.file.{id,name,mime,size,download_url}`, `$nodeLabel.uploaded_at` |

## Як це працює

Вузол працює у дві фази:

1. **Створення.** Коли workflow викликається через HTTP (`POST /api/workflows/{id}/execute`), як інструмент MCP або через кнопку **Run Workflow** на canvas, виконання **не** запускає тіло workflow. Натомість створюється одноразовий слот для завантаження і повертається:

   ```json
   {
     "file_upload_required": true,
     "curl": "curl -F 'file=@/path/to/your/file' 'https://your-host/api/file-intake/u/<token>'",
     "upload_url": "https://your-host/api/file-intake/u/<token>",
     "expires_at": "2026-06-25T13:00:00+00:00",
     "max_size_mb": 100,
     "allowed_types": ["audio/*"]
   }
   ```

2. **Завантаження + виконання.** Викликач запускає `curl` зі своїм файлом. Endpoint завантаження перевіряє слот, зберігає файл, виконує workflow **синхронно** та повертає вихідні дані workflow у відповіді на завантаження. Посилання є **одноразовим** — повторне завантаження повертає `409`.

На canvas кнопка **Run Workflow** показує створений `curl` на панелі налагодження з кнопкою копіювання.

## Параметри

| Параметр | Тип | За замовчуванням | Опис |
|-----------|------|---------|-------------|
| `ttlMinutes` | number | `60` | Як довго посилання для завантаження залишається дійсним (1–10080 хвилин / до 7 днів). |
| `maxSizeMb` | number | `100` | Максимальний прийнятний розмір файлу. Жорстка межа — **100 MB**. |
| `allowedTypes` | string | (порожньо) | Необов'язковий список дозволених MIME-типів/розширень, розділених комами, наприклад `audio/*, .wav`. Порожнє значення дозволяє будь-який тип. |

## Поля виходу

| Вираз | Опис |
|------------|-------------|
| `$nodeLabel.file.id` | UUID збереженого файлу (файл Drive). |
| `$nodeLabel.file.name` | Початкова назва файлу. |
| `$nodeLabel.file.mime` | Визначений тип вмісту. |
| `$nodeLabel.file.size` | Розмір у байтах. |
| `$nodeLabel.file.download_url` | Автентифіковане посилання для завантаження для наступних вузлів. |
| `$nodeLabel.uploaded_at` | Мітка часу завантаження у форматі ISO. |

## Приклад

Workflow транскрипції:

```
File Upload Trigger ("audio")  →  Transcribe ($audio.file)  →  LLM summary  →  Output
```

1. Агент викликає інструмент MCP цього workflow і отримує `curl`.
2. Агент запускає `curl` із записом зі свого sandbox.
3. Завантаження запускає workflow, і відповідь `curl` містить підсумок транскрипції.

## Безпека

- URL завантаження містить token з високою ентропією — token **і є** capability, тому агент у sandbox не потребує облікових даних Heym для завантаження. На сервері зберігається лише хеш token.
- Створення вимагає звичайної автентифікації workflow, тому лише авторизовані викликачі можуть створювати посилання для завантаження.
- Кожне створення та кожна спроба завантаження (прийнята чи відхилена — прострочена, повторна, завелика, заборонений тип, невідомий token) записується до журналу аудиту, що дозволяє лише додавання.
- Завантаження обмежені одноразовим використанням, обмежені за TTL та обмежені за розміром; завеликі завантаження відхиляються.

## Примітки

- Загальні канали виклику через HTTP, MCP та canvas залишаються призначеними лише для JSON; цей вузол є підтримуваним способом приймання multipart-завантажень файлів.
- Завантажений файл зберігається як звичайний файл Drive, тому будь-який наступний вузол, що приймає посилання на файл (транскрипція, надсилання вкладення електронною поштою тощо), може використовувати `$nodeLabel.file`.
