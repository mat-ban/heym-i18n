# Google Meet

Знаходьте вільні часові проміжки в Google Calendar та створюйте, оновлюйте або видаляйте запрошення на зустрічі з посиланнями на Google Meet, адресами електронної пошти учасників та вибраним часом. Підключений обліковий запис Google є власником події; учасники отримують запрошення електронною поштою.

## Підключення вашого облікового запису

1. У [Google Cloud Console](https://console.cloud.google.com) увімкніть **Google Calendar API**.
2. Налаштуйте екран згоди OAuth та створіть клієнт OAuth для **Веб-додатку**. Додайте свій обліковий запис Google як тестового користувача, якщо програма перебуває в тестовому режимі.
3. Зареєструйте `https://your-heym-domain/api/credentials/google-meet/oauth/callback` як авторизований URI перенаправлення. Для локальної розробки використовуйте джерело Heym у вашому браузері з тим самим шляхом.
4. Відкрийте **Dashboard → Credentials → Створити → Google Meet (OAuth2)**, введіть назву, Client ID та Client Secret, натисніть **Підключити** та увійдіть за допомогою Google.
5. Надайте обидва дозволи: Події календаря (`calendar.events`) та доступність календаря (`calendar.events.freebusy`). Виберіть ці облікові дані у вузлі.

Токени шифруються у сховищі та автоматично оновлюються. Це окремі облікові дані від Google AI, Sheets або Drive. Календар повинен підтримувати відеоконференції Google Meet, щоб створення пройшло успішно.

## Операції

| Операція | Поведінка | Обов'язкові поля |
| --- | --- | --- |
| `read` | Повернути доступні та зайняті інтервали для календаря | Облікові дані |
| `create` | Створити заплановану подію з новою конференцією Meet та запрошеннями електронною поштою | Назва, час початку, час завершення |
| `update` | Оновити вказані поля події та сповістити гостей | ID події та щонайменше одне змінене поле |
| `delete` | Видалити подію та сповістити гостей про скасування | ID події |

## Конфігурація

Текстові поля нижче приймають вирази. Усі поля, включно з логічним параметром деталей, можуть бути надані Agent, коли цей вузол приєднано як інструмент.

| Поле | За замовчуванням | Призначення |
| --- | --- | --- |
| `gmCalendarId` | `primary` | Основний календар підключеного облікового запису або доступний ID/email календаря |
| `gmTimeZone` | `UTC` | Зона IANA, наприклад `Europe/Kyiv`, що використовується для місцевих дат і часу відповіді |
| `gmStartDate` | Поточний час | Початок діапазону читання у вигляді ISO дати або datetime |
| `gmEndDate` | Перший день наступного місяця опівночі | Виключний кінець діапазону читання; максимальний діапазон становить 60 календарних днів |
| `gmIncludeBusyDetails` | `false` | Тільки для читання: включити назви подій та учасників у `busy_slots`; boolean |
| `gmEventId` | Порожньо | ID події календаря для update/delete; використовуйте повернутий `event_id`, а не URL Meet |
| `gmTitle` | Порожньо | Назва запрошення; обов'язково при `create` |
| `gmDescription` | Порожньо | Опис запрошення |
| `gmStartTime` | Порожньо | Початок зустрічі, наприклад `2026-11-10T14:00:00+02:00` |
| `gmEndTime` | Порожньо | Кінець зустрічі; має бути після початку |
| `gmAttendees` | Порожньо | Електронні адреси, розділені комами/крапками з комою/перенесеннями рядків, або JSON масив рядків email |
| `gmLocation` | Порожньо | Необов'язкове місце зустрічі поруч із конференцією Meet |

### Доступні часові проміжки

Типове читання охоплює період від поточного часу до **1-го числа наступного місяця, 00:00** у вибраному часовому поясі. Передайте `gmEndDate`, щоб визначити інше вікно. Діапазон понад 60 днів або недійсна дата відхиляються до виклику Google.

Результат базується на API **free/busy** від Google. Зайняті інтервали об'єднуються та віднімаються від запитаного вікна. `available_slots` містить безперервні проміжки з часовими мітками `start` та `end`.

```json
{
  "type": "googleMeet",
  "data": {
    "label": "Availability",
    "credentialId": "YOUR_GOOGLE_MEET_CREDENTIAL_ID",
    "gmOperation": "read",
    "gmCalendarId": "primary",
    "gmTimeZone": "Europe/Berlin",
    "gmStartDate": "2026-11-06",
    "gmEndDate": "2026-11-13"
  }
}
```

### Включення деталей зайнятих подій

У розділі **Читати доступні часові проміжки** увімкніть **Включити деталі зайнятих подій** (`gmIncludeBusyDetails: true`), щоб додати назву та учасників до кожного зайнятого слота. Ця опція вимкнена за замовчуванням.

```json
{
  "start": "2026-11-06T21:15:00+01:00",
  "end": "2026-11-06T21:30:00+01:00",
  "title": "Daily check-in",
  "attendees": [
    "colleague@example.com"
  ]
}
```

### Забронювати зустріч

1. Запустіть вузол `read` з обліковими даними власника workflow.
2. Відобразіть `available_slots` у вашому інтерфейсі бронювання.
3. Передайте `email`, `startTime` та `endTime` як вхідні дані workflow.
4. Запустіть `create` з тими самими обліковими даними. Відвідувачу не потрібен обліковий запис Google; його email реєструється як учасник.

```json
{
  "type": "googleMeet",
  "data": {
    "label": "Booking",
    "credentialId": "YOUR_GOOGLE_MEET_CREDENTIAL_ID",
    "gmOperation": "create",
    "gmCalendarId": "primary",
    "gmTimeZone": "Europe/Berlin",
    "gmTitle": "Meet with me",
    "gmDescription": "A meeting booked through Heym",
    "gmAttendees": "$input.email",
    "gmStartTime": "$input.startTime",
    "gmEndTime": "$input.endTime"
  }
}
```

## Виведення

| Операція | Поля виведення |
| --- | --- |
| `read` | `available_slots`, `busy_slots`, `count`, `calendar_id`, `time_zone`, `start`, `end` |
| `create`, `update` | `event_id`, `meet_url`, `conference_status`, `event`, `calendar_id` |
| `delete` | `event_id`, `calendar_id`, `deleted: true` |

Використовуйте `$Availability.available_slots` або `$Booking.meet_url` у наступних вузлах. Кожна операція також повертає `status: "success"` та відповідну `operation`.
