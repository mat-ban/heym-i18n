# Перетворювач HTML-виводу

Вузол **Перетворювач HTML-виводу** відображає єдиний HTML-шаблон у вигляді сторінки. Використовуйте його, коли клієнтом є **браузер**, а не API-клієнт — у такому разі Workflow відповідає `text/html` замість JSON.

## Огляд

| Властивість | Значення |
|----------|-------|
| Входи | 1 |
| Виходи | 0 (приймач) |
| Вивід під час виконання | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Параметри

| Параметр | Тип | Опис |
|-----------|------|-------------|
| `label` | string | Ідентифікатор вузла (camelCase) |
| `html` | string | Шаблон сторінки. Вирази `$nodeLabel.field` підставляються на своїх місцях. |
| `statusCode` | number | HTTP-статус відповіді (типово `200`) |
| `contentType` | string | Тип вмісту відповіді (типово `text/html; charset=utf-8`) |

## Поведінка Webhook та виконання

Коли цей вузол є **єдиним** термінальним виводом Workflow, endpoint виконання відповідає відрендереною сторінкою, налаштованим кодом статусу та налаштованим типом вмісту — без JSON-обгортки та без обгортки за міткою.

Вимкнути це можуть дві обставини:

- **Другий термінальний вузол.** За наявності іншого активного термінального вузла в графі Heym повертається до звичайної JSON-мапи за мітками, і сторінка надходить як рядкове поле.
- **`X-Simple-Response: false`.** Цей заголовок вимагає повної обгортки з `status`, `node_results` та часовими показниками — саме її використовує Canvas редактора. Надсилайте його під час налагодження Workflow зі сторінкою.

## Обслуговування сторінки для браузера

Установіть **метод запиту** Workflow як `GET` у діалозі cURL, щоб звичайний перехід у браузері міг його досягти. Запит `GET` не містить тіла, тож вхідні дані надходять із рядка запиту:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Зчитуйте ці значення за допомогою `$input.query.name`. Повний контракт методів дивіться в розділі [Webhooks](../reference/webhooks.md).

Workflow без вузла Trigger, єдиним термінальним вузлом якого є цей вузол, показує позначку **WEB** на вкладці [Workflows](../tabs/workflows-tab.md).

## Використання як інструмента агента

Не підтримується. Цей вузол є термінальним приймачем, тож його не можна приєднати до ручки інструментів [Agent Node](./agent-node.md). Те саме стосується [Перетворювача JSON-виводу](./json-output-mapper-node.md).

## Обмеження циклів

Те саме правило, що й для [Output](./output-node.md): не розміщуйте цей вузол усередині гілки ітерації циклу — лише після гілки `done` циклу. Дивіться [Loop](./loop-node.md).

## Приклад

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
