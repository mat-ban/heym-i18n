# Loop

Вузол **Loop** виконує ітерацію над масивом, запускаючи нижчі вузли для кожного елемента. Для переходу до наступної ітерації потрібне зворотне з'єднання від останнього вузла в тілі ітерації.

## Огляд

| Властивість | Значення |
|----------|-------|
| Входи | 2 (типовий + зворотний зв'язок циклу) |
| Виходи | 2 (loop, done) |
| Вихід | `$nodeLabel.item`, `$nodeLabel.index`, `$nodeLabel.total`, `$nodeLabel.isFirst`, `$nodeLabel.isLast` |

## Параметри

| Параметр | Тип | Опис |
|-----------|------|-------------|
| `label` | string | Ідентифікатор вузла (camelCase) |
| `arrayExpression` | expression | Вираз, що обчислюється в масив (наприклад, `$input.items`) |

## З'єднувачі (Edge Handles)

- **Джерело `loop`** – З'єднується з вузлами, що обробляють кожен елемент (виконується на кожній ітерації)
- **Джерело `done`** – З'єднується з вузлами, що виконуються після завершення всіх ітерацій
- **Цільовий `default`** – Отримує початкові дані, що містять масив
- **Цільовий `loop`** – Отримує зворотне з'єднання від останнього вузла тіла ітерації

## Контекст циклу (у тілі ітерації)

- `$loopNode.item` – Поточний елемент
- `$loopNode.index` – Індекс з відліком від 0
- `$loopNode.total` – Загальна кількість елементів
- `$loopNode.isFirst` – Логічне значення
- `$loopNode.isLast` – Логічне значення

## Критичні правила

1. **Потрібне зворотне з'єднання:** Останній вузол у тілі ітерації ПОВИНЕН з'єднуватися назад із вхідним з'єднувачем `loop` вузла циклу.
2. **Відсутність виходу в тілі циклу:** Вузли [Output](./output-node.md) заборонені всередині тіла циклу. Використовуйте [Set](./set-node.md) або [Variable](./variable-node.md) для проміжних результатів.
3. **Відсутність автоматичного збору результатів:** Цикл не збирає результати. Використовуйте вузли Variable з `$array()` та `.add()` для накопичення.

## Приклад

```json
{
  "type": "loop",
  "data": {
    "label": "processItems",
    "arrayExpression": "$httpResponse.body.items"
  }
}
```

Потік: loop → вузол обробки → (назад до loop) → loop → гілка done → output.
