# Об'єднання

Вузол **Об'єднання** очікує на кілька паралельних входів і поєднує їх в один вихід. Використовуйте його, коли потрібно зібрати результати з паралельних гілок перед продовженням.

## Огляд

| Властивість | Значення |
|----------|-------|
| Входи | n (налаштовується) |
| Виходи | 1 |
| Вихід | `$nodeLabel.merged` – об'єкт із входами з кожної гілки |

## Параметри

| Параметр | Тип | Опис |
|-----------|------|-------------|
| `label` | string | Ідентифікатор вузла (camelCase) |
| `inputCount` | number | Кількість входів для очікування (за замовчуванням: 2) |

## Коли використовувати

- Використовуйте, коли потрібно **поєднати** або **зібрати** результати з паралельних гілок
- **Не** використовуйте для паралельних робочих процесів, які завершуються окремими вузлами [Виходу](./output-node.md)
- Кожна вхідна гілка додає свій внесок до об'єднаного виходу

## Приклад

```json
{
  "type": "merge",
  "data": {
    "label": "combineResults",
    "inputCount": 2
  }
}
```

Підключіть кілька гілок до вузла об'єднання. Вузол очікує на всі входи, перш ніж сформувати вихід.
