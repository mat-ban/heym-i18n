# Виведення

Вузол **Виведення** є кінцевою точкою workflow, яка повертає відповідь тому, хто викликав. Завжди посилайтеся на попередній вузол за його міткою — ніколи не використовуйте `$input`.

## Огляд

| Властивість | Значення |
|----------|-------|
| Входи | 1 |
| Виходи | 1 (необов'язково, для асинхронної післяобробки) |
| Виведення | Повертає `message` тому, хто викликав |

## Параметри

| Параметр | Тип | Опис |
|-----------|------|-------------|
| `label` | string | Ідентифікатор вузла (camelCase) |
| `message` | expression | Значення виведення. **Має** посилатися на попередній вузол: `$previousNodeLabel.field` |
| `allowDownstream` | boolean | Якщо true, вузли після виведення виконуються асинхронно після надсилання відповіді |

## Використання як інструмента агента

Коли вузол Виведення під'єднано до [Вузла агента](./agent-node.md) як інструмент вузла на Canvas, поле `message` можна позначити як **надане агентом** за допомогою значка бота. Тоді агент надає повідомлення, коли викликає інструмент. Якщо вузол Виведення не під'єднано як інструмент агента, значок бота приховано.

## Критичне правило

**Ніколи не використовуйте `$input` у вузлі виведення.** Завжди використовуйте мітку попереднього вузла:

- ❌ `"message": "$input.text"`
- ✅ `"message": "$processData.text"` (де `processData` — мітка попереднього вузла)

## Асинхронна післяобробка

Коли `allowDownstream: true`, відповідь повертається негайно. Вузли, під'єднані після виведення, виконуються у фоновому режимі (наприклад, сповіщення Slack, журналювання). Оскільки низхідний хвіст може завершитися пізніше, збій на низхідному етапі може змінити записаний статус виконання на `error` після того, як ранню відповідь уже повернуто; підсумкова історія та аналітика відображають цей пізніший результат.

## Приклад

```json
{
  "type": "output",
  "data": {
    "label": "apiResponse",
    "message": "$generateResponse.text"
  }
}
```

## Приклад – з асинхронністю

```json
{
  "type": "output",
  "data": {
    "label": "apiResponse",
    "message": "$generateResponse.text",
    "allowDownstream": true
  }
}
```
