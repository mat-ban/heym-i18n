# Set

Вузол **Set** перетворює та зіставляє вхідні дані з користувацьким виводом. Використовуйте його для переведення в верхній регістр, виділення підрядків, конкатенації, генерації випадкових чисел та будь-яких інших перетворень даних — але не для виклику workflow (для цього використовуйте [Execute](./execute-node.md)).

## Огляд

| Властивість | Значення |
|----------|-------|
| Входи | 1 |
| Виводи | 1 |
| Вивід | `$nodeLabel.keyName` для кожного ключа зіставлення |

## Параметри

| Параметр | Тип | Опис |
|-----------|------|-------------|
| `label` | string | Ідентифікатор вузла (camelCase) |
| `mappings` | array | Пари ключ-значення. Кожна: `{ key, value }`, де `value` — це [вираз](../reference/expression-dsl.md) |

## Використання як інструмента агента

Коли вузол Set підключено до [Вузла агента](./agent-node.md) як інструмент вузла на Canvas, кожне значення зіставлення можна позначити як **надане агентом** за допомогою значка бота. Позначені значення зіставлення стають параметрами інструмента, які агент заповнює під час виконання. Непозначені зіставлення залишаються фіксованими в конфігурації вузла.

Значок бота з'являється лише тоді, коли вузол Set підключено до порту інструментів агента. Окремий вузол Set не показує елементів керування для наданих агентом значень.

## Правила виразів

- Посилання на попередні вузли: `$nodeName.text`, `$nodeName.body.field`
- Використання функцій: `$randomInt(1, 10)`, `$range(1, 5)`, `$now.format('HH:mm')`
- `$range(a,b)` не включає b; у разі `a > b` виникає помилка.
- Лише один `$` на початку виразу — ніколи всередині дужок
- Доступ до виводу за ключем: `$setNode.randomNumber`, `$setNode.text`

## Приклад

```json
{
  "type": "set",
  "data": {
    "label": "transformData",
    "mappings": [
      { "key": "text", "value": "$userInput.body.text.upper()" },
      { "key": "firstChar", "value": "$userInput.body.text.substring(0, 1)" },
      { "key": "randomNum", "value": "$randomInt(1, 10)" },
      { "key": "rangeArr", "value": "$range(1, 5)" }
    ]
  }
}
```

Наступні вузли отримують доступ через `$transformData.text`, `$transformData.firstChar`, `$transformData.randomNum`, `$transformData.rangeArr`.
