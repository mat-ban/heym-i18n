# Slack

**Вузол Slack** надсилає повідомлення до каналу Slack через Incoming Webhook. Використовуйте його для сповіщень, оповіщень та звітування про помилки.

## Огляд

| Властивість | Значення |
|----------|-------|
| Входи | 1 |
| Виходи | 1 |
| Вихід | Передає вхід далі |

## Параметри

| Параметр | Тип | Опис |
|-----------|------|-------------|
| `credentialId` | UUID | Облікові дані Slack (webhook URL) з [Облікових даних](../tabs/credentials-tab.md) |
| `message` | expression | Текст повідомлення. Підтримує [вирази](../reference/expression-dsl.md). |

## Налаштування

1. Створіть Incoming Webhook у своєму робочому просторі Slack
2. Додайте облікові дані Slack на вкладці «Облікові дані» із зазначенням webhook URL
3. Посилайтеся на ці облікові дані у вузлі

## Приклад

```json
{
  "type": "slack",
  "data": {
    "label": "notifyTeam",
    "credentialId": "slack-credential-uuid",
    "message": "Workflow completed: $userInput.body.text"
  }
}
```

Використовуйте разом з [Error Handler](./error-handler-node.md) для сповіщень про збої:
```json
"message": "Error in $errorHandler.errorNode: $errorHandler.error"
```

## Безпека вихідного трафіку

- Webhook URL, збережений в облікових даних, має використовувати `http://` або `https://` та розпізнаватися лише на публічні адреси. Адреси зворотного зв'язку (loopback), приватні, link-local, multicast та адреси хмарних метаданих заблоковано.
- Heym перевіряє розпізнані адреси та фіксує цільове з'єднання перед надсиланням, тож відповідь DNS не може перемістити запит на внутрішню адресу після перевірки. Проксі середовища вимикаються, поки активний захист, а переспрямування не виконуються.
- Розгортання, які надсилають запити до внутрішнього webhook-одержувача, можуть встановити `HEYM_HTTP_ALLOW_PRIVATE_URLS=true` на довіреному self-hosted екземплярі. Залишайте типове значення на хостованих або мультитенантних розгортаннях.

**Примітка щодо оновлення до v0.0.109:** ця перевірка є новою для Slack. Облікові дані, чий webhook URL вказує на loopback або приватну адресу, відхиляються, якщо не увімкнено наведене вище налаштування.
