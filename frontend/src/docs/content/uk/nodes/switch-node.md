# Switch

Вузол **Switch** спрямовує виконання різними шляхами на основі зіставлення значення з варіантами. Підтримує N варіантів плюс варіант за замовчуванням.

## Огляд

| Властивість | Значення |
|----------|-------|
| Входи | 1 |
| Виходи | n (по одному на кожен варіант + за замовчуванням) |
| Вихід | Передає вхідні дані до відповідного відгалуження |

## Параметри

| Параметр | Тип | Опис |
|-----------|------|-------------|
| `label` | string | Ідентифікатор вузла (camelCase) |
| `expression` | expression | Значення для обчислення (наприклад, `$input.category`) |
| `cases` | string[] | Значення варіантів для зіставлення (наприклад, `["case1", "case2", "case3"]`) |

## Точки з'єднання ребер

- Кожен варіант отримує вихідну точку з'єднання (індекс 0, 1, 2, …)
- Точка з'єднання за замовчуванням для значень, що не збігаються

## Приклад

```json
{
  "type": "switch",
  "data": {
    "label": "routeByCategory",
    "expression": "$classifier.category",
    "cases": ["sales", "support", "billing"]
  }
}
```

З'єднуйте ребра, встановлюючи `sourceHandle` на індекс варіанта (0, 1, 2) або на точку з'єднання за замовчуванням для значень, що не збігаються.
