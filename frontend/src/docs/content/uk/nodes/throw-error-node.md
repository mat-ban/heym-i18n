# Викинути помилку

Вузол **Викинути помилку** негайно зупиняє виконання workflow та повертає відповідь із помилкою із заданим кодом стану HTTP. Використовуйте його для помилок валідації, несанкціонованого доступу або інших помилкових умов.

## Огляд

| Властивість | Значення |
|----------|-------|
| Входи | 1 |
| Виходи | 0 |
| Вихід | Workflow зупиняється; відповідь із помилкою повертається викликачу |

## Параметри

| Параметр | Тип | Опис |
|-----------|------|-------------|
| `label` | string | Ідентифікатор вузла (camelCase) |
| `errorMessage` | expression | Повідомлення про помилку (підтримує вирази) |
| `httpStatusCode` | number | Код стану HTTP (наприклад, 400, 401, 403, 404, 429, 500) |

## Поширені коди стану

| Код | Випадок використання |
|------|----------|
| 400 | Bad Request (недійсні вхідні дані) |
| 401 | Unauthorized (потрібна автентифікація) |
| 403 | Forbidden (доступ заборонено) |
| 404 | Not Found (ресурс відсутній) |
| 422 | Unprocessable Entity (помилка валідації) |
| 429 | Too Many Requests (перевищено ліміт запитів) |
| 500 | Internal Server Error |

## Приклад

```json
{
  "type": "throwError",
  "data": {
    "label": "validationError",
    "errorMessage": "Text input is required",
    "httpStatusCode": 400
  }
}
```

Використовуйте разом із [Condition](./condition-node.md), щоб перевіряти вхідні дані та викидати помилку лише за недійсних даних:
- Умова істинна → перейти до Output
- Умова хибна → Викинути помилку
