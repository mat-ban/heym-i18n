# Wait

Вузол **Wait** призупиняє виконання workflow на вказаний проміжок часу. Використовуйте його для обмеження швидкості запитів, відкладених дій або інтервалів опитування.

## Огляд

| Властивість | Значення |
|----------|-------|
| Входи | 1 |
| Виходи | 1 |
| Вихід | Передає вхідні дані без змін |

## Параметри

| Параметр | Тип | Опис |
|-----------|------|-------------|
| `label` | string | Ідентифікатор вузла (camelCase) |
| `duration` | number | Затримка в мілісекундах (наприклад, 1000 = 1 секунда). Редактор приймає значення від 1 до 900000 (15 хвилин) |

## Приклад

```json
{
  "type": "wait",
  "data": {
    "label": "delayOneSecond",
    "duration": 1000
  }
}
```
