# Chat Voice (TTS & STT)

Вкладка Chat може озвучувати повідомлення вголос і запускати інтерактивний голосовий режим без використання рук на основі [ElevenLabs](https://elevenlabs.io). Обидва напрямки використовують один обліковий запис ElevenLabs: **text-to-speech** для відтворення та **Scribe speech-to-text** для мікрофона.

## Налаштування

1. Відкрийте **Settings** (Ваш аватар, праворуч угорі) → вкладка **Voice**.
2. Виберіть **облікові дані ElevenLabs** або натисніть **Add credential**, щоб створити їх. Ключ API потребує ввімкнених дозволів **Text to Speech**, **Speech to Text** і **Voices** у Вашому обліковому записі ElevenLabs.
3. Виберіть **Voice** зі свого облікового запису ElevenLabs.
4. Натисніть **Save Voice Settings**.

Якщо Ви натиснете кнопку голосу до завершення налаштування, вкладка Voice відкриється автоматично, щоб Ви могли завершити конфігурацію.

Ключ API ElevenLabs зберігається у зашифрованому вигляді й ніколи не потрапляє до браузера — усі виклики проксуються через бекенд Heym. Див. [Credentials](./credentials.md) та [Settings](./user-settings.md).

## Читання повідомлення вголос

Кожна бульбашка повідомлення (Ваша та асистента) має кнопку динаміка поруч із **Copy**. Натисніть її, щоб відтворити повідомлення; натисніть ще раз — або відтворіть інше повідомлення — щоб зупинити. Відтворення використовує багатомовну модель ElevenLabs, тому мова тексту визначається автоматично.

## Інтерактивний голосовий режим

Кнопка звукової хвилі в полі введення чату відкриває повноекранний голосовий режим без використання рук (з підтримкою світлої/темної теми та мобільних пристроїв):

1. Він слухає через Ваш мікрофон і визначає, коли Ви припиняєте говорити.
2. Ваша мова транскрибується за допомогою **Scribe** (мова визначається автоматично — без ручного перемикання TR/EN).
3. Транскрипт надсилається як звичайне повідомлення чату в **тій самій розмові**.
4. Відповідь асистента озвучується вголос, після чого режим відновлює прослуховування.

Використовуйте кнопку **mute**, щоб призупинити прослуховування, та **✕**, щоб вийти (це звільняє мікрофон). Запис працює в усіх сучасних браузерах, включно з Firefox.

## Примітки

- Вибір голосу та облікових даних є персональними налаштуваннями користувача; активна розмова, модель і облікові дані для LLM залишаються незмінними.
- Використання ElevenLabs (як TTS, так і STT) тарифікується на Ваш власний обліковий запис ElevenLabs.
