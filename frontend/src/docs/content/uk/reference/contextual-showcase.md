# Контекстна довідка

**Контекстна довідка** — це легка вбудована навігаційна панель, яка пояснює поточну сторінку, не занурюючи Вас одразу в повний потік документації.

## Що вона робить

- Показує короткий огляд поточної сторінки
- Зберігає перший рівень лаконічним, щоб не перевантажувати Вас
- Дозволяє розгорнути невеликий обсяг додаткових деталей лише за потреби
- Містить посилання на повну сторінку документації для глибшого ознайомлення

## Де вона з'являється

У версії v1 довідка доступна на основних автентифікованих поверхнях Heym:

- Вкладки Dashboard
- [Оцінювання](../tabs/evals-tab.md)
- [Документація](../getting-started/introduction.md)
- Canvas редактора workflow

Публічні сторінки, як-от вхід, реєстрація, портал Chat і HITL-перевірка, не показують довідку.

## Доступ

### Desktop

- Фіксований trigger **Page Guide** з'являється на правому краї екрана
- Довідка відкривається як бічна панель праворуч
- За замовчуванням вона залишається закритою
- Одноразовий тизер допомагає показати, що довідка існує, не відкриваючи її примусово

### Mobile

- Той самий вміст доступний через плаваючу кнопку **Page Guide**
- Вона відкривається в нижній панелі замість правої бічної панелі

## Модель вмісту

Кожен запис довідки використовує структуроване визначення замість повністю кастомного компонента.

- **Заголовок** – Що це за сторінка
- **Огляд** – Одне коротке пояснення
- **Пункти** – Кілька зрозумілих підказок
- **Ключові моменти** – Невеликі картки для ключової цінності або шаблонів використання
- **Додаткові деталі** – Згорнуті розділи для додаткового контексту
- **Дії** – Зазвичай одне або два посилання, найчастіше на повну документацію

Це зберігає систему гнучкою, водночас уникаючи довгих і перевантажених панелей допомоги.

## Контекстна обізнаність

Довідка змінюється відповідно до поточної поверхні.

- Кожна вкладка Dashboard має власний огляд
- Редактор вказує на [Можливості Canvas](./canvas-features.md)
- Сторінка документації використовує загальний огляд документації та, за можливості, вказує на поточну статтю, яку Ви вже відкрили

## Збереження стану

Довідка зберігає невеликий обсяг персонального стану UI у сховищі браузера:

- Чи була панель або нижня панель останнього разу відкрита
- Які контексти сторінок уже показували тизер
- Останній розгорнутий розділ деталей для кожного контексту

## Навіщо вона існує

Мета — зробити Heym простішим для вивчення, не додаючи більше важкого UI-оформлення.

- Короткі підказки, завжди поруч, для орієнтації
- Чіткий шлях до глибшої документації
- Мінімальне переривання для досвідчених користувачів
