# Завантаження та імпорт

Експортуйте workflow або цілі папки як файли чи імпортуйте їх за допомогою перетягування. Використовуйте це для резервного копіювання, обміну або перенесення workflow між інстансами.

## Завантаження workflow (JSON)

**Розташування:** Панель інструментів редактора → кнопка **Download** (відображається на великих екранах)

**Що експортується:**
- `nodes` – Усі вузли на canvas
- `edges` – Усі з'єднання між вузлами

**Ім'я файлу:** `{workflow-name}.json` (похідне від назви workflow)

**Формат:** Див. [Workflow Structure](./workflow-structure.md) щодо схеми JSON.

## Завантаження папки (ZIP)

**Розташування:** Dashboard → вкладка Workflows → меню з трьома крапками папки → **Download as ZIP**

**Що експортується:**
- Усі workflow у папці та всіх підпапках, рекурсивно
- Ієрархія папок зберігається як каталоги всередині ZIP

**Структура ZIP:**
```
FolderName/
  workflow1.json
  workflow2.json
  SubFolder/
    workflow3.json
    DeepSub/
      workflow4.json
```

Кожен файл `.json` містить `{ name, nodes, edges }`.

## Імпорт

### З Dashboard (вкладка Workflows)

1. Перейдіть на вкладку [Workflows](../tabs/workflows-tab.md)
2. Перетягніть файл **JSON** або **ZIP** на область workflow

**Файл JSON:** Створюється новий workflow. Назва workflow береться з поля `name` у JSON або з імені файлу, якщо `name` відсутнє.

**Файл ZIP:** Уся структура папок відтворюється на кореневому рівні. Кожен файл `.json` усередині ZIP стає workflow, розміщеним у відповідній папці. Облікові дані та міжworkflow-посилання, яких немає в поточному інстансі, очищуються автоматично. Якщо деякі workflow не вдалося імпортувати, зведення показує, скільки з них успішно імпортовано.

### З Canvas (редактор)

1. Відкрийте workflow у редакторі
2. Перетягніть файл JSON на canvas
3. Якщо canvas уже містить вузли або з'єднання, діалог підтвердження запитає, чи замінити поточний workflow
4. Імпортовані вузли та з'єднання замінюють або об'єднуються з поточним workflow

## Формати файлів

### JSON (окремий workflow)

```json
{
  "nodes": [...],
  "edges": [...],
  "name": "Optional workflow name"
}
```

- `nodes` – Обов'язково; масив об'єктів вузлів
- `edges` – Необов'язково; масив об'єктів з'єднань (за замовчуванням `[]`)
- `name` – Необов'язково; використовується під час створення нового workflow з імпорту через Dashboard

### ZIP (папка)

ZIP-архів, у якому структура каталогів віддзеркалює ієрархію папок. Кожен файл є JSON workflow (див. вище). Назви папок і workflow походять від назв каталогів і файлів відповідно.

Див. [Workflow Structure](./workflow-structure.md) щодо форматів вузлів і з'єднань.

## Сценарії використання

- **Резервне копіювання** – Завантажуйте workflow або цілі папки перед значними змінами
- **Обмін** – Експортуйте та діліться файлами JSON з колегами
- **Міграція** – Переносьте workflow або структури папок між інстансами Heym
- **Контроль версій** – Зберігайте JSON workflow у Git разом із кодом
