# Drive

Вкладка Drive — це централізоване місце для перегляду, керування та обміну всіма файлами, створеними навичками.

## Доступ до Drive

Перейдіть на вкладку **Drive** на панелі керування. Усі файли, створені навичками вашого workflow, відображаються тут, відсортовані за датою створення.

## Список файлів

Список файлів містить:

- **Name** — початкова назва файлу з іконкою, що відповідає типу
- **Type** — MIME-тип файлу (наприклад, pdf, csv, docx)
- **Size** — розмір файлу у зручному для читання форматі
- **Source** — мітка вузла, що створив файл
- **Date** — дата створення файлу
- **Actions** — кнопки завантаження, обміну та видалення

## Масові дії

Кожен файл, яким ви володієте, має прапорець на початку рядка. Файли, надані вам через команду, доступні лише для читання й не можуть бути вибрані. Виберіть кілька файлів (Shift-клік вибирає суміжний діапазон; прапорець у заголовку вибирає всю сторінку), щоб відкрити панель масових дій над списком, потім натисніть **Bulk actions**, щоб відкрити діалог, який застосовує однакові налаштування до кожного вибраного файлу:

- **Share all with my teams** / **Remove team sharing** — перемикає обмін із командами для всіх вибраних файлів одночасно
- **Create share link for each file** — створює посилання для обміну на кожному вибраному файлі з однаковими значеннями терміну дії, пароля та максимальної кількості завантажень

Діалог повідомляє, до скількох файлів було застосовано налаштування; файли, якими ви не володієте, пропускаються. Селектор кількості рядків на сторінці (25 / 50 / 100 / **All**) внизу списку дозволяє завантажити більше файлів на одній сторінці, щоб вибирати по всьому Drive.

## Обмін файлами

Натисніть іконку **Share**, щоб відкрити діалог обміну. Ви можете створити кілька посилань для обміну на один файл із різними конфігураціями та за бажанням поділитися файлом зі своїми поточними командами.

### Публічне посилання (на основі Token)

Створіть посилання для обміну без пароля. Будь-хто з посиланням може завантажити файл.

### Посилання, захищене паролем (Basic Auth)

Встановіть пароль під час створення посилання для обміну. URL завантаження використовує HTTP Basic Authentication — браузери запитуватимуть ім'я користувача (`file`) та пароль під час відкриття посилання.

### Параметри посилання

- **Expires (hours)** — за бажанням встановіть час закінчення терміну дії
- **Max downloads** — за бажанням обмежте кількість завантажень
- Обидва параметри можна поєднати для максимального контролю

### Обмін із моїми командами

Увімкніть **Share with my teams**, щоб надати доступ лише для читання всім командам, до яких ви наразі належите. Члени команди можуть бачити та завантажувати файл із Drive та використовувати операції вузла Drive, орієнтовані на читання, але лише власник файлу може видаляти файл, створювати або відкликати публічні посилання чи змінювати пароль/TTL/обмеження завантажень.

Налаштування є специфічним для файлу. Якщо ви приєднаєтеся до іншої команди або створите її пізніше, увімкніть обмін знову або запустіть операцію `shareWithMyTeams` вузла Drive, щоб додати цю команду. Використовуйте `unshareWithMyTeams`, щоб видалити обмін із командами для файлу в workflow.

### Керування посиланнями для обміну

Діалог обміну показує всі наявні посилання для обміну з:
- Поточною кількістю завантажень
- Статусом терміну дії
- Чи увімкнено Basic Auth
- Кнопками копіювання та відкликання

## Посилання на файли в Chat і Portal

Коли навичка створює файли під час виконання workflow через чат Portal або Quick Drawer, посилання для завантаження з'являються автоматично у відповіді. Користувачі можуть натиснути, щоб завантажити безпосередньо.

## Сховище

Створені файли зберігаються у файловій системі сервера в `data/files/`. У розгортаннях Docker це монтується як том для забезпечення збереження даних.

## Керування файлами з workflow

[Вузол Drive](../nodes/drive-node.md) дозволяє керувати файлами Drive програмно зсередини workflow. Використовуйте його, щоб:

- **List** — перелічити ваші файли та повернути метадані, як-от назва файлу, MIME-тип, розмір, джерело та URL завантаження
- **Delete** — видалити файл після його доставки користувачеві
- **Share or unshare with your teams** — поділитися з вашими командами або скасувати обмін, щоб члени команди могли читати та завантажувати файл лише поки існує обмін із командою
- **Set a password** — встановити пароль на посилання для завантаження
- **Set a TTL** — встановити TTL, щоб посилання втратило чинність через N годин
- **Set a max downloads** — встановити обмеження максимальної кількості завантажень

Перетворення файлу в інший формат — це завдання [вузла Converter](../nodes/converter-node.md) з `conversion: "fileConvert"`. Він читає файл Drive і зберігає перетворений результат як новий.

Посилайтеся на файл за його ID з виводу навички: `$agentLabel._generated_files[0].id`

Дивіться [документацію вузла Drive](../nodes/drive-node.md) для деталей конфігурації.

## Читання файлів Drive з навичок

Навички агента можуть увімкнути читання з Drive за допомогою налаштування **Enable Drive files** на картці навички. Коли його увімкнено, середовище виконання навички включає згенерований помічник `heym_drive.py`. Код навички може імпортувати такі помічники, як `read_drive_text`, `read_drive_file`, `read_drive_base64`, `get_drive_file`, `get_drive_file_path` і `list_drive_files`.

Читання з Drive обмежено файлами, доступними суб'єкту workflow: файлами, якими він володіє, та файлами, наданими йому через команди. Використовуйте ID файлу для точного пошуку або точну назву файлу, коли користувач посилається на файл за назвою. Пошук за назвою файлу повертає найновіший доступний файл із цією назвою; `list_drive_files(filename="...")` повертає всі збіги.

## Очищення
Прострочені Token для обміну автоматично очищуються щодня. Самі файли зберігаються, доки їх не буде видалено вручну через вкладку Drive. Використовуйте **Clear All**, щоб видалити всі файли та їхні посилання для обміну однією дією.
