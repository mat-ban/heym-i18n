# Історія редагувань

Історія редагувань відстежує збережені версії workflow. Використовуйте її, щоб переглядати зміни в часі, порівнювати версії або повертатися до попереднього стану.

**Примітка:** Історія редагувань відрізняється від [Історії виконань](./execution-history.md). Історія редагувань відстежує **збереження** (зміни структури workflow); Історія виконань відстежує **запуски** (минулі виконання).

## Де це знайти

**Панель інструментів редактора** → **Історія редагувань** (іконка GitBranch)

## Версії

Нова версія створюється щоразу, коли ви **зберігаєте** workflow. Список показує:

- **Поточна** – Останній збережений стан (те, що ви бачите на canvas)
- **Версія N** – Минулі збереження з позначками часу

Версії без змін порівняно з попередньою приховуються.

## Перегляд відмінностей

Виберіть версію, щоб побачити, що змінилося порівняно з поточним workflow:

| Тип зміни | Опис |
|-------------|--------------|
| **Вузли** | Додані, видалені або змінені вузли |
| **Зв'язки** | Додані, видалені або змінені з'єднання |
| **Конфігурація** | Налаштування рівня workflow (автентифікація, обмеження швидкості тощо) |

Розгорніть кожну зміну, щоб побачити відмінності на рівні полів (наприклад, які властивості вузла змінилися).

## Попередній перегляд

Щоб побачити, як виглядав workflow у минулій версії, натисніть **Попередній перегляд** поруч із «Повернути».

Відкриється canvas лише для читання, що показує вузли та зв'язки цієї версії. Ви можете переміщати та масштабувати зображення, щоб дослідити розташування; з цього подання не можна вносити зміни.

## Повернення

Щоб відновити минулу версію:

1. Виберіть потрібну версію
2. Натисніть **Повернути**
3. Підтвердьте дію
4. Поточний workflow замінюється вибраною версією; сторінка перезавантажується

Повернення створює новий «поточний» стан — за потреби ви можете повернутися знову.

## Очищення історії

Натисніть іконку кошика в заголовку діалогового вікна, щоб видалити всю історію версій. Цю дію не можна скасувати. Поточний workflow залишається; видаляються лише минулі версії.

## Коли створюються версії

Версії створюються лише коли ви **зберігаєте** (Ctrl/Cmd+S або кнопка «Зберегти»). Незбережені зміни не зберігаються в Історії редагувань, доки ви не збережете.

Зміни навичок агента включаються до цих знімків. Щоб переглянути або відновити окрему навичку без повернення всього workflow, скористайтеся кнопкою **Історія** на картці цієї навички в панелі властивостей вузла Agent. Див. [Вузол Agent](../nodes/agent-node.md#skill-history).
