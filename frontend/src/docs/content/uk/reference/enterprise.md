# Enterprise

Комерційне ліцензування, професійна підтримка та послуги з розгортання для платформи Heym.

## Огляд

Heym можна безкоштовно використовувати та розгортати самостійно відповідно до його ліцензії з відкритим вихідним кодом. Для організацій, яким потрібне комерційне ліцензування, допомога з розгортанням на рівні production або виділена підтримка, план Enterprise пропонує практичні послуги від команди Heym.

| Послуга | Опис |
|---------|-------------|
| **Підтримка production-агентів** | Огляд архітектури, рекомендації щодо проєктування агентів і workflow, а також практична допомога у виведенні агентів у production |
| **Навчання роботі з інструментами** | Вступні сесії та навчання для Вашої команди, що охоплюють редактор workflow, AI-вузли, агентів та інтеграції |
| **Консультації щодо Heym** | Прямий доступ до інженерної команди Heym для запитань щодо платформи, найкращих практик і вирішення проблем |
| **Розгортання в Kubernetes** | Допомога з налаштуванням кількох worker-вузлів, sidecar-контейнерів, стратегій масштабування та конфігурації кластера |
| **Консалтинг щодо рішень** | Проєктування індивідуальних рішень для Вашого конкретного сценарію використання, включно з плануванням інтеграцій та рекомендаціями щодо архітектури |
| **Пріоритетна підтримка та SLA** | Гарантований час відповіді та пріоритетне вирішення проблем |
| **Індивідуальна розробка** | Розробка функцій і модифікацій, адаптованих до потреб Вашої організації |

## Heym Work

[Heym Work](./heym-work.md) — це інтерфейс для бізнес-команд, який працює поверх Heym. Користувачі описують завдання, відповідають на кілька запитань і отримують протестований workflow, працюють зі сторінок, створених для них, та відповідають на перевірки — з єдиним входом (SSO), ролями Owner, Editor і Viewer та іменем у кожному запуску. Він працює поруч із вашим Heym із власною ліцензією; підключіть його в **Settings → Heym Work**. Дізнайтеся більше та запитайте пробну версію на [heym.run/enterprise](https://heym.run/enterprise).

## Підтримка production-агентів

Команда Heym допомагає Вам проєктувати, створювати та зміцнювати агентів і workflow для Ваших бізнес-процесів. Це включає аналіз Ваших вимог, рекомендації щодо конфігурації вузлів і забезпечення відповідності Ваших workflow найкращим практикам щодо надійності, спостережуваності та керування.

Підтримка охоплює всі типи вузлів, включно з [LLM](../nodes/llm-node.md), [Agent](../nodes/agent-node.md), [HTTP](../nodes/http-node.md) та тригерами [Cron](../nodes/cron-node.md), а також просунуті патерни, як-от [мультиагентна оркестрація](./agent-architecture.md), контрольні точки [Human-in-the-Loop](./human-in-the-loop.md) та [паралельне виконання](./parallel-execution.md) між гілками.

## Розгортання в Kubernetes

Стандартний посібник [Запуск і розгортання](../getting-started/running-and-deployment.md) охоплює Docker Compose для production-налаштувань на одному сервері. Клієнти Enterprise отримують допомогу з production-розгортаннями в Kubernetes для високої доступності та горизонтального масштабування:

- **Кілька worker-вузлів** — Розподіл backend-worker'ів Heym між кількома вузлами Kubernetes для резервування та балансування навантаження
- **Sidecar-контейнери** — Налаштування патернів sidecar для збору логів, агентів моніторингу, service mesh (Istio, Linkerd) та ін'єкції секретів (Vault)
- **Планування ресурсів** — Запити/ліміти CPU та пам'яті, бюджети переривання pod'ів і політики горизонтального автомасштабування pod'ів
- **Мережа** — Конфігурація Ingress-контролера, термінація TLS та внутрішня взаємодія між pod'ами backend, frontend і бази даних
- **Постійне сховище** — Надання томів для бази даних і векторних сховищ з відповідним StorageClass та стратегіями резервного копіювання
- **Моніторинг** — Інтеграція з Prometheus, Grafana або Вашим наявним стеком спостережуваності для метрик контейнерів, логів і сповіщень

## Консалтинг щодо рішень

Кожна організація запускає агентів у різних системах і з різними обмеженнями. Команда Heym надає консультації, щоб допомогти Вам:

- Оцінити, чи підходить Heym для Вашого конкретного сценарію використання
- Спроєктувати наскрізні архітектури агентів і workflow
- Спланувати інтеграції з Вашою наявною інфраструктурою та сторонніми сервісами
- Налагодити складні workflow та вирішити проблеми в production
- Перенести наявні workflow з таких інструментів, як n8n, Zapier або Make.com
