# Комбінації клавіш

Heym надає комбінації клавіш у редакторі workflow та на canvas для прискорення типових дій.

## Глобальні комбінації редактора

Ці комбінації активні в будь-якому місці редактора workflow.

| Комбінація | Дія |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Відкрити Command Palette |
| `Ctrl + I` / `Cmd + I` | Перемкнути панель [AI Assistant](./ai-assistant.md) (працює під час введення тексту) |
| `Ctrl + Enter` / `Cmd + Enter` | Запустити поточний workflow |
| `Ctrl + S` / `Cmd + S` | Зберегти workflow |
| `Ctrl + Z` / `Cmd + Z` | Скасувати |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Повторити |
| `Ctrl + Y` / `Cmd + Y` | Повторити (альтернативна комбінація) |
| `Escape` | Закрити відкриті накладення, діалогові вікна та панелі |

## Комбінації на canvas

Ці комбінації застосовуються, коли canvas перебуває у фокусі (жодне поле введення тексту не активне).

### Вибір і навігація

| Комбінація | Дія |
|----------|--------|
| `Ctrl + A` / `Cmd + A` | Вибрати всі вузли |
| `Shift` (утримувати) | Перетягнути для вибору кількох вузлів |
| `Ctrl` / `Cmd` (утримувати) | Клацнути, щоб додати окремі вузли до вибору |
| `Escape` | Зняти вибір з усіх вузлів; закрити вбудований пошук вузлів |

### Редагування вузлів

| Комбінація | Дія |
|----------|--------|
| `Ctrl + C` / `Cmd + C` | Копіювати вибраний вузол (вузли) |
| `Ctrl + X` / `Cmd + X` | Вирізати вибраний вузол (вузли) |
| `Ctrl + V` / `Cmd + V` | Вставити вузол (вузли) |
| `Delete` або `Backspace` | Видалити вибраний вузол (вузли) та/або зв'язок (зв'язки) |
| `D` | Перемкнути вибраний вузол (вузли) між увімкненим і вимкненим станом |
| `P` | Перемкнути закріплені дані на вибраному вузлі |

### Вбудований пошук вузлів

Введення будь-якого друкованого символу на canvas (коли жодне поле введення тексту не перебуває у фокусі) відкриває спливне вікно вбудованого пошуку вузлів. Введений символ стає першим символом пошукового запиту.

| Комбінація | Дія |
|----------|--------|
| Будь-який друкований символ | Відкрити вбудований пошук вузлів і почати введення |
| `Backspace` | Видалити останній символ із пошукового запиту |
| `Escape` | Закрити вбудований пошук вузлів |

## Command Palette (`Ctrl + K`)

Command Palette доступна з редактора, панелі керування, документації та подань оцінювання. Вона дає змогу швидко переходити до workflow, вкладок і сторінок документації, не відриваючись від клавіатури.

| Комбінація | Дія |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | Відкрити Command Palette |
| `↑` / `↓` | Навігація списком результатів |
| `Tab` / `Shift + Tab` | Навігація списком результатів |
| `Enter` | Відкрити вибраний елемент |
| `Escape` | Закрити Command Palette |

## Комбінації на панелі керування

Ці комбінації активні на вкладці Workflows, коли жодне інше поле введення тексту не активне.

| Комбінація | Дія |
|----------|--------|
| `Ctrl + F` / `Cmd + F` | Перейти до пошуку workflow |
| `Escape` | Очистити пошук workflow, якщо він містить текст |

## Комбінації на панелі властивостей

Ці комбінації активні, коли вибрано вузол і відкрито панель властивостей.

| Комбінація | Дія |
|----------|--------|
| `Ctrl + Shift + O` / `Cmd + Shift + O` | Відкрити пов'язаний під-workflow у новій вкладці (лише для вузла Execute) |

## Комбінації в діалоговому вікні Evaluate

Ці комбінації активні, коли відкрито діалогове вікно Evaluate.

| Комбінація | Дія |
|----------|--------|
| `Ctrl + Enter` / `Cmd + Enter` | Застосувати вираз і закрити діалогове вікно |
| `Ctrl + Z` / `Cmd + Z` | Скасувати зміни в редакторі виразів |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Повторити зміни в редакторі виразів |
| `Ctrl + Y` / `Cmd + Y` | Повторити зміни в редакторі виразів (альтернативна комбінація) |

## Комбінації в History і Traces

Ці комбінації доступні в діалоговому вікні Execution History та на панелі Traces.

| Комбінація | Дія |
|----------|--------|
| `S` | Перемкнути поле пошуку для фільтрації записів |
