# DataTable

Вкладка **DataTable** дозволяє створювати та керувати структурованими таблицями даних безпосередньо в Heym. Таблиці можна використовувати у workflow через [DataTable node](../nodes/datatable-node.md) для програмних операцій CRUD.

## Створення таблиці

1. Перейдіть на вкладку DataTable з панелі керування
2. Натисніть **Create DataTable**
3. Введіть назву та необов'язковий опис
4. Додайте стовпці за допомогою редактора стовпців

## Стовпці

Кожен стовпець має:

| Властивість | Опис |
|----------|-------------|
| Name | Відображувана назва стовпця |
| Type | `string`, `number`, `boolean`, `date` або `json` |
| Required | Чи повинні нові рядки містити цей стовпець |
| Unique | Чи повинні значення бути унікальними в межах рядків |
| Default Value | Автоматично заповнюється, коли рядок не містить цей стовпець |

Додавайте, редагуйте або видаляйте стовпці із заголовка подання деталей таблиці.

## Генерація стовпців за допомогою AI

Замість додавання стовпців вручну Ви можете описати таблицю звичайною мовою (або вставити зразок JSON) і дозволити LLM запропонувати схему. Обидві точки входу відкривають однаковий діалог:

- **Generate with AI** (заголовок списку DataTable) — створює абсолютно нову таблицю з Вашого опису.
- **AI columns** (подання деталей таблиці, поруч із елементами керування стовпцями) — пропонує *нові* стовпці для додавання до відкритої таблиці.

### Як це працює

1. Виберіть **LLM credential** і **model** (за замовчуванням — Ваш перший LLM credential та його найновіша модель).
2. Введіть опис — наприклад, *"Таблиця книг із назвою, автором, кількістю сторінок і чи прочитав я її"* — або вставте зразок/схему JSON.
3. Натисніть **Generate**. Модель повертає запропоновану схему.
4. Перегляньте згенеровані стовпці у формі для редагування: змініть **name**, **type**, **default**, **unique** та **notEmpty** (required) для кожного, видаліть непотрібні стовпці або додайте стовпець вручну через **Add column**. Для нової таблиці Ви також можете редагувати запропоновані AI **name** та **description**.
5. Натисніть **Create Table** (нова таблиця) або **Add Columns** (наявна таблиця), щоб зберегти. Натисніть **Esc**, щоб закрити діалог у будь-який момент.

### Лише додавання для наявних таблиць

Під час генерації стовпців для наявної таблиці модель бачить Ваші поточні стовпці як контекст і пропонує **лише нові** стовпці. Наявні стовпці та їхні дані ніколи не змінюються й не видаляються — згенеровані стовпці додаються. Дублікати назв (без урахування регістру) відкидаються автоматично.

> Потрібен LLM credential (OpenAI, Google або Custom). Якщо у Вас його немає, спершу додайте його в Settings.

## Керування рядками

- **Add row**: Натисніть кнопку додавання, щоб створити новий рядок
- **Inline edit**: Двічі клацніть будь-яку комірку, щоб відредагувати її значення. Натисніть Enter або клацніть поза нею, щоб зберегти, Escape — щоб скасувати
- **Delete row**: Скористайтеся меню дій рядка, щоб видалити рядок
- **Pagination**: Рядки відображаються по 25 на сторінку з навігацією сторінками

## Імпорт/експорт CSV

### Імпорт
1. Натисніть **Import CSV** у поданні деталей таблиці
2. Виберіть файл CSV для завантаження
3. Перегляньте перші 5 рядків і зіставлення стовпців
4. Зелені стовпці зіставлено з наявними стовпцями таблиці; жовті — не зіставлено
5. Натисніть Import, щоб масово вставити рядки

### Експорт
Натисніть **Export CSV**, щоб завантажити всі рядки як файл CSV.

## Спільний доступ

Діліться таблицями з іншими користувачами або командами:

1. Відкрийте діалог спільного доступу з подання деталей таблиці
2. Додайте користувачів за електронною поштою з дозволом **read** або **write**
3. Додайте команди з дозволом **read** або **write**
4. Користувачі лише для читання можуть переглядати дані; користувачі з правами запису можуть змінювати рядки та стовпці. Перейменування таблиці, зміна її опису та керування спільним доступом залишаються доступними лише власнику.

## Створення таблиць з AI Assistant

[AI-асистент](../reference/ai-assistant.md#data-tables) на полотні, [Chat](./chat-tab.md) та інструмент `heym_chat` на [вкладці MCP](./mcp-tab.md) можуть вибрати одну з ваших таблиць для створюваного workflow або створити нову. Вони пропонують назву та стовпці й створюють таблицю після надсилання картки запитань. Асистент на полотні налаштовує вузли workflow на основі метаданих таблиці. Chat і `heym_chat` також можуть переглядати рядки, додавати або видаляти стовпці та безпосередньо вставляти, оновлювати або видаляти рядки. Надайте їм назву таблиці або посилання на цю вкладку. Запис вимагає права власності або прямого/командного доступу для **запису**. Додавання стовпців зберігає наявні дані; видалення стовпців стирає їхні значення з кожного рядка. Видалення стовпців та очищення всіх рядків вимагають підтвердження, так само як на цій вкладці.

## Використання у workflow

[DataTable node](../nodes/datatable-node.md) з'єднує таблиці з workflow. Операції включають find, getAll, getById, insert, update, remove та upsert. Credentials не потрібні.

## Таблиця витрат LLM (системна таблиця)

Закріплений розділ **System tables** з'являється над створеними Вами таблицями з єдиним записом: **LLM Cost Table**. Це подання ціноутворення для кожної моделі з фіксованою схемою, редаговане для кожного користувача, яке використовується діаграмами витрат у [Traces](./traces-tab.md).

### Звідки надходять дані

Heym зберігає глобальну таблицю ціноутворення для кожної моделі, наповнену з публічного endpoint ціноутворення Helicone (`https://www.helicone.ai/api/llm-costs`). Синхронізація виконується у фоновому режимі під час першого відкриття таблиці або Traces і обмежується одним запитом на 24 години. Натисніть **Refresh**, щоб примусово повторити синхронізацію негайно. Моделі, видалені Helicone зі списку upstream, не видаляються локально, тому пошук історичних витрат залишається стабільним.

### Схема (стовпці лише для читання)

| Стовпець | Значення |
|---|---|
| Provider | `ANTHROPIC`, `OPENAI`, `GOOGLE`, … (інформаційно, використовується Helicone) |
| Model | Ідентифікатор моделі, який зіставляється з `trace.model` |
| Op | Оператор зіставлення: `equals`, `startsWith` або `includes` |
| Input $/1M | USD за 1 мільйон prompt tokens |
| Output $/1M | USD за 1 мільйон completion tokens |
| Source | `helicone`, `seed` або `user` |

### Налаштування ціноутворення

- **Відредагуйте рядок**, щоб перевизначити його ціни. Ваше перевизначення є персональним для користувача та позначається значком `Customized`; майбутні синхронізації Helicone його не змінюють.
- **Скинути до стандартних значень** видаляє перевизначення та відновлює глобальне значення для цього рядка.
- **Додати Custom Model** відкриває діалогове вікно для створення рядка, доступного лише користувачу (наприклад, приватна донавчена модель, яку Helicone не відображає). Custom-рядки позначаються `User added`, а їх видалення прибирає їх повністю.

### Зіставлення з traces

Коли панель керування Traces обчислює вартість, вона зіставляє кожен `trace.model` з:

1. Вашими перевизначеннями (точна відповідність назві моделі) спочатку
2. Інакше — з глобальною таблицею — точна відповідність `equals` має пріоритет над `startsWith`/`includes`; збіги в межах одного оператора вирішуються за найдовшим відповідним префіксом/підрядком моделі

Якщо жоден рядок не збігається, модель відображається в повідомленні **Unpriced models** на сторінці Traces; її внесок у вартість дорівнює нулю, доки Ви не додасте custom-рядок або не перевизначите наявний.
