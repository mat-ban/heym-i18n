# Вкладка Drive

Вкладка Drive показує всі файли, згенеровані skills у Ваших workflows.

## Огляд

Файли, згенеровані skills (PDF, DOCX, CSV, зображення тощо), автоматично зберігаються та відображаються у списку на вкладці Drive. Для кожного файлу показано його назву, тип, розмір, вихідний вузол, дату створення та стан спільного доступу для команди.

## Функції

- **Пошук** – фільтруйте файли за назвою, типом або вихідним вузлом
- **Копіювати ID файлу** – скопіюйте UUID файлу до буфера обміну, щоб вставити його у вузол [Drive](../nodes/drive-node.md) або [Converter](../nodes/converter-node.md)
- **Завантажити** – автентифіковане завантаження Ваших файлів і файлів, наданих Вам через команди
- **Поділитися** – створюйте посилання для завантаження з можливим захистом паролем і терміном дії або надавайте файл у режимі лише для читання Вашим поточним командам
- **Видалити** – видаляйте файли та їхні посилання для спільного доступу
- **Очистити все** – видаліть усі файли та їхні посилання для спільного доступу після підтвердження
- **Масові дії** – вибирайте кілька файлів за допомогою прапорців (Shift-клік для діапазону) і застосовуйте ту саму дію до всіх одразу
- **Посторінкова навігація** – переглядайте великі колекції файлів із вибором кількості рядків на сторінку (25 / 50 / 100 / Усі)

## Масові дії

Файли, якими Ви володієте, показують прапорець на початку рядка (файли, надані Вам через команду, доступні лише для читання й не вибираються). Виберіть кілька рядків — або скористайтеся прапорцем у заголовку, щоб вибрати всю сторінку, і **Shift-кліком**, щоб вибрати діапазон — потім скористайтеся панеллю масових дій, що з'являється над списком:

- **Завантажити ZIP** об'єднує всі вибрані файли в один ZIP-архів і завантажує його
- **Масові дії** відкриває одне діалогове вікно, щоб застосувати одне налаштування до кожного вибраного файлу:
  - **Поділитися всіма з моїми командами** / **Прибрати спільний доступ для команд** одним кліком
  - **Створити посилання для кожного файлу** з однаковими налаштуваннями пароля, терміну дії та максимальної кількості завантажень
- **Видалити** видаляє кожен вибраний файл та його посилання для спільного доступу після підтвердження
- **Очистити вибір** знімає виділення з усього

Діалогове вікно повідомляє, до скількох файлів застосовано дію (файли, якими Ви не володієте, пропускаються). Скористайтеся опцією **Усі** у виборі кількості рядків на сторінку, щоб завантажити всі файли на одній сторінці та вибирати по всьому Вашому Drive. Введення тексту в полі пошуку автоматично перемикає вибір кількості рядків на сторінку на **Усі**, щоб пошук охоплював усі файли, а не лише поточну сторінку; очищення пошуку відновлює Ваш попередній вибір.

## Спільний доступ

Створюйте посилання для спільного доступу з:
- **Без автентифікації** – публічна URL-адреса завантаження на основі token
- **Basic Auth** – посилання, захищене паролем (ім'я користувача: `file`)
- **Термін дії** – необов'язковий термін дії на основі часу
- **Обмеження завантажень** – необов'язкова максимальна кількість завантажень

Увімкніть **Поділитися з моїми командами** для файлу, щоб зробити його видимим для всіх команд, до яких Ви наразі належите. Учасники спільної команди отримують доступ лише для читання; дії з керування залишаються доступними лише власнику.

## Доступ для Agent Skill

Skills на вузлі Agent можуть дозволити читання файлів Drive. Коли для skill увімкнено **Enable Drive files**, його код Python може читати доступні файли Drive за id файлу або точною назвою файлу через згенерований помічник `heym_drive.py`. Це налаштування вимкнено за замовчуванням.

Дивіться [Довідник Drive](../reference/drive.md) для повних подробиць.
