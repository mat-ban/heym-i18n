# Вкладка Templates

Вкладка Templates дозволяє зберігати, переглядати та повторно використовувати повні workflow та окремі nodes. Поділіться тим, що Ви створили один раз, і застосовуйте це до нових проєктів одним кліком.

## Огляд

Існує два типи templates:

- **Workflow templates** — збережіть повний workflow (усі nodes та з'єднання) як багаторазову відправну точку.
- **Node templates** — збережіть окремий налаштований node (наприклад, налаштований LLM node або власний HTTP node) для повторного використання в різних workflow.

Перемикайтеся між ними за допомогою перемикача **Workflows / Nodes** у верхній частині вкладки.

Використовуйте рядок пошуку, щоб фільтрувати видимі templates за назвою, описом, тегами або типом node.

---

## Створення Template

### Workflow template

1. Відкрийте workflow, яким хочете поділитися, у редакторі.
2. Натисніть **Share as Template** на верхній панелі інструментів.
3. Заповніть назву, опис і необов'язкові теги.
4. Виберіть видимість: **Everyone** (усі користувачі) або **Specific users** (введіть імена користувачів та/або виберіть teams).
5. Натисніть **Share**. Зелене сповіщення підтвердить успіх.

### Node template

1. Клацніть правою кнопкою миші на будь-якому node на полотні.
2. Виберіть **Share as Template** у контекстному меню.
3. Заповніть форму та натисніть **Share**.

---

## Використання Template

### Workflow template

1. Відкрийте вкладку **Templates** і переконайтеся, що вибрано **Workflows**.
2. Натисніть на картку, щоб переглянути її, або натисніть **Use** одразу.
3. Workflow буде клоновано в новий workflow, який відкриється в редакторі.

### Node template

1. Відкрийте вкладку **Templates** і виберіть **Nodes**.
2. Натисніть **Use** на картці node template.
3. З'явиться діалогове вікно — виберіть, куди додати node:
   - **New workflow** — створює новий workflow, що містить лише цей node.
   - **Existing workflow** — виберіть зі свого списку workflow; node буде вставлено автоматично під час відкриття редактора.

## Попередній перегляд

Натисніть на будь-яку картку template, щоб відкрити повний попередній перегляд:

- **Мініатюри карток** — картки template відображають вписаний знімок полотна лише для читання як для workflow, так і для одно-node templates.
- **Workflow templates** — полотно лише для читання, що відповідає стилю попереднього перегляду історії редагувань, включно з панорамуванням і масштабуванням.
- **Node templates** — збережений node відкривається на тому самому полотні лише для читання як попередній перегляд одного node.
- **Деталі node** — натисніть на будь-який node у попередньому перегляді, щоб оглянути його збережену конфігурацію на бічній панелі.
- Теги, кількість використань і **owner** відображаються для всіх templates.

Натисніть **ESC** або клацніть поза межами, щоб закрити попередній перегляд.

---

## Керування Templates

- **Edit** – Якщо Ви є owner template, наведіть курсор на картку та натисніть значок олівця, щоб оновити її назву, опис, теги або видимість
- **Delete** – Якщо Ви є owner template, наведіть курсор на картку та видаліть template після запиту на підтвердження
- **Дії лише для owner** – Елементи керування редагуванням і видаленням відображаються лише для templates, які Ви створили

---

## Command Palette (CTRL+K)

Templates (як workflow, так і node) можна знайти через command palette **CTRL+K**. Виберіть template, щоб одразу його використати — workflow templates відкриваються в редакторі, node templates запитують місце призначення.

## Templates у Chat

Ви можете ставити AI запитання про Ваші templates — він знає всі templates у Вашому workspace.

---

## Видимість

| Налаштування | Хто може бачити |
|---|---|
| Everyone | Усі користувачі на платформі |
| Specific users | Користувачі, яких Ви вказали за іменем, та/або teams, які Ви вибрали — усі члени team отримують доступ |

Під час надання доступу для **Specific users** Ви можете додати як окремих користувачів (за іменем), так і teams. Члени team бачать template на вкладці Templates і можуть його використовувати.
