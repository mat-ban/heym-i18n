# Bộ ánh xạ đầu ra HTML

Node **HTML output mapper** kết xuất một HTML template duy nhất thành một trang. Sử dụng node này khi bên gọi là **browser** thay vì API client — workflow sẽ trả về `text/html` thay vì JSON.

## Tổng quan

| Thuộc tính | Giá trị |
|----------|-------|
| Inputs | 1 |
| Outputs | 0 (sink) |
| Runtime output | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## Tham số

| Tham số | Kiểu | Mô tả |
|-----------|------|-------------|
| `label` | string | Định danh node (camelCase) |
| `html` | string | Template của trang. Các biểu thức `$nodeLabel.field` được nội suy tại chỗ. |
| `statusCode` | number | HTTP status cho response (mặc định `200`) |
| `contentType` | string | Content type của response (mặc định `text/html; charset=utf-8`) |

## Hành vi Webhook và run

Khi node này là output đầu cuối **duy nhất** của workflow, execute endpoint sẽ trả về trang đã kết xuất, status code đã cấu hình và content type đã cấu hình — không có JSON envelope, không có label wrapper.

Hai điều sẽ vô hiệu hóa hành vi đó:

- **Node đầu cuối thứ hai.** Khi có một terminal đang hoạt động khác trong graph, Heym sẽ quay về JSON map theo từng label thông thường và trang sẽ đến dưới dạng một trường string.
- **`X-Simple-Response: false`.** Header đó yêu cầu envelope đầy đủ với `status`, `node_results` và timings, đây là những gì canvas của editor sử dụng. Hãy gửi header này khi bạn đang debug một page workflow.

## Phục vụ một trang cho browser

Đặt **request method** của workflow thành `GET` trong hộp thoại cURL để một điều hướng browser thông thường có thể truy cập được. Request `GET` không mang body, nên các input đến từ query string:

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

Đọc các giá trị đó bằng `$input.query.name`. Xem [Webhooks](../reference/webhooks.md) để biết đầy đủ về method contract.

Một workflow không có trigger node mà terminal duy nhất là node này sẽ hiển thị chip **WEB** trong [Workflows tab](../tabs/workflows-tab.md).

## Sử dụng làm Agent tool

Không được hỗ trợ. Node này là một terminal sink, nên không thể gắn vào tools handle của [Agent Node](./agent-node.md). Điều tương tự cũng áp dụng cho [JSON output mapper](./json-output-mapper-node.md).

## Giới hạn trong Loop

Cùng quy tắc như [Output](./output-node.md): không đặt node này bên trong nhánh lặp của loop—chỉ đặt sau nhánh `done` của loop. Xem [Loop](./loop-node.md).

## Ví dụ

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
