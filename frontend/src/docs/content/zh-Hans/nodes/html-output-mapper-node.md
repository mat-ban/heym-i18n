# HTML 输出映射器

**HTML 输出映射器**节点将单个 HTML 模板渲染为一个页面。当调用方是**浏览器**而非 API 客户端时使用此节点——工作流将以 `text/html` 而非 JSON 进行响应。

## 概述

| 属性 | 值 |
|----------|-------|
| 输入 | 1 |
| 输出 | 0（终端） |
| 运行时输出 | `{ "html": "…", "statusCode": 200, "contentType": "text/html; charset=utf-8" }` |

## 参数

| 参数 | 类型 | 描述 |
|-----------|------|-------------|
| `label` | string | 节点标识符（camelCase） |
| `html` | string | 页面模板。`$nodeLabel.field` 表达式将就地插值。 |
| `statusCode` | number | 响应的 HTTP 状态码（默认 `200`） |
| `contentType` | string | 响应内容类型（默认 `text/html; charset=utf-8`） |

## Webhook 与运行行为

当此节点是工作流的**唯一**终端输出时，execute endpoint 将以渲染后的页面、配置的状态码和配置的内容类型进行响应——没有 JSON 封装，没有 label 包装。

以下两种情况会关闭该行为：

- **第二个终端节点。** 当图中存在另一个活跃终端时，Heym 会回退到常规的按 label 组织的 JSON 映射，页面将作为字符串字段返回。
- **`X-Simple-Response: false`。** 该请求头要求返回包含 `status`、`node_results` 和计时的完整封装，这正是编辑器画布所使用的格式。在调试页面工作流时发送该请求头。

## 向浏览器提供页面

在 cURL 对话框中将工作流的**请求方法**设置为 `GET`，以便普通浏览器导航能够访问它。`GET` 请求不携带请求体，因此输入来自查询字符串：

```
curl -X GET "https://your-host/api/workflows/<workflow-id>/execute?name=Ada"
```

使用 `$input.query.name` 读取这些值。完整的方法契约请参见 [Webhooks](../reference/webhooks.md)。

一个没有 Trigger 节点、且唯一终端为此节点的工作流会在 [Workflows 标签页](../tabs/workflows-tab.md)中显示 **WEB** 标记。

## Agent 工具用法

不支持。此节点是终端 sink，因此无法附加到 [Agent 节点](./agent-node.md)的 tools 句柄。同样适用于 [JSON 输出映射器](./json-output-mapper-node.md)。

## 循环限制

与 [Output](./output-node.md) 规则相同：不要将此节点放在循环迭代分支内——只能放在循环 `done` 分支之后。请参见 [Loop](./loop-node.md)。

## 示例

```json
{
  "type": "htmlOutputMapper",
  "data": {
    "label": "reportPage",
    "html": "<!doctype html><html><body><h1>$llm.text</h1><p>Generated by Heym</p></body></html>",
    "statusCode": 200,
    "contentType": "text/html; charset=utf-8"
  }
}
```
