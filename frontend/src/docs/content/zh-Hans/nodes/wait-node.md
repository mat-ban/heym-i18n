# 等待

**Wait** 节点会将工作流执行暂停指定的时长。可用于速率限制、延迟操作或轮询间隔。

## 概述

| 属性 | 值 |
|----------|-------|
| 输入 | 1 |
| 输出 | 1 |
| 输出内容 | 透传输入 |

## 参数

| 参数 | 类型 | 描述 |
|-----------|------|-------------|
| `label` | string | 节点标识符（camelCase） |
| `duration` | number | 延迟时长，单位为毫秒（例如 1000 = 1 秒）。编辑器接受 1 到 900000（15 分钟） |

## 示例

```json
{
  "type": "wait",
  "data": {
    "label": "delayOneSecond",
    "duration": 1000
  }
}
```
