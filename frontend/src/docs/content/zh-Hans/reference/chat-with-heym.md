# 与 Heym 对话

与 Heym 对话是一个页面感知助手，可从文档页眉中访问。它会在居中的对话框中打开，允许你选择 LLM 凭据和模型，并以当前文档页面作为首要上下文来回答问题。

## 打开对话框

1. 打开 `/docs` 下的任意页面
2. 点击页眉中的 **Chat with Heym**
3. 选择一个[凭据](../tabs/credentials-tab.md)和模型
4. 就该页面或平台提出问题

在较小的屏幕上，触发入口仅显示图标；在较大的屏幕上，它会显示完整标签。

## 它使用的上下文

- 当前打开的文档路径会作为上下文指引注入到请求中
- 后端仍然使用现有的仪表盘聊天 Endpoint 和文档搜索工具
- 你的账户级[用户规则](./user-settings.md)继续生效，因为复用了相同的聊天后端
- 实时准备步骤会在最终答案之前流式显示在助手气泡中，与仪表盘聊天类似
- 澄清问题以卡片形式显示，与[聊天标签页](../tabs/chat-tab.md)中相同。当工作流请求需要凭据时，你可以选择其中一个或从卡片中创建。当它需要数据表时，你可以选择你的某个表，或以相同方式创建新表。

当你在某篇特定文章上打开对话框时，会显示一个小徽章来标明当前活动的文档路径，以便你确认正在优先使用哪个页面。

## 会话行为

- 在对话框保持挂载期间，凭据和模型的选择会保持不变
- 消息历史仅限当前会话，并在对话框关闭时清除
- 点击背景、按 `Escape` 以及点击关闭按钮都会重置会话
- **Stop** 会中止当前正在流式传输的响应
- 对话框有意设计为宽大且固定尺寸；它不提供全屏切换

## 何时使用它

- 在阅读节点或参考页面时提出后续问题
- 无需离开文档即可厘清功能差异
- 在打开编辑器之前找到正确的文章

如果你想直接构建或修改工作流，请改用编辑器侧的 [AI Assistant](./ai-assistant.md)。
