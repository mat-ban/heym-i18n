# 上下文 Showcase

**上下文展示**是一个轻量级的应用内引导栏，用于说明你当前所在的页面，而不会立即将你推入完整的文档流程。

## 功能说明

- 显示当前页面的简短摘要
- 保持第一层内容简洁，避免信息过载
- 仅在需要时允许你展开少量额外细节
- 链接到完整文档页面以供深入阅读

## 显示位置

在 v1 中，该展示功能可在 Heym 的已认证主要界面上使用：

- Dashboard 标签页
- [Evals](../tabs/evals-tab.md)
- [文档](../getting-started/introduction.md)
- Workflow 编辑器画布

公开页面（如登录、注册、聊天门户和 HITL 审核）不显示该展示功能。

## 访问方式

### 桌面端

- 屏幕右侧边缘会出现一个固定的 **Page Guide** 触发器
- 展示功能以右侧抽屉的形式打开
- 默认保持关闭状态
- 一次性提示有助于让用户了解该引导的存在，但不会强制打开

### 移动端

- 相同内容可通过浮动的 **Page Guide** 按钮访问
- 它以底部面板的形式打开，而非右侧栏

## 内容模型

每个展示条目使用结构化定义，而非完全自定义的组件。

- **标题** – 该页面是什么
- **摘要** – 一段简短说明
- **要点** – 几条可快速浏览的提示
- **亮点** – 用于展示关键价值或使用模式的小卡片
- **更多详情** – 折叠区域，提供额外上下文
- **操作** – 通常为一到两个链接，多数情况下指向完整文档

这样既保持了系统的灵活性，又避免了冗长嘈杂的帮助面板。

## 上下文感知

展示内容会随当前界面而变化。

- Dashboard 各标签页各有自己的摘要
- 编辑器指向 [Canvas 功能](./canvas-features.md)
- 文档页面使用通用文档概览，并在可能的情况下指向你当前已打开的文章

## 持久化

展示功能会在浏览器存储中保存少量个人 UI 状态：

- 面板或底部面板上次是否处于打开状态
- 哪些页面上下文已显示过提示
- 每个上下文上次展开的详情区域

## 存在意义

目标是在不增加更多沉重 UI 元素的前提下，让 Heym 更易于学习。

- 简短、始终就近的引导，帮助定位
- 通往更深入文档的清晰路径
- 对经验丰富的用户干扰极低
