# 编辑历史

编辑历史用于跟踪工作流的已保存版本。你可以通过它查看随时间推移的变更、比较不同版本，或回退到之前的状态。

**注意：** 编辑历史与[执行历史](./execution-history.md)不同。编辑历史跟踪的是**保存**操作（工作流结构变更）；执行历史跟踪的是**运行**记录（过去的执行）。

## 在哪里找到它

**编辑器工具栏** → **编辑历史**（GitBranch 图标）

## 版本

每次**保存**工作流时都会创建一个新版本。列表显示：

- **当前** – 最新保存的状态（即你在画布上看到的内容）
- **版本 N** – 过去的保存记录及其时间戳

与上一个版本相比没有变更的版本会被隐藏。

## 差异视图

选择一个版本即可查看其与当前工作流之间的变更：

| 变更类型 | 描述 |
|-------------|--------------|
| **节点** | 新增、删除或修改的节点 |
| **边** | 新增、删除或修改的连接 |
| **配置** | 工作流级别的设置（认证、速率限制等） |

展开每项变更即可查看字段级差异（例如哪些节点属性发生了变更）。

## 预览

要查看工作流在过去某个版本时的样子，请点击 Revert 旁边的 **Preview**。

此时会打开一个只读画布，显示该版本的节点和边。你可以平移和缩放以查看布局；此视图下无法进行任何更改。

## 回退

要恢复过去的某个版本：

1. 选择你想要回退到的版本
2. 点击 **Revert**
3. 确认操作
4. 当前工作流将被所选版本替换；页面会重新加载

回退会创建一个新的“当前”状态——如有需要，你可以再次回退。

## 清除历史

点击对话框标题栏中的垃圾桶图标可移除所有版本历史。此操作无法撤销。当前工作流会保留；仅过去的版本会被删除。

## 版本何时创建

版本仅在你**保存**时创建（Ctrl/Cmd+S 或 Save 按钮）。未保存的变更在你保存之前不会存储到编辑历史中。

Agent skill 的编辑也会包含在这些快照中。若要浏览或恢复单个 skill 而不回退整个工作流，请使用 Agent 节点属性面板中该 skill 卡片上的 **History** 按钮。参见 [Agent 节点](../nodes/agent-node.md#skill-history)。
