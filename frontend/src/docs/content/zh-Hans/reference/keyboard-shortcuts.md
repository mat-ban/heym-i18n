# 键盘快捷键

Heym 在工作流编辑器和画布中提供了键盘快捷键，以加速常见操作。

## 全局编辑器快捷键

这些快捷键在工作流编辑器的任意位置均处于激活状态。

| 快捷键 | 操作 |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | 打开命令面板 |
| `Ctrl + I` / `Cmd + I` | 切换 [AI Assistant](./ai-assistant.md) 面板（输入时同样有效） |
| `Ctrl + Enter` / `Cmd + Enter` | 运行当前工作流 |
| `Ctrl + S` / `Cmd + S` | 保存工作流 |
| `Ctrl + Z` / `Cmd + Z` | 撤销 |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | 重做 |
| `Ctrl + Y` / `Cmd + Y` | 重做（备用） |
| `Escape` | 关闭打开的浮层、对话框和面板 |

## 画布快捷键

这些快捷键在画布获得焦点时（没有文本输入处于激活状态）生效。

### 选择与导航

| 快捷键 | 操作 |
|----------|--------|
| `Ctrl + A` / `Cmd + A` | 选择所有节点 |
| `Shift`（按住） | 拖拽以选择多个节点 |
| `Ctrl` / `Cmd`（按住） | 点击以将单个节点添加到选择中 |
| `Escape` | 取消选择所有节点；关闭内联节点搜索 |

### 编辑节点

| 快捷键 | 操作 |
|----------|--------|
| `Ctrl + C` / `Cmd + C` | 复制选中的节点 |
| `Ctrl + X` / `Cmd + X` | 剪切选中的节点 |
| `Ctrl + V` / `Cmd + V` | 粘贴节点 |
| `Delete` 或 `Backspace` | 删除选中的节点和/或连线 |
| `D` | 切换选中节点的启用 / 禁用状态 |
| `P` | 切换选中节点的固定数据 |

### 内联节点搜索

在画布上输入任意可打印字符（当没有文本输入获得焦点时）会打开内联节点搜索弹窗。输入的字符将成为搜索查询的第一个字符。

| 快捷键 | 操作 |
|----------|--------|
| 任意可打印字符 | 打开内联节点搜索并开始输入 |
| `Backspace` | 从搜索查询中删除最后一个字符 |
| `Escape` | 关闭内联节点搜索 |

## 命令面板（`Ctrl + K`）

命令面板可从编辑器、仪表盘、文档和评估视图中使用。它让你无需离开键盘即可快速导航到工作流、标签页和文档页面。

| 快捷键 | 操作 |
|----------|--------|
| `Ctrl + K` / `Cmd + K` | 打开命令面板 |
| `↑` / `↓` | 在结果列表中导航 |
| `Tab` / `Shift + Tab` | 在结果列表中导航 |
| `Enter` | 打开选中的项目 |
| `Escape` | 关闭命令面板 |

## 仪表盘快捷键

这些快捷键在 Workflows 标签页上且没有其他文本输入处于激活状态时生效。

| 快捷键 | 操作 |
|----------|--------|
| `Ctrl + F` / `Cmd + F` | 聚焦工作流搜索 |
| `Escape` | 当工作流搜索包含文本时清除搜索内容 |

## 属性面板快捷键

这些快捷键在选中节点且属性面板打开时生效。

| 快捷键 | 操作 |
|----------|--------|
| `Ctrl + Shift + O` / `Cmd + Shift + O` | 在新标签页中打开链接的子工作流（仅限 Execute 节点） |

## Evaluate 对话框快捷键

这些快捷键在 Evaluate 对话框打开时生效。

| 快捷键 | 操作 |
|----------|--------|
| `Ctrl + Enter` / `Cmd + Enter` | 应用表达式并关闭对话框 |
| `Ctrl + Z` / `Cmd + Z` | 撤销表达式编辑器中的更改 |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | 重做表达式编辑器中的更改 |
| `Ctrl + Y` / `Cmd + Y` | 重做表达式编辑器中的更改（备用） |

## 历史记录与 Trace 快捷键

这些快捷键在执行历史记录对话框和 Traces 面板中可用。

| 快捷键 | 操作 |
|----------|--------|
| `S` | 切换搜索输入以筛选条目 |
