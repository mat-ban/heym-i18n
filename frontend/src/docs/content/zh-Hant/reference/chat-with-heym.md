# 與 Heym 對話

「與 Heym 對話」是文件頁首提供的頁面感知助理。它會在置中對話框中開啟，讓你選擇 LLM 認證與模型，並以當前文件頁面作為首要上下文來回答問題。

## 開啟對話框

1. 開啟 `/docs` 下的任一頁面
2. 點擊頁首的 **Chat with Heym**
3. 選擇一個[認證](../tabs/credentials-tab.md)與模型
4. 針對該頁面或平台提出問題

在較小的螢幕上，觸發按鈕僅顯示圖示；在較大的螢幕上，則會顯示完整標籤。

## 使用的上下文

- 當前開啟的文件路徑會作為上下文指引注入請求中
- 後端仍使用既有的儀表板聊天 Endpoint 與文件搜尋工具
- 你的帳號層級 [User Rules](./user-settings.md) 仍會生效，因為重用了相同的聊天後端
- 即時準備步驟會在最終答案之前串流至助理泡泡中，與儀表板聊天類似
- 釐清問題會以卡片形式呈現，與 [Chat 分頁](../tabs/chat-tab.md)相同。當 Workflow 請求需要認證時，你可以挑選一個或直接從卡片建立。當需要資料表時，你可以挑選現有資料表，或以相同方式建立新的資料表。

當你在特定文章上開啟對話框時，會顯示一個小型徽章標示當前文件路徑，讓你確認正在優先處理哪個頁面。

## 工作階段行為

- 只要對話框保持掛載，認證與模型選擇就會維持不變
- 訊息歷史僅限於工作階段，並在對話框關閉時清除
- 點擊背景、按下 `Escape` 以及關閉按鈕都會重設工作階段
- **Stop** 會中止當前串流回應
- 對話框刻意設計為寬版且固定尺寸；不提供全螢幕切換

## 使用時機

- 在閱讀節點或參考頁面時提出後續問題
- 在不離開文件的情況下釐清功能差異
- 在開啟編輯器之前找到正確的文章

如果你想直接建立或修改 Workflow，請改用編輯器端的 [AI Assistant](./ai-assistant.md)。
