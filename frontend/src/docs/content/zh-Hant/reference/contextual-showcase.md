# 上下文 Showcase

**情境式導覽**是一種輕量的應用程式內指引側欄，用於說明您目前所在的頁面，而不會立即將您推入完整的文件流程中。

## 功能說明

- 顯示目前頁面的簡短摘要
- 保持第一層內容精簡，避免資訊過載
- 讓您僅在需要時展開少量額外細節
- 連結至完整文件頁面以供深入閱讀

## 顯示位置

在 v1 中，此導覽適用於 Heym 需驗證的主要介面：

- Dashboard 分頁
- [Evals](../tabs/evals-tab.md)
- [Documentation](../getting-started/introduction.md)
- Workflow 編輯器畫布

公開頁面（例如登入、註冊、聊天入口及 HITL 審查）不會顯示此導覽。

## 存取方式

### 桌面版

- 畫面右側邊緣會顯示固定的 **Page Guide** 觸發按鈕
- 導覽會以右側抽屉的形式開啟
- 預設為關閉狀態
- 一次性提示會協助揭露此指引的存在，而不會強制將其開啟

### 行動版

- 可透過浮動的 **Page Guide** 按鈕存取相同內容
- 會以底部彈出面板的形式開啟，而非右側側欄

## 內容模型

每個導覽項目使用結構化定義，而非完全自訂的元件。

- **Title** – 此頁面的用途
- **Summary** – 一段簡短說明
- **Bullets** – 幾個可快速瀏覽的提示
- **Highlights** – 用於呈現關鍵價值或使用模式的小卡
- **More Detail** – 提供額外情境的收合區段
- **Actions** – 通常為一或兩個連結，最常見的是指向完整文件

這讓系統保持彈性，同時避免冗長且嘈雜的說明面板。

## 情境感知

導覽會隨著目前介面而變化。

- Dashboard 各分頁各自擁有專屬摘要
- 編輯器會指向 [Canvas Features](./canvas-features.md)
- 文件頁面使用通用的文件總覽，並在可能時指向您目前已開啟的當前文章

## 持續性

導覽會在瀏覽器儲存空間中保存少量個人 UI 狀態：

- 面板或底部彈出面板上次是否為開啟狀態
- 哪些頁面情境已顯示過提示
- 每個情境上次展開的詳細區段

## 存在目的

目標是讓 Heym 更容易學習，而不增加更多笨重的 UI 介面元素。

- 提供簡短且隨時可及的指引，協助定位
- 提供通往深入文件的明確路徑
- 對有經驗的使用者降低干擾
