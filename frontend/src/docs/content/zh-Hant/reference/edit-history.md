# 編輯歷史

編輯歷史會追蹤 Workflow 已儲存的版本。您可以用它來檢視歷來的變更、比較版本，或還原至先前的狀態。

**注意：** 編輯歷史與[執行歷史](./execution-history.md)不同。編輯歷史追蹤的是**儲存**（Workflow 結構變更）；執行歷史追蹤的是**執行**（過往的執行紀錄）。

## 在哪裡找到它

**編輯器工具列** → **編輯歷史**（GitBranch 圖示）

## 版本

每次**儲存** Workflow 時，都會建立一個新版本。清單會顯示：

- **Current** – 最新儲存的狀態（您在畫布上看到的內容）
- **Version N** – 過往的儲存版本及其時間戳記

與前一個版本相比沒有任何變更的版本會被隱藏。

## 差異檢視

選擇一個版本，即可查看它與目前 Workflow 相比有哪些變更：

| 變更類型 | 說明 |
|-------------|--------------|
| **Nodes** | 新增、移除或修改的節點 |
| **Edges** | 新增、移除或修改的連接 |
| **Config** | Workflow 層級的設定（auth、rate limits 等） |

展開每一項變更，即可查看欄位層級的差異（例如哪些節點屬性發生了變化）。

## 預覽

若要查看 Workflow 在過去某個版本時的樣貌，請點擊 Revert 旁邊的 **Preview**。

此時會開啟一個唯讀畫布，顯示該版本的節點與連接。您可以平移與縮放以瀏覽版面配置；在此檢視中無法進行任何變更。

## 還原

若要還原至先前的版本：

1. 選擇您想要的版本
2. 點擊 **Revert**
3. 確認此操作
4. 目前的 Workflow 會被所選版本取代；頁面會重新載入

還原會建立一個新的「current」狀態——如有需要，您可以再次還原。

## 清除歷史

點擊對話框標題中的垃圾桶圖示，即可移除所有版本歷史。此操作無法復原。目前的 Workflow 會保留；只有過往的版本會被刪除。

## 版本何時建立

版本只會在您**儲存**時建立（Ctrl/Cmd+S 或 Save 按鈕）。未儲存的變更在您儲存之前，不會存放在編輯歷史中。

Agent skill 的編輯也會包含在這些快照中。若要在不還原整個 Workflow 的情況下瀏覽或還原單一 skill，請使用 Agent 節點屬性面板中該 skill 卡片上的 **History** 按鈕。請參閱 [Agent Node](../nodes/agent-node.md#skill-history)。
